클라이언트(PC)  ◀──응답(Response)──┘
             HTTP 프로토콜을 통해 주고받음

3. 정적 vs 동적 · MPA vs SPA ★1주차

구분설명
정적(Static) 콘텐츠변하지 않는 콘텐츠 · 예) news.html 파일을 그대로 전달
동적(Dynamic) 콘텐츠서버에서 동적으로 만들어진 콘텐츠 · 예) login.jsp → '홍길동, 안녕!'

동적 처리 흐름 : 요청 → 컨테이너(Container)에서 실행코드 실행 → DB 연동 → 결과(html 또는 data 형식) 응답 → 브라우저가 렌더링

MPA vs SPA — Multi Page Application(여러 페이지) vs Single Page Application(단일 페이지)
결과 형식은 html 형식(jsp) 또는 data 형식(JSON) 두 가지입니다.

9. 객체의 구성요소 ★필수암기2주차

객체의 구성요소 = 속성(변수) + 메서드(함수)
비유: 붕어빵틀 = 클래스(Class) / 붕어빵 = 객체(Object)

즉 클래스는 설계도(틀), 객체는 그 틀로 찍어낸 실체(인스턴스)입니다. 속성 접근은 프로퍼티, 동작 호출은 메서드입니다.

class Person {
    String name;          // 속성(변수)
    void eat(){ ... }     // 메서드(함수)
}
P1 = new Person();
P2 = new Person();
P2.eat();                 // "쩝쩝"
P2.name = "쭈굴";          // P2 객체에 대입
P1.name = "한주";          // P1 객체에 대입

문자열과 숫자의 + 연산 (필기 정정)

연산결과이유
"10" + "20""1020"문자열 + 문자열 → 이어 붙이기
10 + "20""1020"문자열 + 숫자 → 숫자가 문자열로 묵시적 형변환되어 이어 붙음 (덧셈 아님!)
10 + 2030숫자 + 숫자 → 덧셈
Number("10") + 2030명시적 형변환 후 덧셈
명시적 형변환 함수 — Number("10") → 10 · parseInt("10개") → 10 (숫자로 시작하는 부분만, "hi10개" → NaN) · String(20) → "20"
⚠️ prompt() 로 받은 값은 항상 문자열입니다. 그냥 더하면 "3"+"4" → 34, Number() 로 바꿔야 7.
// 0915_01.html — 두 수를 입력받아 더하기
let num1 = window.prompt("첫번째 피연산자 입력!");
let num2 = window.prompt("두번째 피연산자 입력!");
let resultObj = document.querySelector("#result");
resultObj.innerHTML = num1 + num2;                   // 3, 4 입력 → 34 (문자열 연결)
resultObj.innerHTML = Number(num1) + Number(num2);   // → 7
resultObj.innerHTML = `결과값은 ${Number(num1) + Number(num2)}`;  // 백틱(템플릿 리터럴)

🔥 시험문제 = 교수님이 수업 중 “시험문제”라고 한 코드 (빨간 테두리) · 4주차 시험 포인트 ③ ++ · ④ || && · ⑤ == === · 교수님 메모 & && · 단락평가

🔥 시험문제 — 수업 중 “시험문제”라고 한 코드

1num8++ 와 ++num84주차 · 증감 연산자

let num8 = 10;
console.log(num8++);
console.log(++num8);
console.log(num8);
💡 풀이 — 후위 num8++ 는 지금 값 10 을 찍고 11 로 · 전위 ++num8 은 먼저 12 로 올리고 찍음

2|| 와 && 는 값을 고른다4주차 · 단락 평가

console.log(5 && 3);
console.log(5 || 3);
console.log(0 && 3);
console.log(0 || 3);
console.log("" || "입력없음");
console.log("안녕" && "입력없음");
💡 풀이 — && 는 왼쪽이 truthy 면 오른쪽, falsy 면 왼쪽 · || 는 왼쪽이 truthy 면 왼쪽, falsy 면 오른쪽 (0 · "" 는 falsy)

3& · | 는 비트 계산4주차 · & 와 &&

console.log(true & true);
console.log(true && true);
console.log(5 & 3);
console.log(5 | 3);
console.log(12 & 10);
console.log(12 | 10);
💡 풀이 — & | 는 2진수 비트 계산이라 결과가 숫자 (true & true → 1) · 5=0101, 3=0011 → & 0001=1, | 0111=7 · 12=1100, 10=1010 → & 1000=8, | 1110=14

4비교 연산자4주차 · == vs ===

console.log("10" == 10);
console.log("10" === 10);
console.log(1 === "1");
console.log(1 !== 2);
console.log(2 >= 2);
💡 풀이 — == 는 형변환 후 값만 비교 → true · === 는 값과 타입 모두 비교 → 문자열과 숫자는 false

5오른쪽 함수가 실행될까?4주차 · 단락 평가

function right() {
    console.log("right() 실행됨");
    return true;
}
console.log(false && right());
console.log(true || right());
console.log(true && right());
console.log(false || right());
💡 풀이 — false && … · true || … 는 왼쪽만으로 결과가 정해져서 right() 를 부르지 않아요 · 나머지 둘은 right() 가 먼저 한 줄 찍고 true 를 돌려줌

✍️ 배운 코드 — 실행 결과 예측하기

6문자열 + 숫자3~4주차 · 형변환

console.log("10" + 5);
console.log(Number("10") + 5);
console.log(10 + "20");
console.log(parseInt("10개"));
console.log(10 * "hi");
💡 풀이 — 문자열이 끼면 + 는 이어 붙이기 (105 · 1020) · Number() 로 바꾸면 덧셈 15 · parseInt 는 숫자로 시작하는 부분만 10 · 계산 불가면 NaN

7${ } 안의 계산3주차 · 템플릿 문자열

console.log(`273 + 52의 값은 ${273 + 52}입니다`);
let num1 = "3";
let num2 = "4";
console.log(`${num1 + num2} / ${Number(num1) + Number(num2)}`);
💡 풀이 — ${ } 안은 계산한 결과가 들어감 → 325 · prompt 처럼 문자열 "3" + "4" 는 34, Number 로 바꾸면 7

8나눗셈과 나머지4주차 · 산술 · 복합 대입

console.log(3 / 2);
console.log(3 % 2);
let num7 = 10;
num7 += 20;
console.log(num7);
num7 %= 7;
console.log(num7);
💡 풀이 — JS 는 정수끼리 나눠도 1.5 (C 와 다름!) · % 는 나머지 · num7 += 20 → 30 · 30 % 7 → 2

9typeof 와 null 병합4주차 · typeof · ??

console.log(typeof true);
console.log(typeof null);
console.log(undefined ?? 10);
console.log(0 ?? 5);
console.log(0 || 5);
💡 풀이 — typeof 는 타입 이름을 문자열로 · typeof null 은 "object" · ?? 는 왼쪽이 null·undefined 일 때만 오른쪽 → 0 ?? 5 는 0 · 0 || 5 는 5

10짝수 · 홀수4주차 · 삼항 연산자

let var8 = 10;
console.log(var8 % 2 === 0 ? "짝수" : "홀수");
var8 = 7;
console.log(var8 % 2 === 0 ? "짝수" : "홀수");
💡 풀이 — 조건이 true 면 콜론 앞, false 면 콜론 뒤

11인수를 안 넘기면?4주차 · 매개변수 · 인수

function printName(person) {
    if (!person) {
        console.log("person의 값이 없음");
        return 0;
    }
    console.log(person.name);
}
let person = { name: "홍길동" };
printName(person);
printName();
💡 풀이 — 인수를 넘기면 person.name → 홍길동 · 안 넘기면 person 은 undefined(falsy) → !person 이 true

12부른 순서대로2주차 · 함수 선언 3가지

function hello() { console.log("안녕"); }
let hi = function () { console.log("하이"); };
let bye = () => { console.log("잘가"); };
bye();
hello();
hi();
💡 풀이 — 함수 선언문 · 함수 표현식 · 화살표 함수 모두 호출한 순서대로 실행
