2. 웹프로그래밍이란 · 프런트엔드 vs 백엔드 ★1주차

구분설명
프런트엔드 (Front-end)클라이언트(웹브라우저)에서 실행되는 기술
백엔드 (Back-end)서버에서 실행되는 기술

웹서비스 프로세스 — 클라이언트(브라우저)가 URL로 요청(Request) → 서버가 처리 → 결과를 응답(Response). 웹서버는 웹 애플리케이션을 실행해 브라우저가 요청한 기능을 수행한 뒤 결과를 응답합니다.

클라이언트(PC)  ──요청(Request)──▶  서버
                                    │ 처리 (필요하면 DB 연동)
클라이언트(PC)  ◀──응답(Response)──┘
             HTTP 프로토콜을 통해 주고받음

3. 정적 vs 동적 · MPA vs SPA ★1주차

구분설명
정적(Static) 콘텐츠변하지 않는 콘텐츠 · 예) news.html 파일을 그대로 전달
동적(Dynamic) 콘텐츠서버에서 동적으로 만들어진 콘텐츠 · 예) login.jsp → '홍길동, 안녕!'

동적 처리 흐름 : 요청 → 컨테이너(Container)에서 실행코드 실행 → DB 연동 → 결과(html 또는 data 형식) 응답 → 브라우저가 렌더링

MPA vs SPA — Multi Page Application(여러 페이지) vs Single Page Application(단일 페이지)
결과 형식은 html 형식(jsp) 또는 data 형식(JSON) 두 가지입니다.

6. 웹문서 실행 단계 ★필수암기2주차

브라우저는 HTML을 파싱해 DOM 트리를 만들고, CSS와 결합해 렌더 트리를 구성한 뒤 페인팅하여 화면에 출력합니다.

태그 안에 태그를 넣는 것을 중첩이라고 합니다. 예) <div><h1></h1></div>

8. 함수 선언 3가지 방법 ★필수암기2주차

① 선언적 함수

function btnClick(){
    ...
}
btnClick();   // 호출

② 표현적 함수 (익명 함수)

let btnClick = function(){
    ...
};
btnClick();   // 호출

③ 화살표 함수

let btnClick = () => {
    ...
};
btnClick();   // 호출
함수도 데이터(값)처럼 변수에 담아 넘겨줄 수 있습니다. (일급 객체)

9. 객체의 구성요소 ★필수암기2주차

객체의 구성요소 = 속성(변수) + 메서드(함수)
비유: 붕어빵틀 = 클래스(Class) / 붕어빵 = 객체(Object)

즉 클래스는 설계도(틀), 객체는 그 틀로 찍어낸 실체(인스턴스)입니다. 속성 접근은 프로퍼티, 동작 호출은 메서드입니다.

class Person {
    String name;          // 속성(변수)
    void eat(){ ... }     // 메서드(함수)
}
P1 = new Person();
P2 = new Person();
P2.eat();                 // "쩝쩝"
P2.name = "쭈굴";          // P2 객체에 대입
P1.name = "한주";          // P1 객체에 대입

10. 변수와 선언 키워드 ★필수암기3주차

변수 = 메모리상의 값을 담는 그릇 · 선언 키워드 3가지: var / let / const
키워드특징
let변수의 중복 정의(재선언) 불가능
var중복 정의 가능 (구버전 방식)
const상수 — 값 변경 불가

ES6부터 JS를 어디서든 쓸 수 있게 되면서 let 이 등장했습니다.

11. JS 자료형과 객체 ★필수암기3주차

구분종류
원시형 (Primitive)String / Number / Boolean (+ null, undefined)
참조형 (Reference)객체(Object)
기본 데이터타입 5종 — 문자열, 숫자, 부울린(Boolean), undefined, null
객체 = 사용자정의 객체 + 내장 객체
항목설명
숫자형정수와 실수 구분 없이 하나의 number 로 처리 (int/double 구분 없음)
NaN계산 오류·부정확한 연산 시 반환 (Not a Number)
null의도적으로 비운 값
undefined값이 할당되지 않은 상태 (초기화 안 함)

12. 형변환 ★필수암기3주차

구분설명
명시적 형변환String() / Number() / Boolean() 함수를 직접 사용
묵시적(암묵적) 형변환연산 과정에서 자동으로 타입이 변환됨
"10" + 5           ===>  "105"   // 묵시적 형변환 (문자열 연결)
Number("10") + 5   ===>  15      // 명시적 형변환 (숫자로 변환)
형변환 = 캐스팅(Casting). 피연산자의 type이 다르면 type을 통일한 뒤 연산합니다.
비교 연산자: == 는 값만 비교 / === 는 값과 타입을 모두 비교

13. 템플릿 문자열 ★암기3주차

백틱( ` )으로 감싸고 ${ } 안에 표현식을 넣으면 문자열 안에서 계산됩니다.

console.log(`273 + 52의 값은 ${273 + 52}입니다`)
// 출력: 273 + 52의 값은 325입니다
