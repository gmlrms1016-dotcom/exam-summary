3. 정적 vs 동적 · MPA vs SPA ★1주차

구분설명
정적(Static) 콘텐츠변하지 않는 콘텐츠 · 예) news.html 파일을 그대로 전달
동적(Dynamic) 콘텐츠서버에서 동적으로 만들어진 콘텐츠 · 예) login.jsp → '홍길동, 안녕!'

동적 처리 흐름 : 요청 → 컨테이너(Container)에서 실행코드 실행 → DB 연동 → 결과(html 또는 data 형식) 응답 → 브라우저가 렌더링

MPA vs SPA — Multi Page Application(여러 페이지) vs Single Page Application(단일 페이지)
결과 형식은 html 형식(jsp) 또는 data 형식(JSON) 두 가지입니다.

9. 객체의 구성요소 ★필수암기2주차

객체의 구성요소 = 속성(변수) + 메서드(함수)
비유: 붕어빵틀 = 클래스(Class) / 붕어빵 = 객체(Object)

즉 클래스는 설계도(틀), 객체는 그 틀로 찍어낸 실체(인스턴스)입니다. 속성 접근은 프로퍼티, 동작 호출은 메서드입니다.

class Person {
    String name;          // 속성(변수)
    void eat(){ ... }     // 메서드(함수)
}
P1 = new Person();
P2 = new Person();
P2.eat();                 // "쩝쩝"
P2.name = "쭈굴";          // P2 객체에 대입
P1.name = "한주";          // P1 객체에 대입

문자열과 숫자의 + 연산 (필기 정정)

연산결과이유
"10" + "20""1020"문자열 + 문자열 → 이어 붙이기
10 + "20""1020"문자열 + 숫자 → 숫자가 문자열로 묵시적 형변환되어 이어 붙음 (덧셈 아님!)
10 + 2030숫자 + 숫자 → 덧셈

명시적 형변환 함수 — Number("10") → 10 · parseInt("10개") → 10 (숫자로 시작하는 부분만, "hi10개" → NaN) · String(20) → "20"
⚠️ prompt() 로 받은 값은 항상 문자열입니다. 그냥 더하면 "3"+"4" → 34, Number() 로 바꿔야 7.
// 0915_01.html — 두 수를 입력받아 더하기
let num1 = window.prompt("첫번째 피연산자 입력!");
let num2 = window.prompt("두번째 피연산자 입력!");
let resultObj = document.querySelector("#result");
resultObj.innerHTML = num1 + num2;                   // 3, 4 입력 → 34 (문자열 연결)
resultObj.innerHTML = Number(num1) + Number(num2);   // → 7
resultObj.innerHTML = `결과값은 ${Number(num1) + Number(num2)}`;  // 백틱(템플릿 리터럴)

증감 연산자: 전위 vs 후위

console.log(num8++);   // 10 출력 (출력한 뒤 num8 은 11)
console.log(++num8);   // 12 출력 (11 → 12 로 먼저 증가)
비교의미예
==타입이 달라도 형변환 후 값만 비교"10" == 10 → true
===값과 타입 모두 비교 (엄격)"10" === 10 → false
!==값 또는 타입이 다르면 true1 !== 2 → true

21. 논리 연산자 · truthy/falsy · 단락 평가 ★시험4주차

연산자설명
&JS 에서는 비트 연산자 — 양쪽을 항상 둘 다 계산하고 결과는 숫자 (true & false → 0)
&&논리 연산자 — 왼쪽이 false 로 확정되면 오른쪽은 계산하지 않고 바로 결과를 돌려줌 = 단락 평가
Truthy와 Falsy (교수님 메모) — 참·거짓(boolean)이 아닌 값도 조건문 안에서는 참 또는 거짓으로 판단되는 것 · 단락평가 : && ||
falsy(거짓으로 취급) 8가지 — false · 0 · -0 · 0n · "" · null · undefined · NaN
이것들을 뺀 나머지는 모두 truthy(참으로 취급)입니다. "0", "false", [], {} 도 truthy!
식동작입력이 "" 일 때입력이 "안녕" 일 때
changeVar = changeVar || "입력없음";왼쪽이 falsy 면 오른쪽"입력없음""안녕" (그대로)
changeVar = changeVar && "입력없음";왼쪽이 truthy 면 오른쪽"" (그대로)"입력없음" (덮어씀)
정리 — || 는 값이 없을 때 대신 쓸 기본값을 넣을 때, && 는 앞의 값이 있을 때만 뒤를 쓸 때. truthy/falsy + 단락 평가를 쓰면 값이 없을 때 날 오류를 미리 막고 if 문을 짧게 쓸 수 있습니다.

22. null 병합 ?? · typeof · 삼항 연산자4주차

연산자설명예 → 결과
?? (null 병합)왼쪽이 null·undefined 일 때만 오른쪽undefined ?? 10 → 10 · 0 ?? 5 → 0 (0 || 5 는 5)
typeof값의 타입을 문자열로 반환typeof true → "boolean" · typeof null → "object"
삼항 ? :if 문을 짧게 줄인 연산자 — 조건이 true 면 콜론 앞, false 면 콜론 뒤10 % 2 === 0 ? "짝수" : "홀수" → "짝수"
// 0915_04.html — 입력이 비었으면 "입력없음" (셋 다 같은 뜻)
if (changeVar == "") { changeVar = "입력없음"; }
changeVar = changeVar == "" ? "입력없음" : changeVar;   // 삼항 연산자

23. 매개변수(parameter)와 인수(argument)4주차

용어뜻아래 예
매개변수 (파라미터)함수를 정의할 때 값을 받으려고 괄호 안에 적는 변수person
인수 (아규먼트)함수를 호출할 때 실제로 넘기는 값{ name: "홍길동" }
function printName(person) {     // person = 매개변수
    if (!person) {               // 값이 없으면(falsy) 오류 대신 안내 후 종료
        console.log("person의 값이 없음");
        return 0;
    }
    console.log(person.name);
}
let person = { name: "홍길동" };
printName(person);               // 인수 전달 → 홍길동
printName();                     // 인수 없음 → person의 값이 없음
