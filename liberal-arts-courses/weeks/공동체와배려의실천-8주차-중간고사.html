★ 강조핵심 정리
토론 vs 토의 · 기본절차토론 = 찬반으로 설득 · 논쟁 (경쟁적) · 토의 = 문제 해결 · 합의 도출 (협력적) · 절차 = 주제 이해 → 생각 정리 → 주장 펼치기 → 경청과 비판 → 합의점 탐색 → 대안과 전망
하비거스트 발달과업시기마다 성취해야 할 과제 · 세 원천 = 신체적 성숙 / 개인적 가치와 열망 / 사회적 압력 · 한 줄 = “인생의 각 시기에는 해내야 할 과제가 있다”
프로이트 3체제 · 발달단계원본능(id) = 쾌락원리 · 자아(ego) = 현실 통제 · 초자아(super ego) = 사회규범 내면화 · 단계 = 구강기 → 항문기 → 남근기 → 잠복기 → 생식기 · 고착
매슬로 욕구 5단계생리적 → 안전 → 애정과 소속 → 존경 → 자아실현 (아래 → 위)
★ 세 이론 한 줄 요약 (✍️ PDF 19쪽 큰 ★)하비거스트 = 시기마다 과제 · 프로이트 = 어린 시절 욕구 · 갈등의 해결이 성격을 만듦 · 매슬로 = 기본 욕구를 넘어 자기다운 가능성을 실현
실존주의 철학자 5명키에르케고르 = 선택(“이것이냐 저것이냐”) · 실존주의의 아버지 / 니체 = 힘의 의지 · 초인 / 야스퍼스 = 한계상황 / 하이데거 = 현존재(Dasein) / 사르트르 = 실존은 본질에 앞선다 · 키워드 = 비합리주의 · 반이성주의 · 주체성 · 선택 · 결단 · 책임
★ 욕구 · 욕망 · 욕심 (음식 예시)욕구 = 본능적 · 생리적 필요 (배고파서 먹음) · 욕망 = 충족될 수 없는 사회적 구성물 (더 맛있는 것) · 욕심 = 절제되지 못한 탐욕 (배가 부른 데도 더 먹음)
비판이론 학자 4명호르크하이머 = 도구적 이성 비판 · 아도르노 = 문화산업 · 획일화 비판 (둘이 『계몽의 변증법』 1944) · ✍️ 마르쿠제 = 허위욕구 · 비판의식 저하 (『일차원적 인간』 1964) · ✍️ 하버마스 = 합리적 의사소통 (『의사소통행위이론』 1981) · 1923 프랑크푸르트 사회연구소

1주차 — 오리엔테이션 (1주차 자세히)

토론과 토의 ★시험 포인트

구분목적성격
토론찬반 입장으로 상대를 설득 · 논쟁경쟁적
토의문제 해결 · 합의 도출협력적
  • ⭐ 강조 — 토론 기본절차: 주제 이해 → 생각 정리 → 주장 펼치기 → 경청과 비판 → 합의점 탐색 → 대안과 전망
  • 토론을 강조한 철학자: 소크라테스(무지의 자각) · 아리스토텔레스(논리·비판) · 칸트(보편적 도덕법칙) · 하버마스(의사소통적 합리성)

수업 목표 · 평가

2주차 — 인간은 어떻게 성장하는가 (2주차 자세히)

세 이론 비교 ★핵심

학자이론핵심 개념한 줄 요약
하비거스트발달과업 이론시기마다 성취해야 할 과제 · 세 원천(신체적 성숙 / 개인적 가치와 열망 / 사회적 압력)인생의 각 시기에는 해내야 할 과제가 있다
프로이트심리성적 발달 이론원본능(id) · 자아(ego) · 초자아(super ego) · 고착어린 시절 욕구와 갈등의 해결이 이후 성격을 만든다
매슬로욕구위계 이론생리적 → 안전 → 애정과 소속 → 존경 → 자아실현기본 욕구를 넘어 자기다운 가능성을 실현하려는 존재
  • ⭐ 강조 — 프로이트 심리성적 발달단계: 구강기 → 항문기 → 남근기 → 잠복기 → 생식기
  • ⭐ 강조 — 원본능 = 쾌락원리 · 자아 = 현실 통제 · 초자아 = 사회규범 내면화
  • ✍️ 필기 — 하비거스트의 한계: '누가 그 과업을 정하는가?' / 프로이트 비판: 성적 욕구 과도 강조 · 과학적 검증 어려움
  • ⭐ 강조 — 라슬렛 인생 4주기론의 제3연령기 = 자아실현 · 활동적 은퇴(액티브 시니어)

  • ✍️ 필기 — 몸 ↔ 마음 · 육체 ↔ 정신 · 물질 ↔ 관심 · 감각 · 경험 ↔ 직관 (마음 쪽 “이상적”) — 둘로 나눠 보는 이원론 구도

7주차 — 나는 문화를 주체적으로 향유하는가? (7주차 자세히)

비판이론 학자 4명 ★ (11 · 12 · 18쪽 · ✍️ 12쪽 밑줄)

학자핵심대표 저서 (9쪽)
호르크하이머도구적 이성 비판 — 이성이 효율성 · 지배의 도구로 전락『계몽의 변증법』(1944, 아도르노와 함께) · 1930년 연구소장
아도르노문화산업 · 획일화 비판 — 대중문화가 공장 제품처럼 생산 · 소비 → 수동적 소비자『계몽의 변증법』(1944)
마르쿠제✍️ 허위욕구와 비판의식 저하 — 사회가 만든 욕구를 내 욕구로 착각『일차원적 인간』(1964)
하버마스✍️ 합리적 의사소통의 중요성 — 자유롭고 평등한 의사소통으로 권력 비판『의사소통행위이론』(1981)
  • ⭐ 강조 — 비판이론 = 마르크스주의를 바탕으로 자본주의 사회의 구조와 모순을 연구 · 1923년 프랑크푸르트 사회연구소 설립
  • ⭐ 강조 — 10쪽 핵심 개념: 이데올로기 비판 · 도구적 이성 · 문화산업 · 허위욕구 · 해방(Emancipation) · 의사소통적 합리성
  • ✍️ 필기 9쪽 — 상부(정신) / 하부(물질) · 공산주의 → 해방 · 자유 (마르크스의 사회 구조)
  • ✍️ 필기 19쪽 “10시 시험” → 중간고사 10월 22일(목) 10:00

6주차 — 나는 왜, 무엇을 욕망하는가? (6주차 자세히)

욕구 · 욕망 · 욕심 ★ (✍️ PDF 2쪽 ★)

낱말뜻차원예시
욕구 (欲求)무엇을 얻거나 무슨 일을 하고자 바라는 일본능적 · 생리적 필요배고파서 먹고자 하는 것
욕망 (欲望)충족될 수 없는 사회적 구성물심리적 · 사회적 갈망더 맛있는 것을 먹으려는 것
욕심 (欲心)분수에 넘치게 무언가를 탐내거나 누리고자 하는 마음절제되지 못한 탐욕배가 부른 데도 더 먹으려는 것
  • ⭐ 강조 예시 줄에 ★ → 예시 ↔ 낱말 짝짓기 · 서술형으로 차이 설명하기 대비
