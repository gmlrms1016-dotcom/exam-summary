3쪽 ★ 여기 시험에 나옴 — 뉴런의 기본 구조

구조하는 일
세포체(soma / cell body)세포의 생명을 유지시켜 주는 기능 / 정보처리 과제를 통합
수상돌기(dendrite)다른 뉴런으로부터 정보를 받아들이는 수용부 역할
축색(axon)정보를 다른 뉴런 · 근육 · 내분비선에 전달
  • 그림 옆: 시냅스(synapse) · 축색 종말(terminal button) · 신경전달물질(neurotransmitter) — 영어 이름마다 밑줄
  • 순서로 외우기: 수상돌기(받음) → 세포체(통합) → 축색(보냄) → 축색 종말 → 시냅스에서 신경전달물질로 다음 뉴런에 전달

4쪽 ★ 신경 가소성

  • ✍️ 필기 — 제목 옆에 “신경 가소성” 을 네모로 두르고 ★
  • 슬라이드: 뉴런은 크기 · 모양 · 기능이 다양 — 소뇌의 퍼킨제 세포 · 피부에서 척수로 가는 감각뉴런 · 대뇌겉질 운동영역의 피라미드 세포 · 망막의 양극세포
  • 📝 교수님 메모(퍼킨제 세포) — 단순 → 복잡하게 발달(생후 1년 = 성인) / 신경가소성 → 뇌가 경험에 따라 바뀌는 성질

5쪽 뉴런의 종류 — 신경돌기 · 유사단극성

뉴런특징
다극성 뉴런(multipolar)세포체에 여러 개의 수상돌기 · 중추신경계에서 가장 일반적
양극성 뉴런(bipolar)세포체에서 하나의 수상돌기 · 주로 감각 뉴런 or 개재 뉴런 · 수상돌기가 외부 환경 탐지
유사단극성 뉴런(unipolar)세포체에서 하나의 줄기가 나와 두 개의 가지로 뻗어 나감 · 촉각 · 온도변화 · 관절 · 근육 · 내장기관 정보 탐지
  • ✍️ 필기 — 다극성 그림 옆 “가지들을 ‘신경돌기’라고 함”
  • ✍️ 필기 — 단극성 앞에 “유사” → 줄기가 하나로 나와서 둘로 갈라지니 유사(가짜) 단극성 뉴런

6쪽 ★ 지지세포 — 아교세포 “종류 암기”

  • 아교세포(glia cell) = 뇌에 분포하는 세포 중 85% (뉴런 < 아교)
  • 기능 5개 (✍️ 모두 ★):
    1. 뉴런을 둘러싸고 있으면서 뉴런을 고정시킴
    2. 뉴런에 영양분을 공급
    3. 신경전달물질의 공급 조절
    4. 뉴런과 뉴런 사이의 절연체 역할
    5. 죽은 뉴런의 잔해를 파괴하고 제거
  • ⭐ 강조 — 종류 암기 ★: 별아교세포(성상세포) / 성긴돌기아교세포(희소돌기아교세포) / 미세아교세포
  • 슈반세포(Schwann cell) — 말초 신경계에 분포 (수초 역할)
  • ✍️ 필기 — 운동을 하던 사람은 운동 습관이 높아지고 스트레스 해소에 좋음

9쪽 뉴런의 영양공급 — 포도당

  • ✍️ 필기 — 포도당은 산소가 필요함
  • 뉴런은 포도당(glucose)에 거의 전적으로 의존 · 유아기 이후 혈뇌장벽을 통과하는 거의 유일한 영양물질
  • 포도당 신진대사는 산소가 필요 → 뇌는 몸에서 소비되는 산소의 20% 정도를 사용
  • 포도당을 쓰려면 비타민 B1(티아민) 필요 → 알코올 중독 시 티아민 결핍 → 뇌 뉴런 손상 · 코르사코프 증후군

17쪽 축색에서의 정보전달 — 전위의 변화

순서단계전위
1분극화(polarization)안정 전위 -70mV
2역치(threshold)-55mV
3탈분극(depolarization)활동전위 +40mV
4재분극(repolarization)
5과분극(hyperpolarization)
  • ✍️ 필기 — 뇌의 뉴런이 A → B → C < D … 이런 식으로 몸의 근육까지 전달해서 몸이 움직이는 원리

22쪽 ★ 도파민 · 세로토닌

  • ✍️ 필기 — 표에서 도파민 · 세로토닌 두 줄을 네모로 두르고 양쪽에 ★ (아래 “4장 22쪽 신경전달물질 표” 참고 · 둘 다 모노아민)
  • 도파민 = 운동 / 주의 / 학습 · 부족 시 파킨슨병 · 세로토닌 = 섭식 / 수면 / 기분 조절 · Prozac(우울증 약) 은 세로토닌 재흡수를 막음

23쪽 시냅스 이후의 정보전달

전위✍️ 필기 예
흥분성 시냅스 후 전위 EPSPex) 몸을 움직이는
억제성 시냅스 후 전위 IPSPex) 몸은 가만히 있는

세포체 (캡처 원문)

  • 📝 교수님 메모 — 만약 뉴런이 반으로 잘린다면 -> 세포체 없는 쪽 사망
  • 📝 교수님 메모 — 왜? -> 유전 정보를 포함하는 핵이 없어 생명에 필요한 단백질을 만들 수 X
  • 📝 교수님 메모 — 정보처리에 필요한 화학물질(신경전달물질)을 생산
  • 📝 교수님 메모 — 세포핵과 여러 소기관이 있다.
  • ⭐ 강조 — 4장 3쪽: 세포체(soma / cell body) = 세포의 생명을 유지시켜 주는 기능 / 정보처리 과제를 통합

축색 종말 (캡처 원문)

  • 📝 교수님 메모 — 축색의 끝부분 -> 여기서 다른 뉴런에게 정보가 전달된다.
  • 📝 교수님 메모 — 끝부분이 둥글게 부풀어 있다.
  • 📝 교수님 메모 — 다른 뉴런의 수상돌기 또는 세포체와 접촉
  • 📝 교수님 메모 — 이 부위를 시냅스라 한다.
  • 4장 3쪽 영어 이름: 축색종말 = terminal button · 시냅스 = synapse · 신경전달물질 = neurotransmitter

신경전달물질 (캡처 원문) 🔥

  • 📝 교수님 메모 — 만약 크기가 큰 경우 -> 뉴런의 세포체에서 합성
  • 📝 교수님 메모 — 그보다 작은 아세틸콜린 -> 축색 종말에서 합성
  • ✍️ 필기 — 신경전달물질에 OX로 나올 수 있음

4장 22쪽 신경전달물질 표 (OX 대비)

신경전달물질기능특징
아세틸콜린(Ach)뇌에서는 흥분성 / 다른 부위에선 흥분 or 억제성기억 / 운동에 관여
노르에피네프린각성 조절 담당(아드레날린)자율신경계 뉴런에서 주로 발견 · 경계와 각성 상태 조절
도파민(DA)시냅스후 수용기에 따라 흥분성 / 억제성운동 / 주의 / 학습 · 부족 시 파킨슨병
세로토닌시냅스후 수용기에 따라 흥분성 / 억제성섭식 / 수면 / 기분 조절 · Prozac(우울증 약)은 세로토닌 재흡수를 막음
GABA뇌와 척수에서 주요한 억제성간질의 주요 원인 중 하나(GABA 뉴런 · 수용기 이상)
글루타메이트뇌와 척수에서 주요한 흥분성GABA 와 함께 최초로 진화한 것으로 추정 · 과도한 방출은 뇌중풍 원인
  • 4장 22쪽: 대략 50여 개의 신경전달물질이 발견 · 노르에피네프린 · 도파민 · 세로토닌 = 모노아민 / GABA · 글루타메이트 = 아미노산

퍼킨제 세포 (캡처 원문)

  • 📝 교수님 메모 — 소뇌 - 신체의 운동에 관여
  • 📝 교수님 메모 — 소뇌 피질에 이 세포가 존재
  • 📝 교수님 메모 — 단순 -> 복잡 발달(생후 1년 = 성인) / 신경가소성
  • 4장 4쪽 그림: 소뇌에 위치한 퍼킨제 세포(Purkinje cell) · 피부에서 척수로 가는 감각뉴런

신경돌기 · 뉴런 분류 (캡처 원문)

  • 📝 교수님 메모 — 신경돌기: 세포체에서 뻗어나온 가지
  • 📝 교수님 메모 — 뉴런의 연결 위치에 따라 분류
