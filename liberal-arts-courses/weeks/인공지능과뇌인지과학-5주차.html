🔥 시험 포인트

  • ✍️ 필기 — 신경전달물질에 OX로 나올 수 있음 → 아래 “신경전달물질” 카드 + 4장 22쪽 표를 OX 로 연습하기
  • 📝 교수님 메모 — 큰 신경전달물질 = 세포체에서 합성 · 작은 아세틸콜린 = 축색 종말에서 합성

세포체 (캡처 원문)

  • 📝 교수님 메모 — 만약 뉴런이 반으로 잘린다면 -> 세포체 없는 쪽 사망
  • 📝 교수님 메모 — 왜? -> 유전 정보를 포함하는 핵이 없어 생명에 필요한 단백질을 만들 수 X
  • 📝 교수님 메모 — 정보처리에 필요한 화학물질(신경전달물질)을 생산
  • 📝 교수님 메모 — 세포핵과 여러 소기관이 있다.
  • ⭐ 강조 — 4장 3쪽: 세포체(soma / cell body) = 세포의 생명을 유지시켜 주는 기능 / 정보처리 과제를 통합

축색 종말 (캡처 원문)

  • 📝 교수님 메모 — 축색의 끝부분 -> 여기서 다른 뉴런에게 정보가 전달된다.
  • 📝 교수님 메모 — 끝부분이 둥글게 부풀어 있다.
  • 📝 교수님 메모 — 다른 뉴런의 수상돌기 또는 세포체와 접촉
  • 📝 교수님 메모 — 이 부위를 시냅스라 한다.
  • 4장 3쪽 영어 이름: 축색종말 = terminal button · 시냅스 = synapse · 신경전달물질 = neurotransmitter

신경전달물질 (캡처 원문) 🔥

  • 📝 교수님 메모 — 만약 크기가 큰 경우 -> 뉴런의 세포체에서 합성
  • 📝 교수님 메모 — 그보다 작은 아세틸콜린 -> 축색 종말에서 합성
  • ✍️ 필기 — 신경전달물질에 OX로 나올 수 있음

4장 22쪽 신경전달물질 표 (OX 대비)

신경전달물질기능특징
아세틸콜린(Ach)뇌에서는 흥분성 / 다른 부위에선 흥분 or 억제성기억 / 운동에 관여
노르에피네프린각성 조절 담당(아드레날린)자율신경계 뉴런에서 주로 발견 · 경계와 각성 상태 조절
도파민(DA)시냅스후 수용기에 따라 흥분성 / 억제성운동 / 주의 / 학습 · 부족 시 파킨슨병
세로토닌시냅스후 수용기에 따라 흥분성 / 억제성섭식 / 수면 / 기분 조절 · Prozac(우울증 약)은 세로토닌 재흡수를 막음
GABA뇌와 척수에서 주요한 억제성간질의 주요 원인 중 하나(GABA 뉴런 · 수용기 이상)
글루타메이트뇌와 척수에서 주요한 흥분성GABA 와 함께 최초로 진화한 것으로 추정 · 과도한 방출은 뇌중풍 원인
  • 4장 22쪽: 대략 50여 개의 신경전달물질이 발견 · 노르에피네프린 · 도파민 · 세로토닌 = 모노아민 / GABA · 글루타메이트 = 아미노산

퍼킨제 세포 (캡처 원문)

  • 📝 교수님 메모 — 소뇌 - 신체의 운동에 관여
  • 📝 교수님 메모 — 소뇌 피질에 이 세포가 존재
  • 📝 교수님 메모 — 단순 -> 복잡 발달(생후 1년 = 성인) / 신경가소성
  • 4장 4쪽 그림: 소뇌에 위치한 퍼킨제 세포(Purkinje cell) · 피부에서 척수로 가는 감각뉴런

신경돌기 · 뉴런 분류 (캡처 원문)

  • 📝 교수님 메모 — 신경돌기: 세포체에서 뻗어나온 가지
  • 📝 교수님 메모 — 뉴런의 연결 위치에 따라 분류
뉴런하는 일
감각뉴런감각 신호를 받음 -> 중추신경계로 전달
연합뉴런(개재 뉴런, inter neuron)뉴런끼리 연결
운동뉴런근육과 연결 -> 움직임을 만듦
  • ⚠️ 정정 — 4장 5쪽에는 “개제뉴런”으로 적혀 있지만 교수님 메모의 “개재 뉴런(介在, 사이에 끼어 있는)”이 맞는 말이에요.
