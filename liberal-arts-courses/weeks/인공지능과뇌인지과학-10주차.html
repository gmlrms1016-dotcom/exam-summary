1. 머신러닝 시스템의 종류 (2 · 3쪽)

📄 분류 기준📄 무엇을 보나📄 종류
훈련 지도 여부사람의 감독 하에 훈련하는 것인지 아닌지지도 · 비지도 · 준지도 · 강화 학습
실시간 훈련 여부실시간으로 점진적인 학습을 하는지 아닌지온라인 학습 · 배치 학습
예측 모델 사용 여부알고 있는 데이터 포인트와 새 데이터 포인트를 비교하는지 · 과학자처럼 훈련 데이터셋에서 패턴을 발견해 예측 모델을 만드는지사례 기반 학습 · 모델 기반 학습
  • 📄 3쪽 — 분류 기준은 서로 배타적이지 않음 (슬라이드 표기는 ‘베타’) → 함께 쓸 수 있음
  • 📄 최첨단 스팸 필터 = 심층 신경망 모델로 스팸 · 스팸이 아닌 메일에서 실시간으로 학습 → 지도 학습 + 온라인 학습 + 모델 기반 학습

2. 훈련 지도 여부 — 지도 · 비지도 · 준지도 · 강화 (4 ~ 7쪽)

📄 종류📄 뜻📄 예
지도 학습 (Supervised Learning)알고리즘에 주입하는 훈련 데이터에 레이블(Label) 이라는 원하는 답이 포함분류(Classification) — 스팸 필터 (많은 메일 샘플 + 스팸인지 아닌지의 정보) · 회귀(Regression) — 중고차 가격 예측
비지도 학습 (Unsupervised Learning)훈련 데이터에 레이블이 없는 학습계층 군집 · 시각화 · 차원 축소 · 특성 추출 · 이상치 탐지 · 특이치 탐지 · 연관 규칙 학습
준지도 학습일부만 레이블이 있는 데이터를 학습 · 비지도 학습으로 군집을 나눈 뒤 샘플로 지도 학습 · 대부분 지도 + 비지도를 혼합구글 포토 호스팅 — 가족 사진 몇 장에만 레이블 → 모든 사진에서 가족 사진 확인
강화 학습에이전트(학습 시스템)가 취한 행동에 보상 또는 벌점 → 가장 큰 보상을 받는 방향으로 유도환경 관찰 → 행동 실행 → 보상 · 벌점 → 시간이 지나면서 정책(최상의 전략)을 스스로 학습
  • 📄 회귀 = 예측 변수(predictor variable)라 부르는 특성(feature)을 사용해 타깃(target) 수치를 예측하는 작업 — 중고차: 특성 = 주행거리 · 연식 · 브랜드 → 타깃 = 가격
  • 📄 정책 = 주어진 상황에서 에이전트가 어떤 행동을 선택해야 할지 정의
  • 🤖 분류 = 정해진 종류 중 하나로 나눔(스팸 / 정상) · 회귀 = 숫자를 예측(가격)

3. 🔥 선형 회귀 · 오차 · MSE (4쪽 ✍️ ★ · 칠판)

✍️ 4쪽 ★ “선형 회귀 계산하는 문제 객관식에 2~3문제 나옴”

칠판뜻
y = ax + b (a · b 에 동그라미)선형 회귀 모델 — 특성 x 로 타깃 y 를 예측하는 직선 · a = 기울기 · b = 절편 (🤖 데이터로 찾아내는 값)
ŷ (와이 햇)🤖 예측값 = 식에 x 를 넣어 나온 값 (직선 위의 점)
e = y − ŷ오차 = 실제 값 − 예측값
MSE = (1/n) Σ (y − ŷ)² (MSE 에 동그라미)✍️ 평균 제곱 오차 ★ (Mean Squared Error) — 오차를 제곱해서 더한 뒤 개수 n 으로 나눔 · 🤖 작을수록 직선이 데이터에 잘 맞음
  • 🤖 왜 제곱? — 오차는 + 도 − 도 나와서(칠판 오른쪽의 2 · −2 처럼) 그냥 더하면 서로 지워짐 → 제곱하면 모두 양수
  • 📄 11쪽 모델 기반 학습의 선형 모델도 같은 모양 — 삶의 만족도 = θ₀ + θ₁ × 1인당 GDP (θ₀ = 4.85 · θ₁ = 4.91 × 10⁻⁵)

🤖 계산 연습 (시험 대비 · 직접 계산해 확인한 값)

문제풀이답
① ŷ = 3x + 2 · x = 4 일 때 예측값3 × 4 + 214
② 실제 값 y = 10 · 예측값 ŷ = 7 일 때 오차e = y − ŷ = 10 − 73
③ 오차가 2 · −2 · 1 · −1 일 때 MSE(4 + 4 + 1 + 1) ÷ 4 = 10 ÷ 42.5
④ 데이터 (1, 4) · (2, 3) · (3, 8) · ŷ = 2x + 1 의 MSEŷ = 3 · 5 · 7 → e = +1 · −2 · +1 → e² = 1 · 4 · 1 → 6 ÷ 32
⑤ 같은 데이터 · ŷ = 2x 의 MSEŷ = 2 · 4 · 6 → e = 2 · −1 · 2 → e² = 4 · 1 · 4 → 9 ÷ 33 → ④(2)보다 큼 = ④ 모델이 더 잘 맞음
⑥ 11쪽 모델 · GDP 40,000 의 삶의 만족도4.85 + 40,000 × 4.91 × 10⁻⁵ = 4.85 + 1.9646.814
  • ⚠️ 함정 — ④ 에서 오차를 그냥 더하면 1 + (−2) + 1 = 0 · 제곱만 하고 안 나누면 6 (MSE 는 평균 = n 으로 나누기까지)

4. 실시간 훈련 여부 — 배치 학습 vs 온라인 학습 (8 · 9쪽)

📄 배치 학습📄 온라인 학습
방법주어진 훈련 세트 전체를 사용해 오프라인에서 훈련 → 먼저 훈련시킨 뒤 더 학습 없이 제품 시스템에 적용적은 양의 데이터(미니배치 · mini-batch) 로 점진적으로 훈련
단점컴퓨팅 자원(cpu · gpu · 메모리 · 저장장치 등)이 충분할 때만 · 새 데이터가 들어오면 처음부터 새롭게 학습나쁜 데이터가 주입되면 성능이 점진적으로 떨어질 수 있음 · 지속적인 시스템 모니터링 필요
예—주식가격 시스템(실시간 반영) · 스마트폰(제한된 자원) · 외부 메모리 학습(매우 큰 데이터셋)
  • 📄 9쪽 끝 학습률(Learning Rate) — 🤖 새 데이터에 얼마나 빨리 적응할지 정하는 값 (크면 빨리 적응하지만 예전 데이터를 빨리 잊음)

5. 예측 모델 사용 여부 — 사례 기반 vs 모델 기반 (10 · 11쪽)

📄 사례 기반 학습📄 모델 기반 학습
방법샘플을 기억하는 것이 훈련의 전부 → 예측할 때 기존 샘플과의 유사도 측정모델을 미리 지정한 뒤 훈련 세트로 훈련 → 훈련된 모델로 새 데이터 예측
예KNN 알고리즘 (🤖 가장 가까운 k 개 이웃 중 많은 쪽으로)선형 모델 학습 — OECD 국가의 1인당 GDP 와 삶의 만족도 관계 · 효용 함수 · 비용 함수
  • 📄 11쪽 그래프 — θ₀ = 4.85 · θ₁ = 4.91 × 10⁻⁵ → 🤖 GDP 가 1 만큼 늘 때 만족도가 θ₁ 만큼 오름 (3절 ⑥)
  • 🤖 효용 함수 = 모델이 얼마나 좋은지 · 비용 함수 = 얼마나 나쁜지(오차) → 선형 회귀는 비용(예: MSE)을 가장 작게 하는 θ 를 찾음

6. 머신러닝의 주요 도전 과제 (12 ~ 16쪽)

  • 📄 12쪽 6가지 — 충분하지 않은 양의 훈련 데이터 · 대표성 없는 훈련 데이터 · 낮은 품질의 데이터 · 관련이 없는 특성 · 과대적합 · 과소적합
    • 🤖 과대적합 = 훈련 데이터에 너무 딱 맞춰 새 데이터에 약함 · 과소적합 = 모델이 너무 단순해 제대로 못 배움
  • 📄 15쪽 데이터 불일치 — 훈련 데이터가 실전 데이터를 완벽하게 대변하지 못할 때 · 예) 인터넷 꽃 사진으로 훈련 → 직접 찍은 사진으로 성능이 낮게 나옴 · 확인: 훈련-개발 세트(훈련 데이터의 일부)로 평가가 좋은데 테스트 세트 성능이 나쁘면 불일치
  • 📄 16쪽 공짜 점심 없음(No free lunch) — 주어진 데이터셋에 가장 적절한 모델을 미리 알 수 없음 → 다양한 모델 · 하이퍼파라미터 튜닝으로 확인
  • ✍️ ✗ 13쪽 검증 — 훈련 세트 80% · 테스트 세트 20% · 검증 기준 = 일반화 오차(새 샘플에 대한 오류 비율) · 과대 적합 = 훈련 오차에 비해 일반화 오차가 높은 경우
  • ✍️ ✗ 14쪽 — 하이퍼파라미터 = 알고리즘 학습 모델에 쓰는 파라미터 · 훈련 과정에 변하지 않음 · 교차 검증 = 여러 검증 세트로 예비표본(홀드아웃) 검증을 반복 (정확하지만 훈련 시간이 늘어남)
