9주차 · 7장 머신러닝 1

포인트핵심 · 답그림
인공지능 정의인간의 지능으로 하는 인식 · 사고 · 학습을 기계가 할 수 있게 구현하는 기술 · 학문 · AI ⊃ 머신러닝 ⊃ 딥러닝AI ⊃ ML
특성 4가지인간 같은 행동(튜링 테스트) · 인간 같은 사고(인지과정 + 신경과학 + 심리학) · 합리적 행동(최선의 행동) · 합리적 사고(삼단논법)특성
튜링 테스트컴퓨터 · 사람 · 심사원이 다른 방에서 메시지 → 심사원이 컴퓨터를 구별 · 통과하면 인간과 같은 기계특성
발전의 역사계산주의(1956 다트머스 · 존 매카시 · 지식을 표현) → 연결주의(1980년대 · 인공신경망 · 데이터로 학습) → 딥러닝(2010~ · GPU · 은닉층 여러 개)역사
약한 vs 강한 AI존 설 — 약한 = 특정 문제 · 합리적으로 / 강한 = 자의식 · 인간처럼 생각유형
수준 Level 1~41 단순 제어(에어컨 · 세탁기) · 2 다채로운 행동(장기 · 청소로봇) · 3 기계학습(추천 시스템) · 4 딥러닝유형
머신러닝 정의아서 새뮤얼(1959) = 명시적 프로그래밍 없이 학습 · 톰 미첼(1997) = 작업 T · 성능 P · 경험 EML
왜 머신러닝?전통 = 사람이 규칙 → 새 스팸 단어마다 업데이트 · 머신러닝 = 데이터('For U')로 스스로 학습 · 새 데이터에 적응 · 데이터 마이닝ML
자세한 표는 9주차 · 문제는 🔒 실제시험.

10주차 · 8장 머신러닝 2

포인트핵심 · 답그림
🔥 선형 회귀모델 y = ax + b (a 기울기 · b 절편) · 예측값 ŷ = 식에 x 대입 · 오차 e = y − ŷ (실제 − 예측)㉒
🔥 MSE평균 제곱 오차 = (1/n) Σ (y − ŷ)² — 오차를 제곱해 더하고 n 으로 나눔 · 작을수록 잘 맞음 · 예) 오차 1 · −2 · 1 → (1 + 4 + 1) ÷ 3 = 2 (그냥 더하면 0 · 안 나누면 6 = 함정)㉒
🔥 선형 모델 예측삶의 만족도 = 4.85 + 4.91 × 10⁻⁵ × GDP → GDP 40,000 이면 6.814㉕
분류 기준 3가지훈련 지도 여부 · 실시간 훈련 여부 · 예측 모델 사용 여부 — 배타적이지 않음 (스팸 필터 = 지도 + 온라인 + 모델 기반)⑳
지도 · 비지도 · 준지도지도 = 레이블 있음(분류 · 회귀) · 비지도 = 없음(군집 · 차원 축소 · 이상치 탐지) · 준지도 = 일부만(구글 포토)㉑
회귀 용어특성(feature) = 예측 변수 → 타깃(target) 수치 예측 · 중고차: 주행거리 · 연식 · 브랜드 → 가격㉑
강화 학습에이전트 · 보상 / 벌점 · 정책 = 상황마다 어떤 행동을 고를지㉓
배치 vs 온라인배치 = 전체 · 오프라인 · 새 데이터면 처음부터 / 온라인 = 미니배치 · 점진적 · 나쁜 데이터 주의 · 모니터링㉔
사례 vs 모델 기반사례 = 기억 · 유사도(KNN) / 모델 = 모델을 정해 훈련 → 예측(선형 모델)㉕
도전 과제데이터 양 · 대표성 · 품질 · 관련 없는 특성 · 과대적합 · 과소적합 · 데이터 불일치 · 공짜 점심 없음㉖
자세한 표 · 계산 연습은 10주차 · 문제는 🔒 실제시험.
