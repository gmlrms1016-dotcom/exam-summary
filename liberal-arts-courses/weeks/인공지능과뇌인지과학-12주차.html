1. 인공 신경망 (2 ~ 4쪽)

  • 📄 ANN(Artificial Neural Network) = 뇌에 있는 생물학적 뉴런의 네트워크에서 영감을 받은 머신러닝 모델
  • 📄 하늘을 나는 비행기 → 새로부터 영감 · 지능적인 기계 → 뇌 구조로부터 영감 — 그러나 비행기가 새처럼 날개를 펄럭일 필요는 없다 → 인공 신경망도 뉴런에서 점점 멀어짐
  • 📄 인공 신경망 → 딥러닝의 핵심 — 다재다능 · 강력 · 확장성이 좋음 · 수백만 개의 이미지 분류(구글 이미지) · 음성 인식(애플 Siri) · 비디오 추천(유투브) · 대규모 머신러닝 문제에 적합
📄 역사 (3 · 4쪽)내용
1943년신경생리학자 워런 매컬러(Warren McCulloh) · 수학자 월터 피트(Walter Pitts) — 명제 논리로 뉴런이 복잡한 계산을 위해 상호작용하는 간단한 계산 모델 → 최초의 인공 신경망 구조
초기 성공 → 1960년지능을 가진 기계와 대화를 나눌 수 있을 거란 기대 → 힘들다는 게 명백해지자 침체기
1980년대 초새로운 네트워크 구조 → 연결주의(신경망 연구) 관심 증가
1990년대서포트 벡터 머신 같은 기술이 더 나아 보임 → 신경망 연구 침체기
부흥 (4쪽)① 훈련 데이터가 많아짐 ② 하드웨어 발전(무어의 법칙 · GPU · 클라우드 플랫폼) ③ 훈련 알고리즘 향상(작은 변화 → But. 커다란 영향) ④ 이론상 제한(지역 최저점 문제)이 실전에선 문제가 안 됨 ⑤ ✍️ 투자와 진보의 선순환 → 자율주행 · 추천시스템 · Chat-GPT
  • ⚠️ 팩트체크 — 슬라이드 철자 McCulloh → 정확한 이름은 Warren McCulloch (🤖)
  • 🤖 9주차 연결 — 연결주의(1980년대 · 인공신경망 · 데이터로 학습) → 딥러닝(2010~ · GPU)

2. 생물학적 뉴런 (5쪽)

  • 📄 뉴런의 구조 — 수상돌기 · 축색 · 축색종말 · 시냅스 · 활동 전위 · 신호 · 신경전달 물질
  • ✍️ 수상돌기 = “정보 받기” · ✍️ 축색 = “다른 뉴런께 정보 전달”
  • 📄 그림 — Dendrites(수상돌기) → Cell body(세포체 · Nucleus 핵) → Axon hillock → Axon(축색 · Myelin sheath 수초) → Synaptic terminals(축색종말) → Synapse(시냅스) → 다음 뉴런 (Presynaptic cell → Postsynaptic cell · Signal direction)
  • 🤖 5주차 연결 — 활동 전위가 축색을 따라 → 축색종말에서 신경전달물질 → 시냅스를 건너 다음 뉴런의 수상돌기로 · 인공 뉴런은 이 흐름을 입력(받기) → 계산 → 출력(전달) 으로 단순화

3. 🔥 뉴런을 사용한 논리 연산 (6쪽 · ✍️ ★ 4개)

  • 📄 인공 뉴런 (매컬러와 피트) — 하나 이상의 이진(on/off) 입력과 이진 출력 하나 · 입력이 일정 개수만큼 활성화되었을 때 출력을 내보냄 · 예: 입력이 둘은 준비되어야 뉴런이 활성화된다고 가정
  • ✍️ ¬ = NOT · ∧ = AND · ∨ = OR (📄 그림 속 ∧ = 논리곱 · ∨ = 논리합 · ¬ = 논리부정)
📄 그림🤖 연결 (그림의 화살표)뜻C 가 켜지는 때
C = AA → C 연결 2개그대로A 가 켜지면 (A 하나로 신호 2개)
C = A ∧ BA → C 1개 · B → C 1개AND (논리곱)A · B 둘 다 켜질 때
C = A ∨ BA → C 2개 · B → C 2개OR (논리합)A · B 중 하나라도 켜질 때
C = A ∧ ¬BA → C 2개 · B → C 는 억제(−) 연결A AND NOT BA 가 켜지고 B 는 꺼져 있을 때
  • 🤖 기준 = “신호 2개가 들어와야 켜짐” — 연결 개수만 세어 보면 표가 이해돼요 (그림 ㉜)

4. 🔥 퍼셉트론 — TLU · 계단함수 (7 · 8쪽 · ✍️ ★)

  • 📄 TLU(threshold logic unit · ✍️ 동그라미 ☆) 또는 LTU(linear threshold unit)라 불리는 인공 뉴런을 활용 · ✍️ LTU 에는 줄 → 🤖 이름은 TLU 로 기억
  • 📄 입력 / 출력 = 숫자 · 모든 입력은 가중치와 연결됨
  • 📄 TLU = 입력값과 가중치를 곱한 값들의 합에 계단함수(step function) 적용 · n = 특성 수
    • 📄 z = xᵀw = x₁w₁ + x₂w₂ + … + xₙwₙ → 출력 h_w(x) = step(z)
  • 📄 8쪽 예제 — 3개의 특성을 갖는 샘플 하나가 입력되면 가중치와 곱한 후 합을 계산 → 계단함수를 통과시킨 결과를 출력 · 보통은 편향에 대한 가중치도 함께 고려
  • 📄 가장 많이 사용되는 계단함수 — Heaviside 계단함수와 sign 함수
📄 계단함수z < 0z = 0z > 0
heaviside(z)011
sgn(z)−101
✍️ 손 계산 (★)x₁ = −1 · x₂ = 0 · x₃ = 1 / w₁ = 1 · w₂ = 2 · w₃ = 2
① 곱해서 더하기z = (−1)×1 + 0×2 + 1×2 = −1 + 0 + 2 = 1
② 계단함수heaviside(1) = 1 (z ≥ 0) · sgn(1) = 1 (z > 0)
  • ⚠️ 팩트체크 — ✍️ “∴ step = z = 1” 은 이번 값이 우연히 같은 것 · 계단함수는 z 를 그대로 내보내지 않고 0 과 비교해서 heaviside 는 0 · 1, sgn 은 −1 · 0 · 1 만 내보냄 → 예) z = 5 여도 heaviside = 1 · z = −3 이면 heaviside = 0 · sgn = −1 (🤖)
  • 🤖 헷갈리는 곳 — z = 0 일 때 heaviside = 1 (z ≥ 0) · sgn = 0

5. 퍼셉트론 정의 · 학습 (9 ~ 11쪽)

  • ✍️ 9쪽 “TLU와 선형 이진분류” 에 큰 ✗ → 🤖 수업에서 넘어간 부분 — 짧게만: 하나의 TLU = 간단한 이진분류기(입계값을 기준으로 양성 / 음성 · 학습 = 최적의 가중치 찾기)
  • 📄 퍼셉트론 정의 (✍️ 동그라미) — 하나의 층에 여러 개의 TLU 로 구성 · TLU 각각은 모든 입력과 연결됨
  • 📄 10쪽 입력층 = 입력 뉴런(입력을 받아 그대로 통과시켜 출력)으로 구성된 층 · 편향값 1 을 항상 출력하는 편향 뉴런도 함께 · 예: 입력 2개 · 출력 3개 퍼셉트론 — ✍️ 그림에 ✗ + “편향은 안함”
  • 📄 11쪽 퍼셉트론 학습 알고리즘 — 오차가 감소되도록 가중치를 조절하며 뉴런 사이의 관계를 강화 · 하나의 샘플이 입력될 때마다 예측 → 오차 계산 → 오차가 줄어드는 방향으로 가중치 조절
    • 📄 w(next step) = w + η (y − ŷ) x — 🤖 η = 학습률(11주차) · y − ŷ = 실제 − 예측(10주차 오차 e) → 예측이 맞으면(y − ŷ = 0) 가중치 그대로

6. 다층 퍼셉트론(MLP)과 역전파 (12 ~ 15쪽)

  • 📄 다층 퍼셉트론(MLP) = 퍼셉트론을 여러 개 쌓아 올린 인공신경망 — 입력층 1개 · 은닉층 여러 개 · 출력층 1개
  • 📄 완전연결 층(밀집 층) = 층에 속한 각각의 뉴런이 이전 층의 모든 뉴런과 연결되어 있을 때
  • ✍️ 14쪽 행렬 수식 h(X) = φ(XW + b) (X 특성행렬 · W 가중치 · b 편향벡터 · φ 활성화 함수) 쪽은 통째로 ✗ — 그림의 은닉층(가운데 두 줄)에 동그라미
  • 📄 심층신경망(DNN) = 여러 개의 은닉층을 쌓아 올린 인공신경망
  • 📄 역전파(backpropagation) — 층이 많을수록 훈련이 어려웠는데 1986년에 소개된 역전파 이후 실용성을 갖춤
📄 역전파하는 일
1단계 (정방향)각 훈련 샘플에 대해 먼저 예측 → 오차 측정
2단계 (역방향)거꾸로 각 층을 거치며 각 연결이 오차에 기여한 정도 측정
3단계오차가 감소하도록 모든 가중치 조정
