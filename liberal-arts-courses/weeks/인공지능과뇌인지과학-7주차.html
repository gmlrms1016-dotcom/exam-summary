서론 — 맹시 · 감각과 지각 (2 · 3쪽)

  • 맹시(2쪽) — 의식적인 시각 자극 처리 없이 시각 능력의 일부를 보유하고 있는 현상
    • 우측 시각피질 손상으로 좌시야장의 모든 물체가 보이지 않는 Ron
    • 그런데 좌시야장에 제시된 물체의 움직임을 파악할 수 있었다! → “본다”는 것의 진정한 의미가 무엇인가?
용어뜻 (3쪽)
감각빛, 음파, 압력 등과 같은 감각 정보의 등록(registration)과 초기 부호화
지각뇌가 물체와 장면의 감각 정보를 시각적 물체나 인식가능한 소리와 같은 의미 있는 표상으로 조직화하는 것
병렬처리 ✍️ 참고한 번에 하나 이상의 처리가 동시에 되는 것
  • ✍️ 필기 병렬처리에 동그라미 + 화살표 “참고” · 3쪽 그림 = 나비 → 빛(Light waves) → 눈 → 신경 신호(Neural signals) → 뇌
  • 🤖 한 줄로 — 감각 = 받아들여 등록 · 지각 = 그것을 의미 있게 조직화

망막 (4쪽)

  • 망막은 눈 내벽에 위치한 몇 개의 신경세포 층으로 구성되어 있다
  • 우리는 눈이 빛을 받고(regist) 뇌로 정보를 전달한다고 단순하게 생각하지만, 뇌가 부분적으로 소화되고 변형된 정보를 받도록 망막 자체 내에서 계산이 일어난다

✍️ 광수용체 — 간상체 vs 추상체 (5 · 6쪽) 🔥

간상체와 추상체는 빛 에너지를 받아 그것을 신경계에서 사용되는 전기화학적 에너지로 변형한다 (5쪽).

차이간상체 (rod)추상체 (cone)
1. 개수1억 2천만 개 (슬라이드 표기 “1억 2천개”)6백만 개
2. 색소로돕신 — ✍️ 약한 빛에 민감(형광펜) · 일광(daylight)에 탈색3종류 S · M · L — 일광 시 처리 · 색지각 → ✍️ 선명한 지각
3. 망막에서의 분포망막 주변부에 밀집망막 중심의 중심와(fovea) 에 밀집 (✍️ 밑줄로 이음)
4. 신경절 세포와의 연결간상체 : 신경절 = 다(多) : 1 → ✍️ 어두울 때 사용 · 선명도↓추상체 : 신경절 = 소(小) : 1 → ✍️ 밝을 때 사용 · 선명도↑
  • ⚠️ 정정 — 5쪽 간상체 개수가 “1억 2천개”로 적혀 있지만, 추상체(6백만 개)보다 훨씬 많다는 뜻이라 1억 2천만 개(120,000,000)의 오타로 보여요. 시험에는 “간상체가 추상체보다 훨씬 많다(약 20배)”로 기억하기
  • ✍️ 필기 6쪽 그림의 간상체 5개 → 신경절 1개 묶음에 “N:1 로 연결”
  • 6쪽 주변시에 비친 얕은 별빛 — 주변시에 있을 때는 보임 · 중심시로 보려 하면 안 보임 · Why? → 아래 🤖 설명 ③

🤖 6쪽 그림 설명 (✍️ “Claude야 그림 자세히 설명해”)

① 왼쪽 그림 — 약한 빛에서 누가 반응하나 (감도)

  1. 위에서 같은 세기의 약한 빛이 수용기 10개에 하나씩 비춰요 — 왼쪽 5개 = 간상체(원통), 오른쪽 5개 = 추상체(뾰족)
  2. 수용기 하나가 만드는 신호는 2 만큼 (그림의 숫자 2)
  3. 간상체 5개는 선이 모두 신경절 세포 1개로 모여요(다:1) → 2 + 2 + 2 + 2 + 2 = +10 → 신경절 세포가 반응(Response)
  4. 추상체는 하나마다 자기 신경절이 따로 있어서 신경절마다 2 뿐 → 반응 없음(No response)
  5. → 약한 빛은 신호를 모아 주는 간상체가 잡아요 = ✍️ 어두울 때 사용

② 오른쪽 그림 (a)(b) — 두 점을 구분하나 (선명도)

  1. (a) 붙어 있는 빛 점 2개 — 간상체 쪽은 두 신호가 같은 신경절 1개로 모여 출력도 1개 → 점이 하나인지 둘인지 구분 못 함
  2. 추상체 쪽은 빛을 받은 추상체마다 자기 신경절이 따로 반응 → 출력 2개 → 두 점을 구분
  3. (b) 두 점을 떨어뜨려도 간상체 쪽 출력은 (a)와 똑같이 1개 → 빛이 어디에 왔는지(위치)가 사라짐 → ✍️ 선명도↓
  4. 추상체 쪽은 빛이 온 그 자리의 신경절이 반응 → 위치까지 전달 → ✍️ 선명도↑ (✍️ 선명한 지각)

③ 주변시에 비친 얕은 별빛 — Why?

  • 희미한 별빛 = 약한 빛 → 신호를 모아 주는 간상체라야 반응해요
  • 간상체는 망막 주변부에 몰려 있음 → 곁눈질(주변시)하면 별빛이 주변부에 떨어져 보임
  • 똑바로 보면(중심시) 별빛이 중심와 = 추상체에 떨어지는데, 추상체는 신호를 모으지 않아 역치를 못 넘음 → 안 보임
간상체추상체
신경절과 연결다(多) : 1 — 모음(수렴)소(小) : 1 — 따로
약한 빛 (감도)강함 → 어두울 때약함
선명도 (해상도)↓ 흐릿↑ 선명 → 밝을 때
망막 위치주변부중심와

✍️ 수용장 (8쪽)

  • 수용장 = 특정한 세포가 반응하는 시공간(visual space)의 특정한 영역
  • 어느 특정 섬유에서 반응을 얻기 위해 조명을 해야 하는 망막 상의 영역 (Hartline, 1936)
  • 특정한 간상체 혹은 추상체의 하위집단을 자극 ⇒ 하나의 신경절 세포
  • 서로 다른 신경절 세포는 서로 다른 수용장을 가진다
  • 그러므로 신경절 세포 배열의 발화 패턴은 망막 전체의 빛의 패턴을 나타낸다
  • 축구장 비유 — ✍️ 필기 그림: 여러 선이 한 점(신경절 세포)으로 모이고, 옆에 점들이 찍힌 네모 = 시공간
  • 🤖 축구장 비유 — 경기장(시야) 전체를 여러 구역으로 나누고 구역마다 담당 관찰자(신경절 세포)가 한 명씩 있다고 생각해요. 관찰자는 자기 구역(수용장)에 공(빛)이 들어올 때만 소리쳐요 → 누가 소리쳤는지를 모으면 경기장 어디에 공이 있는지(빛의 패턴)를 알 수 있어요
  • 8쪽 그림 = 빛 자극(Light stimulus)을 눈에 비추고, 전극(Electrode)으로 신경절 세포 축색의 활동전위를 기록하는 실험

✍️ 중심-주변 수용장 (9쪽) — 여기까지 시험 범위

  • 중심-주변 수용장 — 수용장이 가운데(중심)와 바깥 고리(주변)로 나뉨
  • 흥분성 중심, 억제성 주변 수용장 / 억제성 중심, 흥분성 주변 수용장
  • 신경절 세포 수용장의 이러한 중심-주변 구조는 어두운 영역과 밝은 영역 사이의 경계를 강조하도록 돕는다 ⇒ 대비 향상
  • ✍️ 필기 9쪽 그림 위에 대비율↑(High contrast) · 대비율↓(Low contrast)
  • 9쪽 오른쪽 그림 (a)~(d) — 흥분성 중심(+) · 억제성 주변(−) 수용장에 빛을 비추는 범위를 바꿀 때의 발화
    • (a) 중심 안에 작은 빛 점 → 발화가 늘어남 · (b) 중심을 꽉 채운 빛 → 발화가 가장 많음 · (c) 빛이 주변(−)까지 조금 넘어감 → 줄어듦 · (d) 주변까지 전부 빛 → 가장 적음
    • 🤖 중심이 밝고 주변이 어두울 때 가장 크게 반응 → 경계(가장자리)에서 반응이 커져 윤곽이 또렷해짐 = 대비 향상
  • ✍️ 필기 슬라이드 제목 옆에 “여기까지 시험범위 (밑 슬라이드 X)”
