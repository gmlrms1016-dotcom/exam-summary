1. 생성형 AI 시대 (2 ~ 4쪽)

  • ChatGPT 의 등장 — GPT = Generative Pre-trained Transformer · 자연어 처리(NLP)에서 다양한 작업 · 사람과 거의 구별할 수 없는 텍스트 생성 · 📖 “GPT-3.5 의 경우 1750억 개의 파라미터”
    • ⚠️ 팩트체크 — 1750억(175B)은 GPT-3 논문(2020)에 공개된 수치 · GPT-3.5 의 파라미터 수는 OpenAI 가 공식으로 밝히지 않음 (🤖)
  • AI 업계의 변화 — 단일 작업만 하는 좁은 AI → 다목적 범용 AI 로 초점 이동 · 대규모 모델 학습이 중요해져 데이터 · 컴퓨팅 자원에 대규모 투자 · GPT 같은 기술의 상용화로 AI 도구 생태계가 급속히 확장
  • 사회적 영향 (3쪽) — 챗봇이 상담원을 대체 · 보조 · 콘텐츠 생성 · 번역 · 요약 자동화(언론 · 마케팅 · 출판) · 반복적이고 예측 가능한 작업 대체(콜센터 · 은행 직원 · 번역가) · 새 직업(데이터 엔지니어 · 머신러닝 엔지니어 · AI 윤리 전문가)
종류생성형 AI (4쪽)
텍스트GPT · BERT · LLaMA
이미지DALL-E · StyleGAN
음성WaveNet · Tacotron
영상Sora
  • 🤖 BERT 는 문장을 이해하는 쪽(인코더) 모델이라 보통 “생성” 모델로는 안 부름 — 슬라이드 분류 그대로 적음

2. 🔥 트랜스포머 배경 · Attention (5 ~ 11쪽 · ✍️ 5쪽)

  • 2010년대 주요 딥러닝 모델 — 컴퓨터 비전(CV) → CNN(Convolutional Neural Network · 합성곱 신경망) · 자연어 처리(NLP) → RNN(Recurrent Neural Network · 순환 신경망)
  • RNN 의 단점 (6쪽)
    • 입력이 순차적으로 들어가서 GPU 를 써도 의미가 없음 → 병렬 처리 X
    • 문장이 길어지면 전체적인 문맥 정보를 담아낼 수 없음
  • 🔥 Attention 개념의 등장
    • 문장에서 각 단어들의 중요도(Attention Score) 를 계산 → 어떤 단어가 중요한지 파악 → 문장의 문맥까지 파악 가능
    • 이 계산을 병렬적으로 처리해서 계산 효율 ↑
    • RNN 의 한계를 극복하고 비약적으로 성능 향상 · 지금은 CV 에서도 CNN 보다 성능 높음 → 결과적으로 RNN 과 CNN 을 대체
  • 7 ~ 11쪽 = 시지각에서의 주의 — “빨간색 T 를 찾아 주세요” (여러 글자 중 중요한 것에 주의를 모으는 것 = Attention 의 생각)

3. 트랜스포머의 부흥 · 활용 (12 ~ 14쪽)

  • 최근 2년간 arXiv 에 실린 AI 논문 중 70% 에 트랜스포머 등장 · 현존 최고의 딥러닝 모델 · 의료 · 헬스케어 · 챗봇 등
  • 단백질 구조 예측 — 기존 방법은 시간이 오래 걸림 → 구글 딥마인드 알파폴드 = 약 2억 개 단백질 예측 · 단백질 구조를 이해하면 어떻게 작동하는지 해독 → 신약 개발 · 환경 · 생물학에 큰 영향 (아직 단백질 상호작용 연구 필요)
  • 챗봇 — ChatGPT (chat.openai.com)

4. LLM (15 ~ 19쪽)

  • LLM(Large Language Model) — 대규모 데이터를 학습해 언어 이해 · 생성 능력을 극대화한 모델 · 수백억 개 파라미터
  • 하이퍼파라미터 — 에포크 · 학습률 · 배치 크기 · 최대 출력 토큰 수 · 디코딩 유형 · Top-k 및 Top-p 샘플링
  • 토큰 = 텍스트를 작은 단위로 나눈 것 · 토큰화 = 분석 가능한 기본 요소로 분리 (“나는 학교에 갔다” → “나는” · “학교에” · “갔다”) · 임베딩 = 단어 · 문장을 고정된 크기의 벡터로 변환 (수치화 · 차원의 저주 해결 · 계산 효율 ↑)
디코딩 유형 (17쪽)방법장점단점
그리디매 단계 가장 높은 확률의 토큰간단 · 빠름창의성 ↓ · 전체 문맥에서 최적이 아닐 수 있음
빔 서치여러 경로를 동시에 · 누적 확률이 가장 높은 경로품질 ↑ 가능성계산 비용 ↑ · 복잡
샘플링확률 분포에 따라 무작위로창의적인 텍스트일관성 ↓ · 비논리적 응답 가능
18쪽방법장점단점
Top-k확률이 높은 상위 k 개 토큰만 고려해 샘플링비논리적 응답 ↓ · k 가 클수록 다양k 가 너무 낮으면 다양성 ↓
Top-p누적 확률이 p 에 도달할 때까지 토큰을 선택비논리적 응답 ↓ + 필요하면 더 많은 토큰 → 유연p 를 잘못 잡으면 토큰이 너무 많거나 적어 질 ↓
  • 18쪽 표 (“다음 토큰” 후보) — 도서관에서 0.30 · 점심먹으러 0.25 · 숙제하러 0.22 · 시내에서 0.15 · 반대편에서 0.12
    • 🤖 예시 — 그리디 = 도서관에서 · Top-k(k = 3) = 위 3개 중에서 · Top-p(p = 0.8) = 0.30 + 0.25 + 0.22 = 0.77 → 아직 < 0.8 → + 0.15 = 0.92 → 4개 중에서
  • 19쪽 관련 기술 — 랭체인(LangChain) = LLM 앱 개발용 오픈소스 프레임워크 (OpenAI · Cohere · Hugging Face 등을 같은 방식으로 호출) · 벡터 데이터베이스 = 벡터를 저장 · 검색 (텍스트 · 이미지 · 오디오 → 벡터 · 벡터 임베딩 · 유사성 검색)

5. 논의 (20쪽 · ✍️ 내 답)

질문✍️ 내 답 (요약)
AI 가 가진 문제점과 위험성은?다음 토큰을 확률로 골라 그럴듯하지만 틀린 내용을 말할 수 있음 · 데이터 편향 · 가짜 영상 · 개인정보 유출 · 반복적인 일자리 감소
안전한 AI 를 만들려면?치우치지 않은 데이터 · 개인정보 빼기 · 사람이 결과 확인 · AI 가 만든 것 표시 규칙 · 법 · AI 윤리 전문가
AI 가 인간을 뛰어넘지 못한 부분과 이유는?진짜 이해 · 공감 · 적은 경험으로 응용 — AI 는 확률이 높은 답을 고를 뿐 의미를 느끼거나 몸으로 경험하지 못함 → 판단 · 책임은 사람

6. 🔥 시험 대비 핵심 요약

  • 🔥 ✍️ “오늘까지 시험범위” — 기말고사 = 11장 생성형 AI 까지
  • GPT = Generative Pre-trained Transformer · 좁은 AI → 범용 AI · 사회적 영향(대체되는 일 · 새 직업)
  • CV → CNN · NLP → RNN · 🔥 RNN 단점 2가지 = 병렬 처리 X · 긴 문장의 문맥 X → 🔥 Attention = 단어 중요도(Attention Score) 계산 · 병렬 → 트랜스포머가 RNN · CNN 대체
  • 생성형 AI 종류 — 텍스트 GPT · BERT · LLaMA / 이미지 DALL-E · StyleGAN / 음성 WaveNet · Tacotron / 영상 Sora
  • LLM · 토큰 · 토큰화 · 임베딩 · 디코딩 3가지(그리디 · 빔 · 샘플링) · Top-k = 상위 k 개 · Top-p = 누적 확률 p 까지
