# 나는 존재하는가 실존하는가

> 자료: 나는 존재하는가 실존하는가_공배실 5주차.pdf · 정리 범위 = 노션 필기 1줄 + 12쪽 손글씨 "claude야 정리해" (원본 txt 없음 → PDF 와 대조)

## 1. 실존에서 마주하는 요소 (키에르케고르) — 내 필기
- ✍️ **필기** — "인간의 실전에서 느끼는데에 아주 중요한 요소가 있다. 불안, 죽응, 고독, 자유"
- ⚠️ **정정** — 6쪽 원문: 키에르케고르에게 실존이란 **불안 · 죽음 · 고통 · 고독 · 자유**를 직면하는 개인의 살아있는 현실
  - 필기에서 **고통**이 빠졌습니다 → 요소는 **5개**
  - 오타: 실전 → **실존** · 죽응 → **죽음**
- 키에르케고르 = 덴마크의 철학자, **실존주의의 아버지** (6쪽)

## 2. 🤖 실존주의 철학자 한눈에 보기 (12쪽 "claude야 정리해")
| 철학자 | 핵심어 | 한 줄 설명 |
|---|---|---|
| 키에르케고르 | 자유로운 개인의 선택 | "이것이냐 저것이냐" — 불안 속에서도 스스로 선택하며 자신을 실현한다 |
| 니체 | 힘의 의지 · 초인 | 기존 가치를 뛰어넘어 새로운 가치를 창조하는 인간상 |
| 야스퍼스 | 한계상황 | 죽음 · 고통처럼 피할 수 없는 상황에서 진정한 실존이 각성된다 |
| 하이데거 | 현존재(Dasein) | 세계 속에 던져진 존재로, 죽음을 향해 달려가며 자신의 존재를 이해한다 |
| 사르트르 | 실존은 본질에 앞선다 | 인간은 스스로 선택하고 창조하는 자유로운 존재 |

- ⭐ **강조** — 실존주의 핵심 키워드: **비합리주의 · 반이성주의 · 주체성 · 선택 · 결단 · 책임**
- 🤖 외우는 요령 — 다섯 명 모두 "정해진 답은 없다, **내가 선택하고 책임진다**"는 같은 줄기입니다. 이름 ↔ 핵심어만 짝지으면 됩니다.
  - **키**에르케고르 = **선택**("이것이냐 저것이냐") · **니**체 = **초인** · **야**스퍼스 = **한계상황** · **하**이데거 = **현존재** · **사**르트르 = **실존 > 본질**
- 🤖 시대 순서(13쪽): 키에르케고르(1810~1850년대) → 니체(1880~1900년대) → 하이데거(1920년대) → 야스퍼스 · 사르트르 · 카뮈(1930~40년대) → 전후 유럽 전반(1945년 이후)
