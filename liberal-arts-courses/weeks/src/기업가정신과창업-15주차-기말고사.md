# 기말고사 시험문제 정리 (9주차 반영)

🔒 [실제시험](../기업가정신과창업-실제시험.html)

> 📌 교수님의 기말고사 안내(일시 · 범위 · 문제 수)가 나오면 이 맨 위에 카드로 정리해요. 중간고사는 1강 ~ 4강 · 5점 문제 4개 + 10점 문제 1개였어요.

## 🎨 그림으로 정리
🎬 [그림 정리](anim/기업가정신과창업-그림정리.html?weeks=9-15#four)

- 9주차(5강 창업) — ① 4대 필수요소 · ② 개인기업 설립 · ③ 주식회사 설립 · ④ 허가 · 등록 · 신고 · ⑤ 사회적 기업

## 9주차 · 5강 창업 — 창업절차 · 사회적 기업
| 포인트 | 핵심 · 답 | 그림 |
|---|---|---|
| 창업의 정의 · 4대 필수요소 | 돈을 버는 것을 목적으로 기업을 새로 만드는 일 · 창업자(사람) · 창업자금(자본) · 업종(아이템) · 사업장(장소) | ① |
| 창업이 아닌 경우 | 사업 승계 · 개인 → 법인 전환 · 폐업 후 같은 사업 재개 (+ 조세특례제한법: 사업 확장 · 업종 추가) | |
| 개인기업 설립절차 | 아이템 · 타당성 → 사업계획 → 인 · 허가 → **사업자등록 (개시일부터 20일 이내 · 관할 세무서)** → 사업 개시 | ② |
| 주식회사 설립절차 | 발기인 구성 → 정관 → 주식발행사항 → 발기 설립 / 모집 설립 → 설립등기 → 20일 이내 법인설립 신고 · 사업자등록 · 유한책임 | ③ |
| 4대 보험 | 건강 · 연금 · 고용 · 산재 · 고용 · 산재의 근로자는 법인 대표자 제외 · 산재 = 사업주 전액 | |
| 허가 · 등록 · 신고 | 허가 = 금지 해제 (단란 · 유흥주점) · 등록 = 전문 자격요건 (공인중개사 · 약국 · 학원) · 신고 = 요건 + 신고증 (일반 · 휴게음식점 · 미용실) | ④ |
| 사회적 기업 | 사회적 목적의 경제활동 · 유형 5 · 사회적기업 육성법 · 매출 ≥ 노무비 30% · 이윤 2/3 재투자 | ⑤ |

> 자세한 표는 [9주차](기업가정신과창업-9주차.html) · 문제는 🔒 실제시험.
