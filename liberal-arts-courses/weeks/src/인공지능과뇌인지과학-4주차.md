## 1. 인지신경과학 연구 방법 (3쪽)
- 손상법 · 자극법과 기록법 · 뇌 영상기법(CT · MRI · PET · fMRI)

## 2. 손상법 (4쪽) 🔥
- 사람 또는 동물에게 가해진 **뇌 손상**을 통해 관련된 기능을 연구
  - 손상된 뇌 부위 – **행동 평가**를 통해 그 영역의 기능을 추론
- 뇌의 각 영역이 어떤 기능을 수행하며, 특정 행동을 위해 기능들이 어떻게 조합되는가를 밝힘
- ✍️ **필기** — “불안이 꼭 나쁜 것은 아니다.”
- ✍️ **필기** — 쥐 실험 그림 옆: “술 == **전두엽** 역할을 통제” (전두엽에 형광펜)

| ✍️ 시험 | 🤖 무엇인지 (자료에는 사진 · 이름만 있어 일반 지식으로 보충) |
|---|---|
| **피니어스 게이지** | 1848년 철도 공사 중 쇠막대가 머리(왼쪽 **전두엽**)를 관통 → 살아남았지만 **성격이 크게 바뀜** → 전두엽이 성격 · 판단에 관여한다는 증거 |
| **브로카 영역** (← 더 편함) | 왼쪽 **전두엽** — 손상되면 말을 이해는 하지만 **말을 만들어 내기(말하기)**가 어려움 (브로카 실어증) |
| **베르니케 영역** | 왼쪽 **측두엽** — 손상되면 말은 술술 하지만 뜻이 안 통하고 **말을 이해**하기 어려움 (베르니케 실어증) |

- 외우기: **브로카 = 말하기(표현)** · **베르니케 = 이해하기(수용)** · 게이지 = 전두엽 · 성격

## 3. 자극법 (5쪽)
- 뇌를 **미세전극**으로 직접 자극하여 반응을 보고하게 함
- W. Penfield(1959): 통각 수용기가 없는 뇌 조직에 직접 전기자극 → 각 피질 영역의 기능 규명

## 4. 전극 기록법 — EEG (6쪽 · ✍️ 시험 X) · MEG (7쪽)
- **EEG**(electroencephalogram) — ✍️ **시험 X**: 뇌에서 자발적으로 일어나는 뇌전위 변화 측정 · 의식 상태에 따라 다른 모양 · 주기 · 간질 · 종양 등 뇌 손상 · 정신질환 진단 · 주로 **수면 연구**
- **MEG 뇌자도**(magnetoencephalography) — ✍️ **뇌자도 == MEG**
  - 여러 개의 **SQUID** 로 구성된 신경자기기록기가 활동전위 · 시냅스 후 전위에 의해 생기는 **자기장의 변화**를 측정
  - **fMRI 에 비해 시간적 해상도가 높다**는 장점
