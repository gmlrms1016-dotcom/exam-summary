## 2. 🔥 경사하강법 (8 ~ 14쪽)
- 📄 8쪽 **기본 아이디어** — 훈련 세트를 이용한 훈련 과정 중에 **가중치 등과 같은 파라미터를 조금씩 반복적으로 조정** · 조정 기준: **비용 함수의 크기 줄이기** (그림 — 공이 내려가다 작은 골짜기에 멈추고, 더 깊은 곳이 Best!)

| 📄 9쪽 관련 주요 개념 | 뜻 · 예 |
|---|---|
| **최적 학습 모델** | 비용함수를 **최소화**하는 또는 효용함수를 **최대화**하는 파라미터를 사용하는 모델 |
| **파라미터** | 예측값을 생성하는 함수로 구현되는 학습 모델에 사용되는 파라미터 · 예) 선형 회귀 모델의 **편향과 가중치** |
| **비용함수** | 모델이 **얼마나 나쁜지**를 계산해 주는 함수 · 예) 선형 회귀 모델의 **평균 제곱 오차(MSE)** |
| **전역 최솟값** | 비용함수가 가질 수 있는 **최솟값** · 예) MSE 함수가 갖는 최솟값 |

- 📄 `MSE(θ) = (1/m) Σ (θᵀx⁽ⁱ⁾ − y⁽ⁱ⁾)²` (i = 1 ~ m) — ✍️ θᵀx⁽ⁱ⁾ = **예측한 y** · ✍️ **평균 제곱 오차**
  - 🤖 10주차 칠판 `MSE = (1/n) Σ (y − ŷ)²` 와 같은 식 — ŷ 자리에 θᵀx⁽ⁱ⁾(예측값) · n 대신 m(샘플 수) · 빼는 순서가 바뀌어도 **제곱**하니 값은 같음
- 📄 10쪽 **학습률** = 훈련 과정에서의 비용함수 파라미터 **조정 비율**
  - 📄 과정 — θ 를 **임의의 값**으로 지정하고 훈련 시작 → θ 가 지정된 오차 범위 안으로 **수렴할 때까지 반복**: ① (배치 크기로) 지정된 수의 훈련 샘플로 학습 ② 학습 후 MSE(θ) 계산 ③ 이전 θ 에서 **∇θMSE(θ) 와 학습률 η 를 곱한 값 빼기**
- 📄 11쪽 `θ(new) = θ(old) − η · ∇θ MSE(θ(old))` · 그림 = 임의의 초깃값 → 학습 스텝 → 최솟값 θ̂
  - ✍️ “알고리즘은 끝없이 돌아가서 **끝나는 지점을 미리 정해야 함**” · ✍️ η = “**학습률은 양수, 작은 값**”
  - 🤖 끝나는 지점 = 10쪽의 “**지정된 오차 범위 안으로 수렴**”(허용 오차)이나 반복 횟수 상한 · ∇(그레이디언트) = 기울기 → 기울기의 **반대 방향**으로 조금씩 내려감

| 📄 학습률 | 결과 |
|---|---|
| 12쪽 **너무 작으면** | 비용 함수가 전역 최솟값에 **너무 느리게 수렴** |
| 13쪽 **너무 크면** | 비용 함수가 **수렴하지 않음** (🤖 골짜기를 넘나들며 점점 위로) |

- 📄 14쪽 (선형 회귀가 **아닌** 경우) **시작점**에 따라 전역 최솟값에 수렴하지 못할 수도 있음 (🤖 작은 골짜기 = 지역 최솟값에 갇힘 · 8쪽 그림)
- 📄 14쪽 **선형 회귀와 학습률** — 비용함수(MSE)가 **볼록 함수** = **지역 최솟값을 갖지 않음** → 학습률이 너무 크지 않으면 **언젠가는 전역 최솟값에 수렴**

## 3. 특성 스케일링 (15쪽)
- 📄 특성들의 **스케일을 통일**시키면 보다 **빠른 학습**이 이루어짐
  - 📄 그림 왼쪽 = 스케일 통일(동그란 등고선 → 곧장 가운데로) · 오른쪽 = 스케일 다름(길쭉한 타원 → 돌아가서 오래 걸림)
- ✍️ `y = ax + b` → a = θ₁ · b = θ₂ — 그림의 두 축 θ₁ · θ₂ = 찾아야 할 파라미터 두 개
  - 🤖 번호 붙이는 법은 자료마다 달라요 — 10주차 11쪽은 θ₀ = 절편 · θ₁ = 기울기 · 6쪽 코드는 `intercept_`(절편) · `coef_`(기울기)

## 4. 서포트 벡터 머신 SVM (16 ~ 20쪽)
| 📄 용어 | 뜻 |
|---|---|
| **마진**(margin) | 클래스를 구분하는 **도로의 경계** |
| **라지 마진 분류** | **마진 폭을 최대로** 하는 클래스 분류 |
| **서포트 벡터** | 도로의 **양쪽 경계에 위치하는 샘플** (그림의 동그라미) — 서포트 벡터 사이의 간격(도로 폭)이 **최대**가 되도록 학습 |
| **SVM 모델** | 두 클래스로부터 **최대한 멀리 떨어져 있는 결정 경계**를 찾는 분류기 · 목표: 특정 조건을 만족하면서 동시에 클래스를 분류하는 **가능한 넓은 도로**의 결정 경계 찾기 |

- 📄 17쪽 특성 스케일을 조정하면 **결정 경계가 훨씬 좋아짐** (3절과 연결)

| | 📄 하드 마진 분류 (19쪽) | 📄 소프트 마진 분류 (20쪽) |
|---|---|---|
| 뜻 | **모든** 훈련 샘플이 도로 바깥쪽에 올바르게 분류되도록 하는 마진 분류 | 🤖 도로 폭과 마진 오류(도로 안 · 반대편 샘플) 사이에서 균형 |
| 특징 | 훈련 세트가 **선형적으로 구분되는 경우에만** 가능 · **이상치에 민감** | **C** 로 조절 |

- 📄 20쪽 **C** — ✍️ **무조건 양수**(밑줄)이어야 하며 **클수록 마진 오류를 적게** = **도로 폭을 작게** 만듦 · `C=float("inf")` 로 지정하면 **하드 마진** 분류 모델
  - 📄 그림 — **C = 1** 도로가 넓고 마진 오류가 많음 · **C = 100** 도로가 좁고 마진 오류가 적음 (붓꽃 virginica · versicolor · 꽃잎 길이 · 너비)
- ✍️ ✗ 두 줄 — **hinge**(힌지 손실 · 예측값과 실제 라벨 사이의 차이가 클수록 큰 손실) · **`dual=True`**(쌍대성 이용 여부 · 기본 True · 특성 수가 샘플 수보다 작을 때는 False 권장) → 🤖 글 없이 ✗ 만 있어서 수업에서 넘어간 줄로 보여 짧게만
