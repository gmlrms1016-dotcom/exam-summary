### 4장 22쪽 신경전달물질 표 (OX 대비)
| 신경전달물질 | 기능 | 특징 |
|---|---|---|
| 아세틸콜린(Ach) | 뇌에서는 흥분성 / 다른 부위에선 흥분 or 억제성 | 기억 / 운동에 관여 |
| 노르에피네프린 | 각성 조절 담당(아드레날린) | 자율신경계 뉴런에서 주로 발견 · 경계와 각성 상태 조절 |
| 도파민(DA) | 시냅스후 수용기에 따라 흥분성 / 억제성 | 운동 / 주의 / 학습 · 부족 시 **파킨슨병** |
| 세로토닌 | 시냅스후 수용기에 따라 흥분성 / 억제성 | 섭식 / 수면 / 기분 조절 · Prozac(우울증 약)은 세로토닌 재흡수를 막음 |
| GABA | 뇌와 척수에서 주요한 **억제성** | 간질의 주요 원인 중 하나(GABA 뉴런 · 수용기 이상) |
| 글루타메이트 | 뇌와 척수에서 주요한 **흥분성** | GABA 와 함께 최초로 진화한 것으로 추정 · 과도한 방출은 뇌중풍 원인 |

- 4장 22쪽: 대략 **50여 개**의 신경전달물질이 발견 · 노르에피네프린 · 도파민 · 세로토닌 = 모노아민 / GABA · 글루타메이트 = 아미노산

- 📝 **교수님 메모** — 소뇌 - 신체의 운동에 관여

## 신경돌기 · 뉴런 분류 (캡처 원문)
- 📝 **교수님 메모** — 신경돌기: 세포체에서 뻗어나온 가지
- 📝 **교수님 메모** — 뉴런의 연결 위치에 따라 분류

| 뉴런 | 하는 일 |
|---|---|
| 감각뉴런 | 감각 신호를 받음 -> 중추신경계로 전달 |
| 연합뉴런(개재 뉴런, inter neuron) | 뉴런끼리 연결 |
| 운동뉴런 | 근육과 연결 -> 움직임을 만듦 |
