⚠️ 문제지 · 답안지 둘 다 학과 / 학년 / 학번 / 이름 쓰기 · 신분증 또는 학생증 꼭 지참

🎯 강의에서 ★로 강조된 것 — ① 인지과학의 넓은/좁은 의미 ② Donders · Wundt · Watson · Skinner · Tolman 연구 ③ 인지과학 형성 배경(튜링 · 사이버네틱스 · 폰 노이만 · 섀넌) ④ 1956년 인지과학 원년 ⑤ Mind = Computer = Brain ⑥ 인지심리학 3대 접근 ⑦ 🔥 신경전달물질 OX(5주차 필기) ⑧ ★ 뉴런의 기본 구조 — “여기 시험에 나옴”(4장 3쪽 PDF 필기) ⑨ ★ 아교세포 종류 암기(4장 6쪽) ⑩ 🔥 대뇌피질 4개 엽의 기능 — “시험 ★”(5장 18쪽 PDF 필기) ⑪ 뇌의 구조 전뇌 · 후뇌(5장 13쪽)

🔒 실제시험

1주차 — OT (1주차 자세히)

  • ⭐ 강조 — 뇌인지과학 = 인간의 마음(mind)을 과학적으로 연구 · 철학·심리학·신경과학·컴퓨터공학·AI 의 학제적 연결
  • ⭐ 강조 — 평가: 중간 35% + 기말 35% + 학습점검·과제 10% + 출석 20%

2주차 — 인지과학 형성 역사 (2주차 자세히)

인물 · 연도 정리 ★

연도인물핵심
1868Donders최초의 인지심리학 실험 — 반응시간 측정
1879Wundt최초의 심리학 실험실 — 구성주의 · 분석적 내성법
1885Ebbinghaus기억 · 망각 — 절약법 · 망각곡선
1890William James기능주의 — 『심리학의 원리』
—Watson행동주의 · 고전적 조건형성 (외적 행동만 연구)
—Skinner조작적 조건형성 — 강화와 처벌 · Skinner Box
1948Tolman인지도(cognitive map) · 잠재학습
  • ⭐ 강조 — 인지과학 좁은 의미: 마음의 특성을 인지에 두고 인지과정을 과학적으로 연구
  • ✍️ 필기 — 잠재학습: 보상이 없어도 학습은 일어난다 (학습 ≠ 수행)

4주차 — 인지신경과학 1 · 연구 방법 (4주차 자세히)

  • 🔥 ✍️ 필기 — 3장 4쪽 네모 칸 “시험”: 피니어스 게이지(쇠막대 사고 → 전두엽 손상 · 성격 변화) · 브로카(← 더 편함 · 말하기) · 베르니케(이해하기)
  • 손상법: 뇌 손상 → 손상 부위 – 행동 평가로 기능 추론 · 자극법: 미세전극 직접 자극(Penfield)
  • ✍️ 필기 — EEG = 시험 X · 뇌자도 == MEG (SQUID · fMRI 보다 시간적 해상도 높음)

3주차 — 인지과학의 출범 (3주차 자세히)

  • ⚠️ 정정 — PDF 펜 필기: 튜링 · Colossus · 폰 노이만 ‘저장 프로그램’ = “시험 미출제”
  • 🔥 ✍️ 필기 — ★ 섀넌: 릴레이 회로를 불(Boole)식 2진법으로 · “AND gate, OR gate” · ★ Cherry(1953) = 양분 청취 과제 · Miller 7 ± 2 · chunk · “두뇌 == 논리 기계”

형성 배경 · 인지혁명 ★

인물 · 사건핵심
앨런 튜링튜링 자동기계 — 사고 과정의 형식화
N. Wiener인공두뇌학(사이버네틱스) — 두뇌를 전자장치로 대치 가능
폰 노이만저장 프로그램 개념
섀넌불(Boole) 2진법 · 정보이론
Broadbent(1958)주의 여과기(필터) 모형
Chomsky언어는 생득적 프로그램으로 결정 (Skinner 와 논쟁)
1956년인지과학의 원년 — AI 용어 최초 사용 · Miller '마법의 숫자 7'
  • ⭐ 강조 — 인지주의 핵심 가정: Mind = Computer = Brain (정보처리체계 · IPS)
  • ⭐ 강조 — 인지심리학 3대 접근: ① 실험인지적(심리시간분석법 · Stroop Task) ② 신경인지적(손상연구 · EEG·ERP · CT·MRI·PET·fMRI) ③ 계산적(컴퓨터 시뮬레이션)

6주차 — 인지신경과학 3 · 약물 · 신경계의 구성 (6주차 자세히)

🔥 대뇌피질 4개 엽 (✍️ 5장 18쪽 “시험 ★”)

엽하는 일위치
전두엽복잡한 과제 처리 (계획, 실행 다양한 기능)앞
두정엽감각 / 주의위
측두엽언어 / 청각옆
후두엽시각 정보 처리뒤
  • 대뇌피질 = 인간이 신체 대비 가장 큼 · 두께 3mm · 총 6개 층 · 회백질 = 세포체 / 백질 = 축색 · 구(작은 홈) / 열(큰 홈) / 회(융기부)

뇌의 구조 (✍️ 13쪽 전뇌 · 후뇌 ○ · 중뇌 X)

구분속하는 것
전뇌시상(감각정보 → 대뇌피질) · 시상하부(욕구 · 자율신경 · 호르몬) · 변연계(편도체 = 정서 · 해마 = 학습과 기억) · 기저핵(느리고 순차적인 운동) · 대뇌피질
후뇌연수(생명 유지) · 뇌교(수면 · 각성) · 소뇌(움직임 협응)

약물 (✍️ 3쪽 · 4쪽)

  • 사회적 약물 = 카페인 · 알코올 · 니코틴 같은 합법적 물질 · 사회적 차원 · ✍️ ○ 인지수행에도 큰 영향
  • ✍️ 범위 아님 — 불법적 약물(3쪽 X) · 중독(4쪽 “시험X”) · 카페인 부정/긍정 설명(5쪽 X) · 뇌와 컴퓨터 비교표(22쪽 X)

5주차 — 인지신경과학 2 · 뉴런 (5주차 자세히)

  • ✍️ 필기 — 🔥 신경전달물질에 OX로 나올 수 있음
  • 📝 교수님 메모 — 크기가 큰 신경전달물질 = 세포체에서 합성 · 작은 아세틸콜린 = 축색 종말에서 합성
  • 📝 교수님 메모 — 뉴런이 반으로 잘리면 세포체 없는 쪽 사망(핵이 없어 단백질을 못 만듦)
  • 📝 교수님 메모 — 축색 종말: 둥글게 부풀어 있고 다른 뉴런의 수상돌기·세포체와 접촉 = 시냅스
  • 📝 교수님 메모 — 퍼킨제 세포: 소뇌 피질 · 운동 관여 · 생후 1년이면 성인 수준(신경가소성)
  • 📝 교수님 메모 — 감각뉴런(→ 중추신경계) · 연합뉴런(개재 뉴런 · 뉴런끼리) · 운동뉴런(근육 → 움직임)

✍️ PDF 필기 (Apple Pencil) — 시험 표시

  • ⭐ 강조 — 4장 3쪽 ★ “여기 시험에 나옴”: 세포체(생명 유지 · 정보처리 통합) · 수상돌기(정보 받음) · 축색(다른 뉴런 · 근육 · 내분비선에 전달) · 시냅스 · 축색 종말(terminal button) · 신경전달물질
