5. 하비거스트 — 발달과업 이론 ★핵심2주차

⭐ 발달과업(developmental tasks) — 각 시기마다 반드시 성취해야 할 과제. 달성하면 행복·다음 단계 성공, 실패하면 불행·사회적 어려움
시기발달과업
유아기
(초등 입학 전)		걸음마·언어·배설훈련·단순 개념 형성 (부모와의 안정적 애착 중요)
아동기
(초등)		또래 관계·성 역할·읽기쓰기셈하기·양심과 도덕성 형성
청소년기
(중·고)		인간관계·정서적 독립·직업 선택 준비·시민 자질 (정체성 형성의 핵심 시기)
청년기
(20~35)		배우자 선택·가정 형성·직장생활 시작 (친밀감 대 고립감)
중년기
(36~60)		사회적 책임·경제생활·자녀와 노부모 부양 (생산성 대 침체감)
노년기
(61~)		체력·은퇴·배우자 죽음에 적응 (자아통합 대 절망)
⭐ 성장과업의 세 원천 — 신체적 성숙 / 개인적 가치와 열망 / 사회적 압력에 대응하는 힘
✍️ 한계점 — '누가 그 과업을 정하는가?' · '과업을 수행하지 않으면 발달하지 못한 사람인가?'

6. 프로이트 — 심리성적 발달 이론 ★핵심2주차

성격의 3체제원리
원본능 (id)쾌락원리
자아 (ego)현실 통제
초자아 (super ego)사회규범 내면화
⭐ 심리성적 발달단계 — 구강기 → 항문기 → 남근기 → 잠복기 → 생식기
✍️ 고착(fixation) — 각 단계에서 욕구가 지나치게 충족·억압되면 갈등이 해결되지 않고 이후 성격에 영향
구분내용
의의무의식(억압·갈등·방어기제) 발견, 인생 초기(특히 5세 이전) 경험의 중요성 강조
비판 ✍️성적·공격적 욕구 과도 강조 · 인간을 과거에 의해 결정된 존재로 봄 · 과학적 검증 어려움
신프로이트 학파에릭슨·아들러 — 성적 본능보다 사회·문화적 요인을 더 강조

7. 매슬로 — 욕구위계 이론 ★핵심2주차

⭐ 성장 = '가능성을 실현하는 과정' — 인간을 성장 지향적 존재로 봄
욕구 (아래 → 위)예
① 생리적음식 · 물 · 수면
② 안전신체 · 경제적 안정
③ 애정과 소속가족 · 친구 · 사랑
④ 존경자존감 · 성취 · 인정
⑤ 자아실현잠재력 · 창의성 · 도덕성
✍️ 필기 — 하위 욕구가 충족되어야 상위로 나아가지만, 현실에서는 여러 욕구가 동시에 작용(동적 맥락) · 의의: 인간을 '가능성을 가진 능동적 존재'로 봄, 경영·교육·상담에 널리 응용

8. 세 이론 한 줄 요약 · 라슬렛 인생 4주기론2주차

학자한 줄 요약 ★ (19쪽 별표)
하비거스트"인생의 각 시기에는 해내야 할 과제가 있다."
프로이트"어린 시절 욕구와 갈등을 어떻게 해결했는지가 이후의 성격을 만든다."
매슬로"인간은 기본적 욕구를 넘어 자기다운 가능성을 실현하려는 존재다."

[참고] 피터 라슬렛 — 인생 4주기론

연령기특징
제1연령기 (학습)출생~20대 초 · 타인에 의존하며 사회화·교육으로 성장
제2연령기 (책임)20대 후반~50대 후 · 직업·가정·사회적 책임 (가장 바쁜 시기)
제3연령기 (자아실현) ★50대 후~70·80대 초 · 은퇴 후에도 자아실현 추구 = 활동적 은퇴 / 액티브 시니어
제4연령기 (의존)80대 중후반~ · 다시 타인에 의존, 삶을 갈무리하고 죽음을 준비

객관식

1토론과 토의에 대한 설명으로 옳은 것은?

정답 B — 토론 = 찬반 설득·논쟁 / 토의 = 문제 해결·합의 도출(협력적) (1주차)

2토론 기본절차의 순서로 옳은 것은?

정답 B — 주제 이해 → 생각 정리 → 주장 펼치기 → 경청과 비판 → 합의점 탐색 → 대안과 전망

3'배워서 남 주는 수업'의 3대 학습 목표가 아닌 것은?

정답 D — 3대 학습 목표 = 배려의 철학 이해 · 논리적 사고 표현 · 배려윤리 체득. 이 과목은 경쟁·효율의 논리 대신 협력·배려·포용을 강조합니다.

4토론을 강조한 철학자와 핵심의 연결이 틀린 것은?

정답 C — 칸트는 보편적 도덕법칙, 의사소통적 합리성은 하버마스입니다.

5이 과목의 시험 형식으로 옳은 것은?

정답 B — 평가: 출석 20% + 중간 20% + 기말 20% + 과제·참여도 30%+10% · 시험은 객관식+단답형+서술형 (1주차)

6하비거스트의 발달과업에 대한 설명으로 옳은 것은?

정답 B — B 하비거스트 / A 프로이트 / C 매슬로 / D 라슬렛

7프로이트 성격의 3체제 중 쾌락원리를 따르는 것은?

정답 A — 원본능 = 쾌락원리 · 자아 = 현실 통제 · 초자아 = 사회규범 내면화

8프로이트의 심리성적 발달단계 순서로 옳은 것은?

정답 C — 구강기 → 항문기 → 남근기 → 잠복기 → 생식기

9매슬로 욕구 피라미드를 아래에서 위로 바르게 나열한 것은?

정답 A — 생리적 → 안전 → 애정과 소속 → 존경 → 자아실현 (D 는 위에서 아래 순서)

10라슬렛 인생 4주기론에서 '활동적 은퇴 · 액티브 시니어'에 해당하는 시기는?

정답 C — 제3연령기(자아실현, 50대 후~70·80대 초) — 은퇴 후에도 자아실현 추구
