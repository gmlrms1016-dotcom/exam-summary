2. 자바의 태동과 WORA ★핵심2주차

기계어(0·1) → 어셈블리어(니모닉) → 고급언어(C/C++, Java, C#) 순으로 발전했습니다.

시기내용
1991선마이크로시스템즈 제임스 고슬링의 그린 프로젝트 (초기명 오크 OAK)
1995자바 발표 · 목적은 플랫폼 독립성
2009오라클이 선마이크로시스템즈 인수
WORA (Write Once Run Anywhere) — 한 번 작성한 코드가 모든 플랫폼에서 실행
용어설명
바이트코드 (byte code)자바 소스를 컴파일한 CPU 중립적 목적코드 · .class 에 저장
JVM (Java Virtual Machine)바이트코드를 인터프리터 방식으로 해석·실행하는 가상기계
⚠️ JVM 자체는 플랫폼에 종속적(OS마다 별도 제공)이지만, 바이트코드는 플랫폼 독립적입니다.
컴파일: 자바 .java → .class / C .c → .obj → .exe

17. while 실습 — -1 이 나올 때까지 평균 (예제 3-2)5주차

📂 5주차 (9/22) — 수업은 4주차 강의자료 3장을 이어서 진행했고, 수업 중 작성한 소스 WhileSample · NestedLoop · ContinueExample · BreakExample · ArrayAccess · ForEx1~3 로 정리했어요 (노션 필기: “5주차 수업이지만 4주차 강의자료인 3장을 진도 나갔음”). 코드 주석과 ▶ 실행 화면은 전부 직접 컴파일·실행한 결과예요.
// WhileSample.java (예제 3-2) — -1 이 입력될 때까지 정수를 받아 평균 구하기
import java.util.Scanner;

public class WhileSample {
    public static void main(String[] args) {
        int count = 0;                  // 입력된 정수의 개수
        int sum = 0;                    // 합
        Scanner sc = new Scanner(System.in);
        System.out.println("정수를 입력하고 마지막에 -1을 입력하세요.");

        int n = sc.nextInt();           // 첫 번째 수는 반복 전에 먼저 받는다
        while (n != -1) {               // -1 이 아니면 계속 반복
            sum += n;
            count++;
            n = sc.nextInt();           // 다음 수 → 다시 조건 검사
        }

        if (count == 0) {               // 처음부터 -1 이면 0 으로 나누게 되므로 따로 처리
            System.out.println("입력된 수가 없습니다.");
        } else {
            System.out.print("정수의 개수는 " + count + "개이며 ");
            System.out.println("평균은 " + (double) sum / count + "입니다.");   // 실수 나눗셈
        }
        sc.close();
    }
}

예제 3-5 ContinueExample — 양수만 더하기

// ContinueExample.java (예제 3-5) — continue 로 양수만 더하기
import java.util.Scanner;

public class ContinueExample {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.println("정수를 5개 입력하세요.");
        int sum = 0;
        for (int i = 0; i < 5; i++) {
            int n = sc.nextInt();
            if (n <= 0) {
                continue;               // 0 이하면 아래를 건너뛰고 다음 반복으로
            } else {
                sum += n;               // 양수만 더한다
            }
        }
        System.out.println("양수의 합은 " + sum);
        sc.close();
    }
}
정수를 5개 입력하세요.
5 -2 6 10 -4
양수의 합은 21
-2 와 -4 는 continue 로 건너뛰어서 5 + 6 + 10 = 21

예제 3-6 BreakExample — exit 입력 시 종료

// BreakExample.java (예제 3-6) — "exit" 이 입력되면 break 로 while 을 빠져나간다
import java.util.Scanner;

public class BreakExample {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.println("exit을 입력하면 종료합니다.");
        while (true) {                  // 조건이 항상 true → break 로만 빠져나올 수 있다
            System.out.print(">>");
            String text = sc.nextLine();
            if (text.equals("exit")) {  // 문자열 비교는 == 가 아니라 equals()
                break;                  // while 문 하나를 완전히 벗어남
            }
        }
        System.out.println("종료합니다...");
        sc.close();
    }
}
exit을 입력하면 종료합니다.

>>java
>>exit

⚠️ while (true) 는 조건이 항상 참이라 break 가 없으면 무한 반복 · 문자열 비교는 text.equals("exit") (== 아님)

1강제 형변환 (int) · (byte)3주차 · 타입 변환

public class TypeConversion {
    public static void main(String[] args) {
        System.out.println((int)2.9 + 1.8);
        System.out.println((int)(2.9 + 1.8));
        System.out.println((int)2.9 + (int)1.8);

        byte b = 127;
        int i = 100;
        System.out.println(b + i);
        System.out.println((byte)(b + i));
    }
}
💡 풀이 — (int)2.9 = 2 → 2 + 1.8 = 3.8 · (int)(4.7) = 4 · 2 + 1 = 3 · byte + int 는 int 로 계산 → 227 · byte(-128~127) 로 강제 변환하면 넘쳐서 -29 (데이터 손실)

2try · catch · finally 실행 순서4주차 · 예외 처리

public class DivideByZero {
    public static void main(String[] args) {
        int dividend = 10, divisor = 0;
        try {
            System.out.println("나누기 시작");
            System.out.println("몫은 " + dividend / divisor);
            System.out.println("여기는 실행될까?");
        } catch (ArithmeticException e) {
            System.out.println("0으로 나눌 수 없습니다!");
        } finally {
            System.out.println("나눗셈 끝");
        }
    }
}
💡 풀이 — 0 으로 나누는 순간 ArithmeticException → try 의 나머지 줄은 건너뛰고 catch 로 · finally 는 예외가 있든 없든 항상 실행

15양수만 더하기 (배열)5주차 · continue

public class PositiveSum {
    public static void main(String[] args) {
        int[] nums = {5, -2, 6, 10, -4};
        int sum = 0;
        for (int i = 0; i < 5; i++) {
            if (nums[i] <= 0) {
                continue;
            }
            sum += nums[i];
            System.out.println("더함: " + nums[i]);
        }
        System.out.println("양수의 합은 " + sum);
    }
}
💡 풀이 — 0 이하(-2, -4)일 때 continue 가 아래 두 줄을 건너뛰고 다음 반복으로 → 5 + 6 + 10 = 21 (예제 3-5 와 같은 값)
