1. 강의 안내

  • 담당: 김희숙 교수 · 카카오 오픈채팅(본인 한글이름으로 변경)
  • ⭐ 강조 — 교재: 'SQL과 NoSQL 기반의 데이터베이스 입문', 박성진 저, 생능출판사, 2023.2
  • ⭐ 강조 — 평가: 출석 20% + 중간 30% + 기말 30% + 과제 20% (결석 4회 F, 지각 3회=결석 1회)
  • ✍️ 필기 — 프로그램: MySQL 8.0, MongoDB — 설치 시 사용자 계정은 반드시 영문(한글 금지)

2. 데이터베이스 개념 ★핵심

  • ⭐ 강조 — 데이터베이스: 한 조직의 여러 응용시스템이 데이터를 공유할 수 있도록 통합·저장한 운영 데이터의 집합체
  • 테이블(릴레이션): 행과 열로 구성된 2차원 표 형태 (예: 학생(번호,이름,학년,분반,학과번호))

3. 첫 SQL 실습

-- 데이터 조회
select * from 학생;                  -- 학생 테이블의 모든 열 · 모든 행
select 이름, 성적 from 학생;             -- 이름 · 성적 두 열만
select * from 학생 where 이름='kim';   -- 이름이 'kim' 인 행만 (MySQL 기본 설정은 대소문자 구별 X → Kim 도 나옴)
  • 윈도우 화면 캡처 단축키: 윈도우 + Shift + S
  • 예제 DB: testdb (Charset: utf8mb4)
