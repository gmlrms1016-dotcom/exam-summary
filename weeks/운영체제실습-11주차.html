5. 🔥 LVM 개념 (📖 6장 462 ~ 464쪽 · ✍️ “실습은 안 하지만 시험에 개념은 출제함”)

  • 📖 LVM(Logical Volume Manager) = ‘논리 디스크 관리자’ · 앞에서 배운 Linear RAID 와 비슷한 기본 기능 + 더 많은 기능 · Rocky Linux 는 기본적으로 LVM 으로 디스크를 분할해 설치
  • 📖 NOTE — Server · Server(B) 는 LVM 없이 표준 파티션 · Client 는 파티션 구성 기본값 LVM 으로 설치
  • 📖 쓰임 — 여러 디스크를 합쳐 1개의 파티션으로 구성한 뒤 필요에 따라 다시 나눠야 할 때 · 예) 2TB 디스크 2개를 합친 뒤 1TB 와 3TB 로 나눔 · 디스크 1개로도 LVM 구성 가능
📖 용어 3가지뜻
물리 볼륨 (Physical Volume)/dev/sda1 · /dev/sdb1 등의 파티션
볼륨 그룹 (Volume Group)물리 볼륨을 합쳐서 1개의 물리 그룹으로 만든 것
논리 볼륨 (Logical Volume)볼륨 그룹을 1개 이상으로 나눈 것 · 논리적 그룹이라고도 함
  • 📖 그림 6-113 — 물리 볼륨 2TB(/dev/sdb) + 3TB(/dev/sdc) → 5TB 볼륨 그룹 → 1TB · 3TB · 1TB 로 나눠 /lvm1 · /lvm2 · /lvm3 에 마운트
  • 📖 결국 LVM = 여러 디스크(물리 볼륨)를 묶어 1개의 볼륨 그룹으로 만든 뒤 다시 필요한 용량의 파티션(논리 그룹)으로 나눠 쓰는 방식
  • 📖 그림 6-114 구현 순서 — fdisk(타입 LVM) → pvcreate(/dev/sdb1 · /dev/sdc1) → vgcreate(/dev/myVG) → lvcreate(/dev/myVG/myLG1 ~ 3) → mkfs.ext4 → mount → /etc/fstab 등록 → reboot
  • 🤖 RAID 와 차이 — RAID = 속도 · 결함 허용(미러링 · 패리티)이 목적 · LVM = 용량을 묶었다가 원하는 크기로 나누는 유연한 관리가 목적

6. 트러블슈팅 (학교 PC 기록 · 노션)

  • dnf 가 404 · 느림 → Rocky 10.0 저장소가 vault 로 옮겨져서 · 기다리기 · 안 되면 dnf clean all 뒤 다시 · 그래도 안 되면 dnf --releasever=10 -y install …
  • ipconfig → 명령을 찾을 수 없습니다 → 리눅스는 ifconfig
  • 텔넷 login: timed out after 60 seconds → 다시 telnet 192.168.111.200 하고 바로 로그인
  • 텔넷에 ^T^E^L 같은 글자 → Ctrl 이 눌린 상태 · Ctrl 을 한 번 눌렀다 떼고 다시
  • superuser privileges 오류 → root 가 아님 (프롬프트 끝이 # 인지) · Client 는 sudo
  • 원격 데스크톱이 바로 닫힘 → Client 화면 로그아웃 · 비밀번호 · 한/영 · Client 가 켜져 있는지

8. 🔥 시험 대비 핵심 요약

  1. 텔넷 서버 = dnf -y install telnet-server → adduser · passwd → 방화벽 → systemctl start telnet.socket → status = active (listening) · Listen: [::]:23
  2. 글자 화면 방화벽 = firewall-cmd --permanent --add-service=telnet + firewall-cmd --reload (그래픽 = firewall-config) · 🤖 --permanent 가 없으면 재부팅하면 사라짐
  3. 포트 — 텔넷 23 · RDP 3389 · 🤖 SSH 22
  4. Windows 에서 — 텔넷 = PowerShell telnet 192.168.111.200 (60초 안에 로그인) · 원격 데스크톱 = mstsc
  5. XRDP = rpm 3개(tigervnc-license · tigervnc-server-minimal · xrdp) → epel-release → dnf -y install tiger*.rpm xrdp*.rpm → systemctl start · enable xrdp → 3389 허용 → rocky 로 로그인
  6. 🔥 LVM = 논리 디스크 관리자 · 물리 볼륨(파티션) → 볼륨 그룹(합침) → 논리 볼륨(나눔) · Rocky Linux 기본 설치 = LVM (Server · Server(B) = 표준 파티션 · Client = LVM)
  7. LVM 순서 — fdisk(LVM) → pvcreate → vgcreate → lvcreate → mkfs.ext4 → mount → /etc/fstab
