자료: 명령어 정리 스크립트(txt)

1. 기본 정보 및 시스템 탐색

  • ⭐ 강조 — whoami(사용자명) · pwd(절대경로) · tree(디렉토리 트리, tree / -L 4 로 깊이 제한)
  • ⭐ 강조 — ls(목록) · ls -l(상세) · ls -al(숨김 포함) · ls -i(inode 번호)

2. 디렉토리 이동 (cd)

  • ⭐ 강조 — cd .. (상위) · cd /home (절대경로) · cd rocky (상대경로) · cd ~ (홈 디렉토리)

3. 디렉토리 생성·삭제

  • ⭐ 강조 — mkdir 이름 (생성) · mkdir a b c (여러 개) · mkdir -p a/b/c (상위까지 계층 생성)
  • ⭐ 강조 — rmdir 이름 (빈 디렉토리 삭제) · rmdir -p a/b/c (계층적 빈 디렉토리 삭제)
  • ✍️ 필기 — rm -rf 이름 : 비어있지 않은 디렉토리도 강제 삭제 (주의! 되돌릴 수 없음)

4. 시스템 종료

  • ⭐ 강조 — poweroff : 시스템 종료 및 전원 차단
