7주차 — 🔥 switch · 얕은/깊은 복사 · spread · Rest · BOM (7주차 자세히)

  • 🔥 ✍️ 필기 — 코드 문법(손코딩) · 용어는 객관식 출제 예정 · switch 문 시험에 나옴 → switch (day.getDay()) · getDay() 는 0 = 일요일 ~ 6 = 토 · break 가 없으면 아래 case 까지 실행
  • 🔥 얕은 복사 let o2 = o1; → 주소만 복사, 같은 객체 → o1 === o2 true / 깊은 복사 let o4 = {...o3}; → 새 객체 → o3 === o4 false / JSON.stringify(o3) === JSON.stringify(o4) → true (문자열로 내용 비교)
  • 🔥 BOM “성격이 다른 것은?” — window · screen · location · history · navigator → 🤖 window(최상위 객체 · 나머지 4개는 window 의 하위 객체)
  • 🔥 매개변수 빈칸 (claude야 시험문제로) — function funcA( a1, a2, a3 ) · funcA(arrayObj) → [ 1, '둘', true ] · undefined · undefined / funcA(...arrayObj) → 1 · 둘 · true
  • spread ... = 배열 · 객체의 값을 개별로 흩뿌림 ([...arr, 4] · {...obj, c:true} · f(...arr)) / Rest function f(a1, ...a2) = 나머지 인수를 배열로 모음
  • 구조분해 할당 뜻 (✍️) — 안의 데이터를 넣거나 빼려면 방 번호(index, 0 부터) 로 대괄호 접근 → let [a1, a2, a3] = arr; (순서) · let {b, a} = obj; (key 이름)
  • 객체 만들기: new Object() · 리터럴 {} (✍️ 대부분 사용) · new Date() — ✍️ “object 를 생성할 때 new” · truthy/falsy: if (!name) 가 undefined · null · "" 를 한 번에 막음 · 내장객체는 수업에 나온 것만 출제 (Object · Date · JSON)

6주차 — 비동기 · 타이머 · 구조분해 할당 · DOM (6주차 자세히)

  • 🔥 시험문제 — 매개변수 구조분해 "여기서 중괄호를 빼면 출력되는 결과" (0929_04.js)
let person = { name: "윤희근", age: 23, hobby: "테니스" };   // 넘겨줄 객체
const func = ({ name, age, hobby, extra }) => {   // { } 로 받으면 넘겨받은 객체에서 같은 이름의 속성을 꺼냄
    console.log(name, age, hobby, extra);          // name · age · hobby 는 person 에서 · extra 는 없음 → undefined
}                                               // func 함수 끝 → 호출한 곳으로 돌아감
func(person);   // { } 로 받아 같은 이름의 속성을 꺼냄 → name=윤희근 · age=23 · hobby=테니스 · extra 없음 → 윤희근 23 테니스 undefined
// 중괄호를 빼고 (name, age, hobby, extra) 로 받으면
// → { name: '윤희근', age: 23, hobby: '테니스' } undefined undefined undefined
  • 🔥 시험 예고 — "new Date() 에 2026-01-01을 쓰면 출력결과는?(시험에 나올 수 있음)" → 따옴표 없이 2026-01-01 은 빼기라 2024 → new Date(2024) = 1970. 1. 1. · 오전 9:00:02 / 따옴표 "2026-01-01" 이면 2026. 1. 1. · 오전 9:00:00 · 날짜가 고정돼서 1초마다 같은 줄이 계속 찍히고 clearInterval 은 실행되지 않음
  • ✍️ 필기 — 동기화 = 클라이언트에서 백엔드까지 답이 오기까지 아무것도 못 하는 것 · setTimeout 은 비동기화로 선언되는 내장함수 → console.log("시작"); setTimeout(…, 3000); console.log("끝"); 은 시작 → 끝 → (3초 뒤) 콜백
  • setTimeout(함수, 시간, 인수…) 한 번 실행 · clearTimeout(번호) 취소 / setInterval(함수, 시간) 반복 실행 · clearInterval(번호) 멈춤
  • ✍️ 필기 — 구조분해 할당: 배열은 index 번호(순서) 로 짝 → 남는 a4 는 error 가 아니라 undefined · 객체는 이름으로 짝 → age: myAge 는 age 값을 myAge 에 담음(출력도 myAge) · school = "동양미래대학교" 는 기본값
  • DOM: getElementsByTagName("body") 는 목록 → box[0] · getElementById("box") 는 요소 하나 · setAttribute("class", "boxRed") 로 class 를 바꿔 CSS 적용

5주차 — 함수 · 콜백 · 객체 · 배열 (5주차 자세히)

  • 🔥 시험문제 — "문제가 생기는 코드 라인을 찍어주시오" (0922_01.js)
console.log(imsi);            // ← 문제가 생기는 줄 (ReferenceError: let 선언 전에 사용)
let imsi;                           // let 선언은 여기 — 위 줄에서 먼저 쓰면 ReferenceError (TDZ)
console.log(getArea(5, 5));   // 문제없음 — 선언적 함수는 호이스팅
function getArea(width, height) {   // 선언적 함수 (호이스팅 → 위에서 불러도 됨)
    let area = width * height;      // 넓이 = 가로 × 세로
    return area;                    // 계산한 넓이를 돌려줌
}                                   // getArea 함수 끝 → 호출한 곳으로 돌아감
  • ⭐ 강조 — 호이스팅: 선언적 함수는 선언이 맨 위로 끌어올려진 것처럼 동작 → 선언보다 먼저 호출 가능 · let 변수와 let 에 담은 익명 함수는 선언 전에 쓰면 ReferenceError
  • ⭐ 강조 — 콜백 함수 = 다른 함수에 인자로 전달되어서, 나중에 실행되는 함수 · 넘길 때는 괄호 없이 call2(call1) (call1() 은 실행 결과)
  • 객체: 리터럴 {} · 점 표기법 person.name / 대괄호 person["age"] · 속성 추가 person.job = … · 삭제 delete · const 객체는 통째로 재대입 X, 속성 추가·수정 O
  • 배열: 리터럴 [] · 번지는 0 부터 · arr.length = 요소 개수

  • ⭐ 강조 — Node.js = 자바스크립트를 브라우저 밖에서도 단독으로 실행할 수 있게 해 주는 런타임 실행 플랫폼 (주관식)

  • 📝 교수님 메모 — 연산자 9가지: 대입 / 산술 / 복합 대입 / 증감 / 논리 / 비교 / null 병합 / typeof / 삼항
  • ⭐ 강조 — 전위 ++num8 먼저 증가 후 사용 / 후위 num8++ 먼저 사용 후 증가 → let num8 = 10; console.log(num8++); 은 10, 이어서 console.log(++num8); 은 12
  • ⭐ 강조 — == 형변환 후 값만 비교("10" == 10 → true) / === 값과 타입 모두 비교("10" === 10 → false)
  • 📝 교수님 메모 — Truthy와 Falsy: 참·거짓이 아닌 값도 조건문 안에서는 참 또는 거짓으로 판단되는 값 · 단락평가: && ||
  • ⭐ 강조 — falsy 8가지: false 0 -0 0n "" null undefined NaN (나머지는 모두 truthy, "0" [] {} 도 truthy)
  • ⭐ 강조 — A || B: A 가 falsy 면 B / A && B: A 가 truthy 면 B · & 는 비트 연산자라 양쪽을 모두 계산
  • ?? 는 왼쪽이 null·undefined 일 때만 오른쪽 (0 ?? 5 → 0) · typeof true → "boolean" · 삼항 조건 ? 참 : 거짓
  • 형변환: 10 + "20" → "1020" · Number("10") + 20 → 30 · prompt() 값은 항상 문자열
  • querySelector("#id") 는 CSS 선택자로 첫 요소 선택 · id = JS / class = CSS / name = 백엔드
  • 매개변수 = 함수 정의 때 괄호 안 변수 / 인수 = 호출 때 넘기는 값

    • 어테치먼트(Attachment) = DOM 트리의 요소마다 CSS 스타일 규칙을 붙이는(결합) 단계 → 그 결과가 렌더트리 · 4단계에서 “CSS 와 결합해 렌더 트리”라고 한 부분이 바로 이 단계
    • 4단계와 6단계는 같은 순서 — 6단계는 DOM 트리 앞(파서)과 렌더트리 앞(어테치먼트)에 이름을 붙여 더 잘게 나눈 것
  • ✍️ 필기 — 리플로우 = 레이아웃(크기·배치) 다시 계산 / 리페인트 = 색상·모양 다시 그리기
  • ⭐ 강조 — 이벤트 4요소: 이벤트 · 이벤트 소스 · 이벤트 핸들러(=리스너) · 이벤트 객체
  • ⭐ 강조 — 함수 선언 3가지: ① 선언적 함수 ② 표현적(익명) 함수 ③ 화살표 함수
  • ⭐ 강조 — 객체 구성요소 = 속성(변수) + 메서드(함수) · 붕어빵틀 = 클래스 / 붕어빵 = 객체

1주차 — 웹 개요 (1주차 자세히)

  • ✍️ 필기 — 프런트엔드 = 클라이언트(브라우저)에서 실행 / 백엔드 = 서버에서 실행
  • 정적 콘텐츠 = 변하지 않음 / 동적 콘텐츠 = 서버에서 만들어 변함 · ⭐ MPA(여러 페이지) vs SPA(단일 페이지)
  • ⭐ 강조 — 웹페이지 3요소: HTML = 구조·내용 / CSS = 모양 / JS = 동작
  • ⭐ 강조 — 렌더링 엔진 = HTML·CSS 파싱해 화면 표시 / 자바스크립트 해석기 = JS 해석·실행
  • ⭐ 강조 — Node.js 등장으로 서버도 JS 로 개발 · 설치 3종: Chrome / VS Code / Node.js
