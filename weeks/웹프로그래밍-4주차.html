1. 복습: Node.js ★시험(주관식)

  • ⭐ 강조 — Node.js = 자바스크립트를 브라우저 밖에서도 단독으로 실행할 수 있게 해 주는 런타임(실행 환경)
  • ✍️ 필기 — JS 로 할 수 있는 일이 많다: 웹 클라이언트 · 서버(Node.js) · 모바일 앱 · 데스크톱 앱 등
  • ✍️ 필기 정정 — TypeScript = JS 에 타입(정적 타입 검사)을 추가한 언어(JS 의 상위 집합). Next.js 는 TypeScript 의 "다음 단계"가 아니라 React 기반 웹 프레임워크(TypeScript 와 함께 자주 쓰일 뿐)

3. 변수 · 상수 · 이름 규칙

  • ✍️ 필기 — 변수를 선언만 하고 값을 넣지 않으면 undefined, 값이 없음을 일부러 표시하고 싶으면 null 을 대입
  • 이름 규칙: $ · _ 외의 기호 금지 / 숫자로 시작 금지 / 키워드 금지
  • ✍️ 필기 — 관례: 상수는 모두 대문자(const PI = 3.14;) · 변수·객체 이름은 소문자로 시작(카멜 표기법 myName)
  • var 는 같은 이름으로 다시 선언 가능(var tel2 = 20; var tel2 = 30;) · let 은 재선언 불가

4. 자료형 보충

  • Number: 정수·실수·음수 모두 number · Infinity / -Infinity · 계산할 수 없으면 NaN (10 * "hi" → NaN)
  • String: 백틱(템플릿 리터럴) 안에 ${변수} 를 넣으면 값이 들어간 문자열이 된다
  • Boolean true / false · Null null · Undefined: let none; console.log(none); → undefined 출력
  • ✍️ 필기 — 시스템(브라우저·JS)이 미리 만들어 제공하는 객체 = 내장 객체 (예: document · window · Math · Date)

5. 형변환(캐스팅) ★필수암기

  • ✍️ 필기 정정 — 문자열 + 숫자는 덧셈이 아니라 숫자가 문자열로 바뀌어 이어 붙는다: 10 + "20" → "1020"
연산결과설명
"10" + "20""1020"문자열 + 문자열 → 이어 붙이기
10 + "20""1020"문자열 + 숫자 → 숫자가 문자열로 묵시적 형변환 후 이어 붙이기
10 + 2030숫자 + 숫자 → 덧셈
Number("10") + 2030명시적 형변환 후 덧셈
  • 명시적 형변환 함수: Number("10") → 10 · parseInt("10개") → 10 (숫자로 시작하는 부분만, parseInt("hi10개") → NaN) · String(20) → "20"
  • ⭐ 강조 — prompt() 로 받은 값은 항상 문자열 → 그냥 더하면 "3" + "4" → 34, Number() 로 바꿔야 7
// 0915_01.html — 두 수를 입력받아 더하기
let num1 = window.prompt("첫번째 피연산자 입력!");
let num2 = window.prompt("두번째 피연산자 입력!");
let resultObj = document.querySelector("#result");
resultObj.innerHTML = num1 + num2;                   // 3, 4 입력 → 34 (문자열 연결)
resultObj.innerHTML = Number(num1) + Number(num2);   // → 7
resultObj.innerHTML = `결과값은 ${Number(num1) + Number(num2)}`;   // 백틱(템플릿 리터럴)

6. 요소 선택과 속성 쓰임새

  • ✍️ 필기 — 기존에 배운 것 document.getElementById("result") → 이번에 배운 것 document.querySelector("#result")
  • querySelector() 는 CSS 선택자(#아이디 · .클래스 · 태그)로 첫 번째 요소를 찾는다
  • ✍️ 필기 — id → JS 에서 요소 하나를 선택할 때 / class → CSS 로 여러 요소를 꾸밀 때 / name → 백엔드(서버) 로 폼 값을 보낼 때의 이름표
  • ✍️ 필기 정정 — 리플로우(Reflow) = 레이아웃(크기·위치)을 다시 계산 / 리페인트(Repaint) = 색상 등 화면을 다시 그리기

  • 📝 교수님 메모 — 연산자 : 대입 연산자 / 산술 연산자 / 복합 대입 연산자 / 증감 연산자 / 논리 연산자 / 비교 연산자 / null 병합 연산자 / typeof 연산자 / 삼항 연산자

8. 증감 연산자: 전위 vs 후위 ★시험

  • ⭐ 강조 — 전위 ++num8: 먼저 1 증가 → 증가된 값을 사용 / 후위 num8++: 현재 값을 먼저 사용 → 그다음 1 증가
let num8 = 10;
console.log(num8++);   // 10 출력 (출력한 뒤 num8 은 11)
console.log(++num8);   // 12 출력 (11 → 12 로 먼저 증가)

9. 비교 연산자: == vs === ★시험

  • ⭐ 강조 — == 는 타입이 달라도 형변환 후 값만 비교 / === 는 값과 타입 모두 비교(엄격)
  • "10" == 10 → true · "10" === 10 → false · 1 !== 2 → true
  • ✍️ 필기 정정 — 필기의 ture 는 true 오타

10. 논리 연산자 · truthy/falsy · 단락 평가 ★시험

  • ✍️ 필기 정정 — & 는 JS 에서 비트 연산자: 양쪽을 항상 둘 다 계산하고 결과는 숫자(true & false → 0) / && 는 논리 연산자: 왼쪽이 false 로 확정되면 오른쪽은 계산하지 않고 바로 결과를 돌려준다 = 단락 평가
  • 📝 교수님 메모 — Truthy와 Falsy: 참·거짓(boolean)이 아닌 값도 조건문 안에서는 참 또는 거짓으로 판단되는 값 · 단락평가: && ||
  • ⭐ 강조 — falsy(거짓으로 취급) 8가지: false · 0 · -0 · 0n · "" · null · undefined · NaN → 이것들을 뺀 나머지는 모두 truthy(참으로 취급). "0", "false", [], {} 도 truthy
  • ⭐ 강조 — A || B : A 가 falsy 면 B, truthy 면 A / A && B : A 가 truthy 면 B, falsy 면 A
코드입력이 "" 일 때입력이 "안녕" 일 때
changeVar = changeVar || "입력없음";"입력없음""안녕" (그대로)
changeVar = changeVar && "입력없음";"" (그대로)"입력없음" (덮어씀)
  • ✍️ 필기 — truthy/falsy + 단락 평가를 쓰면 값이 없을 때 생길 오류를 미리 막고(방어 코드) if 문을 짧게 쓸 수 있다

11. null 병합 · typeof · 삼항 연산자

  • ?? (null 병합): 왼쪽이 null·undefined 일 때만 오른쪽 → undefined ?? 10 은 10, 0 ?? 5 는 0 (0 || 5 는 5)
  • typeof: 값의 타입을 문자열로 반환 → typeof true 는 "boolean", typeof null 은 "object"
  • ✍️ 필기 — 삼항 연산자 = if 문을 짧게 줄인 연산자: 조건 ? 참일 때 : 거짓일 때 → 조건이 true 면 콜론 앞, false 면 콜론 뒤
let res = var8 % 2 === 0 ? "짝수" : "홀수";   // 0915_03.js

// 0915_04.html — 입력이 비었으면 "입력없음" (셋 다 같은 뜻)
if (changeVar == "") { changeVar = "입력없음"; }
changeVar = changeVar == "" ? "입력없음" : changeVar;
changeVar = changeVar || "입력없음";   // 취소(null)까지 한 번에 처리
  • ⚠️ 0915_04.html 은 querySelector("#result") 인데 태그 id 가 content 라서 null 오류가 났다 → #content 로 맞춰야 화면에 출력된다 (4주차 폴더 파일은 #content 로 고침). prompt 에서 취소하면 null 이 들어와 == "" 검사로는 못 거른다

12. 매개변수(parameter)와 인수(argument)

  • ⭐ 강조 — 매개변수 = 함수를 정의할 때 값을 받으려고 괄호 안에 적는 변수(person) / 인수 = 함수를 호출할 때 실제로 넘기는 값({ name: "홍길동" })
function printName(person) {     // person = 매개변수(파라미터)
    if (!person) {               // 값이 없으면(falsy) 오류 대신 안내 후 종료
        console.log("person의 값이 없음");
        return 0;
    }
    console.log(person.name);
}
let person = { name: "홍길동" };
printName(person);               // 인수 전달 → 홍길동
printName();                     // 인수 없음 → person의 값이 없음

13. 복습: 함수 선언 3가지

  • ① 선언적 함수 function btnClick() { ... } ② 표현적(익명) 함수 let btnClick = function() { ... }; ③ 화살표 함수 let btnClick = () => { ... }; → 호출은 모두 btnClick();
  • ✍️ 필기 정정 — 필기에서 화살표 함수 번호가 1로 되어 있던 것 → 3번
✍️ 수업 중 원본 필기 (정리 전 메모) 
타입 스크립트{ 자바 스크립트에 타입을 강화한 다음단계에서 나온 netx js }
변수를 선언만하면 undefined상태이고, 값을 넣기 싫으면 null을 주면 된다.
함수 선언 방법: 1. 선언적 함수 · 2. 표현적 함수(익명함수) · 1. 화살표 함수 · 캐스팅==형변환
string(문자열)+number(정수)=형변환(캐스팅)을 시켜서 덧셈을 실행한다 · string(문자열)+string(문자열)=문자 이어 붙이기 · number(정수)+number(정수)=10진수 덧셈
id를 js에서 많이 씀 · class를 css에서 많이 씀 · name을 백엔드에서 많이 씀
시스템에서 제공하는 객체를 "내장객체"라고 함 · 상수는 모두 대문자 · 객체는 소문자
레이아웃을 다시만든느 리플로워 · 다시 화면을 그려주는 리페인트
기존에 배운것: document.getElementById(); · 이번에 배운것: document.querySelector();
주관식 시험문제+저번수업 복습=자바 스크립트를 단독적으로 실행 할 수 있게 도와주는 "node.js" · js로 할 수 있는 일이 많다.
비교연산자{ "10"==10 : ture "type 상관없이 값이 같으니 ture" · "10"===10 : false "type이 다르니 false" }
console.log(num8++); 과 console.log(++num8); 차이 중요 · ++이 앞에있으면 먼저 1을 더하고, ++이 뒤에 있으면 실행을 먼저하고 +1을 한다.
&는 첫번째와 두번째 모두 보고 그뒤에 판단을 내리고 &&는 첫번째 결과를 보고 flase가 출력이 확정이 되면 굳이 그 뒤에를 안 보고 바로 출력해줌
html,css,js 마다 주석이 다른것도 시험문제 출제 가능
삼항 연산자(if문을 간단하게 축약 해 놓은 연산자){ ture이면 콜론 앞을 실행 · false이면 콜론 뒤를 실행 }
false(false, 0, -0, null, undefined, NaN, "", ..) 빼고 다 true · //단락 평가 : && ||
changeVar=changeVar || "입력없음"; 과 changeVar=changeVar && "입력없음"; 의 차이 → ||는 왼쪽이 falsy일 때 오른쪽을 반환하고, &&는 왼쪽이 truthy일 때 오른쪽을 반환한다
