1. while 실습 — -1 이 나올 때까지 평균 (예제 3-2)

📂 5주차 (9/22) — 수업은 4주차 강의자료 3장을 이어서 진행했고, 수업 중 작성한 소스 WhileSample · NestedLoop · ContinueExample · BreakExample · ArrayAccess · ForEx1~3 로 정리했어요 (노션 필기: “5주차 수업이지만 4주차 강의자료인 3장을 진도 나갔음”). 코드 주석과 ▶ 출력 결과은 전부 직접 컴파일·실행한 결과예요.
// WhileSample.java (예제 3-2) — -1 이 입력될 때까지 정수를 받아 평균 구하기
import java.util.Scanner;

public class WhileSample {
    public static void main(String[] args) {
        int count = 0;                  // 입력된 정수의 개수
        int sum = 0;                    // 합
        Scanner sc = new Scanner(System.in);
        System.out.println("정수를 입력하고 마지막에 -1을 입력하세요.");

        int n = sc.nextInt();           // 첫 번째 수는 반복 전에 먼저 받는다
        while (n != -1) {               // -1 이 아니면 계속 반복
            sum += n;
            count++;
            n = sc.nextInt();           // 다음 수 → 다시 조건 검사
        }

        if (count == 0) {               // 처음부터 -1 이면 0 으로 나누게 되므로 따로 처리
            System.out.println("입력된 수가 없습니다.");
        } else {
            System.out.print("정수의 개수는 " + count + "개이며 ");
            System.out.println("평균은 " + (double) sum / count + "입니다.");   // 실수 나눗셈
        }
        sc.close();
    }
}

2. 중첩 for — 구구단 (예제 3-4)

📌 강의자료 p15 문제 — 2중 중첩 for 문을 사용하여 구구단을 출력하는 프로그램을 작성하시오. 한 줄에 한 단씩 출력한다.
// NestedLoop.java (예제 3-4) — 2중 for 로 구구단 (한 줄에 한 단씩)
public class NestedLoop {
    public static void main(String[] args) {
        for (int i = 1; i < 10; i++) {          // 바깥: 1단 ~ 9단
            for (int j = 1; j < 10; j++) {      // 안쪽: 곱하는 수 1 ~ 9
                System.out.print(i + "*" + j + "=" + i * j);
                System.out.print("\t");         // 탭으로 칸 띄우기
            }
            System.out.println();               // 한 단이 끝나면 줄바꿈
        }
    }
}

3. continue · break 실습 (예제 3-5 · 3-6)

키워드하는 일 (강의자료 p16 · p18)
continue반복문을 빠져나가지 않고 다음 반복으로 진행 (아래 문장 건너뜀)
break반복문 하나를 완전히 빠져나감 · 중첩이면 안쪽 반복문만 벗어남

예제 3-5 ContinueExample — 양수만 더하기

// ContinueExample.java (예제 3-5) — continue 로 양수만 더하기
import java.util.Scanner;

public class ContinueExample {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.println("정수를 5개 입력하세요.");
        int sum = 0;
        for (int i = 0; i < 5; i++) {
            int n = sc.nextInt();
            if (n <= 0) {
                continue;               // 0 이하면 아래를 건너뛰고 다음 반복으로
            } else {
                sum += n;               // 양수만 더한다
            }
        }
        System.out.println("양수의 합은 " + sum);
        sc.close();
    }
}
정수를 5개 입력하세요.
5 -2 6 10 -4
양수의 합은 21
-2 와 -4 는 continue 로 건너뛰어서 5 + 6 + 10 = 21

예제 3-6 BreakExample — exit 입력 시 종료

// BreakExample.java (예제 3-6) — "exit" 이 입력되면 break 로 while 을 빠져나간다
import java.util.Scanner;

public class BreakExample {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.println("exit을 입력하면 종료합니다.");
        while (true) {                  // 조건이 항상 true → break 로만 빠져나올 수 있다
            System.out.print(">>");
            String text = sc.nextLine();
            if (text.equals("exit")) {  // 문자열 비교는 == 가 아니라 equals()
                break;                  // while 문 하나를 완전히 벗어남
            }
        }
        System.out.println("종료합니다...");
        sc.close();
    }
}
exit을 입력하면 종료합니다.
>>hello
>>java
>>exit
종료합니다...
⚠️ while (true) 는 조건이 항상 참이라 break 가 없으면 무한 반복 · 문자열 비교는 text.equals("exit") (== 아님)

4. 배열 — 필요성과 접근 ★중요

📸 수업 중 “중요한 강의자료” 로 캡처한 슬라이드 — 3장 p21 자바 배열의 필요성과 모양
방법만들기 → 합 구하기
변수 10개int i0, i1, …, i9; · → sum = i0+i1+…+i9; 변수마다 따로 써야 함 ❌
배열 1개int i[] = new int[10]; · → for 문에서 sum += i[n]; 인덱스 n 만 바꿔 반복 ✅
📌 배열 = 인덱스와 그에 대응하는 같은 타입 데이터들의 모음 · 한 번에 많은 메모리 공간 할당 · 인덱스는 0 부터, 마지막은 크기 − 1 · 반복문으로 처리하기에 적합 (강의자료 p20 · p25) — 선언·생성 문법은 4주차 배열

ArrayAccess — 인덱스로 넣고 꺼내기, for 로 전체 출력

// ArrayAccess.java — 배열 생성 · 인덱스로 접근 · for 로 전체 출력
public class ArrayAccess {
    public static void main(String[] args) {
        int[] numbers = new int[5];     // 정수 5개짜리 배열 생성 → 인덱스 0 ~ 4
        numbers[0] = 10;
        numbers[1] = 20;
        numbers[2] = 30;
        numbers[3] = 40;
        numbers[4] = 50;                // 마지막 인덱스 = 크기 - 1
        System.out.println("첫번째 요소 : " + numbers[0]);
        System.out.println("세번째 요소 : " + numbers[2]);   // 세 번째 = 인덱스 2

        int[] score = {90, 85, 78, 100, 95};    // 선언과 동시에 초기화
        for (int i = 0; i < 5; i++) {
            System.out.println(i + 1 + "번학생 점수 = " + score[i] + "점");
            // i + 1 이 먼저 더해진 뒤(숫자) 문자열과 붙는다 → 1번, 2번 …
        }
    }
}
첫번째 요소 : 10
세번째 요소 : 30
1번학생 점수 = 90점
2번학생 점수 = 85점
3번학생 점수 = 78점
4번학생 점수 = 100점
5번학생 점수 = 95점
⚠️ i + 1 + "번학생" — + 는 왼쪽부터 계산해서 i + 1 이 먼저 숫자로 더해진 뒤 문자열과 붙어요 → 1번, 2번 … · 수업 파일 이름은 교재 예제 3-7(배열에서 제일 큰 수 찾기, p27)과 같지만 내용은 배열 접근 기본 연습이에요.

5. 수업 실습 문제 — ForEx1 · ForEx2 · ForEx3

ForEx1 — 5! 구하는 프로그램을 작성하시오

// ForEx1.java — 5! (5 팩토리얼) 구하기
public class ForEx1 {
    public static void main(String[] args) {
        int result = 1;                 // 곱하기는 1 부터 시작 (0 이면 계속 0)
        for (int i = 1; i <= 5; i++) {
            result *= i;                // 1 × 2 × 3 × 4 × 5
        }
        System.out.println(result);
    }
}

// ForEx3.java — while 문으로 0 ~ 9 출력
public class ForEx3 {
    public static void main(String[] args) {
        int i = 0;                      // 초기화는 while 밖에서

            System.out.print(i);        // print → 줄을 안 바꾸고 이어서 출력
            i++;                        // 증감을 빼먹으면 무한 반복
        }
    }
}
