합집합만 나옴 (10주차)합집합 ∪ = SQL UNION — 두 SELECT 결과를 합치고 중복은 한 번만 · UNION ALL = 중복까지 모두 · 두 릴레이션은 합병 가능(속성 개수 · 도메인이 같아야) — 열 개수가 다르면 ERROR 1222 · 사원 {1 고길동, 2 이순신} ∪ 직원 {2 이순신, 3 둘리} → 1 고길동 · 2 이순신 · 3 둘리 (UNION ALL 은 4행)
강의자료 28페이지 (10주차)프로젝션 π = 원하는 열(속성)을 검색 · 관계대수식 π 고객이름,등급,적립금 (고객) → SQL SELECT 고객이름, 등급, 적립금 FROM 고객; → 행 수는 그대로 · 열만 3개 (실렉션 σ 는 행을 고름)
키 · 도메인 제약조건 (6주차)키 제약조건 = 키는 중복된 값을 갖지 않는다 (UNIQUE) · 도메인 제약조건 = 값의 범위 · 기본값 지정 (CHECK · DEFAULT — 10주차 Quiz 10-2 적립금 int DEFAULT 0)

10주차 · 🔥 관계대수 — 합집합 · 프로젝션 · 조인 / 널 값과 집계함수

포인트핵심 · 답그림
🔥 ✍️ 합집합 UNION기말고사에 합집합만 나옴 — UNION 중복 제거 · UNION ALL 중복 포함 · 합병 가능해야 (열 개수 · 도메인 같음) · 교집합 INTERSECT · 차집합 MINUS(Oracle) / EXCEPT(MS SQL) — ⚠️ MySQL 8.0.31+ 는 INTERSECT · EXCEPT 도 됨 · MINUS 는 없음④
🔥 28쪽 프로젝션 π원하는 열 — π 고객이름,등급,적립금 (고객) = SELECT 고객이름, 등급, 적립금 FROM 고객;⑤
✍️ 실렉션 σ원하는 행 — σ 등급='gold' (고객) = SELECT * FROM 고객 WHERE 등급='gold'; · ⚠️ 필기 PRODUCTION → PROJECTION⑤
✍️ 조인 4가지 (Quiz 10-5)카티션 프로덕트 × (R1 2행 × S1 3행 = 6행) · 동등조인 = (R1.A = S1.A → 2행 · A 열 2개) · 자연조인 (공통 필드 하나 제거 → A · B · C · D) · 세타조인 (R1.A >= C → 3행)⑥
✍️ 널 값 · 집계함수NULL 과 산술연산 → NULL · AVG(필드) · COUNT(필드) 는 NULL 제외 · COUNT(*) 는 포함 · Quiz 10-3 → 45 · 50 · 2 · Quiz 10-4 → 10 · 20 (⚠️ 필기 30 은 WHERE 를 빼먹은 값)③
Quiz 10-2 고객고객이름 NOT NULL · 적립금 int DEFAULT 0 — 빼면 0 · 직접 NULL 이면 NULL · 이름을 빼면 ERROR 1364
자세한 SQL · 실행 결과는 10주차 · 문제는 🔒 실제시험.

9주차 · SELECT 문법 — LIKE · NULL · ORDER BY · 집계함수 · GROUP BY · HAVING

포인트핵심 · 답그림
✍️ 실행 순서쓰는 순서 SELECT · FROM · WHERE · GROUP BY · HAVING · ORDER BY → 실행 5 · 1 · 2 · 3 · 4 · 6 · WHERE 에 집계함수 → ERROR 1111 → HAVING①
✍️ LIKE% 0개 이상 · _ 1개 — '정%' 정씨 · '%동%' 동이 들어감 · '__우' 세 번째 글자 우 · 여러 성은 LIKE … OR LIKE … / 아닌 것은 NOT LIKE … AND …
IN · BETWEEN · NULLIN ('서울','안양') · NOT IN · BETWEEN 350 AND 500 (양 끝 포함) · IS NULL (✕ = NULL → 결과 없음) · ✍️ 드 모르간 ~(A ∨ B) = ~A ∧ ~B
✍️ ORDER BYASC 기본값 · DESC · 여러 열 ORDER BY city ASC, point DESC · ORDER BY 3 = 3번째 열 · NULL 은 오름차순 맨 앞
✍️ COUNT · 집계함수COUNT(*) NULL 포함 (8) · COUNT(점수) NULL 제외 (7) · AVG = SUM ÷ COUNT(점수) · COUNT(DISTINCT 과목) 3③
GROUP BY · HAVING과목별 COUNT(점수) → 수학 4 · 국어 1 · 영어 2 · HAVING AVG(점수) >= 75 (교수님 답) · WHERE(행) → GROUP BY → HAVING(그룹) → ORDER BY②
자세한 SQL · 실행 결과는 9주차 · 문제는 🔒 실제시험.
