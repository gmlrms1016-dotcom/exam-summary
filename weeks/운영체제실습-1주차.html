🎬 1주차 그림 — 새 창으로 크게 보기

0. 참고 자료

  • 리눅스 학습 카페: cafe.naver.com/thisislinux
  • 실습 환경: VMware 가상머신 위에 Rocky Linux

1. 네트워크 설정 분석 (ipconfig /all)

  • ✍️ 필기 — 두 번의 ipconfig /all 결과를 비교하여 변경된 네트워크 어댑터 설정을 분석
    • VMnet1: 임대 만료 시간이 갱신됨
    • VMnet8: DHCP가 비활성화되면서 수동 IP(192.168.111.1)로 변경, 기존 임대·DHCP 서버 정보가 사라짐

2. 파일 목록 확인 (ls) ★암기

  • ⭐ 강조 — ls -l : 상세 정보(권한·크기·수정일 등) 표시, 숨김 파일 제외
  • ⭐ 강조 — ls -al : 상세 정보 + 마침표(.)로 시작하는 숨김 파일까지 모두 표시

3. 터미널 프롬프트 기호 ★암기

  • ⭐ 강조 — $ (일반 사용자): 시스템 권한이 제한된 일반 계정
  • ⭐ 강조 — # (관리자/Root): 시스템의 모든 권한을 가진 최고 관리자 계정

4. 기본 시스템 명령어

  • ⭐ 강조 — whoami : 현재 로그인한 사용자 계정 이름 확인
  • ⭐ 강조 — pwd : 현재 작업 중인 폴더의 절대 경로 확인
