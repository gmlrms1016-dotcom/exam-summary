1. ✍️ [이론] 빌드 = 컴파일 + 링크

  • ✍️ 필기 — 빌드 = 컴파일 + 링크 → .exe 실행파일 (Windows) · .o 목적파일 (Linux)
단계하는 일Windows (Visual Studio)Linux · macOS (gcc · clang)
컴파일소스(.c) 한 개를 기계어로 번역목적파일 .obj목적파일 .o
링크목적파일들 + 라이브러리(printf 등)를 하나로 묶음실행파일 .exe실행파일 (확장자 없음 · gcc 기본 이름 a.out)
빌드컴파일 + 링크를 한 번에.exe 가 생김실행파일이 생김
  • ⚠️ 팩트체크 — .o 는 Linux 의 실행파일이 아니라 목적파일이에요 (컴파일만 하고 링크하기 전 결과). Linux 실행파일은 보통 확장자가 없어요. 맥에서 clang -c 01localvar.c → 01localvar.o 는 object 파일, 이걸 링크하면 executable 로 바뀌는 걸 직접 확인했어요. Windows 목적파일은 .obj.

2. ✍️ 기억장치 공간 (메모리 공간) — 4 영역

영역 (세그먼트)언제 정해지나🤖 무엇이 들어가나
A. 정적 공간1. 코드 (code) — ✍️ 중요!✍️ 컴파일 시간번역된 명령 (main · 함수들)
2. 데이터 (data) — ✍️ 중요!✍️ 컴파일 시간전역변수 · 정적(static) 변수 — 프로그램 시작 ~ 끝까지
3. 스택 (stack) — ✍️ 아주 중요!✍️ 컴파일 시간지역변수 · 매개변수 — 함수가 불릴 때 생기고 끝나면 사라짐
B. 동적 공간4. 힙 (heap)✍️ 런타임 (실행 시간)실행 중에 빌려 쓰는 공간 (malloc — 아직 안 배움)
  • ⚠️ 팩트체크 — 스택에 들어갈 지역변수의 크기 · 개수는 컴파일 때 정해지지만, 스택 칸이 실제로 생기고 없어지는 건 함수가 호출 · 끝날 때(실행 중) 예요. 그래서 지역변수는 함수가 끝나면 값이 사라져요 (필기의 “컴파일 시간에 결정” = 크기가 정해진다는 뜻으로 이해).

3. ✍️ 변수의 유효범위 (scope) · 기억 클래스

  • ✍️ 유효범위 = 선언된 변수가 사용될 수 있는 범위 (scope)
종류✍️ 어디서 선언쓸 수 있는 곳기본값 (📄 02-1global)
지역변수 (local)블록(중괄호) 또는 함수의 내부그 블록 · 함수 안에서만🤖 정해지지 않음 (초기화하고 쓰기)
전역변수 (global)함수의 외부파일 어디서나 (다른 파일은 extern 으로)0 (gi: 0)
정적변수 (static) · 외부변수 (extern) · 레지스터변수 (register)✍️ 필기 빈칸 — 다음 시간
  • ✍️ 🔥 지역이 전역보다 우선 — 전역과 같은 이름의 지역변수가 있으면 그 블록 안에서는 지역변수가 쓰여요 → 아래 ③ PI
  • 📄 for (int m = 0, sum = 0; …) 처럼 for 괄호 안에서 선언한 변수도 for 블록의 지역변수 → for 밖에서 쓰면 오류

4. 오늘의 실습 ① scope1_5.c — 블록 밖에서 b 를 쓰면 오류

// scope1_5.c                                       // 지역변수의 범위 — 함수 · 블록 안에서만
#include <stdio.h>                                  // printf

void test1() {                                      // 매개변수 없는 함수
	int local1 = 10;                                // test1 의 지역변수 → test1 안에서만
	printf("local1: %d\n", local1);                 // local1: 10
}                                                   // test1 끝 → local1 사라짐

void test2(int local2) {                            // 매개변수 local2 도 지역변수
	printf("local2: %d\n", local2);                 // test2(100) → local2: 100
}                                                   // test2 끝 → local2 사라짐

int main() {   // 원본 그대로 int main() — 괄호를 비워 둔 옛 방식 · int main(void) = '매개변수 없음'을 확실히 적음 — 실행 결과는 같음
	test1();                                        // local1: 10
	test2(100);                                     // local2: 100

	int a = 0;                                      // main 의 지역변수 a = 0
	while (a < 5) {                                 // a = 0 ~ 4 → 5번 반복
		a++;                                        // a: 1 → 2 → 3 → 4 → 5
		int b = 20;                                 // while 블록 안 지역변수 b (반복마다 새로 20)
		printf("a, b: %d, %d\n", a, b);             // a, b: 1, 20 … a, b: 5, 20
	}                                               // while 블록 끝 → b 사라짐
	printf("b: %d\n", b); // error                  // ❌ b 는 while 블록의 지역변수 → 여기서는 없음

	return 0;                                       // 정상 종료
}                                                   // main 끝

▶ 컴파일 결과 (맥 clang) — b 가 선언되지 않았다는 오류 → 실행 파일이 만들어지지 않음

scope1_5.c:23:20: error: use of undeclared identifier 'b'
   23 |         printf("b: %d\n", b); // error
      |                           ^
1 error generated.

▶ printf("b: …") 줄을 지우고 실행하면

5. 오늘의 실습 ② 01localvar.c — 지역변수

// 01localvar.c                                     // 지역변수: 블록 · 함수 안에서만 쓸 수 있음
#include <stdio.h>                                  // printf
void sub(int param);                                // 함수 원형 (아래에 정의)

int main(void) {   // (void) = '매개변수 없음'을 확실히 적음 · int main() 은 괄호를 비워 둔 옛 방식 — 실행 결과는 같음
	auto int n = 10;                                // 지역변수 n = 10 (auto = 자동 지역변수 · 생략 가능)
	printf("%d\n", n);                              // 10
	for (int m = 0, sum = 0; m < 3; m++) {          // m · sum 은 for 블록의 지역변수 (m = 0, 1, 2)
		sum += m;                                   // sum: 0 → 0+1=1 → 1+2=3
		printf("\t%d %d\n", m, sum);                // 탭 + "0 0" → "1 1" → "2 3"
	}                                               // for 끝 → m · sum 사라짐
	printf("%d\n", n);                              // n 은 main 블록 → 아직 참조 가능 → 10
	// printf("%d %d\n", m, sum);                   // ❌ m · sum 참조 불가능 (for 밖)
	sub(20);                                        // 함수 호출 → param = 20
	return 0;                                       // 정상 종료
}                                                   // main 끝

void sub(int param) {                               // 매개변수 param 도 sub 의 지역변수
	auto int local = 100;                           // sub 의 지역변수 local = 100
	printf("\t%d %d\n", param, local);              // 탭 + "20 100"
	// printf("%d\n", n);                           // ❌ n 은 main 의 지역변수 → sub 에서 참조 불가능
}                                                   // sub 끝

6. 오늘의 실습 ③ 02-1global.c + 02-2circumference.c — 전역변수 (파일 2개)

// 02-1global.c                                     // 전역변수 PI · gi + 같은 이름 지역변수 PI
#include <stdio.h>                                  // printf
double getArea(double);                             // 함수 원형 — 면적 (이 파일 아래)
double getCircum(double);                           // 함수 원형 — 둘레 (02-2 파일에 있음)

double PI = 3.14;                                   // 전역변수 PI = 3.14 (함수 밖)
int gi;                                             // 전역변수 gi — 초기화 안 함 → 기본값 0

int main(void) {   // (void) = '매개변수 없음'을 확실히 적음 · int main() 은 괄호를 비워 둔 옛 방식 — 실행 결과는 같음
	double r = 5.87;                                // 지역변수 반지름 r = 5.87
	const double PI = 3.141592;                     // 전역 PI 와 같은 이름의 지역변수 → main 안에서는 이게 우선
	printf("면적: %.2f\n", getArea(r));             // getArea 는 전역 PI 사용 → 5.87 × 5.87 × 3.14 = 108.19
	printf("둘레1: %.2f\n", 2 * PI * r);            // main 의 지역 PI → 2 × 3.141592 × 5.87 = 36.88
	printf("둘레2: %.2f\n", getCircum(r));          // 다른 파일의 함수 → 전역 PI → 2 × 5.87 × 3.14 = 36.86
	printf("PI: %f\n", PI);                         // 지역변수 PI 참조 → 3.141592
	printf("gi: %d\n", gi);                         // 전역변수 gi 기본값 → 0
	return 0;                                       // 정상 종료
}                                                   // main 끝

double getArea(double r) {                          // 매개변수 r 은 getArea 의 지역변수
	return r * r * PI;                              // 여기엔 지역 PI 가 없음 → 전역 PI(3.14) 참조
}                                                   // getArea 끝
// 02-2circumference.c                              // 같은 프로젝트의 두 번째 파일
extern double PI;                                   // 이미 다른 파일(02-1)에서 선언된 전역변수 PI 를 쓰겠다는 선언
double getCircum(double r) {                        // 둘레 = 2 × r × PI
	return 2 * r * PI;                              // 전역 PI(3.14) 참조
}                                                   // getCircum 끝

▶ 두 파일을 같이 빌드 (clang 02-1global.c 02-2circumference.c)

면적: 108.19
둘레1: 36.88
둘레2: 36.86
PI: 3.141592
gi: 0
  • 🔥 둘레1 ≠ 둘레2 인 이유 = 둘레1 은 main 의 지역 PI(3.141592), 둘레2 는 전역 PI(3.14) → ✍️ “지역이 전역보다 우선”
  • extern = “이 전역변수는 다른 곳에 이미 있다” 는 선언 (외부변수 — 필기 빈칸 · 다음 시간에 자세히)

7. 한 줄 정리

  • 빌드 = 컴파일(→ 목적파일 .obj · .o) + 링크(→ 실행파일 .exe)
  • 메모리 = 코드 · 데이터 · 스택(정적 · 컴파일 때 크기 결정) + 힙(동적 · 실행 중)
  • 지역변수 = 블록 · 함수 안 · 그 안에서만 / 전역변수 = 함수 밖 · 어디서나 · 기본값 0 / 같은 이름이면 지역 우선
