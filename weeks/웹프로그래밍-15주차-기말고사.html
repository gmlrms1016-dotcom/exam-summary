✍️ 요청 · 파라미터요청(request) = 클라이언트 → 서버 · 요청에 담아 보내는 값 = 파라미터 (⚠️ 필기는 “보내는 것 = 파라미터”)②
✍️ 응답 · JSON응답(response) = 서버 → 클라이언트 텍스트 (흔히 JSON 형식) → JSON.parse → 객체 → 화면에 출력(뿌려 줌)②
