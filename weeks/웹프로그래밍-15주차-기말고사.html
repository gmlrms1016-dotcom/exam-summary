9주차 · 이벤트 4요소 · 요소 순회 · 요청과 응답

포인트핵심 · 답그림
🔥 ✍️ 이벤트 4요소기말고사에 나옴 — 이벤트 'click' · 이벤트 소스 addBtn · 이벤트 핸들러(= 리스너) function(){…} · 이벤트 객체 e①
📄 1027_01_event.htmladdBtn.addEventListener('click', function(){…}) → prompt("할 일 입력") → list.innerHTML += '<li>' + txt + '</li>' → 목록 끝에 추가 (li 4개 → 5개)①
✍️ 요청 · 파라미터요청(request) = 클라이언트 → 서버 · 요청에 담아 보내는 값 = 파라미터 (⚠️ 필기는 “보내는 것 = 파라미터”)②
✍️ 응답 · JSON응답(response) = 서버 → 클라이언트 텍스트 (흔히 JSON 형식) → JSON.parse → 객체 → 화면에 출력(뿌려 줌)②
📄 1027_02_요소순회.js방법1 for (let i = 0; …) → arr[i] · 방법2 for (let item of arr) → 값 · Object.keys 키 배열 · Object.values 값 배열 · person[key]③

10주차 · 🔥 기말 = 실기 (⚠️ 12주차: 필기 + 실기) · 누른 항목 선택 · 배열 메서드 · CRUD

포인트핵심 · 답그림
🔥 ✍️ 기말 방식기말고사는 필기가 아닌 실기 — 직접 코드를 짜는 시험 · ⚠️ 12주차에 필기 + 실기 둘 다로 바뀜—
✍️ 이벤트 4요소 복습오늘 코드: 이벤트 'click' · 소스 list(ul) · 핸들러 activeItem (괄호 없이 이름만) · 이벤트 객체 e④
📄 1027_01_event.htmle.target = 누른 li · nodeName == 'LI' (대문자) · title.innerHTML = e.target.innerHTML · 모든 li removeAttribute('class') → 누른 li setAttribute('class','active') · 🤖 ul 에 하나 = 이벤트 위임 (새 li 도 됨)④
📄 push · pop맨 뒤 추가 → 반환 새 길이 / 맨 뒤 제거 → 반환 뺀 요소⑤
📄 shift · unshift맨 앞 제거 → 반환 뺀 요소 / 맨 앞 추가 → 반환 새 길이⑤
📄 slice · concatslice(시작, 끝) 끝 직전까지 · 음수 = 뒤에서 (slice(-3) → [3, 4, 5]) · concat 이어 붙임 → 둘 다 원본 그대로 · 새 배열⑤
📄 forEach · includesforEach((item, idx, arr) => …) 요소마다 · 반환 없음 / includes(값) → true · false⑥
📄 indexOf · findIndexindexOf(값) → 인덱스 · 없으면 -1 / findIndex(콜백) → 참인 첫 요소의 인덱스 · 없으면 -1 · 객체는 indexOf({…}) → -1 (주소 비교) → findIndex(i => i.name === …)⑥
⚠️ 수업 파일 오타arr.forEach · inIncludes · const 같은 이름 두 번(SyntaxError → 한 줄도 실행 안 됨) · findexIndex⑥
✍️ 프론트 · 백엔드 · CRUD프런트엔드 = 브라우저 · 백엔드 = 서버 · 🤖 CRUD = Create · Read · Update · Delete · ✍️ 다음 주: 백엔드에 요청해서 투두리스트⑦

11주차 · 🎮 미니게임 과제 · 두더지잡기 · 선택 삭제 · map · filter

포인트핵심 · 답그림
✍️ 과제두더지게임 같은 미니게임 1개 · 수업에서 언급한 내장객체 · 함수만 · 200줄 이하 · 겹치지 않는 주제일수록 높은 점수 · 11/17(화) 09:55 까지—
판 · 두더지 위치판 position: relative + 두더지 absolute → left · top 이 판 기준 · overflow: hidden · 최댓값 = clientWidth − target.clientWidth (550)⑧
랜덤 정수Math.random() = 0 이상 1 미만 · Math.floor = 내림 → Math.floor(Math.random() * 550) = 0 ~ 549 · Math.floor(Math.random()) 은 항상 0⑧
style 로 옮기기style.left = 값 + 'px' (단위 없이 숫자만 넣으면 무시) · display = 'none' 숨김 · 'block' 보임⑧ ⑨
setIntervalsetInterval(moveTarget, 1000) = 1초마다 되풀이 · 함수 이름만 (괄호를 붙이면 한 번만 실행) · e.clientX · e.clientY = 창 기준 좌표 · 두더지 클릭이 판까지 올라감(버블링)⑨
✍️ map · filter“앞으로 많이 쓸 함수” — filter = 조건을 만족하는 요소만 새 배열 · map = 모든 요소의 콜백 결과를 모은 새 배열 · 둘 다 원본 그대로 · forEach 는 undefined⑩
HTMLCollectionchildren 은 유사 배열 → .map 없음 (TypeError: … is not a function) → [...liArray] · Array.from(liArray) 로 배열로 (⚠️ 주석의 Array.form 은 오타)⑪
선택 삭제querySelector('#list .active') → 없으면 null → alert · 있으면 remove() · 선택 수정 버튼은 아직 기능 없음⑪

12주차 · 🔥 HTTP 메시지 구조 · 이벤트 핸들러 3가지 · onload · fetch · DNS · 요청 방식 · CRUD

포인트핵심 · 답그림
🔥 ✍️ 기말 방식필기 + 실기 둘 다 — 필기 = 중간고사처럼 이론 맞히기 · 실기 = 미니게임 만들기 (주제는 아직 안 정해짐)—
🔥 ✍️ HTTP 메시지 구조클라이언트 · 서버가 주고받는 정해진 형식의 데이터 단위 · 요청 · 응답 2가지 · 시작 줄 → 헤더 → 빈 줄(CRLF) → 바디(선택) · 요청 시작 줄 = 방식 · 주소 · 버전 · 응답 시작 줄 = 버전 · 상태 코드 · 상태 글⑭
✍️ 이벤트클릭 · 스크롤 말고도 요청 · 응답 · onload 도 이벤트 (🤖 fetch 는 응답을 Promise 로 알려 줌)⑬
📄 1117_01_event.html핸들러 3가지 — ① addEventListener('click', 함수) ✍️ 가장 추천 · 여러 개 OK ② onclick = 함수 다시 대입하면 덮어씀 ③ HTML 속성 onclick="btnClick3()" 괄호 필수 · 세미콜론은 상관없음 · 셋 다 기본은 버블링 단계⑫
window.onload페이지를 이미지까지 다 불러온 뒤 실행 → head 의 script 에서도 img 를 찾음 · onload 없이 쓰면 null → TypeError: Cannot set properties of null⑬
📄 1117_02_fetch.htmlfetch('https://jsonplaceholder.typicode.com/users/1') = users 중 id 가 1번인 사람을 요청 · 2번째 파라미터(옵션) 생략 = GET · ⚠️ “.com 까지 URI 전체가 URL” → 표준은 주소 전체가 URL 이자 URI⑮
✍️ DNSDomain Name System — 도메인 이름 → IP 주소 (⚠️ 경로는 그대로) · 1주차 210.89.160.88/news.html = naver.com/news.html⑮
✍️ 요청 방식 · CRUDGET · POST · PUT · DELETE / Create · Read · Update · Delete (🤖 GET-Read · POST-Create · PUT-Update · DELETE-Delete 짝은 관례)⑮
✍️ 단일 · 멀티 스레드단일 = 일하는 흐름 1개 · 한 번에 하나 (JS → 그래서 기다리지 않는 비동기) · 멀티 = 여러 개가 동시에⑯
