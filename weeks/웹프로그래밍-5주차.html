1. 호이스팅 · 선언적 함수 ★시험

📂 5주차 (9/22) — 강의자료 없이 노션 필기와 수업 파일 0922_01.js · 0922_02.js · 0922_03.js 로 정리했어요. 오늘 주제: 함수 · 콜백 함수 · 객체 · 배열 · ✍️ 수업 시작 복습 — Node.js 는 JS 를 단독으로 실행하는 것만이 아니라 서버 기능도 간단하게 넣은 것 · 내장 객체 = 시스템 안에서 제공되는 객체 (예: JSON)
구분선언보다 먼저 쓰면?
선언적 함수function f(){} → ✅ 실행된다 — 호이스팅: 선언이 코드 맨 위로 끌어올려진 것처럼 동작
let 변수let a; → ❌ ReferenceError — 선언한 줄보다 먼저 쓸 수 없다
익명 함수let f = function(){} → ❌ ReferenceError — 결국 let 변수에 담긴 함수라서

예제 ① 0922_01.js — 선언보다 먼저 부른 getArea

// 0922_01.js 1-1. 선언적 함수 — 선언보다 먼저 호출해도 실행된다 (호이스팅)
console.log(getArea(5, 5));   // 아직 아래에 선언하기 전인데 호출 → 25
function getArea(width, height) {
    let area = width * height;
    return area;
}
console.log(getArea(10, 5));  // 50
25
50

🔥 시험문제 — “문제가 생기는 코드 라인을 찍어주시오”

// ★시험문제 — "문제가 생기는 코드 라인을 찍어주시오" (0922_01.js 에서 주석 처리한 두 줄)
console.log(imsi);            // ← 여기서 오류! let 변수는 선언한 줄보다 먼저 쓸 수 없다
let imsi;
console.log(getArea(5, 5));   // 이 줄은 문제없다 (선언적 함수는 호이스팅)
function getArea(width, height) {
    let area = width * height;
    return area;
}
ReferenceError: Cannot access 'imsi' before initialization
🔥 정답: console.log(imsi); 줄 — let imsi 가 아래에 있어서 선언 전에 쓴 것이 오류 (ReferenceError). 그 줄에서 멈추기 때문에 아래는 실행되지 않지만, console.log(getArea(5, 5)); 자체는 호이스팅 덕분에 문제없는 줄이에요. (수업 파일에서는 이 두 줄을 주석으로 막아 둠)

비교 — 익명 함수는 선언 전에 부르면 오류

// 비교 — 익명 함수(함수 표현식)는 선언 전에 부르면 오류
console.log(sum(7, 5));       // ← 오류: sum 은 let 변수라 아직 쓸 수 없다
let sum = function (n1, n2) {
    return n1 + n2;
}
ReferenceError: Cannot access 'sum' before initialization

2. 익명 함수 · 화살표 함수

📌 함수 만드는 3가지(→ 2주차) 중 익명 함수는 이름 없는 함수를 변수에 담고, 화살표 함수는 function 대신 => 를 쓴다

예제 0922_01.js 1-2 · 1-3

// 0922_01.js 1-2. 익명 함수 · 1-3. 화살표 함수
let sum = function (n1, n2) {     // 이름 없는 함수를 변수 sum 에 담는다
    return n1 + n2;
}
sum(7, 5);                        // 수업 코드: 계산만 하고 출력은 안 함 → 화면엔 아무것도 없다
console.log(sum(7, 5));           // 12 ← 결과를 보려면 console.log 로 감싼다

let sum1 = (n1, n2) => {          // function 대신 => (화살표)
    return n1 + n2;
}
console.log(sum1(3, 4));          // 7
12
7
⚠️ 수업 코드의 sum(7,5); 는 값을 돌려주기만 하고 출력하지 않아서 콘솔에 아무것도 안 나와요 → 결과를 보려면 console.log(sum(7, 5))

3. 콜백 함수 ★

✍️ 필기 — 콜백 함수 : 다른 함수에 인자로 전달되어서, 나중에 실행되는 함수

예제 ① 0922_01.js 1-4 — call1 을 call2 에 넘기기

// 0922_01.js 1-4. 콜백 함수 — 다른 함수에 인자로 전달되어 나중에 실행되는 함수
let call1 = function () {
    console.log(`나는 콜되어진 함수`);
}
function call2(funcVar) {         // funcVar 로 함수를 받아서
    funcVar();                    // 여기서 실행 (= 콜백)
}
call2(call1);                     // 괄호 없이 call1 을 넘긴다 → 나는 콜되어진 함수

console.log(call1());             // 괄호 O = 실행 → 나는 콜되어진 함수, 그리고 반환값이 없어서 undefined
나는 콜되어진 함수
나는 콜되어진 함수
undefined
쓰는 법뜻 · console.log 하면
call1 · (괄호 X)함수 그 자체(값) — 콜백으로 넘기거나 변수에 담을 때 · 찍으면 함수 모양이 나온다 (node: [Function: call1])
call1() · (괄호 O)함수를 실행한 결과 — 실행되고, 반환값이 없으면 undefined
✍️ 필기 — 괄호가 있는 것과 없는 것은 다르다: console.log(call1) ≠ console.log(call1()) · 콜백으로 넘길 때는 괄호 없이 이름만

예제 ② 0922_01.js — 반복은 repeat, 할 일은 콜백

// 0922_01.js 콜백함수 예제 — 반복은 repeat 가, 할 일은 콜백이 정한다
function repeat(count, callback) {
    for (let idx = 1; idx <= count; idx++) {
        callback(idx);            // 넘겨받은 함수에 idx 를 넣어 실행
    }
}
repeat(5, (idx) => { console.log(idx); });       // 1 2 3 4 5
repeat(5, (idx) => { console.log(idx * 2); });   // 2 4 6 8 10
repeat(5, (idx) => { console.log(idx * 3); });   // 3 6 9 12 15

// 수업 파일처럼 같은 이름의 선언적 함수를 여러 번 만들면 → 마지막 것만 남는다
function repeat(count) {
    for (let i = 0; i <= count; i++) console.log(i);
}
function repeat(count, callback) {   // 이 선언이 위의 repeat 를 덮어쓴다
    for (let idx = 1; idx <= count; idx++) callback(idx);
}
repeat(3, (idx) => { console.log(idx * 10); });  // 10 20 30
repeat(3);                                       // ← 오류: 첫 번째 repeat 가 아니라 콜백 버전이 불려서 callback 이 없다

TypeError: callback is not a function
⚠️ 수업 파일 0922_01.js 에도 function repeat 가 3번 선언돼 있어요. 선언적 함수는 호이스팅되면서 마지막 선언이 앞의 것을 덮어써서, 파일의 모든 호출은 마지막 repeat(count, callback) 을 씁니다.

예제 ① 0922_02.js — 점 표기법 · 대괄호 표기법

// 0922_02.js 2. 객체 — 생성 · 프로퍼티(속성) · 메서드
let obj1 = new Object();          // 객체 생성자
let obj2 = {};                    // 객체 리터럴 (대부분 이걸 쓴다)

let person = {
    name: "윤희근",                // 속성(프로퍼티)  key: value
    age: 23,
    eat: () => { console.log("먹는다"); }   // 메서드 (객체 안의 함수)
}
console.log(person.name);         // 점 표기법 → 윤희근
console.log(person["age"]);       // 대괄호 표기법 → 23 (key 를 문자열로)
person.eat();                     // 메서드 호출 → 먹는다

let test = "name";
console.log(person[test]);        // 따옴표 없이 쓰면 변수 → test 안의 "name" → 윤희근

필기 정정 — 필기의 “꼭!! 쌍따옴표로 key명” → 대괄호 안에는 key 를 문자열로 쓰면 되므로 person["age"] · person['age'] 둘 다 돼요. 따옴표 없이 person[test] 처럼 쓰면 변수로 보고 그 안의 값("name")을 key 로 씁니다.

예제 ② 0922_02.js 2-3 — 속성 추가 · 삭제

// 0922_02.js 2-3. 프로퍼티 추가 · 삭제
let person = { name: "윤희근", age: 23 };

person.job = "developer";         // 없던 key 에 대입 → 속성 추가
console.log(person.job);          // developer

delete person.job;                // 속성 삭제
delete person["age"];             // 대괄호로도 삭제 가능
console.log(person.job);          // undefined (없는 속성)
console.log(person.age);          // undefined
console.log(person.name);         // 윤희근 (남아 있음)

만드는 법코드

// 0922_03.js 3. 배열 — 생성 · 요소 접근 · 수정 · 반복
