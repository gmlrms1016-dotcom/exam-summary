① 🔥 기말고사 — 13쪽 [실습 1-06] Hello 를 출력하는 2가지

✍️ 노션 “강의자료 13페이지에 Hello 를 출력하는 방법을 2개 다 알기 — 예: 다음과 똑같이 출력이 되도록 포인터를 사용하여 출력하시오”

// ex01_06-main.c — 📄 13쪽 [실습 1-06] 문자열 (🔥 ✍️ “Hello 를 출력하는 방법을 2개 다 알기”)
#include <stdio.h>                              // printf 를 쓰기 위한 표준 입출력 헤더

int main(void) {                                // (void) = '매개변수 없음'을 확실히 적음 · int main() 은 괄호를 비워 둔 옛 방식 — 실행 결과는 같음
    char a1[6] = {'H','e','l','l','o','\0'};    // ① 배열 — 칸 6개에 한 글자씩 · 마지막 '\0' = 문자열의 끝 표시
    printf("a1: %s\n", a1);                     // a1 = 첫 칸의 주소 → %s 는 '\0' 앞까지 읽음 → a1: Hello
    char* a2 = "Hello";                         // ② 포인터 — "Hello"(문자열 상수 · 끝에 '\0' 자동)가 따로 저장되고 a2 에는 그 주소
    printf("a2: %s\n", a2);                     // a2 가 가리키는 곳부터 '\0' 앞까지 → a2: Hello
    return 0;                                   // 0 을 돌려주며 정상 종료
}                                               // main 끝
a1: Hello
a2: Hello
  • 📄 13쪽 — 문자열 = 리터럴 중 " " 에 묶여 있는 것 · char 타입의 배열로 관리하며 주로 포인터 변수를 사용 · 문자열을 받아올 때 = char 형 배열 · 직접 문자열을 적어 줄 때 = 포인터 변수 (기억장소가 마련되고 그 다음에 주소값을 받아옴)
  • 🔥 “포인터를 사용하여 똑같이 출력” → char* a2 = "Hello"; + printf("a2: %s\n", a2);
  • 🤖 배열은 '\0' 칸까지 세어 크기를 정해요 — "Hello" 는 5글자 + '\0' = 6칸

② 🔥 기말고사 — 문법오류 체크: 배열을 입력받는 scanf 에는 & 를 쓰지 않음 (10 · 11쪽)

✍️ 노션 “다음 문제에 문법오류를 체크하시오 (예: 배열을 입력받는데 scanf("%s", /*여기에 '&' 를 쓰면 오류임*/))”

// ex01_04-main.c — 📄 10쪽 [실습 1-04] 문자 입출력 scanf() (🔥 ✍️ “배열을 입력받는데 & 를 쓰면 오류”)
#define _CRT_SECURE_NO_WARNINGS                 // VS 에서 scanf 보안 경고(C4996)를 끔
#include <stdio.h>                              // printf · scanf 를 쓰기 위한 표준 입출력 헤더

int main(void) {                                // (void) = '매개변수 없음'을 확실히 적음 · int main() 은 괄호를 비워 둔 옛 방식 — 실행 결과는 같음
    char a1[100];                               // 문자열을 받을 char 배열 (100칸)
    int a2;                                     // 정수를 받을 보통 변수
    printf("문자열 입력: ");                     // 안내 글자 (줄바꿈 없음 → 같은 줄에서 입력)
    scanf("%s", a1);                            // 📄 “배열이므로 a1 의 주소값이 들어간다” → & 없이 · abcd → a1 = "abcd"
    printf("숫자 입력: ");                       // 두 번째 안내
    scanf("%d", &a2);                           // 보통 변수는 & 로 주소를 줌 → 100 → a2 = 100
    printf("a1: %s, a2: %d\n", a1, a2);         // a1 = abcd · a2 = 100 → a1: abcd, a2: 100
    return 0;                                   // 정상 종료
}                                               // main 끝
문자열 입력: abcd
숫자 입력: 100
a1: abcd, a2: 100
  • 문자열(배열) → scanf("%s", a1); (배열 이름 = 첫 칸 주소) · 정수 같은 보통 변수 → scanf("%d", &a2); (& 로 주소)
  • 📄 11쪽 [실습 1-05] — 한 번에 받기 scanf("%s %d", a1, &a2); → 값 입력: 문자열 100 → a1: 문자열, a2: 100 (띄어쓰기로 나눠 받음)
  • ⚠️ 팩트체크 — scanf("%s", &a1); 은 맥 clang 에서 경고(format specifies type 'char *' but the argument has type 'char (*)[100]')만 나고 실행은 돼요 (가리키는 주소가 같아서). 하지만 형식이 맞지 않는 틀린 코드 → 시험에서는 교수님 말씀대로 “& 를 쓰면 오류”

③ 🔥 기말고사 — 포인터로 참조하면 값을 하나만 바꿔도 변수 2개가 바뀜 (✍️ 노션)

✍️ 노션 “변수가 2개 있는데 a 의 변수를 b 가 포인터로 참조하고 있으면 값을 하나만 바꿔도 변수 2개가 바뀌는 것도 시험문제” — 🤖 11 · 12주차 포인터(& · *)로 만든 예

// 🤖 예제 — b 가 a 를 가리키면 (11주차 pointer-03 · 12주차 5쪽과 같은 원리)
#include <stdio.h>                              // printf 를 쓰기 위한 표준 입출력 헤더

int main(void) {                                // (void) = '매개변수 없음'을 확실히 적음 · int main() 은 괄호를 비워 둔 옛 방식 — 실행 결과는 같음
    int a = 10;                                 // a ← 10
    int* b = &a;                                // b ← a 의 주소 → b 가 a 를 가리킴
    *b = 20;                                    // b 를 따라가 a 에 20 을 씀 → a = 20 · *b = 20
    printf("%d %d\n", a, *b);                   // a = 20 · *b = a = 20 → 20 20
    a = 30;                                     // 이번엔 a 를 직접 바꿈 → a = 30
    printf("%d %d\n", a, *b);                   // *b 도 같은 칸(a)을 읽음 → 30 30
    return 0;                                   // 정상 종료
}                                               // main 끝
20 20
30 30
  • ⚠️ 팩트체크 — 실제로 바뀌는 칸은 a 하나예요. *b 는 b 가 가리키는 a 를 읽는 것이라 같이 바뀐 것처럼 보이고, b 에 든 주소(&a)는 그대로예요

1. [요약] main() 함수 매개변수 · [실습 1-01] 명령어 라인 인수 (6 · 7쪽 · ✍️ 수업 실행)

  • 📄 6쪽 — int main(int argc, char *argv[]) · argc = 명령행에 있는 인수의 개수를 셈 · argv = 인수들의 값을 참조하는 포인터 배열 (각 요소는 그 인수를 가리키는 문자열 포인터) · argv 의 첫 번째 요소는 언제나 프로그램의 이름
  • 📄 7쪽 — 명령어 라인 인수 = 실행 프로그램 이름 뒤에 쓰는 정보 (project1 a.txt b.txt c.txt)
// ex01_01-main.c — 📄 7쪽 [실습 1-01] 명령어 라인 인수 (✍️ 수업 main.c — = 를 for 로 100개 찍게 바꿈)
#include <stdio.h>                              // printf 를 쓰기 위한 표준 입출력 헤더

int main(int argc, char* argv[]) {              // argc = 인수의 개수 · argv = 인수 문자열의 주소를 담은 포인터 배열
    int i;                                      // argv 칸을 차례로 볼 첨자
    printf("argc: %d\n", argc);                 // 인수의 수 → project1 a.txt b.txt c.txt 면 4
    for (int e = 1; e <= 100; e++) {            // ✍️ 수업 코드 — = 를 100번 (강의자료는 printf("=====================\n"); 한 줄 · 21개)
        printf("=");                            // = 한 개
    }                                           // for 끝 → = 100개
    printf("\n");                               // 줄바꿈
    for (i = 0; i < argc; i++) {                // i = 0 ~ argc-1 → 인수마다
        printf("argv[%d]: %s, %p\n", i, argv[i], argv[i]); // %s = 그 주소의 문자열 · %p = 저장된 주소 (실행마다 다름)
    }                                           // for 끝 → 다음 인수
    return 0;                                   // 정상 종료
}                                               // main 끝

  • 🤖 주소는 실행할 때마다 달라요 · 문자열이 붙어서 저장돼 …EDE8 → …EDF1 = 9칸 뒤 (project1 8글자 + \0) · a.txt 5글자 + \0 → 6칸씩

2. [실습 1-02 · 1-03] 문자 입출력 — getchar · gets · puts (8 · 9 · 12쪽)

// ex01_02-main.c — 📄 8쪽 [실습 1-02] 문자 입출력 getchar()
#include <stdio.h>                              // printf · getchar 를 쓰기 위한 표준 입출력 헤더

int main(int argc, char* argv[]) {              // 강의자료 그대로 main 매개변수를 둠 (이 예제에서는 안 씀)
    printf("문자입력: ");                        // 안내 글자
    char a1 = getchar();                        // 키보드에서 문자 1개를 읽음 → a 를 치면 a1 = 'a'
    printf("a1: %c\n", a1);                     // %c = 문자 1개 → a1: a
    return 0;                                   // 정상 종료
}                                               // main 끝
문자입력: a
a1: a
// ex01_03-main.c — 📄 9쪽 [실습 1-03] 문자 입출력 gets() (✍️ 수업 main.c 에서도 실행)
#include <stdio.h>                              // printf · gets · puts 를 쓰기 위한 표준 입출력 헤더

int main(void) {                                // (void) = '매개변수 없음'을 확실히 적음 · int main() 은 괄호를 비워 둔 옛 방식 — 실행 결과는 같음
    printf("문자열 입력: ");                     // 안내 글자
    char a2[100];                               // 한 줄을 받을 char 배열
    gets(a2);                                   // Enter 칠 때까지 읽어 a2 에 저장 → abcd → a2 = "abcd"
    printf("a2: %s\n", a2);                     // %s → a2: abcd
    puts(a2);                                   // 문자열 출력 + 줄바꿈 자동 → abcd
    return 0;                                   // 정상 종료
}                                               // main 끝
문자열 입력: abcd
a2: abcd

  • 📄 12쪽 — gets(문자배열); 문자열 입력함수 · 문자배열의 이름으로 호출 → 문자열을 저장할 기억장소 주소(포인터)를 인수로 넘김 · 사용자가 Enter 를 입력할 때까지 문자들을 읽어 그 주소에 저장
  • 🤖 puts 는 문자열을 찍고 줄바꿈을 자동으로 붙여요 (printf("%s\n", a2) 와 같은 모양)
  • ⚠️ 10주차에 정리한 대로 gets 는 입력 길이를 검사하지 않아 C11 에서 빠졌고 VS2015 부터는 없어요 → VS 에서 안 되면 gets_s(a2, 100); (맥 clang 은 'gets' is deprecated 경고와 함께 실행)

3. [요약] 문자열 · 문자열 함수 — strlen · strcpy · strcat (12 · 14 ~ 16쪽 · ✍️ 수업 main.c)

  • 📄 12쪽 — C 언어는 내부에 문자열 자료형이 없다 → 1차원 문자배열로 문자열을 지원 (1차원 배열을 가장 많이 쓰는 곳) · 문자열 상수는 컴파일러가 자동으로 null 로 종료
  • 📄 14쪽 — 문자열 함수 <string.h>: strcpy(문자열1, 문자열2) 문자열1에 문자열2 복사 · strcat(문자열1, 문자열2) 문자열1에 문자열2 를 붙인다 · strlen(문자열) 문자열의 바이트수 (한글 2byte)
// ex01_07-main.c — 📄 15쪽 [실습 1-07] 문자열 함수 strlen() (⚠️ 강의자료엔 #include <string.h> 가 없음 → 넣음)
#include <stdio.h>                              // printf 를 쓰기 위한 표준 입출력 헤더
#include <string.h>                             // strlen 이 들어 있는 헤더 (14쪽)

int main(void) {                                // (void) = '매개변수 없음'을 확실히 적음 · int main() 은 괄호를 비워 둔 옛 방식 — 실행 결과는 같음
    int data_length;                            // 길이를 받을 변수
    char data[10] = {'H','e','l','l','o', 0,};  // H e l l o 다음 0(= '\0') · 나머지 칸도 0
    data_length = strlen(data);                 // '\0' 앞까지 센 글자 수 → 5
    printf("data_length= %d\n", data_length);   // data_length= 5
    return 0;                                   // 정상 종료
}                                               // main 끝
data_length= 5
// ex01_08-main.c — 📄 16쪽 [실습 1-07] 문자열 함수 (✍️ 수업 main.c 에서 마지막으로 실행한 코드 · ⚠️ #include <string.h> 넣음)
#include <stdio.h>                              // printf 를 쓰기 위한 표준 입출력 헤더
#include <string.h>                             // strcpy · strcat · strlen 이 들어 있는 헤더

int main(void) {                                // (void) = '매개변수 없음'을 확실히 적음 · int main() 은 괄호를 비워 둔 옛 방식 — 실행 결과는 같음
    int data_length;                            // 길이를 받을 변수
    char data[10] = {'a','b','c', 0,};          // a b c 다음 0(= '\0') → 문자열 "abc"
    char result[16];                            // 결과를 담을 배열 (아직 쓰레기값)
    strcpy(result, data);                       // result ← data 복사 → "abc"
    strcat(result, "def");                      // result 끝('\0' 자리)부터 "def" 붙임 → "abcdef"
    data_length = strlen(result);               // '\0' 앞까지 → 6
    printf("%s + \"def\" = %s\n", data, result);  // \" = 큰따옴표 글자 → abc + "def" = abcdef
    printf("data_length = % d\n", data_length); // % d = 공백 플래그 → 양수 앞에 공백 1칸 → data_length =  6
    return 0;                                   // 정상 종료
}                                               // main 끝
abc + "def" = abcdef
data_length =  6
