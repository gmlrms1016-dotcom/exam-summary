자료: 필기.png · 명시적 형변환.txt · 02_변수와 자료형.pdf(교재) · eClass 강의노트(9/8)

1. 변수(Variable)와 선언 키워드 ★필수암기

  • ✍️ 필기 — 변수 = 메모리상의 값을 담는 그릇
  • ⭐ 강조 — 변수 선언 키워드 3가지: var / let / const
  • ✍️ 필기 — let: 변수의 중복 정의(재선언) 불가능
  • ✍️ 필기 — var: 중복 정의 가능 (구버전 방식)
  • ✍️ 필기 — const: 상수 — 값 변경 불가
  • ⭐ 강조 — ES6부터 JS를 어디서든 쓸 수 있게 되면서 let 이 등장

2. JS 자료형(Data Type) ★필수암기

  • ⭐ 강조 — 원시형(Primitive): String / Number / Boolean (+ null, undefined)
  • ⭐ 강조 — 참조형(Reference): 객체(Object)
  • ✍️ 필기 — 기본 데이터타입 5종: 문자열, 숫자, 부울린(Boolean), undefined, null
    • 숫자형: 정수와 실수 구분 없이 하나의 number로 처리 (int/double 구분 없음)
    • 계산 오류·부정확한 연산 시 NaN(Not a Number) 반환
    • null = 의도적으로 비운 값 / undefined = 값이 할당되지 않은 상태(초기화 안 함)

3. 객체(Object)

  • ⭐ 강조 — 객체 = 사용자정의 객체 + 내장 객체
  • ✍️ 필기 — 객체의 구성요소 = 속성(변수) + 메서드(함수)
    • 속성 접근은 프로퍼티, 동작 호출은 메서드
class Person {
    String name;
    void eat(){ ... }
}
P1 = new Person();
P2 = new Person();
P2.eat();          // "쩝쩝"
P2.name = "쭈굴";   // P2 객체에 대입
P1.name = "한주";   // P1 객체에 대입

4. Node.js ★필수암기

  • ⭐ 강조 — Node.js = 자바스크립트 코드가 단독으로 실행될 수 있는 런타임 실행 플랫폼
  • ✍️ 필기 — JS가 브라우저 밖에서도 단독 실행되게 해주는 소프트웨어 (자바의 JVM과 유사한 역할 비교)

5. 형변환(Type Conversion) ★필수암기

  • ⭐ 강조 — 명시적 형변환: String() / Number() / Boolean() 함수를 직접 사용
  • ✍️ 필기 — 묵시적(암묵적) 형변환: 연산 과정에서 자동으로 타입이 변환됨
"10" + 5  ===>  "105"          // 묵시적 형변환(문자열 연결)
Number("10") + 5  ===>  15     // 명시적 형변환(숫자로 변환)
  • ✍️ 필기 — 형변환 = 캐스팅(Casting). 피연산자의 type이 다르면 type을 통일한 뒤 연산한다
    • 비교 연산자: == 는 값만 비교 / === 는 값과 타입을 모두 비교

6. 템플릿 문자열 ★암기

  • ⭐ 강조 — 템플릿 문자열: 백틱( ` )으로 감싸고, ${ } 안에 표현식을 넣으면 문자열 안에서 계산됨
console.log(`273 + 52의 값은 ${273 + 52}입니다`)  // 273 + 52의 값은 325입니다

7. [참고] 연산자 (교재 02장)

  • 복합 대입 연산자: += , -= , *= , /= , %= (예: a += 1 은 a = a+1)
  • 증감 연산자: 변수++ / ++변수 (후위·전위), 변수-- / --변수
  • typeof 연산자: string·number·boolean·undefined·function·object·symbol·bigint 중 하나 반환
  • 입력 함수: prompt(메시지, 기본값) 문자열 입력 / confirm() 확인·취소(true/false) 반환

8. 메모리 구조 (스택 vs 힙)

  • ✍️ 필기 — 스택(Stack): 작고 빠르며 정리된 저장 공간 — 원시형 값 저장
  • ✍️ 필기 — 힙(Heap): 크고 유동적인 저장 공간 — 참조형(객체) 저장
