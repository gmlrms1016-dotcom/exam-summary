2. 🔥 APM 설치 (VITAMIN QUIZ 12-1)

2-1. 처음 — 기본 저장소로 설치 (수업 로그)

  • rpm -qa 이름 = 설치돼 있는지 확인 (아무것도 안 나오면 없음) → 기본 저장소 PHP = 8.3.19 · httpd 2.4.63 · mariadb-server 10.11.11 → 39 꾸러미
  • 🤖 ownCloud 10 은 PHP 7.4 가 필요 → 아래처럼 Remi 저장소의 PHP 7.4 로 다시 설치

2-2. 🔥 Remi 저장소 + PHP 7.4 (과제 = 이 순서)

dnf -y install dnf-utils https://rpms.remirepo.net/enterprise/10/remi/x86_64/remi-release-10.0-3.el10.remi.noarch.rpm   # Remi 저장소 등록 (EPEL 도 같이)
dnf -y module reset php                     # PHP 모듈 선택을 처음으로
dnf -y module enable php:remi-7.4           # PHP 7.4 (Remi) 를 쓰겠다고 정함
dnf -y install httpd mariadb-server php php-mysqlnd php-gd php-mbstring php-pecl-zip php-xml php-json php-intl
  • php-mysqlnd = PHP 가 MariaDB 에 연결하는 부품 · gd(그림) · mbstring(한글 같은 여러 바이트 글자) · zip · xml · json · intl = ownCloud 가 쓰는 PHP 확장
  • 학교 PC 기록: 한 줄(&&)로 이어 치면 PHP 7.4.33 + httpd + mariadb-server 56 꾸러미 설치 · 미러 연결 실패는 다른 미러로 넘어가서 괜찮음 · “PHP 7.4 End of Life” 경고는 정상

2-3. 서비스 켜기 · 확인

systemctl restart mariadb && systemctl enable mariadb    # DB 서버 시작 + 부팅 때 자동 시작
systemctl restart httpd && systemctl enable httpd        # 웹 서버 시작 + 자동 시작
systemctl status mariadb --no-pager                      # active (running) 이면 정상
systemctl status httpd --no-pager
  • restart = 껐다 켜기(꺼져 있으면 켬) · enable = 부팅할 때 자동으로 · status = 지금 상태 · --no-pager = 한 화면에 다 출력하고 바로 프롬프트로

2-4. 방화벽 · 웹 페이지 확인

firewall-cmd --permanent --add-service=http     # 80번 (웹)
firewall-cmd --permanent --add-service=https    # 443번 (보안 웹)
firewall-cmd --reload                           # 바꾼 설정 적용
firewall-cmd --list-services                    # 열린 서비스 목록에 http https 가 보이면 됨
echo '<?php phpinfo(); ?>' > /var/www/html/phpinfo.php    # PHP 정보 페이지
ip addr                                         # ens160 의 inet = 서버 주소 (Server 192.168.111.100 · Server(B) .200)
  • 수업(Server · GNOME) = 그래픽 firewall-config 창 → 설정 런타임 → 영구적 · 영역 public · 서비스 탭에서 http · https 체크 → 옵션 → Firewalld 다시 불러오기 · 창은 파일 → 끝내기로 닫기 (학교 PC 기록)
  • 수업은 gedit index.html 로 첫 화면을 만들고(Rocky 10 은 alias gedit="gnome-text-editor") Windows 크롬 http://192.168.111.100 · /phpinfo.php 로 확인 · 📖 phpinfo.php = 교재 714쪽
  • 🤖 웹 문서 폴더 = /var/www/html — 주소창 http://IP/파일이름 이 이 폴더의 파일

3. 🔥 MariaDB — ownCloud 가 쓸 DB · 사용자

MariaDB [(none)]> create database webDB;
Query OK, 1 row affected (0.001 sec)

MariaDB [(none)]> create user webuser@localhost identified by '비밀번호';
Query OK, 0 rows affected (0.001 sec)

MariaDB [(none)]> grant all on webDB.* to webuser@localhost;
Query OK, 0 rows affected (0.000 sec)

MariaDB [(none)]> exit
Bye
  • mysql = MariaDB 접속 (root · 서버 안) · webDB = ownCloud 가 표를 만들 DB · webuser@localhost = 서버 안(localhost)에서만 접속하는 사용자 · webDB.* = webDB 의 모든 표 (12주차 *.* = 모든 DB)

4. 🔥 ownCloud 설치 (VITAMIN QUIZ 12-3)

cd /var/www/html 로 웹 문서 폴더에 들어간 뒤:

순서명령하는 일
1wget 주소인터넷에서 파일 내려받기 (69M zip)
2unzip -q조용히(-q) 압축 풀기 → owncloud 폴더
3mkdir owncloud/data올린 파일이 저장될 폴더
4🔥 chown -R apache:apache owncloud주인 · 그룹을 apache 로 (-R = 안쪽까지 모두) — 🤖 웹 서버(httpd)가 apache 사용자로 돌아서 이래야 data 에 쓸 수 있음
5chmod -R 755 owncloud주인 rwx · 나머지 r-x (7 = 4+2+1 · 5 = 4+1)
6systemctl restart httpd웹 서버 다시 시작
  • 크롬 http://IP/owncloud → 관리자 계정 admin 만들기 → 저장소 · 데이터베이스 = MySQL/MariaDB · 사용자 webuser · DB 이름 webDB · 호스트 localhost → 설치 완료 → admin 로그인
  • admin → 사용자 → thisuser 만들기 → thisuser 로그인 → owncloud_test.txt 업로드 → 서버에서 확인:

6. 📖 웹 서버 설정 파일 httpd.conf (12.3 · 747 ~ 748쪽)

  • 아파치 설정 파일 = /etc/httpd/conf/httpd.conf — 고급 웹 서비스를 만들려면 의미를 알아 두면 좋음 (수업 · 과제에선 고치지 않음)
📖 설정뜻
ServerRoot "/etc/httpd"웹 서버의 설정 파일 · 로그 파일 등이 저장되는 최상위 디렉터리
Listen 80웹 서버의 포트 번호 (대부분 80번)
Include conf.modules.d/*.conf설정 파일에 포함될 파일의 경로와 이름
User apache / Group apache웹 서비스를 작동하는 사용자와 그룹 (→ ownCloud 를 chown apache:apache 한 이유)
ServerAdmin root@localhost관리자의 메일 주소
DocumentRoot "/var/www/html"웹 서버의 홈 디렉터리 — http://서버IP 로 접속되는 디렉터리
<Directory "/var/www/html"> … </Directory>디렉터리 단위로 허가 · 거부 등 접근 권한 설정 · Options Indexes FollowSymLinks = DirectoryIndex 에 지정된 파일(index.html 등)이 없으면 파일 목록을 대신 출력 · AllowOverride None · Require all granted
  • 고친 뒤 문법 검사 = service httpd configtest → 이상이 없으면 Syntax OK

8. 🔥 시험 대비 핵심 요약

  • 🔥 ✍️ 리눅스 시험 = 필기시험 → 명령을 손으로 쓸 수 있게: APM 설치 한 줄 · 서비스 3종(restart · enable · status) · 방화벽 3줄 · ownCloud 6단계
  • 📖 APM = Apache(httpd) · PHP · MariaDB · 리눅스 환경 = LAPM · Rocky 는 dnf 로 한 번에 · 웹 문서 폴더 /var/www/html · 웹 = 80번 · DB = 3306번
  • 📖 설정 파일 /etc/httpd/conf/httpd.conf — ServerRoot /etc/httpd · Listen 80 · User/Group apache · DocumentRoot /var/www/html · <Directory> = 디렉터리마다 접근 권한 · 검사 service httpd configtest → Syntax OK
  • PHP 7.4 = Remi 저장소 → module reset php → module enable php:remi-7.4
  • ownCloud = wget → unzip → mkdir owncloud/data → 🔥 chown -R apache:apache owncloud → chmod -R 755 → restart httpd → 웹 설치(DB = webDB · webuser@localhost)
  • 올린 파일 위치 = owncloud/data/사용자/files · DB 준비 = create database webDB; · create user webuser@localhost identified by '…'; · grant all on webDB.* to webuser@localhost;
