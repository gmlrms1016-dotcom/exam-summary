7주차 — 🔥 ALTER · Quiz 7-3 dept · dmember (7주차 자세히)

  • 🔥 ✍️ 필기 — ALTER ADD 가 시험에 나옴 (“추가하는 게 시험문제임”) · 7주차 내용은 시험의 10%
  • ALTER (DDL) = 테이블 구조 변경 — 추가 ALTER TABLE project ADD budget int; (기존 행의 budget 은 NULL) · 수정 ALTER TABLE project MODIFY projname varchar(20); (✍️ MySQL · Oracle 문법, MS-SQL 은 다름) · 삭제 ALTER TABLE project DROP COLUMN budget;
  • 🔥 Quiz 7-3 (8 · 9쪽 시험 페이지) — 생성 순서 dept → dmember (부모 → 자식) · 삭제 순서 dmember → dept (자식 → 부모) · 입력 순서 dept → dmember · dmember.dept_id 자료형 = char(3) (참조하는 열과 같게) · FK 테이블명 dept · FK 열 dept_id
  • 9쪽 빈칸: 1) dmember 2) dept 3) CREATE 4) PRIMARY · (빈칸) CREATE · 5) char(3) · (빈칸) PRIMARY · 6) FOREIGN KEY(dept_id) REFERENCES dept(dept_id)
  • 순서를 어기면 — 자식 먼저 CREATE 1824 · 자료형 다름 3780 · 부모 먼저 DROP 3730 · 없는 학과 입력 1452

  • 🧮 정수 범위는 C · 자바와 같은 공식 — TINYINT 8비트 → 2⁸ = 256 가지 → SIGNED -128 ~ 127 / UNSIGNED 0 ~ 255 (INT UNSIGNED = 음수 자리를 양수로 돌려서 0 ~ 약 42억)
  • ⚠️ 범위 밖 값을 넣으면 — 기본(STRICT) 모드에서 ERROR 1264 Out of range value (TINYINT 에 128 · UNSIGNED 에 -1 · INT 에 2147483648 · decimal(3,1) 에 100) · 글자가 길면 ERROR 1406 Data too long (varchar(30) 에 31 글자) · 소수 자리만 넘으면 오류 없이 반올림 (decimal(3,1) 에 12.36 → 12.4)
  • CHAR(n) · VARCHAR(n) 의 n 은 바이트가 아니라 글자 수 → 한글 '가' 도 1 글자 · INT(11) 의 괄호 숫자는 화면 표시 폭일 뿐 범위와 상관없음
-- 📏 범위 확인 — 끝값은 들어가고, 1 만 넘어도 오류
CREATE DATABASE rangedb;                          -- 연습용 데이터베이스 만들기
USE rangedb;                                      -- 이제부터 rangedb 사용
CREATE TABLE t (                                  -- 범위 확인용 테이블
    a TINYINT,                                    -- 1byte · SIGNED → -128 ~ 127
    b TINYINT UNSIGNED,                           -- 1byte · 음수 없음 → 0 ~ 255
    c INT,                                        -- 4byte → -2147483648 ~ 2147483647
    d DECIMAL(3, 1)                               -- 전체 3자리 중 소수 1자리 → -99.9 ~ 99.9
);                                                -- 테이블 정의 끝
INSERT INTO t VALUES (127, 255, 2147483647, 99.9);   -- 전부 최댓값 → 들어감
INSERT INTO t VALUES (128, 0, 0, 0);              -- a 에 128 → 127 을 넘음 → ERROR 1264 Out of range value for column 'a'
INSERT INTO t VALUES (0, -1, 0, 0);               -- b 는 UNSIGNED → -1 불가 → ERROR 1264 (column 'b')
INSERT INTO t VALUES (0, 0, 0, 12.36);            -- 소수 2자리 → 1자리로 반올림 → 12.4 로 저장 (오류 아님)
SELECT * FROM t;                                  -- 들어간 2줄만 나옴 → 127 255 2147483647 99.9 / 0 0 0 12.4
a   | b   | c          | d
127 | 255 | 2147483647 | 99.9
0   | 0   | 0          | 12.4
