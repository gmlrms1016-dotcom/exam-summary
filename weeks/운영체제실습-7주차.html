2. 프로세스 — 개념과 상태 (✍️ 필기)

  • ✍️ 필기 프로세스의 상태 = 생성 · 실행 · 준비 · 대기 · 종료
  • ✍️ 필기 상태가 있는 이유 — “CPU 는 멀티가 안 되고 순차적으로 처리를 하니 하나씩 생성 → 실행 → 준비 → 대기 → 종료 라는 절차를 거침”
    • 🤖 보충 — CPU(코어 하나)는 한 순간에 프로세스 하나만 실행해요. 그래서 여러 프로세스가 번갈아 쓰려면 CPU 차례를 기다리는 준비, 입출력(키보드 입력 · 파일 읽기)이 끝나길 기다리는 대기 상태가 필요해요
상태🤖 뜻
생성프로그램이 메모리에 올라와 프로세스가 만들어짐
준비실행할 준비가 끝나 CPU 차례를 기다림
실행CPU 를 받아 실제로 실행 중
대기입출력 같은 일이 끝나기를 기다림 (끝나면 다시 준비로)
종료실행이 끝나 사라짐
  • ✍️ 필기 포그라운드 프로세스 vs 백그라운드 프로세스 · 프로세스 번호 vs 작업 번호
    • 🤖 프로세스 번호(PID) = 시스템 전체에서 프로세스마다 붙는 번호 (ps -ef 두 번째 칸) / 작업 번호 = 그 터미널에서 jobs 에 [1] 처럼 나오는 번호 (fg 1 · bg 1 에 씀) — 예: [1] 2680 = 작업 번호 1 · PID 2680
  • ✍️ 필기 프로세스 명령어 ps 와 옵션 — 교수님이 언급한 옵션 -e · -f
    • 🤖 -e = 모든(every) 프로세스 · -f = 자세히(full — UID · PID · PPID · 시작 시각 · 명령) → 둘을 합친 ps -ef
  • ✍️ 필기 yes — 🤖 y 를 끝없이 출력하는 명령 → 6주차에 yes > /dev/null 로 프로세스 실습
  • ✍️ 필기 service 는 데몬이라고도 하며 서버 프로세스를 의미하고, 거의 백그라운드 프로세스
  • ✍️ 필기 systemctl 명령으로 언급한 옵션 (start, stop, restart, en??) — service 의 시작과 종료
    • ⚠️ 정정 — “en??” = enable (부팅할 때 자동으로 시작) · 반대는 disable
systemctl status sshd.service      # 서비스 상태 보기 (active = 실행 중)
systemctl stop sshd.service        # 서비스 정지
systemctl start sshd.service       # 서비스 시작
systemctl restart sshd.service     # 서비스 다시 시작 (stop + start)
systemctl enable sshd.service      # 부팅할 때 자동으로 시작되게

#! /bin/sh                                # 이 파일을 sh(셸)로 실행
echo "1. 첫 번째 정수 입력"               # 안내 출력

#! /bin/sh                                # sh 로 실행
echo "> 명령 수행 파라미터 (A, B, O, AB)"  # 안내 출력
case "$1" in                              # $1 = sh test_1102.sh A 의 첫 번째 값
A | a)                                    # A 또는 a (대/소문자 구별 없이)
echo "A형을 선택하였습니다." ;;           # 출력 후 case 끝으로
B | b)                                    # B 또는 b
echo "B형을 선택하였습니다." ;;           # 출력
O | o)                                    # O 또는 o
echo "O형을 선택하였습니다." ;;           # 출력
AB | ab | Ab | aB)                        # AB 의 대/소문자 조합
echo "AB형을 선택하였습니다." ;;          # 출력
*)                                        # 그 밖의 모든 값
echo "혈액형은 알파벳 대/소문자 구별 없이 A, B, O, AB만 가능합니다." ;;   # 알림 메시지
esac                                      # case 끝
echo "프로그램을 종료합니다."             # 마지막 메시지 (문제 6번)
exit 0                                    # 정상 종료

  1. 셸 스크립트 프로그램 test_1103.sh 작성하기
  2. 프로그램은 while문과 case~esac문 사용하기
  3. 알파벳은 변수를 선언하여 키보드로 입력받기
  4. 대/소문자 구별 없이 알파벳 H, S, P, E를 조건으로 정하기
  5. 출력메시지는 H:처음, S:시작, P:스톱, E:종료
  6. H는 continue 사용, P는 break 사용, E는 exit 0 사용
  7. H, S, P, E 알파벳 이외의 알파벳 입력 시 무한 반복하기
# gedit test_1103.sh
# sh test_1103.sh
💡 모범답안 · 실행 결과 (입력 H · s · k · p) 
#! /bin/sh                                # sh 로 실행
echo "> 처음(H)/시작(S)/스톱(P)/종료(E) 분기 프로그램 "   # 안내 출력
while [ 1 ]                               # 조건이 늘 참 → 무한 반복
do                                        # 반복 시작
echo "> 대/소문자 구별 없이 알파벳 입력 (H, S, P, E) "   # 입력 안내
read choice                               # 키보드 입력 → choice
case $choice in                           # choice 값으로 나누기
H | h)                                    # H 또는 h
echo "처음" ; continue ;;                 # 출력 후 continue → 반복 처음으로
S | s)                                    # S 또는 s
echo "시작" ;;                            # 출력 후 다음 반복
P | p)                                    # P 또는 p
echo "스톱" ; break ;;                    # 출력 후 break → while 을 빠져나감
E | e)                                    # E 또는 e
echo "종료" ; exit 0 ;;                   # 출력 후 프로그램 끝
*)                                        # 그 밖의 알파벳
echo "허용하는 알파벳 대/소문자 구별 없이 H, S, P, E 만 가능합니다. "   # 알림
continue ;;                               # 다시 입력받기 (무한 반복)
esac                                      # case 끝
done                                      # while 끝
exit 0                                    # 정상 종료
> 처음(H)/시작(S)/스톱(P)/종료(E) 분기 프로그램 
> 대/소문자 구별 없이 알파벳 입력 (H, S, P, E) 
처음
> 대/소문자 구별 없이 알파벳 입력 (H, S, P, E) 
시작
> 대/소문자 구별 없이 알파벳 입력 (H, S, P, E) 
허용하는 알파벳 대/소문자 구별 없이 H, S, P, E 만 가능합니다. 
> 대/소문자 구별 없이 알파벳 입력 (H, S, P, E) 
스톱

  2. 사용자 정의 함수 2개(hap, cha) 정의하기

  5. 키보드로 두 수를 입력 받아 변수 num1과 num2에 저장하기

💡 모범답안 · 실행 결과 (입력 1 · 23 · 56) 
#! /bin/sh                                # sh 로 실행
echo "> 사용자 정의 함수 프로그램 "       # 안내 출력
hap ( )                                   # 덧셈 함수 hap 정의
{                                         # 함수 몸통 시작
echo "> 첫 번째 정수 입력"                # 입력 안내
read num1                                 # 키보드 → num1
echo "> 두 번째 정수 입력 "               # 입력 안내
read num2                                 # 키보드 → num2
result=`expr $num1 + $num2`               # 덧셈
echo " 덧셈 결과 : $num1 + $num2 = $result "   # 결과 출력 (return 문 없음)
}                                         # hap 끝
cha ( )                                   # 뺄셈 함수 cha 정의
{                                         # 함수 몸통 시작
echo "> 첫 번째 정수 입력"                # 입력 안내
read num1                                 # 키보드 → num1
echo "> 두 번째 정수 입력 "               # 입력 안내
read num2                                 # 키보드 → num2
result=`expr $num1 - $num2`               # 뺄셈
echo " 뺄셈 결과 : $num1 - $num2 = $result "   # 결과 출력 (return 문 없음)
}                                         # cha 끝
echo "> 함수를 숫자로 선택하세요.(1:덧셈, 2:뺄셈)"   # 선택 안내
read choice                               # 키보드 → choice
case $choice in                           # 고른 숫자로 나누기
1)                                        # 1 이면
hap ;;                                    # hap 함수 호출
2)                                        # 2 이면
cha ;;                                    # cha 함수 호출
*)                                        # 1 · 2 가 아니면
echo "허용되는 숫자가 아니라서 프로그램을 종료합니다. " ;;   # 종료 안내
esac                                      # case 끝
exit 0                                    # 정상 종료
