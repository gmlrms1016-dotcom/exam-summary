3. 🔥 사용자 등록 — root 비밀번호 · 원격 사용자 winuser

단계명령뜻
사용자 목록use mysql; → select user, host from user;🔥 사용자 = '이름'@'호스트' 짝 (처음 6 rows)
root 비밀번호alter user 'root'@'localhost' identified by '비밀번호'; → flush privileges;이제 mariadb 만 치면 ERROR 1045 Access denied → mariadb -h localhost -u root -p
원격 사용자create user winuser@'192.168.111.%' identified by '비밀번호';🤖 % = 아무 글자 → 192.168.111.아무 번호 컴퓨터에서 접속하는 winuser (7 rows)
권한grant all on *.* to winuser@'192.168.111.%'; → flush privileges;🤖 *.* = 모든 DB 의 모든 표 · ⚠️ 노션 수업 로그엔 없던 줄 — 없으면 winuser 로 CREATE DATABASE 를 못 함 (학교 PC 기록 · 사용자가 “grant all on *.*” 를 알려 줌)
  • 🤖 -h = 접속할 서버(host) · -u = 사용자(user) · -p = 비밀번호를 물어봄(password) — -p 뒤에 비밀번호를 붙여 쓰면 묻지 않고 바로 (📄 txt 원본 mysql -h 192.168.111.100 -u winuser -p비밀번호 · 화면에 남아서 붙여 쓰지 않는 게 안전)
  • 🤖 flush privileges; = 권한 표를 다시 읽기 — create user · grant 같은 계정 명령은 바로 적용돼서 안 해도 동작하지만, 수업 · 과제 순서대로 써 두면 돼요

5. 🔥 NFS — 디렉터리 공유 (수업 Server → Client · 과제 14-1 Server(B) → Client · Windows)

흐름 한눈에

쪽단계명령뜻
서버① 패키지rpm -qa nfs-utils → 없으면 dnf -y install nfs-utils수업 Server 엔 있었음 · ⚠️ Server(B) 엔 없어서 설치
서버② 공유 설정/etc/exports 에 /share *(rw,sync)🔥 공유할 폴더 · 허용할 컴퓨터 · (옵션) — * = 모든 컴퓨터
서버③ 폴더mkdir /share → chmod 707 /share → cp /boot/vm* /share707 = 다른 사용자(others)도 rwx → 클라이언트 사용자가 파일을 넣을 수 있음
서버④ 서비스systemctl restart nfs-server → enable → status🔥 active (exited) 가 정상
서버⑤ 확인exportfs -v/share <world>(sync,…,rw,…,root_squash,…)
서버⑥ 방화벽systemctl stop firewalld수업 방식 = 방화벽을 끔 (🤖 실습용 · 보안은 약해짐)
클라이언트⑦ 확인showmount -e 192.168.111.100/share * = 공유 목록
클라이언트⑧ 마운트mkdir myshare → sudo mount -t nfs 192.168.111.100:/share myshare🔥 mount -t nfs 서버IP:/공유폴더 마운트할곳
클라이언트⑨ 쓰기ls -l myshare/ → cp /boot/mem* ~/myshare/testfile서버 /share 에 바로 생김
Windows⑩ 연결mount.exe 192.168.111.200:/share Z: → dir Z:\학교 PC 기록 · PowerShell 의 mount 는 다른 명령이라 .exe 까지
📄 /etc/exports 옵션 (exportfs -v 에 보인 것)🤖 뜻
rw읽기 · 쓰기 (ro = 읽기만)
sync쓴 내용을 디스크에 기록한 뒤 응답 (바로 기록)
root_squash클라이언트의 root 를 익명 사용자로 바꿈 (기본값 · 서버 root 권한을 막음)
<world>* = 모든 컴퓨터에 공유

7. 트러블슈팅 (수업 로그 · 학교 PC 기록)

  • show database → -> 만 계속 / ERROR 1064 → show databases; (s · ; 확인) · 안 끝난 문장은 Ctrl+C
  • use msql → ERROR 1049 Unknown database → DB 이름 오타
  • mariadb → ERROR 1045 (using password: NO) → root 비밀번호를 정했으니 mariadb -h localhost -u root -p
  • create user winuser'192…' 처럼 @ 빠뜨림 → ERROR 1064
  • winuser 로 CREATE DATABASE 가 안 됨 → grant all on *.* to winuser@'192.168.111.%'; + flush privileges;
  • Windows 에서 접속 안 됨 → Server(B) 방화벽 3306(--permanent + --reload) · winuser 호스트가 192.168.111.% 인지 · 접속 IP 가 .200 인지
  • /etc/exports 만 침 → 허가 거부 (실행하려 함) → 편집기(gnome-text-editor · nano)로 열거나 cat 으로 보기
  • showmount → RPC: Program not registered → showmount -e 서버IP
  • mkdir /myshare → 허가 거부 → 홈에 mkdir myshare
  • umount → device is busy → 터미널이 그 폴더 안이거나 열린 파일 · cd ~ 뒤 다시
  • ls -l\ 처럼 끝에 \ → 다음 줄을 기다리는 > → Ctrl+C
  • dnf 가 느림 → 저장소에서 종속 꾸러미를 받는 중 · Complete!(완료되었습니다!)까지 기다리기 (^C X)

9. 🔥 시험 대비 핵심 요약

  1. MariaDB 설치 = rpm 5개(MariaDB-client · common · server · shared · galera-4) → dnf -y install M*.rpm g*.rpm → systemctl restart · enable mariadb → status active (running)
  2. MariaDB 포트 3306 — 글자 화면 = firewall-cmd --permanent --add-port=3306/tcp + firewall-cmd --reload (📖 VITAMIN QUIZ 11-1 HINT2)
  3. systemctl enable = 부팅 때 자동 시작 · restart = 지금 다시 시작
  4. DB 사용자 = '이름'@'호스트' · % = 아무 글자 → create user winuser@'192.168.111.%' identified by '…'; → grant all on *.* to winuser@'192.168.111.%'; (*.* = 모든 DB · 모든 표) → flush privileges;
  5. root 비밀번호를 정한 뒤엔 mariadb 만으로는 ERROR 1045 → mariadb -h localhost -u root -p
  6. NFS 서버 = nfs-utils · /etc/exports = 공유폴더 허용호스트(옵션) → /share *(rw,sync) (rw 읽기 · 쓰기 · sync 바로 기록) · chmod 707 · systemctl restart nfs-server = active (exited) 정상 · exportfs -v
  7. NFS 클라이언트 = showmount -e 서버IP → mount -t nfs 서버IP:/share 마운트할곳 · Windows = mount.exe 서버IP:/share Z:
