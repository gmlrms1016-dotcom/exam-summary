9주차 · 6장 디스크 관리와 사용자별 공간 할당

포인트핵심 · 답그림
디스크 추가 순서(VM 끄고) SCSI 디스크 추가 → fdisk → mkfs.ext4 → mkdir → mount → /etc/fstab → reboot · df⑮
fdisk 키n 새로 · p primary(Select) / print(Command) · d 삭제 · w 저장 — w 전엔 디스크가 안 바뀜 · Last sector +2G = 2GB 만큼⑮
마운트하면 가려짐마운트 전 test1 (sda2) → mount 뒤 lost+found · test2 (sdb1) → umount 뒤 다시 test1 — 지워진 게 아니라 가려짐⑯
fstab 6칸장치 · 마운트 위치 · 파일 시스템 · 옵션 · dump · fsck 순서 — /dev/sdb1 /mydata ext4 defaults 0 0⑰
장치 이름이 바뀜부팅 · 디스크 추가 · 제거마다 sda ↔ sdb 가 바뀔 수 있음 → fstab 장치를 못 찾으면 응급 모드 → root 로그인 → fstab 고치기 · # 주석 → 예방 = UUID(blkid)⑱
절대 · 상대경로/ 로 시작 = 절대 · mydata/test1 = /root/mydata/test1 · vi etc/fstab → E212
쿼터 순서defaults,usrquota,grpquota → tune2fs -O quota → 다시 마운트 → quotacheck -augmn → quotaon -avug → edquota -u → quota · repquota · edquota -p A B = 한도 복사⑲
soft · hardsoft = 유예 기간(기본 7일) 동안 넘을 수 있음 · hard = 절대 못 넘음 Disk quota exceeded · 단위 KB (40960 = 40MB) · 0 = 제한 없음⑲
viEsc 먼저 → :wq 저장 · :q! 저장 안 함 · G 맨 아래 · o 새 줄 · dd 줄 삭제 · u 되돌리기⑬
자세한 로그 · 캡처는 9주차 · 문제는 🔒 실제시험.
