9주차 · 6장 디스크 관리와 사용자별 공간 할당

포인트핵심 · 답그림
디스크 추가 순서(VM 끄고) SCSI 디스크 추가 → fdisk → mkfs.ext4 → mkdir → mount → /etc/fstab → reboot · df⑮
fdisk 키n 새로 · p primary(Select) / print(Command) · d 삭제 · w 저장 — w 전엔 디스크가 안 바뀜 · Last sector +2G = 2GB 만큼⑮
마운트하면 가려짐마운트 전 test1 (sda2) → mount 뒤 lost+found · test2 (sdb1) → umount 뒤 다시 test1 — 지워진 게 아니라 가려짐⑯
fstab 6칸장치 · 마운트 위치 · 파일 시스템 · 옵션 · dump · fsck 순서 — /dev/sdb1 /mydata ext4 defaults 0 0⑰
장치 이름이 바뀜부팅 · 디스크 추가 · 제거마다 sda ↔ sdb 가 바뀔 수 있음 → fstab 장치를 못 찾으면 응급 모드 → root 로그인 → fstab 고치기 · # 주석 → 예방 = UUID(blkid)⑱
절대 · 상대경로/ 로 시작 = 절대 · mydata/test1 = /root/mydata/test1 · vi etc/fstab → E212
쿼터 순서defaults,usrquota,grpquota → tune2fs -O quota → 다시 마운트 → quotacheck -augmn → quotaon -avug → edquota -u → quota · repquota · edquota -p A B = 한도 복사⑲
soft · hardsoft = 유예 기간(기본 7일) 동안 넘을 수 있음 · hard = 절대 못 넘음 Disk quota exceeded · 단위 KB (40960 = 40MB) · 0 = 제한 없음⑲
viEsc 먼저 → :wq 저장 · :q! 저장 안 함 · G 맨 아래 · o 새 줄 · dd 줄 삭제 · u 되돌리기⑬

10주차 · 6장 RAID — Linear RAID 구축 · 고장 · 복구 · RAID 0

포인트핵심 · 답그림
RAID · 하드웨어 vs 소프트웨어여러 디스크를 하나처럼 · 하드웨어 RAID = 컨트롤러 장비 · 안정적 · 비쌈 · 소프트웨어 RAID = 운영체제 지원 · 저렴 (mdadm)⑳
RAID 종류기본 7가지 = Linear · RAID 0 ~ 5 · 실무 = Linear · 0 · 1 · 5 · 6 · 1+0 · 단순 볼륨은 RAID 아님⑳
최소 디스크 · 용량Linear 2개↑ · N / RAID 0 2개↑ · N / RAID 1 2개 · N/2 / RAID 5 3개↑ · N−1 / RAID 6 4개↑ · N−2⑳
Linear vs RAID 0Linear = 앞 디스크를 다 채운 뒤 다음 (12초 · 크기 달라도 전부) · RAID 0 = 스트라이핑 동시에 (4초 · 가장 빠름 · 하나만 고장 나도 전부 잃음 → 잃어도 되는 데이터)㉑
RAID 1미러링 · 같은 데이터 2벌 → 결함 허용 · 공간 효율 50% · 속도 변화 없음㉑
RAID 5 · 6짝수 패리티 = 한 행의 1 개수가 짝수가 되게 (0+0+0+P → P=0) → 디스크 1개 고장 복구 · RAID 6 = 패리티 2개 → 2개 동시 고장까지 · 속도 약간 ↓㉒
VMware SCSI슬롯 4개 × 15개 (0:7 제외) = 60개 · 디스크 종류는 SCSI 로
Linear RAID 명령fdisk(t → fd) → mdadm --create /dev/md9 --level=linear --raid-devices=2 /dev/sdb1 /dev/sdc1 → mdadm --detail → mkfs.ext4 /dev/md9 → mount /dev/md9 /raidLinear → fstab · mdadm --detail --scan > /etc/mdadm.conf㉓
고장 → 복구디스크를 빼면 응급 모드 · mdadm --run = not enough drives → mdadm --stop + fstab # → 새 디스크 · 다시 --create(y) · mkfs → 장치는 복구 · 데이터(testFile)는 ✗㉓
RAID 0 명령mdadm --create /dev/md0 --level=0 --raid-devices=2 /dev/sdb1 /dev/sdc1 → /raid0 · detail = raid0 · Chunk Size 512K

11주차 · 원격 접속 (텔넷 · XRDP) + 🔥 LVM 개념

  • ✍️ “LVM 실습은 안 하지만 시험에 개념은 출제함” — 물리 볼륨(파티션) → 볼륨 그룹(합침) → 논리 볼륨(나눔) · pvcreate → vgcreate → lvcreate → mkfs.ext4 → mount · Rocky 기본 설치 = LVM (📖 462 ~ 464쪽)
  • 텔넷 서버 — dnf -y install telnet-server → adduser teluser · passwd teluser → 방화벽 → systemctl start telnet.socket → active (listening) · 포트 23
  • 글자 화면 방화벽 — firewall-cmd --permanent --add-service=telnet → firewall-cmd --reload (그래픽 = firewall-config)
  • XRDP — dnf -y install epel-release → dnf -y install tiger*.rpm xrdp*.rpm → systemctl start · enable xrdp → 3389 허용 → Windows mstsc → rocky

12주차 · DB 서버(MariaDB) · NFS

포인트핵심 · 답그림
MariaDB 설치rpm 5개(MariaDB-client · common · server · shared · galera-4) → dnf -y install M*.rpm g*.rpm → systemctl restart · enable mariadb → status = active (running)㉗
포트 3306글자 화면 = firewall-cmd --permanent --add-port=3306/tcp → firewall-cmd --reload (📖 VITAMIN QUIZ 11-1 HINT2) · 그래픽 = firewall-config㉗
접속 · 오류mariadb → show databases; (s · ; 빠뜨리면 ERROR 1064 · ->) · root 비밀번호를 정한 뒤엔 mariadb 만 = ERROR 1045 → mariadb -h localhost -u root -p㉗
DB 사용자사용자 = '이름'@'호스트' (select user, host from user;) · create user winuser@'192.168.111.%' identified by '…'; (% = 아무 글자)㉘
권한grant all on *.* to winuser@'192.168.111.%'; (*.* = 모든 DB · 모든 표) → flush privileges; · 없으면 winuser 로 CREATE DATABASE 못 함㉘
실습 3Windows mariadb -h 192.168.111.200 -u winuser -p → CREATE DATABASE shopping_db CHARACTER SET utf8; → customer 표(id 기본키) → SELECT * FROM customer; = id 순㉘
NFS 서버nfs-utils · /etc/exports = 공유폴더 허용호스트(옵션) → /share *(rw,sync) (rw 읽기 · 쓰기 · sync 바로 기록) → mkdir /share · chmod 707 → systemctl restart nfs-server = active (exited) 정상 · exportfs -v㉙
NFS 클라이언트showmount -e 서버IP → mkdir myshare → sudo mount -t nfs 서버IP:/share myshare · Windows = mount.exe 서버IP:/share Z: (그냥 mount 는 PowerShell 명령)㉙

PHP 7.4 (Remi)dnf -y install dnf-utils (remi-release-10 주소) → dnf -y module reset php → dnf -y module enable php:remi-7.4 → dnf -y install httpd mariadb-server php php-mysqlnd php-gd php-mbstring php-pecl-zip php-xml php-json php-intl (📖 VITAMIN QUIZ 12-1)㉚
