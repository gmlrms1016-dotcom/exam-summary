2. 동기 vs 비동기 · 단일 스레드 vs 멀티 스레드

✍️ 필기 — 클라이언트에서 백엔드까지 답이 오기까지 아무것도 못 하는 것을 "동기화" 라고 함 · setTimeout 은 비동기화로 선언되는 내장함수
🤖 필기에 적은 요청 — "비동기화와 동기화 차이를 표로 · 멀티스레드, 단일스레드 차이도 표로" — 대로 정리한 표예요.
구분동기 (synchronous)비동기 (asynchronous)
실행 방식앞 작업이 끝날 때까지 기다렸다가 다음 작업기다리지 않고 다음 작업을 먼저 실행 · 끝난 작업은 나중에 처리(콜백)
필기 예백엔드 답이 올 때까지 클라이언트가 아무것도 못 함setTimeout 3초를 기다리는 동안 아래 console.log("끝") 이 먼저 찍힘
실행 순서코드에 쓴 순서 그대로코드 순서와 다를 수 있음
장점흐름이 단순해서 이해하기 쉽다기다리는 동안 다른 일을 해서 화면이 멈추지 않는다 · 전체 시간이 짧아진다
단점오래 걸리는 작업 하나가 전체를 멈춘다실행 순서를 따라가기 어렵다
💡 비동기 작업이 좋은 이유 — 서버 응답·타이머처럼 오래 걸리는 일을 기다리는 동안에도 다음 코드, 클릭, 화면 갱신이 계속된다 → 사용자가 멈춘 화면을 보지 않는다
구분단일 스레드 (single thread)멀티 스레드 (multi thread)
뜻일하는 흐름(스레드)이 1개 → 한 번에 한 가지 일스레드가 여러 개 → 여러 일을 동시에
예자바스크립트 (브라우저 · Node.js 의 JS 실행)스레드를 여러 개 만드는 프로그램 (예: 자바의 Thread)
장점구조가 단순하고, 같은 데이터를 동시에 고치는 충돌이 없다여러 작업을 동시에 처리해서 빠르다
단점오래 걸리는 일이 있으면 뒤의 일이 모두 기다린다 → 그래서 JS 는 비동기를 쓴다스레드끼리 데이터가 꼬이지 않게 관리하기 어렵다

3. setTimeout · clearTimeout — 한 번 예약 ★

📌 setTimeout(함수, 밀리초) = 정해진 시간(1000 = 1초) 뒤에 한 번 실행하는 내장함수 · 기다리는 동안 아래 코드가 먼저 실행된다 (비동기)

예제 ① 0929_03.js — "끝" 이 먼저 찍힌다

// 0929_03.js 내장함수 : setTimeout — 3초 뒤에 한 번 실행 (비동기)
console.log("시작");               // ① 시작
setTimeout(() => {               // 3초 뒤에 실행할 함수를 예약 (기다리지 않고 바로 다음 줄로)
    console.log("3초가 지났습니다!");   // ③ 3초 뒤 → 3초가 지났습니다!
}, 3000);                  // 3000 밀리초 = 3초
console.log("끝");         // 3초를 기다리지 않고 바로 실행된다
시작
끝
3초가 지났습니다!

예제 ② 0929_03.js — 인수 넘기기 · 예약 취소 clearTimeout

// 0929_03.js setTimeout(함수, 시간, 인수1, 인수2) — 3번째부터는 함수에 넘길 인수
setTimeout(greet, 1000, '지민', '개발자');   // 1초 뒤 greet('지민', '개발자') — 함수는 괄호 없이 넘긴다 (콜백)
function greet(name, role) {                  // 선언적 함수라 아래에 있어도 된다 (호이스팅)
    console.log(`안녕하세요, ${role} ${name}님!`);   // 1초 뒤 → 안녕하세요, 개발자 지민님!
}                                              // greet 함수 끝 → 호출한 곳으로 돌아감

const timerId = setTimeout(() => {            // setTimeout 은 예약 번호(timerId)를 돌려준다
    console.log("이 메시지는 출력되지 않습니다.");          // 예약이 취소돼서 실행되지 않음
}, 5000);                                      // 5000 밀리초 = 5초 뒤로 예약했던 것
clearTimeout(timerId);                        // 예약 취소 → 5초가 지나도 아무것도 안 나온다
안녕하세요, 개발자 지민님!
📌 인수는 순서대로 name = '지민', role = '개발자' 로 들어가고, 템플릿 문자열이 ${role} ${name} 순서라서 개발자 지민님

✍️ 필기 — "둘다 실행이 된다 안된다(차이)"

필기의 두 코드(let a=()=>{} / function a(){...})는 a 를 부르지 않아서 둘 다 오류 없이 실행돼요. 차이는 선언보다 먼저 쓸 때 생겨요 → 5주차 호이스팅 복습
// ① 선언적 함수 — 선언보다 먼저 setTimeout 에 넘겨도 된다 (호이스팅)
console.log("시작");                      // 시작
setTimeout(a, 1000);                    // 1초 뒤 a 실행을 예약 (함수 a 는 괄호 없이 넘김)
function a() { console.log("a 실행"); }   // 선언적 함수 → 호이스팅돼서 위에서 써도 됨 → 1초 뒤 a 실행
시작
a 실행
// ② let 에 담은 화살표 함수 — 선언보다 먼저 쓰면 오류
console.log("시작");                        // 시작
setTimeout(b, 1000);                      // ← 오류: b 는 아래 let 줄 전이라 아직 쓸 수 없음 (ReferenceError)
let b = () => { console.log("b 실행"); };   // let 에 담은 화살표 함수 (선언 뒤에만 사용 가능)
시작
ReferenceError: Cannot access 'b' before initialization

4. setInterval · clearInterval — 반복 예약

내장함수하는 일멈추기
setTimeout(함수, 시간)시간 뒤 한 번 실행clearTimeout(번호)
setInterval(함수, 시간)시간마다 계속 반복 실행clearInterval(번호)

예제 ① 0929_03.js — 멈추지 않는 setInterval

// 0929_03.js setInterval — 1초마다 반복 (멈추는 코드가 없음)
let count = 0;                   // 경과 초를 셀 변수
setInterval(() => {              // 1초마다 아래 함수를 계속 반복 실행
  count++;                       // count = count + 1
  console.log(`${count}초 경과`);   // 1초 경과 / 2초 경과 / … (멈추지 않고 계속)
}, 1000);                        // 1000 밀리초 = 1초 간격
1초 경과
2초 경과
3초 경과
4초 경과
⚠️ clearInterval 이 없어서 영원히 반복돼요 (위는 4초까지만 보여 준 것 · node 는 Ctrl + C 로 멈춤)

예제 ② 0929_03.js — 5초가 되면 clearInterval

// 0929_03.js 카운트다운 — sec 가 5 가 되면 clearInterval 로 멈춘다
let sec = 0;                       // 지난 초를 셀 변수

const intervalId = setInterval(() => {   // setInterval 도 번호를 돌려준다
  sec++;                           // sec = sec + 1
  console.log(`카운트다운: ${sec}초`);   // 카운트다운: 1초 … 카운트다운: 5초

  if (sec >= 5) {                  // 5초가 되면
    clearInterval(intervalId);           // 반복 멈춤
    console.log("카운트 종료!");        // 카운트 종료! (마지막에 한 번)
  }                                // if 끝
}, 1000);                          // 1000 밀리초 = 1초 간격

5. Date 로 시계 만들기 · 🔥 new Date(2026-01-01)

예제 0929_03.js — 1초마다 현재 시간

// 0929_03.js 시간출력 코드 — 1초마다 현재 시간을 찍는다
const clockInterval = setInterval(() => {      // 1초마다 현재 시간을 확인하는 반복 예약 (번호를 clockInterval 에 저장)
    const now = new Date(/*여기에 2026-01-01을 쓰면 출력결과는?(시험에 나올 수 있음)*/);
    const timeString = now.toLocaleTimeString();   // 시간만 → 오후 12:03:15
    if (timeString === "오전 8:58:00") {           // 오전 8시 58분 0초가 되면
        clearInterval(clockInterval);              // 반복을 멈춘다
    }                                          // if 끝
    else {                                     // 아직 그 시각이 아니면
        console.log(`현재 시간: ${timeString}`);   // 현재 시간: 오후 12:03:15 처럼 1초마다
    }                                          // else 끝
}, 1000);                                      // 1000 밀리초 = 1초 간격
현재 시간: 오후 12:03:15
현재 시간: 오후 12:03:16
현재 시간: 오후 12:03:17
📌 출력은 실행한 시각에 따라 달라요 (위는 예시). 노션 필기의 날짜출력 코드는 toLocaleDateString() 이라 날짜만 찍혀요 → 현재 시간: 2026. 9. 29.

console.log(d2.toLocaleDateString());    // "2026-01-01" → UTC 0시 → 한국 9시 → 날짜 그대로 → 2026. 1. 1.
console.log(d2.toLocaleTimeString());    // UTC 0시 + 9시간(한국) → 오전 9:00:00

6. 구조분해 할당 — 배열 · 객체 ★

📌 구조분해 할당 = 배열·객체 안의 값을 꺼내 여러 변수에 한 번에 나눠 담는 문법 · ✍️ 필기 — 배열이 100개이면 코드를 100줄 쳐야 하니 구조분해를 한다 · index 번호(순서)가 중요하다
구분모양무엇으로 짝을 짓나
배열 구조분해let [a1, a2] = arrayObj;순서(index 번호)
객체 구조분해let { name, age } = person;이름(key) — 순서 상관없음

예제 ① 0929_04.js — 배열 구조분해

// 0929_04.js 배열 구조분해 — index 번호(순서)대로 들어간다
let arrayObj = [1, 2, 3];   // 요소 3개짜리 배열
// 구조분해 전: let a1 = arrayObj[0]; let a2 = arrayObj[1]; let a3 = arrayObj[2]; ← 하나씩
let [a1, a2, a3, a4] = arrayObj;   // 순서대로 a1 ← [0] = 1 · a2 ← [1] = 2 · a3 ← [2] = 3 · a4 ← [3] 없음 → undefined
console.log(a1, a2, a3, a4);   // → 1 2 3 undefined
1 2 3 undefined
✍️ 필기 — a4 는 error 가 아니라 undefined 이다 (배열에 4번째 값이 없어서)
⚠️ 정정 — 수업 파일 0929_04.js 는 let a1=arrayObj[0]; 과 let [a1,a2,a3,a4] 가 둘 다 있어서 그대로 실행하면 SyntaxError: Identifier 'a1' has already been declared (let 은 같은 이름을 다시 선언할 수 없음 → 3주차). 하나씩 꺼내는 세 줄은 주석으로 막고 실행하세요.

예제 ② 0929_04.js — 객체 구조분해 · 이름 바꾸기 · 기본값

// 0929_04.js 객체 구조분해 — key 이름으로 꺼낸다 (순서 상관없음)
let person = {                                  // 구조분해할 객체
    name: "윤희근",                                // 속성 name
    age: 23,                                    // 속성 age
    hobby: "테니스"                                // 속성 hobby
};                                              // person 객체 끝
let { age: myAge, name, hobby, school = "동양미래대학교" } = person;   // age → myAge 로 이름 바꿔 받기 · name · hobby 는 그대로 · school 은 기본값
// age 값은 myAge 에 · name · hobby 는 같은 이름으로 · school 은 person 에 없으니 기본값
console.log(`이름 : ${name}\n나이 : ${myAge}살\n취미 : ${hobby}\n학교 : ${school}`);   // \n 마다 줄바꿈 → 이름 : 윤희근 / 나이 : 23살 / 취미 : 테니스 / 학교 : 동양미래대학교

쓴 것뜻
nameperson.name → 변수 name
age: myAgeperson.age → 변수 myAge (이름 바꾸기) — age 라는 변수는 만들어지지 않는다

✍️ 필기 — age: myAge 처럼 작성하면 객체의 age 값을 myAge 라는 변수에 할당 → 출력할 때는 age 가 아니라 myAge 를 사용해야 한다
// 이름을 바꾼 뒤 age 를 쓰면?
let person = { name: "윤희근", age: 23, hobby: "테니스" };   // 구조분해할 객체

7. 🔥 매개변수 구조분해 — "중괄호를 빼면?" ★시험

예제 0929_04.js — 매개변수 자리에서 바로 구조분해

// 0929_04.js 매개변수를 { } 로 받으면 → 넘겨받은 객체를 그 자리에서 구조분해
let person = { name: "윤희근", age: 23, hobby: "테니스" };   // 넘겨줄 객체
const func = ({ name, age, hobby, extra }) => {   // person 에서 같은 이름의 속성을 꺼낸다
    console.log(name, age, hobby, extra);          // name · age · hobby 는 person 에서 꺼냄 · extra 는 person 에 없음 → undefined → 윤희근 23 테니스 undefined
}                                               // func 함수 끝 → 호출한 곳으로 돌아감
func(person);                                   // person 객체를 넘김 → 윤희근 23 테니스 undefined
윤희근 23 테니스 undefined

🔥 시험문제 — 여기서 중괄호를 빼면 출력되는 결과

// ★시험문제 — "여기서 중괄호를 빼면 출력되는 결과" (0929_04.js)
let person = { name: "윤희근", age: 23, hobby: "테니스" };   // 넘겨줄 객체
const func = (name, age, hobby, extra) => {   // { } 가 없으면 평범한 매개변수 4개
    console.log(name, age, hobby, extra);       // → { name: '윤희근', age: 23, hobby: '테니스' } undefined undefined undefined
}                                               // func 함수 끝 → 호출한 곳으로 돌아감
func(person);   // 인수는 person 하나 → name = 객체 통째로 · age · hobby · extra = 받은 값 없음(undefined) → { name: '윤희근', age: 23, hobby: '테니스' } undefined undefined undefined
{ name: '윤희근', age: 23, hobby: '테니스' } undefined undefined undefined
🔥 정답 — { name: '윤희근', age: 23, hobby: '테니스' } undefined undefined undefined (수업 파일 주석과 같음). 중괄호가 있으면 객체에서 속성을 꺼내고, 없으면 첫 번째 매개변수 name 에 객체가 통째로 들어가고 age · hobby · extra 는 넘겨받은 인수가 없어서 undefined (4주차 매개변수 · 인수). 객체는 node 에서 { key: '값' } 모양으로 찍혀요 (크롬 콘솔은 모양이 조금 달라요).

8. DOM — 클릭으로 색 바꾸기 (0929_01.html)

<!-- 0929_01.html -->
<style>                                         <!-- CSS 시작 -->
    #box { width: 100px; height: 100px; border: 3px solid black; }   /* # = id 선택자 */
    .box { background-color: orange; }                               /* . = class 선택자 */
    .boxRed { background-color: red; }          /* 빨간 배경 class */
    .boxBlue { background-color: blue; }        /* 파란 배경 class */
</style>                                        <!-- CSS 끝 -->

<div id="box" onclick="changeColor()">Hello box</div>   <!-- id=box 인 상자 · 누르면 changeColor() 실행 -->
<input type="button" value="red" onclick="setColorRed()">   <!-- red 버튼 · 누르면 setColorRed() -->
<input type="button" value="blue" onclick="setColorBlue()">   <!-- blue 버튼 · 누르면 setColorBlue() -->

<script>                                        <!-- 자바스크립트 시작 -->
    function changeColor() {                    // 상자를 누르면 → body 배경을 주황으로
        var box = document.getElementsByTagName("body");   // 태그 이름으로 → 여러 개(목록)
        box[0].setAttribute("class", "box");                 // 목록의 0번째 = body 에 class="box"
    }                                           // changeColor 끝
    function setColorRed() {                    // red 버튼 → 상자를 빨갛게
        var box = document.getElementById("box");            // id 로 → 딱 하나
        box.setAttribute("class", "boxRed");                 // class 를 boxRed 로 → 빨간 배경
    }                                           // setColorRed 끝
    function setColorBlue() {                   // blue 버튼 → 상자를 파랗게
        var box = document.getElementById("box");   // id 로 상자 하나를 찾음
        box.setAttribute("class", "boxBlue");                // class 를 boxBlue 로 → 파란 배경
    }                                           // setColorBlue 끝
</script>                                       <!-- 자바스크립트 끝 -->
코드돌려주는 것쓰는 법
document.getElementsByTagName("body")그 태그의 요소 전부(목록) — Elementsbox[0] 처럼 번지로 꺼낸다
document.getElementById("box")id 가 box 인 요소 하나 — Element바로 쓴다
요소.setAttribute("class", "boxRed")속성 값을 바꾼다 → 그 class 의 CSS 가 적용된다
onclick="함수()"클릭 이벤트가 생기면 함수 실행 (2주차 이벤트)
📌 동작 — Hello box 를 누르면 body 에 class="box" → 페이지 배경 전체가 주황 (박스가 아니라 body!) · red 버튼 → 박스만 빨강 · blue 버튼 → 박스만 파랑
⚠️ 정정 — 수업 코드 주석 // box[0].style.background-color: orange; 는 CSS 문법이라 JS 에서는 SyntaxError 예요. JS 로 직접 색을 넣으려면 box[0].style.backgroundColor = "orange"; (- 를 빼고 뒤 글자를 대문자로)
