★ 3주차 시험문제 (3주차 자세히)

① 23p — ex01_05-sizeof.c 실행결과

변수의 할당크기
gender: 1, age: 4, weight: 4, height: 8

자료형 크기
char: 1, int: 4, float: 4, double: 8

정수형상수: 4, 실수형상수: 8
  • ⭐ 강조 — sizeof 결과는 정수 → %d · sizeof(10) = 4 (int) · sizeof(3.14159) = 8 (double) · 3.14f 는 float → 4

② 27p — quiz 1-01 빈칸채우기 · 오류 수정

  • 출력 성별: w, 나이: 21, 신장: 165.700000
  • 빈칸 ① = 성별: %c, 나이: %d, 신장: · double 출력 = %lf (printf 는 %f 도 가능, scanf 는 반드시 %lf)
  • 오류 줄 = height = 165.7 → height = 165.7; (세미콜론 누락 → 컴파일 오류)
  • 실수는 소수점 아래 6자리 → 165.700000

③ 오류 수정 모음

  • printf("%c", "A"); ❌ → 'A' ✅ · char a1 = "c"; ❌ → 'c' ✅
  • short → %s ❌ → %d · long → %ld · 0진법 ❌ → 10진법 %d
  • unsigned char (1)~(256) ❌ → 0 ~ 255
  • #define CRT_SECUE_NO_WARNINGS ❌ → #define _CRT_SECURE_NO_WARNINGS

3주차 — 변수 · 상수 · 자료형

자료형크기서식범위
char1byte%c-128 ~ 127 (unsigned 0 ~ 255)
short2byte%d-32,768 ~ 32,767
int4byte%d약 ±21억
long4byte(VS)%ldint 와 같음
float4byte%f소수점 6자리 출력
double8byte%lfscanf 는 반드시 %lf
  • ⭐ 강조 — 변수 = 값이 바뀌는 기억장소 / 상수 = 바뀌지 않음(const)
  • ⭐ 강조 — 서식: %d 10진 · %o 8진 · %x 16진 · %c 문자 · %s 문자열 · %f 실수 · %p 주소
  • ⭐ 강조 — 'A' = 문자 1개 / "A" = 문자열 · 'A' = 65 = 01000001 · 'a' = 97
  • ⭐ 강조 — const 는 선언과 동시에 초기화, 재대입하면 컴파일 오류 / #define 은 전처리기가 컴파일 전에 치환(끝에 ; 없음)
  • ⭐ 강조 — scanf("%d", &age); — & 로 주소를 넘겨야 저장됨 · VS 는 #define _CRT_SECURE_NO_WARNINGS
  • 변수 이름 규칙: 숫자로 시작 X · 공백 X · 대·소문자 구별 · 예약어 X · 초기화 안 한 변수 출력은 VS 에서 C4700 오류

2주차 — C 기본 실습 (2주차 자세히)

  • ⭐ 강조 — 소스 작성 → 전처리 → 빌드(컴파일 + 링크) → 실행 · .c → [컴파일] → .obj → [링크] → .exe
  • ⭐ 강조 — printf 는 자동 줄바꿈 없음(\n 필요) / puts 는 출력 후 자동 줄바꿈
  • ✍️ 필기 — C 는 함수들로 구성 · main() 에서 시작 · 다른 함수는 호출해야 실행
  • ✍️ 필기 — 세미콜론 · 닫는 따옴표 누락 → 컴파일 오류

1주차 — C 개요 (1주차 자세히)

  • ⭐ 강조 — C 언어 = 절차지향 언어(함수 중심 구조적 프로그래밍) · 간결·효율 · 이식성
  • ⭐ 강조 — 실행 과정: 소스(.c) → 컴파일(.obj) → 링킹(.exe) → 실행
  • VS 실행 단축키 Ctrl+F5 · ✍️ 파일명에 .c 를 생략하면 .cpp 로 저장됨
