ArrayList<Integer> suList = [5, 4, 100, -1]

돌려준 값
아래 버튼을 눌러 보세요
값
맨 뒤에 추가 → 돌려주는 값 = true (boolean)
인덱스 값
그 자리에 끼워 넣기 — 뒤는 한 칸씩 밀림 (덮어쓰지 않음) · 돌려주는 값 없음(void) · 인덱스가 size() 보다 크면 예외
인덱스
그 자리를 지우고 뒤가 앞으로 당겨짐 → 돌려주는 값 = 지운 요소
값
같은 첫 요소를 지움 → 돌려주는 값 = true / false · 🤖 Integer 리스트에 remove(100) 이라고 쓰면 100번 자리를 지우려 함 (인덱스로 봄)
모든 요소 삭제 → size() = 0 · 돌려주는 값 없음(void)
인덱스
그 자리 요소 (배열의 a[2] 처럼) · 없는 자리면 IndexOutOfBoundsException
요소 개수 — 배열은 a.length · String 은 s.length()
값
같은 첫 요소의 인덱스 · 없으면 -1
값
있으면 true · 없으면 false
비어 있으면 true
인덱스 for — suList.get(index) 를 하나씩 출력
for-each — 앞에서부터 하나씩 꺼냄 · ✍️ “위 for문과 아래 for문은 같음”
✍️ 노션 “for문 실수 예” — 1부터 시작하면 0번 칸을 건너뜀
마지막 인덱스는 size() - 1 → size() 자리는 없음 → 실행 중 예외
✍️ ArrayList<String> 에 정수 → 컴파일 오류 (제네릭이 타입을 정해 둠)
📄 21쪽 — ArrayList 에 없는 메소드 → 컴파일 오류 (elementAt 도 Vector 메소드라 없음)
