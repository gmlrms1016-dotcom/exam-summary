아래 버튼을 눌러 보세요
값
맨 뒤에 추가 → 돌려주는 값 = 새 길이
맨 뒤 요소를 빼서 → 돌려주는 값 = 뺀 값
맨 앞 요소를 빼서 → 돌려주는 값 = 뺀 값 · 나머지 인덱스가 하나씩 앞으로
값
맨 앞에 추가 → 돌려주는 값 = 새 길이 · 나머지 인덱스가 하나씩 뒤로
시작 끝
시작 ~ 끝 직전까지 잘라 새 배열 · 끝을 비우면 끝까지 · 음수 = 뒤에서부터 (-3 → 길이 - 3)
배열
두 배열을 이어 붙인 새 배열
요소마다 콜백을 불러 돌려준 값을 그대로 모은 새 배열 (길이 같음)
콜백이 true 인 요소만 모은 새 배열 (길이 같거나 짧음)
요소마다 콜백을 한 번씩 · 돌려주는 값 = undefined → 결과를 모으려면 다른 배열에 push (수업 doubledArr)
값
있으면 true · 없으면 false · 따옴표를 붙여 "30" 으로 찾으면? (글자 ≠ 숫자)
값
처음 나오는 인덱스 · 없으면 -1
콜백이 처음 true 인 인덱스 (거기서 멈춤) · 없으면 -1
수업 objectArr = [{name:"에스파"}, {name:"홍길동"}] — 새로 쓴 객체는 주소가 달라서 못 찾음 → -1 (수업 주석 “얕은 비교”)
객체 안의 name 값을 비교하는 콜백 → 0
