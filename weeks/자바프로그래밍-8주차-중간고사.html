논리boolean1바이트true · false 두 값만숫자가 아님 (0 · 1 로 못 씀)
  • 🧮 ✍️ 필기 공식 −2ⁿ ~ (2ⁿ − 1) · n = 비트 수 − 1 → byte 8비트 n = 7 → -128 ~ 127 · short 16비트 n = 15 → -32,768 ~ 32,767 · int 32비트 n = 31 → -2,147,483,648 ~ 2,147,483,647 · long 64비트 n = 63
    • 왜 음수가 1 더 많나 — byte 8비트 = 2⁸ = 256 가지 → 맨 앞 비트가 부호 → 0111 1111 = 1+2+4+8+16+32+64 = 127 이 최대 · 1000 0000 = -128 이 최소 · 0 이 양수 쪽 자리를 하나 써서 음수 쪽이 1 더 큼
  • ⚠️ MIN_VALUE 함정 — Float.MIN_VALUE(1.4E-45) · Double.MIN_VALUE(4.9E-324) 는 가장 작은 음수가 아니라 0 에 가장 가까운 양수 → 가장 작은 음수는 -Float.MAX_VALUE · 정수(Integer.MIN_VALUE 등)는 진짜 최솟값
  • C 와 다른 점 — 자바는 unsigned 가 없음(char 만 0 부터) · long 은 어느 컴퓨터든 8바이트(JVM 이 정함 → 플랫폼 독립) · char 가 2바이트(C 는 1바이트)
  • ⚠️ 범위 밖 리터럴은 컴파일 오류 — int a = 3000000000; → integer number too large → long a = 3000000000L; · byte b = 128; → 오류(127 까지) · float f = 3.14; → 오류(3.14 는 double) → 3.14F
  • 🔄 계산하다 넘으면(오버플로) — 오류 없이 한 바퀴 돌아감: Integer.MAX_VALUE + 1 → -2147483648 · byte b = 127; b++; → -128 · (byte) 200 → 200 - 256 = -56
// 📏 자바 데이터타입 8가지 최솟값 ~ 최댓값 — 래퍼 클래스의 MIN_VALUE · MAX_VALUE 상수
public class 연습 {                                       // 파일 이름 연습.java
    public static void main(String[] args) {             // 시작점
        System.out.println(Byte.MIN_VALUE + " " + Byte.MAX_VALUE);       // byte 8비트 → -2⁷ ~ 2⁷-1 → -128 127
        System.out.println(Short.MIN_VALUE + " " + Short.MAX_VALUE);     // short 16비트 → -2¹⁵ ~ 2¹⁵-1 → -32768 32767
        System.out.println(Integer.MIN_VALUE + " " + Integer.MAX_VALUE); // int 32비트 → -2³¹ ~ 2³¹-1 → -2147483648 2147483647
        System.out.println(Long.MIN_VALUE + " " + Long.MAX_VALUE);       // long 64비트 → -2⁶³ ~ 2⁶³-1 → -9223372036854775808 9223372036854775807
        System.out.println(Float.MIN_VALUE + " " + Float.MAX_VALUE);     // float → 0 에 가장 가까운 양수 · 가장 큰 수 → 1.4E-45 3.4028235E38
        System.out.println(Double.MIN_VALUE + " " + Double.MAX_VALUE);   // double → 4.9E-324 1.7976931348623157E308
        System.out.println((int) Character.MIN_VALUE + " " + (int) Character.MAX_VALUE); // char 16비트 · 부호 없음 → 0 ~ 2¹⁶-1 → (int) 로 숫자로 바꿔 → 0 65535
        int i = Integer.MAX_VALUE;                       // i = 2147483647 (int 최댓값)
        i++;                                             // 최댓값 + 1 → 범위를 넘음(오버플로) → 한 바퀴 돌아 최솟값
        System.out.println(i);                           // → -2147483648
        byte j = (byte) 200;                             // 200 은 byte 범위(127) 밖 → 강제 형변환 → 200 - 256 = -56
        System.out.println(j);                           // → -56
        long k = 3000000000L;                            // 30억 = int 범위(약 21억) 밖 → 끝에 L 을 붙여 long 리터럴로 (L 없으면 컴파일 오류)
        System.out.println(k);                           // → 3000000000
    }                                                    // main 끝
}                                                        // 연습 끝
