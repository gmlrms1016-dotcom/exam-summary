## 1. 🔥 이벤트 4요소 — 기말고사에 나옴 (1027_01_event.html)
✍️ **필기** — “(이벤트,이벤트소스,이벤트헨들러,이벤트객체) **기말고사에 나옴**”

| 4요소 | 뜻 (2주차 정리) | 오늘 코드에서 |
|---|---|---|
| **이벤트** | 웹에서 발생하는 **사건** (클릭 등) | `'click'` — addEventListener 의 첫 번째 인자 |
| **이벤트 소스** | 이벤트가 발생한 **근원지** (요소) | `addBtn` — 목록 추가 버튼 |
| **이벤트 핸들러** (= 리스너) | 이벤트가 일어나면 **실행되는 코드(함수)** | `function(){ … }` — 두 번째 인자 |
| **이벤트 객체** | 발생한 이벤트의 **정보**를 담은 객체 | 🤖 핸들러의 매개변수 `e` 로 받음 (오늘 코드는 받지 않음 · 아래 확인 코드) |

- ⚠️ 필기 오타 `이벤트헨들러` → **이벤트 핸들러** (handler)
- ⚠️ **팩트체크** — 수업 코드 주석은 같은 함수를 **‘이벤트리스너’** 라고 했어요. MDN 정의: **리스너** = 이벤트가 일어나는지 기다리는 쪽(`addEventListener` 로 등록) · **핸들러** = 이벤트가 일어나면 **불리는 함수** → 둘이 함께 일하고, 수업에서는 같은 뜻으로 써요 (2주차 “이벤트 핸들러(=이벤트 리스너)”).

```html
<!DOCTYPE html>                                                  <!-- HTML5 문서라고 알림 -->
<html lang="ko">                                                 <!-- 문서 시작 · 한국어 -->
<head>                                                           <!-- 문서 정보 시작 -->
    <meta charset="UTF-8">                                       <!-- 한글이 깨지지 않게 UTF-8 -->
    <meta name="viewport" content="width=device-width, initial-scale=1.0">   <!-- 폰 화면 폭에 맞춤 -->
    <title>Document</title>                                      <!-- 탭 제목 -->
    <style>                                                      /* CSS 시작 */
        #add-btn{                                                /* id 가 add-btn 인 버튼 */
            padding: 5px 10px;                                   /* 안쪽 여백 위아래 5px · 좌우 10px */
            border: 0;                                           /* 테두리 없앰 */
            background: #f80;                                    /* 주황 배경 */
            color: white;                                        /* 흰 글자 */
            border-radius: 5px;                                  /* 모서리 둥글게 */
        }                                                        /* #add-btn 끝 */
        ul {                                                     /* 목록 */
            padding: 0;                                          /* 왼쪽 들여쓰기 없앰 */
            list-style-position: inside;                         /* 글머리 기호(•)를 안쪽에 */
        }                                                        /* ul 끝 */
        li {                                                     /* 목록 한 줄 */
            border-bottom: 1px solid #999;                       /* 아래 회색 선 */
            padding: 5px 0;                                      /* 위아래 여백 5px */
        }                                                        /* li 끝 */
        .active {                                                /* active 클래스 (오늘 코드에서는 아직 안 씀) */
            background: #abc;                                    /* 연한 파랑 배경 */
        }                                                        /* .active 끝 */
    </style>                                                     <!-- CSS 끝 -->
</head>                                                          <!-- 문서 정보 끝 -->
<body>                                                           <!-- 화면에 보이는 부분 -->
    <h1 id="title">할일 목록</h1>                                 <!-- 제목 -->
    <button id="add-btn">목록 추가</button>                       <!-- 🔥 이벤트 소스가 될 버튼 -->
    <ul id="list">                                               <!-- 할 일 목록 (새 li 가 끝에 붙는 곳) -->
        <li>제목 1</li>                                           <!-- 처음부터 있는 항목 1 -->
        <li>제목 2</li>                                           <!-- 항목 2 -->
        <li>제목 3</li>                                           <!-- 항목 3 -->
        <li>제목 4</li>                                           <!-- 항목 4 -->
    </ul>                                                        <!-- 목록 끝 -->
    <script>                                                     // 자바스크립트 시작 (위의 요소들이 이미 있어서 찾을 수 있음)
        let title = document.getElementById('title');           // id 로 h1 찾기 (오늘 코드에서는 안 씀)
        let list = document.getElementById('list');             // ul 요소 → 새 li 를 붙일 곳
        let li = document.getElementsByTagName('li');           // li 요소들 → 지금 4개 · 추가하면 5개로 저절로 늘어남
        let addBtn = document.getElementById('add-btn');        // 버튼 요소 → 🔥 이벤트 소스

        addBtn.addEventListener('click',function(){ //이벤트,이벤트리스너,이벤트소스 ← 'click' = 이벤트 · function = 핸들러(리스너) · addBtn = 소스
            let txt=prompt("할 일 입력");                         // 입력 창 → 입력한 글자가 txt 에 ("제목 5")
            list.innerHTML+='<li>'+txt+'</li>';                  // 원래 목록 HTML + "<li>제목 5</li>" → 목록 끝에 추가
        });                                                      // 핸들러 함수 끝 · addEventListener 끝
    </script>                                                    <!-- 스크립트 끝 -->
</body>                                                          <!-- 화면 끝 -->
</html>                                                          <!-- 문서 끝 -->
```
> ▶ 크롬에서 직접 눌러 본 결과 — **목록 추가** 를 누르면 `할 일 입력` 창이 뜨고, `제목 5` 를 입력하면 목록 **맨 끝에 제목 5** 가 붙어요 (li 4개 → 5개) · `getElementsByTagName` 으로 받은 `li` 는 새로 붙은 li 까지 저절로 세어서 5 가 돼요.

### 🤖 이벤트 객체 e 확인 — 핸들러에 매개변수를 하나 받으면 브라우저가 넣어 줘요
```html
<!DOCTYPE html>                                         <!-- HTML5 문서 -->
<html lang="ko">                                        <!-- 문서 시작 -->
<body>                                                  <!-- 화면 -->
    <button id="btn">눌러 보기</button>                   <!-- 이벤트 소스가 될 버튼 -->
    <script>                                            // 자바스크립트 시작
        let btn = document.getElementById('btn');       // 버튼 요소를 찾아 btn 에
        btn.addEventListener('click', function (e) {    // 'click' = 이벤트 · function = 핸들러 · e = 이벤트 객체 (브라우저가 넣어 줌)
            console.log(e.type);                        // 무슨 이벤트? → click
            console.log(e.target.id);                   // 이벤트가 일어난 요소(소스)의 id → btn
        });                                             // 핸들러 끝 · addEventListener 끝
    </script>                                           <!-- 스크립트 끝 -->
</body>                                                 <!-- 화면 끝 -->
</html>                                                 <!-- 문서 끝 -->
```
```output
click
btn
```
> MDN — 이벤트 객체는 핸들러에 **자동으로 전달**되고 이름은 `e` · `evt` · `event` 처럼 마음대로 · `e.target` = 이벤트가 **일어난 요소** (= 이벤트 소스) · 버튼을 누른 뒤 크롬 콘솔에 찍힌 값이에요.

## 2. 요소 순회 — for · for…of · Object.keys · Object.values (1027_02_요소순회.js)
```javascript
let arr = [1, 2, 3];                          // 배열 — 값 1 · 2 · 3 (인덱스 0 · 1 · 2)

console.log("\n방법1");                        // 맨 앞 \n → 빈 줄을 먼저 찍고 → 방법1
for (let i = 0; i < arr.length; i++) {        // 방법1 for — i = 0, 1, 2 (arr.length 3 이 되면 끝)
    let item = arr[i];                        // 인덱스로 꺼냄 → arr[0] = 1 · arr[1] = 2 · arr[2] = 3
    console.log(item);                        // 1 → 2 → 3
};                                            // for 끝 (뒤의 ; 는 빈 문장이라 있어도 없어도 같음)

console.log("\n방법2");                        // 빈 줄 → 방법2
for (let item of arr) {                       // 방법2 for…of — 인덱스 없이 값이 차례로 item 에
    console.log(item);                        // 1 → 2 → 3
}                                             // for…of 끝

let person = {                                // 객체 — 키: 값 3쌍
    name: "윤희근",                            // 키 name → 값 "윤희근"
    age: 27,                                  // 키 age → 값 27
    hobby: "테니스",                           // 키 hobby → 값 "테니스" (마지막 쉼표는 있어도 됨)
};                                            // 객체 끝

let keys = Object.keys(person);               // 키만 모은 배열 → ["name", "age", "hobby"]
let values = Object.values(person);           // 값만 모은 배열 → ["윤희근", 27, "테니스"]

for (let key of keys) {                       // key = "name" → "age" → "hobby"
    const value = person[key];                // 대괄호 + 키 변수 → person["name"] → "윤희근"
    console.log(key, value);                  // 쉼표로 두 값 → 한 칸 띄어 출력 → name 윤희근
}                                             // for…of 끝

for (let key of keys) {                       // 키만 다시 돌기
    console.log(key);                         // name → age → hobby
}                                             // for…of 끝

for (let value of values) {                   // 값만 돌기
    console.log(value);                       // 윤희근 → 27 → 테니스
}                                             // for…of 끝
```

```output
age 27
hobby 테니스

```
| 방법 | 코드 | 꺼내는 것 |
|---|---|---|
| 방법1 for | `for (let i = 0; i < arr.length; i++)` | **인덱스** i → `arr[i]` 로 값 |
| 방법2 for…of | `for (let item of arr)` | 인덱스 없이 **값**을 바로 |
| Object.keys | `Object.keys(person)` | 객체의 **키**만 모은 배열 `["name", "age", "hobby"]` |
| Object.values | `Object.values(person)` | 객체의 **값**만 모은 배열 `["윤희근", 27, "테니스"]` |
| 객체[변수] | `person[key]` | 변수 key 에 든 이름으로 값 꺼내기 → `"윤희근"` |

> ⚠️ `person.key` 라고 쓰면 변수 key 의 값이 아니라 **‘key’ 라는 이름의 속성**을 찾아서 `undefined` 예요 (node 로 확인) → 변수로 꺼낼 때는 꼭 **대괄호** `person[key]` · 출력 맨 위의 빈 줄은 `"\n방법1"` 의 `\n` 때문이에요.

## 3. ✍️ 요청 · 파라미터 · 응답 · JSON
- ✍️ **필기** — “클라이언트가 서버에 전송(리퀘스트) 하는 것을 **파라미터**라고 함”
  - ⚠️ **팩트체크** — 서버에 보내는 것 자체는 **요청(request)** 이고, 요청에 **담아 보내는 값**이 **파라미터**예요 (🤖 예: `…/search?name=hong&age=20` 의 `name=hong` · `age=20`)
- ✍️ **필기** — “서버에서 받은 리스판스된 텍스트를 json으로 저장되고 json으로 저장된 텍스트를 클라이언트 화면에 뿌려줌”
  - ⚠️ **팩트체크** — 서버의 **응답(response)** 은 **텍스트(문자열)** 이고 흔히 **JSON 형식**이에요 → 클라이언트는 `JSON.parse()` 로 **객체**로 바꾼 뒤 → 화면(DOM · `innerHTML` 등)에 출력(= “뿌려 줌”)

| 말 | 뜻 |
|---|---|
| 요청 (request · 리퀘스트) | 클라이언트 → 서버 |
| 파라미터 (parameter) | 요청에 담아 보내는 값 (이름=값) |
| 응답 (response · 리스폰스) | 서버 → 클라이언트 · 텍스트 |
| JSON | JavaScript Object Notation — 객체 모양의 **텍스트** 형식 · 키는 반드시 큰따옴표 `{"name":"hong"}` (따옴표 없는 키는 `JSON.parse` 가 SyntaxError — node 로 확인) |

### 🤖 JSON 문자열 ↔ 객체 (node)
```javascript
let txt = '{"name":"윤희근","age":27}';      // 서버가 보낸 응답이라고 생각 — JSON 형식의 "문자열" (키는 큰따옴표)
console.log(typeof txt);                     // 아직 글자일 뿐 → string
let obj = JSON.parse(txt);                   // 문자열 → 자바스크립트 객체로 바꿈
console.log(typeof obj);                     // object
console.log(obj.name, obj.age);              // 점(.)으로 값 꺼내기 → 윤희근 27
console.log(JSON.stringify(obj));            // 반대로 객체 → JSON 문자열 ({"name":"윤희근","age":27})
```
```output
string
object
윤희근 27
{"name":"윤희근","age":27}
```
> `JSON.stringify` 는 [7주차](웹프로그래밍-7주차.html) 깊은 비교에서 썼던 함수 — `parse` 는 그 반대(문자열 → 객체)예요.
