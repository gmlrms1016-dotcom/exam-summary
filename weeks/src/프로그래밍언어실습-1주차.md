## 2. C 언어 특징 ★암기
- ⭐ **강조** — 절차지향 언어(procedural) — 함수 중심의 구조적 프로그래밍
- 간결하고 효율적, 다양한 시스템 라이브러리 제공
- 이식성이 좋음 — 다양한 CPU·플랫폼의 컴파일러 지원

## 3. C 프로그램 실행 과정 ★핵심
- ⭐ **강조** — ① 소스코드 작성(.c) → ② 컴파일(→ 오브젝트 .obj/.o) → ③ 링킹(→ 실행파일 .exe/a.out) → ④ 실행
```c
// hello.c
#include <stdio.h>
int main(void) {
    printf("hello world!");  // 출력
    return 0;               // 프로그램 종료
}
```
- VS 단축키: 모두 저장 Ctrl+Shift+S / 빌드 [빌드]>솔루션빌드 / 실행 Ctrl+F5
- ✍️ **필기** — 주의: 파일명 입력 시 확장자 .c 를 생략하면 .cpp로 저장됨
