### ArrayAccess (예제 3-7) — 입력받은 수 중 제일 큰 수
```java
// ArrayAccess.java (예제 3-7) — 양수 5개를 배열에 저장하고 제일 큰 수 출력
import java.util.Scanner;

public class ArrayAccess {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int intArray[] = new int[5];        // 배열 생성

        int max = 0;                        // 지금까지 가장 큰 수
        System.out.println("양수 5개를 입력하세요.");
        for (int i = 0; i < 5; i++) {
            intArray[i] = sc.nextInt();     // 입력받은 정수를 배열에 저장
            if (intArray[i] > max)          // 더 크면
                max = intArray[i];          // max 교체
        }
        System.out.print("가장 큰 수는 " + max + "입니다.");
        sc.close();
    }
}
```
```output
양수 5개를 입력하세요.
1
39
78
100
99
가장 큰 수는 100입니다.
```

### ArrayLength (예제 3-8) — length 로 평균
```java
// ArrayLength.java (예제 3-8) — 배열의 length 만큼 입력받아 평균 구하기
import java.util.Scanner;

public class ArrayLength {
    public static void main(String[] args) {
        int intArray[] = new int[5];
        int sum = 0;

        Scanner sc = new Scanner(System.in);
        System.out.print(intArray.length + "개의 정수를 입력하세요>>");   // length = 5
        for (int i = 0; i < intArray.length; i++)
            intArray[i] = sc.nextInt();
        for (int i = 0; i < intArray.length; i++)
            sum += intArray[i];

        System.out.print("평균은 " + (double) sum / intArray.length);   // sum 을 먼저 double 로
        sc.close();
    }
}
```
```output
5개의 정수를 입력하세요>>2 3 4 5 9
평균은 4.6
```
> 📌 `(double) sum / intArray.length` — sum 을 **먼저** double 로 바꿔서 23.0 / 5 = **4.6** · `(double) (sum / intArray.length)` 로 쓰면 정수 나눗셈 23 / 5 = 4 가 먼저 돼서 **4.0** (타입 변환 ★시험단골 → 3주차)

## 2. for-each 문 (예제 3-9)
> 📌 **for-each 문** = 배열이나 나열(enumeration)의 원소를 **처음부터 끝까지 차례로** 꺼내 쓰는 for 문 · `for (int k : n)` → 반복할 때마다 k 는 n[0], n[1], … n[4] (인덱스가 아니라 **원소 값**)

| 쓰는 법 | 반복할 때마다 변수에 들어가는 것 |
|---|---|
| `for (int k : n)` | int 배열 n 의 원소 n[0] ~ n[4] |
| `for (String s : names)` | String 배열 names 의 원소 names[0] ~ names[5] |
| `for (Week day : Week.values())` | enum Week 의 값 월, 화, … 일 |

### foreachEx (예제 3-9)
```java
// foreachEx.java (예제 3-9) — for-each 로 int 배열 · String 배열 · enum 돌기
public class foreachEx {
    enum Week { 월, 화, 수, 목, 금, 토, 일 }     // 나열(enum) 타입

    public static void main(String[] args) {
        int[] n = {1, 2, 3, 4, 5};
        String names[] = {"사과", "배", "바나나", "체리", "딸기", "포도"};

        int sum = 0;
        for (int k : n) {                        // k = 1, 2, 3, 4, 5
            System.out.print(k + " ");
            sum += k;
        }
        System.out.println("합은 " + sum);
        for (String s : names) {                 // s = "사과", "배", …
            System.out.print(s + " ");
        }
        System.out.println();
        for (Week day : Week.values()) {         // day = 월, 화, … 일
            System.out.print(day + "요일 ");
        }
        System.out.println();
    }
}
```
```output
1 2 3 4 5 합은 15
사과 배 바나나 체리 딸기 포도 
월요일 화요일 수요일 목요일 금요일 토요일 일요일 
```

## 3. 2차원 배열 · 비정방형 배열 (예제 3-10 · 3-11)
| 코드 | 뜻 |
|---|---|
| `double score[][] = {{3.3, 3.4}, {3.5, 3.6}, …};` | 2차원 배열 선언 + 초기화 (행 = 학년, 열 = 학기) |
| `score.length` | **행**의 개수 → 4 |
| `score[year].length` | year 번째 행의 **열** 개수 → 2 |
| `new int[4][]` 후 `intArray[0] = new int[3];` | **비정방형 배열** — 행마다 열 개수가 다름 |

### ScoreAverrage (예제 3-10) — 4년 평점 평균
```java
// ScoreAverrage.java (예제 3-10) — 2차원 배열로 4년(8학기) 평점 평균
public class ScoreAverrage {
    public static void main(String[] args) {
        double score[][] = {{3.3, 3.4},     // 1학년 1, 2학기
                            {3.5, 3.6},     // 2학년
                            {3.7, 4.0},     // 3학년
                            {4.1, 4.2}};    // 4학년

        double sum = 0;
        for (int year = 0; year < score.length; year++) {             // 학년(행) 4번
            for (int term = 0; term < score[year].length; term++) {   // 학기(열) 2번
                sum += score[year][term];
            }
        }
        int n = score.length;       // 행 개수 4
        int m = score[0].length;    // 열 개수 2
        System.out.println("4년 전체 평점 평균은 " + sum / (n * m));
    }
}
```
```output
4년 전체 평점 평균은 3.725
```
> ⚠️ 수업 파일 이름 **ScoreAverrage** 는 교재 **ScoreAverage** 의 오타(r 하나 더)예요 · 클래스 이름과 파일 이름만 서로 같으면 실행에는 문제없어요.

### IrregularArray (예제 3-11) — 비정방형 배열
```java
// IrregularArray.java (예제 3-11) — 행마다 열 개수가 다른 2차원 배열
public class IrregularArray {
    public static void main(String[] args) {
        int intArray[][] = new int[4][];    // 행 4개만 먼저 만들고
        intArray[0] = new int[3];           // 0행: 열 3개
        intArray[1] = new int[2];           // 1행: 열 2개
        intArray[2] = new int[3];
        intArray[3] = new int[2];

        for (int i = 0; i < intArray.length; i++) {
            for (int j = 0; j < intArray[i].length; j++) {   // 행마다 길이가 달라서 intArray[i].length
                intArray[i][j] = (i + 1) * 10 + j;
            }
        }
        for (int i = 0; i < intArray.length; i++) {
            for (int j = 0; j < intArray[i].length; j++) {
                System.out.print(intArray[i][j] + " ");
            }
            System.out.println();
        }
    }
}
```
```output
10 11 12 
20 21 
30 31 32 
40 41 
```

## 4. 예외 처리 실습 — 0으로 나누기 (예제 3-15) ★시험단골
```java
// DevideByZeroHandling.java (예제 3-15) — 0 으로 나누면 다시 입력받기
import java.util.Scanner;

public class DevideByZeroHandling {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        while (true) {
            System.out.print("나뉨수를 입력하시오:");
            int dividend = sc.nextInt();
            System.out.print("나눗수를 입력하시오:");
            int divisor = sc.nextInt();
            try {
                System.out.println(dividend + "를 " + divisor + "로 나누면 몫은 " + dividend / divisor + "입니다.");
                break;                              // 정상으로 나누면 while 탈출
            } catch (Exception e) {                 // 0 으로 나누면 여기로 (break 는 건너뜀)
                System.out.println("에러났습니다.");
                System.out.println("0으로 나눌 수 없습니다! 다시 입력하세요");
                e.printStackTrace();                // 예외 종류와 발생 위치(줄 번호) 출력
            }
        }
        sc.close();
    }
}
```
```output
나뉨수를 입력하시오:100
나눗수를 입력하시오:0
에러났습니다.
0으로 나눌 수 없습니다! 다시 입력하세요
java.lang.ArithmeticException: / by zero
	at DevideByZeroHandling.main(DevideByZeroHandling.java:14)
나뉨수를 입력하시오:100
나눗수를 입력하시오:5
100를 5로 나누면 몫은 20입니다.
```
| 교재 예제 3-15 | 수업 코드 |
|---|---|
| `catch (ArithmeticException e)` — 0 으로 나누는 예외만 잡음 | `catch (Exception e)` — **Exception 은 모든 예외의 부모**라 어떤 예외든 잡음 |
| 안내 문구만 출력 | "에러났습니다." 추가 + `e.printStackTrace()` → 이클립스 콘솔에 **빨간 글씨**로 예외 이름과 발생 줄 번호 (위 결과의 14 = `println` 줄 · 수업 파일은 package test 라서 `test.DevideByZeroHandling … :15`) |

> 📌 try 안에서 예외가 나면 그 **아래 문장(break)은 건너뛰고** catch 로 간다 → while(true) 가 다시 돌아 입력을 받는다 · 정상이면 break 로 반복 탈출 (예외 처리 이론 → 4주차)

## 5. 객체지향 특성 — 캡슐화 · 상속 · 다형성 (4장 p2 ~ 9)
> ✍️ **필기** — 4장 첫 시간에 배운 것: **객체, 캡슐화, 상속** · 세상 모든 것이 객체 — 객체마다 고유한 **특성(state)** 과 **행동(behavior)** 을 가짐 (예: 테트리스의 블록, 한글 프로그램의 메뉴·버튼)

| 특성 | 뜻 | 자바에서는 |
|---|---|---|
| **캡슐화** | 객체를 캡슐로 싸서 **내부를 볼 수 없게** 하는 것 · 외부의 접근으로부터 객체 보호 | 클래스 = 객체 모양을 선언한 틀 · 필드와 메소드를 **모두 클래스 안에** 구현 · 외부는 공개된 메소드로만 비공개 멤버에 접근 |
| **상속** | 상위 개체의 속성이 하위 개체에 **물려짐** (나무는 식물이고 생물이다) | 자식 클래스(**서브클래스**)가 부모 클래스(**수퍼클래스**)를 물려받고 기능 확장 · 클래스 **다중 상속 없음** (인터페이스 다중 상속은 허용) |
| **다형성** | 같은 이름의 메소드가 클래스나 객체에 따라 **다르게 동작** | 메소드 **오버로딩** (같은 이름, 다른 매개변수) · 메소드 **오버라이딩** (서브클래스마다 다르게 구현) |

| 절차지향 프로그래밍 | 객체지향 프로그래밍 |
|---|---|
| **작업 순서**를 표현 · 작업을 함수로 작성한 **함수들의 집합** | **객체들 간의 상호작용**으로 표현 · **클래스 혹은 객체들의 집합**으로 프로그램 작성 |

> 📌 객체지향 언어의 목적 — ① **소프트웨어 생산성 향상** (상속·다형성·캡슐화로 재사용, 부분 수정이 빠름) ② **실세계에 대한 쉬운 모델링** (절차보다 객체들의 상호작용으로 묘사)

## 6. 클래스와 객체 ★중요 (4장 p10 ~ 16)
> ⭐ **강조** — ✍️ **클래스(중요!) = 객체를 만들어내기 위한 설계도 혹은 틀**

| 구분 | 뜻 | 예 |
|---|---|---|
| **클래스** | 객체를 만들어내기 위한 **설계도 혹은 틀** · 객체의 속성(state)과 행동(behavior) 포함 | 붕어빵틀 · 소나타 자동차 · 사람 |
| **객체** (인스턴스, instance) | 클래스의 모양 그대로 **찍어낸 실체** · 프로그램 실행 중에 생성 · 메모리 공간을 갖는 구체적인 실체 | 구워낸 붕어빵들 · 출고된 실제 소나타 100대 · 나, 너, 윗집 사람 |

> 📌 붕어빵은 틀의 모양대로 만들어지지만 치즈 · 크림 · 앙코처럼 서로 조금씩 다르다 → 객체들은 클래스에 선언된 **같은 속성**을 가지지만 **객체마다 값이 다르다**

| 클래스 구성 (p14) | 설명 |
|---|---|
| `class Circle { }` | class 키워드로 선언 · { } 안에 모든 필드와 메소드 구현 |
| `public` | 접근 지정자 — 다른 모든 클래스의 접근 허용 |
| **필드** (field) | 객체 안에 값을 저장하는 **멤버 변수** (`int radius;`) |
| **메소드** (method) | 함수 · 객체의 **행동** 구현 (`getArea()`) |
| **생성자** | 클래스 **이름과 같은** 특별한 메소드 · 객체가 생성될 때 **자동으로 한 번** 호출 · 객체 초기화 코드 작성 |

### 객체 생성과 멤버 접근 (p15 ~ 16)
```java
Circle pizza;              // ① 레퍼런스 변수 선언 (아직 객체 없음)
pizza = new Circle();      // ② 객체 생성 — new 가 메모리를 할당하고 생성자를 호출
pizza.radius = 10;         // ③ 객체 멤버 접근 — 점(.) 연산자
pizza.name = "자바피자";
double area = pizza.getArea();   // ④ 메소드 호출도 점(.) 으로
```
> 📌 객체는 반드시 **new** 로 생성 (레퍼런스 변수 선언 → 객체 생성 → 메모리 할당 → 생성자 실행) · 멤버 접근은 `객체레퍼런스.멤버`

## 7. 클래스 실습 — Circle (예제 4-1) · Rectangle (예제 4-2) · 붕어빵
### Circle + CircleMain (예제 4-1 을 두 파일로)
```java
// Circle.java — 원의 설계도(클래스)
public class Circle {
    public int radius;          // 필드: 반지름
    public String name;         // 필드: 이름

    public Circle() {           // 생성자 (클래스 이름과 같음 · 하는 일 없음)
    }

    public double getArea() {   // 메소드: 면적 계산
        return 3.14 * radius * radius;
    }
}
```
```java
// CircleMain.java — Circle 틀로 객체 3개 찍어내기
public class CircleMain {
    public static void main(String[] args) {
        Circle pizza = new Circle();        // 객체 생성
        pizza.name = "자바피자";
        pizza.radius = 10;
        double area = pizza.getArea();      // 3.14 * 10 * 10
        System.out.println(pizza.name + "면적 = " + area);

        Circle donut = new Circle();
        donut.radius = 2;
        donut.name = "자바도넛";
        double area2 = donut.getArea();     // 3.14 * 2 * 2
        System.out.println(donut.name + "면적 = " + area2);

        Circle gomg = new Circle();
        gomg.radius = 5;
        gomg.name = "gomg";
        double area3 = gomg.getArea();      // 3.14 * 5 * 5
        System.out.println(gomg.name + "면적 = " + area3);
    }
}
```
```output
자바피자면적 = 314.0
자바도넛면적 = 12.56
gomg면적 = 78.5
```
> 📌 교재 예제 4-1 은 main 이 Circle 안에 있지만, 수업에서는 **Circle(설계도)** 과 **CircleMain(실행)** 을 두 파일로 나눴어요 · 틀 하나(Circle)로 찍은 객체 3개가 **반지름 · 이름을 각자** 가져요 · 같은 패키지(test)라서 CircleMain 에서 Circle 을 바로 쓸 수 있어요.

### Rectangle (예제 4-2) — 너비 · 높이 입력받아 면적
```java
// Rectangle.java (예제 4-2) — 필드 width · height 와 getArea() 메소드
import java.util.Scanner;

public class Rectangle {
    int width;                      // 필드
    int height;

    public int getArea() {          // 메소드
        return width * height;
    }

    public static void main(String[] args) {
        Rectangle rect = new Rectangle();       // 객체 생성
        Scanner sc = new Scanner(System.in);
        System.out.print(">> ");

        rect.width = sc.nextInt();              // 입력값을 객체의 필드에
        rect.height = sc.nextInt();

        System.out.println("사각형의 면적은" + rect.getArea());
        sc.close();
    }
}
```
```output
>> 4 5
사각형의 면적은20
```
> ⚠️ `"사각형의 면적은" + rect.getArea()` 는 문자열 끝에 띄어쓰기가 없어서 **면적은20** 으로 붙어 나와요 (교재 결과도 같음).

### FishBread + Main — 붕어빵틀(클래스)과 붕어빵(객체)
```java
// FishBread.java — 붕어빵틀 = 클래스
public class FishBread {
    // 필드(속성)
    String flavor;      // 팥, 치즈, 슈크림
    int price;          // 가격

    // 생성자
    FishBread() {
    }

    // 메서드
    String showInfo() {
        return flavor + " 붕어빵 가격은 " + price + "원";
    }
}
```
```java
// Main.java — 틀 하나로 붕어빵(객체) 3개 굽기
public class Main {
    public static void main(String[] args) {
        FishBread pap = new FishBread();
        pap.flavor = "팥";
        pap.price = 1000;
        String result = pap.showInfo();
        System.out.println("객체 = " + result);

        FishBread sue = new FishBread();
        sue.flavor = "슈크림";
        sue.price = 2000;
        String result2 = sue.showInfo();
        System.out.println("객체 = " + result2);

        FishBread cheese = new FishBread();
        cheese.flavor = "치즈";
        cheese.price = 3000;
        String result3 = cheese.showInfo();
        System.out.println("객체 = " + result3);
    }
}
```
```output
객체 = 팥 붕어빵 가격은 1000원
객체 = 슈크림 붕어빵 가격은 2000원
객체 = 치즈 붕어빵 가격은 3000원
```
> 📌 4장 p10 ~ 11 의 **붕어빵틀 = 클래스, 구워낸 붕어빵 = 객체** 를 코드로 만든 것 · 세 객체 모두 flavor · price 필드를 가지지만 **값은 각자 다르다** · showInfo() 는 출력하지 않고 문자열을 **return** 해서, main 에서 받아 출력해요.
