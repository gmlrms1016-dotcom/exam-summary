## 1. 🔥 switch 문 — 요일 번호로 요일 이름 (1013_01.html)
✍️ **필기** — “**switch문 시험에 나옴!**”
```javascript
// 1013_01.html switch — 요일 번호(getDay)로 요일 이름 고르기 · 날짜를 수업 날(2026-10-13)로 고정
let day = new Date(2026, 9, 13);                // 월은 0 부터 → 9 = 10월 · 2026년 10월 13일
console.log(day.getDay());                      // getDay() = 요일 번호 0(일) ~ 6(토) → 화요일 → 2
switch (day.getDay()) {                         // 2 와 같은 case 를 찾음 (=== 처럼 값 · 타입 비교)
    case 0: console.log("오늘은 일요일 입니다."); break;   // 0 아님 → 건너뜀
    case 1: console.log("오늘은 월요일 입니다."); break;   // 1 아님 → 건너뜀
    case 2: console.log("오늘은 화요일 입니다."); break;   // 2 → 출력하고 break 로 switch 탈출
    case 3: console.log("오늘은 수요일 입니다."); break;   // (실행 안 됨)
    case 4: console.log("오늘은 목요일 입니다."); break;   // (실행 안 됨)
    case 5: console.log("오늘은 금요일 입니다."); break;   // (실행 안 됨)
    case 6: console.log("오늘은 토요일 입니다."); break;   // (실행 안 됨)
    default: console.log("정상적인 요일이 아닙니다.");      // 0 ~ 6 이 아닐 때만
}                                               // switch 끝
```
```output
2
오늘은 화요일 입니다.
```
| 부분 | 뜻 |
|---|---|
| `new Date()` | 내장객체 Date 로 **지금 날짜 · 시간** 객체를 만듦 (위 코드는 결과가 늘 같게 수업 날 2026-10-13 으로 고정) |
| `getDay()` | 요일 번호 — **0 = 일요일** · 1 = 월 · … · 6 = 토 (월 `getMonth()` 도 0 부터) |
| `case 값:` | switch 괄호 값과 **같은(===)** case 로 바로 감 |
| `break;` | switch 를 빠져나감 — 빠지면 **아래 case 까지 계속 실행**(fall-through) |
| `default:` | 어느 case 에도 안 맞을 때 |

## 2. if ~ else if ~ else — 나이 확인 (1013_01.html)
```javascript
// 1013_01.html 나이 확인 — prompt 대신 입력값 3개를 차례로 넣어 봄 (브라우저에서는 prompt · alert)
let inputs = ["17", "25", "abc"];               // prompt 로 받았다고 치는 문자열 3개
for (let i = 0; i < inputs.length; i++) {       // i = 0 · 1 · 2 → 입력 3번 시험
    let ageInput = inputs[i];                   // "17" → "25" → "abc"
    let age = parseInt(ageInput);               // 문자열 → 정수: "17" → 17 · "25" → 25 · "abc" → NaN(숫자 아님)
    if (age < 20) {                             // 17 < 20 → true / 25 < 20 → false / NaN < 20 → false
        console.log("미성년자!");               // 17 → 미성년자!
    } else if (age >= 20) {                     // 25 >= 20 → true / NaN >= 20 → false
        console.log("성인!");                   // 25 → 성인!
    } else {                                    // 둘 다 false 인 건 NaN 뿐
        console.log("유효한 나이를 입력해주세요!");   // "abc" → NaN → 유효한 나이를 입력해주세요!
    }                                           // if 끝
}                                               // for 끝
```
```output
미성년자!
성인!
유효한 나이를 입력해주세요!
```
> `parseInt("abc")` → **NaN** · NaN 은 어떤 비교도 **false** 라서 `age < 20` · `age >= 20` 둘 다 거짓 → 마지막 else 로 가요. 브라우저 수업 코드는 `prompt("나이 입력!")` 으로 받고 `alert` 로 보여 줘요.

## 3. truthy · falsy 로 짧게 — printName (1013_01.html)
```javascript
// 1013_01.html truthy · falsy — 이름이 없을 때 처리 (두 함수를 이름만 바꿔 같이 비교)
function printName1(name) {                     // 활용하기 전: undefined · null 만 직접 검사
    if (name === undefined || name === null) {  // 두 가지만 막음 → 빈 문자열 "" 은 통과해 버림
        return '사람이 없네요.';                 // 이름이 없을 때
    }                                           // if 끝
    return `안녕하세요 ${name}님`;              // 템플릿 문자열 → 이름을 끼워 넣음
}                                               // printName1 끝
function printName2(name) {                     // 활용한 코드: !name 하나로
    if (!name) {                                // falsy(undefined · null · "" · 0 · NaN · false) → !falsy = true
        return `사람이 없네요.`;                 // 이름이 없을 때
    }                                           // if 끝
    return `안녕하세요 ${name}님`;              // truthy 면 인사
}                                               // printName2 끝
console.log(printName1());                      // 인수 없음 → name = undefined → 사람이 없네요.
console.log(printName2());                      // undefined → falsy → 사람이 없네요.
console.log(printName1(""));                    // "" 은 undefined 도 null 도 아님 → 안녕하세요 님 (빈 이름 그대로)
console.log(printName2(""));                    // "" 은 falsy → 사람이 없네요.
console.log(printName2("윤희근"));              // "윤희근" → truthy → 안녕하세요 윤희근님
```
```output
사람이 없네요.
사람이 없네요.
안녕하세요 님
사람이 없네요.
안녕하세요 윤희근님
```
> **falsy** = `false` · `0` · `""`(빈 문자열) · `null` · `undefined` · `NaN` — 나머지는 전부 truthy · `!name` 하나가 `name === undefined || name === null` 보다 더 넓게 막아요 (빈 문자열 `""` 까지) · 🤖 `printName1("")` 줄은 차이를 보이려고 더한 줄이에요.

> ⚠️ **정정** — 수업 파일은 두 함수를 **같은 이름 `printName`** 으로 두 번 선언했어요. 선언적 함수는 호이스팅되고 **뒤에 쓴 것이 앞의 것을 덮어써서**, `console.log(printName());` 은 실제로 두 번째(`!name`) 함수로 실행돼요 (결과는 둘 다 `사람이 없네요.`).

## 4. 객체를 만드는 방법 — new · { } · 내장객체 (1013_01.html)
✍️ **필기** — “**object 를 생성할 때 new 라는 것을 쓰고 생성을 한다** · obj 를 만들 때, class 가 일을 하는 게 아니라 **obj 가 일을 해서** 만드는 거다”
```javascript
// 1013_01.html 객체 만드는 3가지 — new 생성자 · 리터럴 { } · 내장객체 Date
let obj1 = new Object();                        // 객체 생성자 → 빈 객체 {}
let obj2 = {};                                  // 객체 리터럴 → 빈 객체 {} (대부분 이걸 씀)
let obj3 = new Date(2026, 9, 13);               // 내장객체 Date 를 new 로 → 날짜 객체 (수업 코드는 new Date() = 지금)
obj1.name = "윤희근";                           // 점(.) 으로 속성 추가 → { name: "윤희근" }
console.log(obj1);                              // { name: '윤희근' }
console.log(obj2);                              // {}
console.log(typeof obj1, typeof obj2, typeof obj3);   // 셋 다 object → object object object
console.log(obj3.getFullYear(), obj3.getMonth() + 1, obj3.getDate());   // 2026 · 9+1=10 · 13 → 2026 10 13
```
```output
{ name: '윤희근' }
{}
object object object
2026 10 13
```
| 방법 | 코드 | 비고 |
|---|---|---|
| 객체 생성자 | `let obj1 = new Object();` | new 로 생성 |
| **객체 리터럴** | `let obj2 = {};` | ✍️ 대부분 이걸 씀 |
| 내장객체 생성자 | `let obj3 = new Date();` | 내장객체도 new 로 만듦 |

> ✍️ **필기** — 수업 시간에 나온 **내장객체**만 시험에 나와요 → 지금까지 수업 파일 · 필기에 나온 것: **Object** · **Date**(`getDay` · `getFullYear` …) · **JSON**(`JSON.stringify`) · (6주차) Date 시계

## 5. 🔥 얕은 복사 vs 깊은 복사 (노션 필기 코드)
✍️ **필기** — `let o2=o1; //얕은 복사(뜻 알기)` · `let o4={...o3}; //깊은 복사(뜻 알기)`
```javascript
// 노션 필기 — 얕은 복사 vs 깊은 복사 · === 비교 · JSON.stringify 로 내용 비교
let o1 = { name: "홍길동" };                    // 객체 하나 (메모리에 하나)
let o2 = o1;                                    // 얕은 복사: 주소만 복사 → o1 과 o2 는 같은 객체
let o3 = { name: "홍길동" };                    // 새 객체
let o4 = { ...o3 };                             // 깊은 복사(수업 용어): spread 로 속성을 꺼내 새 객체를 만듦
console.log(o1 === o2);                         // 같은 객체(같은 주소) → true
console.log(o3 === o4);                         // 내용은 같아도 다른 객체 → false
console.log(JSON.stringify(o3) === JSON.stringify(o4));   // 둘 다 '{"name":"홍길동"}' 문자열 → true (깊은 비교)
o2.name = "이몽룡";                             // o2 를 바꾸면
console.log(o1.name);                           // 같은 객체라 o1 도 바뀜 → 이몽룡
o4.name = "성춘향";                             // o4 를 바꿔도
console.log(o3.name);                           // 다른 객체라 o3 는 그대로 → 홍길동
```
```output
true
false
true
이몽룡
홍길동
```
| 구분 | 코드 | 뜻 | `===` |
|---|---|---|---|
| **얕은 복사** | `let o2 = o1;` | 객체의 **주소(참조)만** 복사 → 두 변수가 **같은 객체**를 가리킴 → 하나를 바꾸면 둘 다 바뀜 | `o1 === o2` → **true** |
| **깊은 복사** | `let o4 = { ...o3 };` | 속성을 꺼내 **새 객체**를 만듦 → 서로 따로 | `o3 === o4` → **false** |
| 깊은 비교 | `JSON.stringify(o3) === JSON.stringify(o4)` | 객체를 **문자열로 바꿔 내용**을 비교 | **true** |

> 🤖 **참고** — 시험은 수업 용어(위 표)대로 답하면 돼요. 다만 `{...o3}` 는 **한 단계만** 새로 만들어서, 객체 안에 또 객체가 있으면 안쪽은 같이 쓰게 돼요 (그래서 교재에 따라서는 spread 도 “얕은 복사”라고 부르기도 해요) · `let o2 = o1` 은 “참조 복사”라고도 해요.

## 6. 🔥 매개변수 빈칸 — “claude야 여기 시험문제로 정리해” (1013_02.js)
```javascript
let arrayObj=[1,"둘",true];
function funcA(/*시험문제 빈칸          정답:a1,a2,a3*/){
    console.log(a1);
    console.log(a2);
    console.log(a3);
}
funcA(arrayObj)
```
🤖 **시험문제로 정리** — ① 빈칸 = **`a1, a2, a3`** (함수 안에서 a1 · a2 · a3 를 쓰니까 매개변수 3개) ② 이때 `funcA(arrayObj)` 의 출력은? → 배열을 **통째로 1개**만 넘겨서 a1 만 받고 a2 · a3 는 **undefined** ③ 셋 다 받게 하려면 → `funcA(...arrayObj)` (spread 로 흩뿌려 넘김)
```javascript
// 1013_02.js 🔥 claude야 여기 시험문제로 정리해 — 매개변수 자리 빈칸 정답: a1, a2, a3
let arrayObj = [1, "둘", true];                 // 배열 안에 숫자 · 문자열 · 불린이 섞여도 됨 (JS)
function funcA(a1, a2, a3) {                    // 빈칸 → a1, a2, a3 (매개변수 3개)
    console.log(a1);                            // 첫 번째 인수
    console.log(a2);                            // 두 번째 인수
    console.log(a3);                            // 세 번째 인수
}                                               // funcA 끝
funcA(arrayObj);                                // 배열 통째로 1개만 넘김 → a1 = [1,"둘",true] · a2 · a3 는 못 받음 → undefined
console.log("---");                             // 구분선
funcA(...arrayObj);                             // spread → funcA(1, "둘", true) 로 흩뿌려 넘김 → 1 · 둘 · true
```
```output
[ 1, '둘', true ]
undefined
undefined
---
1
둘
true
```
> node 는 배열을 `[ 1, '둘', true ]` 로, 브라우저 콘솔은 `(3) [1, '둘', true]` 로 보여 줘요.

## 7. Rest 매개변수 (...a2) · spread 연산자 (...) (1013_02.js)
```javascript
// 1013_02.js Rest 매개변수 (...a2) — 나머지 인수를 배열로 모음
let arrayObj = [1, "둘", true];                 // 배열 3칸
function funcB(a1, ...a2) {                     // a1 = 첫 번째 · ...a2 = 나머지를 배열로 (수업 코드 이름은 funcA)
    console.log(a1);                            // 1
    console.log(a2);                            // 나머지 "둘", true → [ '둘', true ]
}                                               // funcB 끝
funcB(...arrayObj);                             // spread 로 1, "둘", true 를 넘김
funcB(arrayObj);                                // 배열 통째로 1개 → a1 = [1,'둘',true] · 나머지 없음 → []
```
```output
1
[ '둘', true ]
[ 1, '둘', true ]
[]
```
```javascript
// 1013_02.js spread(...) · 구조분해 할당 — 이름을 겹치지 않게 고친 실행 가능한 판
let arrayObj = [1, "둘", true];                 // 배열 3칸
let obj = { a: 1, b: "하이" };                  // 객체 (key a · b)
let obg2 = { ...obj, c: true };                 // 객체 spread → a:obj.a, b:obj.b 를 쓴 것과 같음 + c 추가
console.log(obg2);                              // { a: 1, b: '하이', c: true }
let arrayObj2 = [...arrayObj, 4];               // 배열 spread → [arrayObj[0], arrayObj[1], arrayObj[2], 4] 와 같음
console.log(arrayObj2);                         // [ 1, '둘', true, 4 ]
let [a1, a2, a3] = arrayObj;                    // 배열 구조분해 → 순서(index 0 · 1 · 2)대로 a1=1 · a2="둘" · a3=true
let { b, a } = obj;                             // 객체 구조분해 → 순서가 아니라 key 이름으로 → b="하이" · a=1
console.log(b, a);                              // 하이 1
console.log(`첫번째 값:${a1}     두번째 값:${a2}     세번째 값:${a3}`);   // 첫번째 값:1     두번째 값:둘     세번째 값:true
```
```output
{ a: 1, b: '하이', c: true }
[ 1, '둘', true, 4 ]
하이 1
첫번째 값:1     두번째 값:둘     세번째 값:true
```
| 이름 | 자리 | 하는 일 | 예 |
|---|---|---|---|
| **spread** 연산자 `...` | **호출 · 배열 · 객체 안** | 여러 값을 **개별로 흩뿌림** | `funcA(...arrayObj)` → `funcA(1, "둘", true)` · `[...arrayObj, 4]` · `{...obj, c:true}` |
| **Rest** 매개변수 `...` | **함수 선언의 매개변수 맨 끝** | 나머지 인수를 **배열로 모음** | `function funcA(a1, ...a2)` → a2 = `[ '둘', true ]` |

> ✍️ **필기** — “spread 연산자(...) : 객체나 배열에 저장된 여러 개의 값을 **개별로 흩뿌려 주는**” · 하나하나 쓰기 귀찮으면 `[...arrayObj, 4]` 로 한 번에 · `let obg2 = {...obj, c:true}` 는 `a: obj.a, b: obj.b` 를 쓴 것과 같은 말 · JS 는 배열 안에 **데이터 타입이 섞여도** 상관없음 · 선언적 함수는 **호이스팅** 덕분에 호출문이 위에 있어도 문제없음

### 구조분해 할당 — ✍️ 뜻
✍️ **필기** — “구조분해할당 뜻 { 안에 들어 있는 데이터를 넣거나 빼고 싶으면 **방 번호로 대괄호**를 이용해서 접근한다 · **index 번호는 0번부터** 시작 }”
| 방법 | 코드 | 결과 |
|---|---|---|
| 방법 1 (하나씩) | `let a1 = arrayObj[0]; let a2 = arrayObj[1]; let a3 = arrayObj[2];` | 방 번호 0 · 1 · 2 |
| 방법 2 (배열 구조분해) | `let [a1, a2, a3] = arrayObj;` | **순서대로** a1 = 1 · a2 = "둘" · a3 = true |
| 객체 구조분해 | `let {b, a} = obj;` | **key 이름으로** b = "하이" · a = 1 (순서 상관없음) |

> ⚠️ **정정** — 수업 파일 1013_02.js 는 그대로 실행하면 `SyntaxError: Identifier 'a1' has already been declared` 가 나요 — 방법 1 · 방법 2 를 같은 파일에 `let a1` 로 두 번 선언했고, `arrayObj2` 도 두 번 선언했어요. 위 코드는 한 번씩만 선언하게 고친 판이에요. 그리고 **`funcA` 를 두 번 선언**해서(매개변수 3개 판 · Rest 판) 호이스팅으로 **뒤의 Rest 판만 남아요** → 파일 맨 위 `funcA(arrayObj)` 도 실제로는 Rest 판으로 실행돼 `[ 1, '둘', true ]` · `[]` 이 찍혀요 (같은 이름 함수 선언은 마지막 것이 이김).
```javascript
// 🤖 같은 이름 함수를 두 번 선언하면? — 수업 파일에서 중복 let 줄만 뺀 판
let arrayObj = [1, "둘", true];                 // 배열 3칸
funcA(arrayObj);                                // 호이스팅으로 선언보다 먼저 호출 가능 — 그런데 어느 funcA?
function funcA(a1, a2, a3) {                    // 첫 번째 선언 (매개변수 3개)
    console.log(a1); console.log(a2); console.log(a3);   // ← 덮어써져서 한 번도 실행 안 됨
}                                               // 첫 번째 funcA 끝
function funcA(a1, ...a2) {                     // 두 번째 선언 (Rest) → 같은 이름이라 앞의 것을 덮어씀
    console.log(a1); console.log(a2);           // 위 호출: a1 = [1,'둘',true] · a2 = [] / 아래 호출: 1 · ['둘', true]
}                                               // 두 번째 funcA 끝
funcA(...arrayObj);                             // spread → funcA(1, "둘", true) → 1 · [ '둘', true ]
```
```output
[ 1, '둘', true ]
[]
1
[ '둘', true ]
```

## 8. 🔥 BOM — 브라우저 객체 모델 · “다음 중 성격이 다른 것은?”
✍️ **필기** — 브라우저 객체모델(BOM) { // 시험문제 **다음 중 성격이 다른 것은?** window 객체 · screen 객체 · location 객체 · history 객체 · navigator 객체 }

| 객체 | 하는 일 | 관계 |
|---|---|---|
| **window** | 브라우저 **창 전체** · BOM 의 **최상위 객체** (alert · prompt · setTimeout 도 window 의 메소드) | 맨 위 (부모) |
| screen | 모니터 화면 정보 (너비 · 높이) | `window.screen` |
| location | 지금 페이지의 **주소(URL)** · 이동 | `window.location` |
| history | 방문 기록 · 뒤로 / 앞으로 | `window.history` |
| navigator | 브라우저 정보 (이름 · 버전 · 언어) | `window.navigator` |

> 🤖 **답 (추론)** — 성격이 다른 것 = **window 객체**: 나머지 4개는 모두 **window 의 하위 객체**(window 의 속성)인데, window 는 그것들을 담고 있는 **최상위 객체**예요. 수업에서 다른 기준을 말씀하셨으면 노션에 적어 두세요 — 반영할게요.
