## 3. 🔥 사용자 등록 — root 비밀번호 · 원격 사용자 winuser

| 단계 | 명령 | 뜻 |
|---|---|---|
| 사용자 목록 | `use mysql;` → `select user, host from user;` | 🔥 사용자 = **'이름'@'호스트'** 짝 (처음 6 rows) |
| root 비밀번호 | `alter user 'root'@'localhost' identified by '비밀번호';` → `flush privileges;` | 이제 `mariadb` 만 치면 **ERROR 1045 Access denied** → `mariadb -h localhost -u root -p` |
| 원격 사용자 | `create user winuser@'192.168.111.%' identified by '비밀번호';` | 🤖 `%` = 아무 글자 → 192.168.111.**아무 번호** 컴퓨터에서 접속하는 winuser (7 rows) |
| 권한 | `grant all on *.* to winuser@'192.168.111.%';` → `flush privileges;` | 🤖 `*.*` = **모든 DB 의 모든 표** · ⚠️ 노션 수업 로그엔 없던 줄 — 없으면 winuser 로 `CREATE DATABASE` 를 못 함 (학교 PC 기록 · 사용자가 “grant all on *.*” 를 알려 줌) |

- 🤖 `-h` = 접속할 서버(host) · `-u` = 사용자(user) · `-p` = 비밀번호를 물어봄(password) — `-p` 뒤에 비밀번호를 붙여 쓰면 묻지 않고 바로 (📄 txt 원본 `mysql -h 192.168.111.100 -u winuser -p비밀번호` · 화면에 남아서 붙여 쓰지 않는 게 안전)
- 🤖 `flush privileges;` = 권한 표를 다시 읽기 — `create user` · `grant` 같은 계정 명령은 바로 적용돼서 안 해도 동작하지만, 수업 · 과제 순서대로 써 두면 돼요

## 5. 🔥 NFS — 디렉터리 공유 (수업 Server → Client · 과제 14-1 Server(B) → Client · Windows)

### 흐름 한눈에

| 쪽 | 단계 | 명령 | 뜻 |
|---|---|---|---|
| 서버 | ① 패키지 | `rpm -qa nfs-utils` → 없으면 `dnf -y install nfs-utils` | 수업 Server 엔 있었음 · ⚠️ Server(B) 엔 없어서 설치 |
| 서버 | ② 공유 설정 | `/etc/exports` 에 `/share *(rw,sync)` | 🔥 **공유할 폴더 · 허용할 컴퓨터 · (옵션)** — `*` = 모든 컴퓨터 |
| 서버 | ③ 폴더 | `mkdir /share` → `chmod 707 /share` → `cp /boot/vm* /share` | 707 = **다른 사용자(others)도 rwx** → 클라이언트 사용자가 파일을 넣을 수 있음 |
| 서버 | ④ 서비스 | `systemctl restart nfs-server` → `enable` → `status` | 🔥 **active (exited)** 가 정상 |
| 서버 | ⑤ 확인 | `exportfs -v` | `/share <world>(sync,…,rw,…,root_squash,…)` |
| 서버 | ⑥ 방화벽 | `systemctl stop firewalld` | 수업 방식 = 방화벽을 끔 (🤖 실습용 · 보안은 약해짐) |
| 클라이언트 | ⑦ 확인 | `showmount -e 192.168.111.100` | `/share *` = 공유 목록 |
| 클라이언트 | ⑧ 마운트 | `mkdir myshare` → `sudo mount -t nfs 192.168.111.100:/share myshare` | 🔥 `mount -t nfs 서버IP:/공유폴더 마운트할곳` |
| 클라이언트 | ⑨ 쓰기 | `ls -l myshare/` → `cp /boot/mem* ~/myshare/testfile` | 서버 /share 에 바로 생김 |
| Windows | ⑩ 연결 | `mount.exe 192.168.111.200:/share Z:` → `dir Z:\` | 학교 PC 기록 · PowerShell 의 `mount` 는 다른 명령이라 **.exe 까지** |

| 📄 `/etc/exports` 옵션 (exportfs -v 에 보인 것) | 🤖 뜻 |
|---|---|
| **rw** | 읽기 · 쓰기 (ro = 읽기만) |
| **sync** | 쓴 내용을 디스크에 기록한 뒤 응답 (바로 기록) |
| root_squash | 클라이언트의 root 를 익명 사용자로 바꿈 (기본값 · 서버 root 권한을 막음) |
| `<world>` | `*` = 모든 컴퓨터에 공유 |

## 6. 한눈에 — DB 서버 vs NFS

| | MariaDB (DB 서버) | NFS (파일 공유) |
|---|---|---|
| 하는 일 | 데이터베이스 서비스 — 다른 컴퓨터가 SQL 로 접속 | 서버의 디렉터리를 다른 컴퓨터가 **자기 폴더처럼** 사용 |
| 서버 패키지 | rpm 5개 (MariaDB-server 등 · galera-4) | **nfs-utils** |
| 서비스 | `mariadb` → active **(running)** | `nfs-server` → active **(exited)** |
| 설정 | 사용자 · 권한 = SQL (`create user` · `grant`) | **/etc/exports** 한 줄 |
| 포트 | **3306** | 🤖 2049 (수업은 방화벽을 꺼서 따로 열지 않음) |
| 방화벽 | 수업 `firewall-config` · 과제 `firewall-cmd --permanent --add-port=3306/tcp` | `systemctl stop firewalld` |
| 클라이언트 | `mariadb -h 서버IP -u 사용자 -p` | `mount -t nfs 서버IP:/share 폴더` · Windows `mount.exe` |

## 7. 트러블슈팅 (수업 로그 · 학교 PC 기록)
- `show database` → `->` 만 계속 / ERROR 1064 → **`show databases;`** (s · `;` 확인) · 안 끝난 문장은 Ctrl+C
- `use msql` → ERROR 1049 Unknown database → DB 이름 오타
- `mariadb` → ERROR 1045 (using password: NO) → root 비밀번호를 정했으니 `mariadb -h localhost -u root -p`
- `create user winuser'192…'` 처럼 **@ 빠뜨림** → ERROR 1064
- winuser 로 `CREATE DATABASE` 가 안 됨 → `grant all on *.* to winuser@'192.168.111.%';` + `flush privileges;`
- Windows 에서 접속 안 됨 → Server(B) 방화벽 3306(`--permanent` + `--reload`) · winuser 호스트가 `192.168.111.%` 인지 · 접속 IP 가 .200 인지
- `/etc/exports` 만 침 → 허가 거부 (실행하려 함) → 편집기(`gnome-text-editor` · nano)로 열거나 `cat` 으로 보기
- `showmount` → RPC: Program not registered → `showmount -e 서버IP`
- `mkdir /myshare` → 허가 거부 → 홈에 `mkdir myshare`
- `umount` → device is busy → 터미널이 그 폴더 안이거나 열린 파일 · `cd ~` 뒤 다시
- `ls -l\` 처럼 끝에 `\` → 다음 줄을 기다리는 `>` → Ctrl+C
- dnf 가 느림 → 저장소에서 종속 꾸러미를 받는 중 · `Complete!`(완료되었습니다!)까지 기다리기 (^C X)

## 8. 명령어 한 줄 사전

| 명령 | 뜻 |
|---|---|
| `dnf -y install M*.rpm g*.rpm` | 받아 둔 MariaDB rpm 5개 설치 (종속 꾸러미는 저장소에서) |
| `systemctl restart mariadb` · `systemctl enable mariadb` · `systemctl status mariadb` | 지금 시작 · 부팅 때 자동 시작 · 상태 (active (running)) |
| `firewall-cmd --permanent --add-port=3306/tcp` · `firewall-cmd --reload` | 3306/tcp 영구 허용 · 지금 적용 |
| `mariadb` · `mariadb -h localhost -u root -p` | 접속 (비밀번호를 정한 뒤엔 `-u root -p`) |
| `show databases;` · `use mysql;` | DB 목록 · DB 고르기 |
| `select user, host from user;` · `desc user;` | 사용자 목록 · user 표 구조 |
| `alter user 'root'@'localhost' identified by '비밀번호';` | root 비밀번호 정하기 |
| `create user winuser@'192.168.111.%' identified by '비밀번호';` | 원격 사용자 만들기 (`%` = 아무 글자) |
| `grant all on *.* to winuser@'192.168.111.%';` · `flush privileges;` | 모든 권한 주기 · 권한 표 다시 읽기 |
| `rpm -qa nfs-utils` · `dnf -y install nfs-utils` | NFS 패키지 확인 · 설치 |
| `/share *(rw,sync)` (/etc/exports) | /share 를 모든 컴퓨터에 읽기 · 쓰기로 공유 |
| `chmod 707 /share` | others 도 rwx |
| `systemctl restart nfs-server` · `systemctl enable nfs-server` | NFS 서버 시작 · 자동 시작 (status = active (exited)) |
| `exportfs -v` | 공유 중인 폴더 · 옵션 보기 |
| `systemctl stop firewalld` | 방화벽 끄기 (수업 방식) |
| `showmount -e 서버IP` | 서버의 공유 목록 |
| `mount -t nfs 서버IP:/share myshare` · `umount myshare` | NFS 연결 · 해제 |
| `mount.exe 서버IP:/share Z:` · `umount.exe Z:` (Windows) | Windows 에서 NFS 연결 · 해제 |

## 9. 🔥 시험 대비 핵심 요약

1. **MariaDB 설치** = rpm 5개(MariaDB-client · common · server · shared · galera-4) → `dnf -y install M*.rpm g*.rpm` → `systemctl restart` · `enable mariadb` → status **active (running)**
2. MariaDB 포트 **3306** — 글자 화면 = `firewall-cmd --permanent --add-port=3306/tcp` + `firewall-cmd --reload` (📖 VITAMIN QUIZ 11-1 HINT2)
3. `systemctl enable` = **부팅 때 자동 시작** · `restart` = 지금 다시 시작
4. DB 사용자 = **'이름'@'호스트'** · `%` = 아무 글자 → `create user winuser@'192.168.111.%' identified by '…';` → `grant all on *.* to winuser@'192.168.111.%';` (`*.*` = 모든 DB · 모든 표) → `flush privileges;`
5. root 비밀번호를 정한 뒤엔 `mariadb` 만으로는 ERROR 1045 → `mariadb -h localhost -u root -p`
6. **NFS 서버** = nfs-utils · `/etc/exports` = **공유폴더 허용호스트(옵션)** → `/share *(rw,sync)` (rw 읽기 · 쓰기 · sync 바로 기록) · `chmod 707` · `systemctl restart nfs-server` = **active (exited)** 정상 · `exportfs -v`
7. **NFS 클라이언트** = `showmount -e 서버IP` → `mount -t nfs 서버IP:/share 마운트할곳` · Windows = `mount.exe 서버IP:/share Z:`
