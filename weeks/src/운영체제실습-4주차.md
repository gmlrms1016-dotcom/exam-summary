> 🐧 **운영체제실습 4주차** — 사용자 생성·수정·삭제 / 그룹 관리 / 사용자 전환·소유권 / rpm·dnf 패키지 설치
> 실습 터미널 기록에서 **오타로 실패한 명령과 똑같이 반복한 명령은 빼고** 주제별로 정리했습니다. 출력이 긴 명령은 **접어 두었어요**(눌러서 펼치기).
> 📌 교수님이 강의자료는 **중간고사 전주**에 올려주심 · ★ **시험문제는 7번 DNF 작동 흐름도**

## 1. 사용자 만들기 — useradd · passwd

> 💡 **useradd** 로 계정을 만들면 `/etc/passwd`(계정) · `/etc/shadow`(암호) · `/etc/group`(같은 이름의 그룹)에 **한 줄씩 추가**되고 홈 디렉터리 `/home/사용자명` 이 생깁니다.
> 암호는 **passwd** 로 따로 정합니다.

| 명령 | 설명 |
|---|---|
| `useradd 사용자` | 사용자 생성 (홈 `/home/사용자` + 같은 이름 그룹 자동 생성) |
| `useradd -d 디렉터리 사용자` | 홈 디렉터리를 **직접 지정**해서 생성 |
| `passwd 사용자` | 암호 설정·변경 |
| `tail -3 파일` | 파일의 **마지막 3줄** 보기 |
| `grep 단어 파일` | 파일에서 **그 단어가 들어간 줄만** 보기 |

## 2. 사용자 수정 — usermod · chage

> 💡 **usermod** = 이미 있는 계정의 정보(UID · 홈 · 이름)를 수정
> **chage** = 암호를 쓸 수 있는 기간 · 계정 만료일을 관리 (change age)

| 명령 | 설명 |
|---|---|
| `usermod -u UID 사용자` | **UID** 변경 |
| `usermod -d 디렉터리 사용자` | **홈 디렉터리** 변경 |
| `usermod -l 새이름 기존이름` | **로그인 이름** 변경 (새 이름이 **앞**) |
| `usermod -d 디렉터리 -l 새이름 기존이름` | 옵션 여러 개를 한 번에 |

### 2-1. UID 바꾸기 (-u)
```bash
usermod -u 2001 user_002
tail -3 /etc/passwd
```
```output
use_002:x:1002:1002::/work_06:/bin/bash
user_002:x:2001:1003::/home/user_002:/bin/bash
master:x:1004:1004::/home/master:/bin/bash
```

> 🔎 `user_002` 의 UID 가 1003 → **2001** (세 번째 칸만 바뀌고 GID 1003 은 그대로)

### 2-2. 홈 + 이름 한 번에 (-d · -l)
```bash
usermod -d /home/workpasce_06 -l guest_001 user_002
tail -3 /etc/passwd
```
```output
use_002:x:1002:1002::/work_06:/bin/bash
master:x:1004:1004::/home/master:/bin/bash
guest_001:x:2001:1003::/home/workpasce_06:/bin/bash
```

> 🔎 `user_002` → **guest_001** 로 이름이 바뀌고 홈이 `/home/workpasce_06` 으로 바뀜 (UID 2001 유지). 수정된 줄은 파일 **맨 아래**로 갑니다.
> `workpasce_06` 은 실습 때 입력한 이름 그대로입니다.

### 2-3. master → manager
```bash

tail -3 /etc/passwd
```

```output
use_002:x:1002:1002::/work_06:/bin/bash
```


### 2-4. chage — 암호 기간 · 계정 만료

| 명령 | 설명 |
|---|---|
| `chage -l 사용자` | 암호·계정 기간 정보 **보기** (list) |
| `chage -m 일수 사용자` | 암호를 바꿀 수 있는 **최소** 날 수 |
| `chage -M 일수 사용자` | 암호를 바꿔야 하는 **최대** 날 수 → 암호 만료일이 생김 |

## 3. 사용자 삭제 — userdel · find

| 명령 | 설명 |
|---|---|
| `userdel 사용자` | 계정만 삭제 (홈 디렉터리는 남음) |
| `userdel -r 사용자` | 계정 + **홈 디렉터리까지** 삭제 |
| `find -user UID -exec rm -r {} \;` | 그 UID 가 소유한 파일을 **찾아서 삭제** |

```bash
userdel -r user_001
ls /home
```
```output
master  rocky  user_002
```

> 🔎 `user_001` 홈이 사라졌습니다. `user_002` 폴더가 남아 있는 건 2-2 에서 이름만 guest_001 로 바꿨기 때문 — `usermod -d` 는 홈 **주소만** 바꾸고 폴더를 옮기지는 않습니다.

```bash
find -user 1001 -exec rm -r {} \;   # UID 1001(지운 user_001)이 소유한 파일 찾아 삭제
grep user_001 /etc/passwd
```
```output
(출력 없음)
```

> 💡 `find` 는 경로를 생략하면 **현재 디렉터리 아래**에서 찾고, `{}` 자리에 찾은 파일이 하나씩 들어가며 `\;` 가 -exec 명령의 끝입니다.
> `grep` 결과가 **아무것도 없다** = /etc/passwd 에서 user_001 이 완전히 지워짐

## 4. 그룹 관리 — groupadd · gpasswd

> 💡 그룹 정보 `/etc/group` = 그룹명 : x : **GID** : 소속 사용자
> 그룹 암호 `/etc/gshadow` = 그룹명 : **암호** : 관리자 : 소속 사용자

| 명령 | 설명 |
|---|---|
| `groupadd 그룹` | 그룹 생성 (GID 자동) |
| `groupadd -g GID 그룹` | **GID 를 지정**해서 생성 |
| `groupadd -g GID -o 그룹` | **이미 쓰는 GID** 로도 생성 허용 (`-o` = non-unique) |
| `gpasswd -a 사용자 그룹` | 그룹에 사용자 **추가** (add) |
| `gpasswd -d 사용자 그룹` | 그룹에서 사용자 **제거** (delete) |
| `gpasswd 그룹` | 그룹 **암호 설정** |
| `gpasswd -r 그룹` | 그룹 암호 **제거** (remove) |

## 5. 사용자 전환과 소유권 — su · id · newgrp · chown

| 명령 | 설명 |
|---|---|
| `su - 사용자` | 그 사용자로 **전환** (`-` = 그 사용자의 홈·환경으로) · 프롬프트 `#` → `$` |
| `exit` | 전환하기 전 사용자로 **돌아가기** (로그아웃) |
| `id` | 현재 사용자의 **UID · GID · 소속 그룹** |
| `newgrp 그룹` | 현재 **주 그룹**을 다른 그룹으로 바꾸기 |
| `chown 소유자 파일` | 파일 **소유자** 변경 |
| `chown 소유자:그룹 파일` | 소유자와 **그룹을 한 번에** 변경 |

> 💡 **rpm** = `.rpm` 파일 하나를 직접 설치 → 필요한 다른 패키지(**의존성**)는 **직접** 해결해야 함

## 7. ★ 시험문제 — DNF 작동 흐름도 (그림 4-111)

> 📝 **시험문제** — `dnf install 패키지이름` 명령이 **내부적으로 작동하는 순서** (교재 그림 4-111 · 수업 화면 사진 `4주차/시험문제.jpeg`)

| 순서 | 하는 일 |
|---|---|
| ① | **dnf install** 입력 |
| ② | `/etc/yum.repos.d/` 디렉터리의 **repo 파일**을 열어서 **URL 주소** 확인 |
| ③ | **전체 패키지 목록 파일** 요청 (내 컴퓨터 → 저장소) |
| ④ | **전체 패키지 목록 파일만** 다운로드 (저장소 → 내 컴퓨터) |
| ⑤ | 설치할 패키지와 **관련된 패키지의 이름**을 화면에 출력 |
| ⑥ | **'y'** 를 입력하면 설치에 필요한 **패키지 파일** 요청 (내 컴퓨터 → 저장소) |
| ⑦ | 설치할 **패키지 파일을 다운로드**해서 **자동 설치** (저장소 → 내 컴퓨터) |

> 🗄️ **Rocky Linux 10 패키지 저장소** 안에는 **baseos 패키지 · appstream 패키지 · 기타 패키지 · 패키지 목록** 이 있고, 내 컴퓨터와는 **인터넷**으로 연결됩니다.
> 교재 예시: 앞서 **실습 11** 에서 설치한 **mysql8.4-errmsg** 로 흐름을 따라가면 ① `dnf install mysql8.4-errmsg` 입력 → ② 자동으로 `/etc/yum.repos.d/` 의 repo 파일 확인 (핵심 파일은 **rocky.repo** 와 rocky-… — 사진에서 잘림)

> 🎯 **외우는 요령** — 입력 → **repo 확인** → **목록 요청** → **목록만 다운** → **이름 출력** → **y 입력 · 파일 요청** → **파일 다운 · 자동 설치**
> 요청(③⑥)은 내 컴퓨터 → 저장소, 다운로드(④⑦)는 저장소 → 내 컴퓨터. **목록**(③④)을 먼저 받고 **파일**(⑥⑦)은 y 를 누른 뒤에 받습니다.
> 실습 연결: 6-3 dnf 출력의 `Rocky Linux 10 - BaseOS … 23 MB` = ④ 목록 다운로드, `종속 꾸러미 설치 중:` 표 = ⑤, `꾸러미 내려받기 중:` → `설치 중` = ⑦
> ⑥ 은 사진에서 끝부분이 가려져 있어 **'요청'** 은 흐름(③ 요청 ↔ ④ 다운로드)에 맞춘 추정입니다.
