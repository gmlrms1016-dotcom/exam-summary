## 9주차 · 이벤트 4요소 · 요소 순회 · 요청과 응답
| 포인트 | 핵심 · 답 | 그림 |
|---|---|---|
| 🔥 ✍️ 이벤트 4요소 | **기말고사에 나옴** — 이벤트 `'click'` · 이벤트 소스 `addBtn` · 이벤트 핸들러(= 리스너) `function(){…}` · 이벤트 객체 `e` | ① |
| 📄 1027_01_event.html | `addBtn.addEventListener('click', function(){…})` → `prompt("할 일 입력")` → `list.innerHTML += '<li>' + txt + '</li>'` → 목록 끝에 추가 (li 4개 → 5개) | ① |
| ✍️ 요청 · 파라미터 | 요청(request) = 클라이언트 → 서버 · 요청에 담아 보내는 값 = **파라미터** (⚠️ 필기는 “보내는 것 = 파라미터”) | ② |
| ✍️ 응답 · JSON | 응답(response) = 서버 → 클라이언트 **텍스트** (흔히 JSON 형식) → `JSON.parse` → 객체 → 화면에 출력(뿌려 줌) | ② |
| 📄 1027_02_요소순회.js | 방법1 `for (let i = 0; …)` → `arr[i]` · 방법2 `for (let item of arr)` → 값 · `Object.keys` 키 배열 · `Object.values` 값 배열 · `person[key]` | ③ |
