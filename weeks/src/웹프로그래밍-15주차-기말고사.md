## 9주차 · 이벤트 4요소 · 요소 순회 · 요청과 응답
| 포인트 | 핵심 · 답 | 그림 |
|---|---|---|
| 🔥 ✍️ 이벤트 4요소 | **기말고사에 나옴** — 이벤트 `'click'` · 이벤트 소스 `addBtn` · 이벤트 핸들러(= 리스너) `function(){…}` · 이벤트 객체 `e` | ① |
| 📄 1027_01_event.html | `addBtn.addEventListener('click', function(){…})` → `prompt("할 일 입력")` → `list.innerHTML += '<li>' + txt + '</li>'` → 목록 끝에 추가 (li 4개 → 5개) | ① |
| ✍️ 요청 · 파라미터 | 요청(request) = 클라이언트 → 서버 · 요청에 담아 보내는 값 = **파라미터** (⚠️ 필기는 “보내는 것 = 파라미터”) | ② |
| ✍️ 응답 · JSON | 응답(response) = 서버 → 클라이언트 **텍스트** (흔히 JSON 형식) → `JSON.parse` → 객체 → 화면에 출력(뿌려 줌) | ② |
| 📄 1027_02_요소순회.js | 방법1 `for (let i = 0; …)` → `arr[i]` · 방법2 `for (let item of arr)` → 값 · `Object.keys` 키 배열 · `Object.values` 값 배열 · `person[key]` | ③ |

> 자세한 코드 · 실행 결과는 [9주차](웹프로그래밍-9주차.html) · 문제는 🔒 실제시험.

## 10주차 · 🔥 기말 = 실기 · 누른 항목 선택 · 배열 메서드 · CRUD
| 포인트 | 핵심 · 답 | 그림 |
|---|---|---|
| 🔥 ✍️ 기말 방식 | **기말고사는 필기가 아닌 실기** — 직접 코드를 짜는 시험 | — |
| ✍️ 이벤트 4요소 복습 | 오늘 코드: 이벤트 `'click'` · 소스 `list`(ul) · 핸들러 `activeItem` (괄호 없이 이름만) · 이벤트 객체 `e` | ④ |
| 📄 1027_01_event.html | `e.target` = 누른 li · `nodeName == 'LI'` (대문자) · `title.innerHTML = e.target.innerHTML` · 모든 li `removeAttribute('class')` → 누른 li `setAttribute('class','active')` · 🤖 ul 에 하나 = 이벤트 위임 (새 li 도 됨) | ④ |
| 📄 push · pop | **맨 뒤** 추가 → 반환 **새 길이** / **맨 뒤** 제거 → 반환 **뺀 요소** | ⑤ |
| 📄 shift · unshift | **맨 앞** 제거 → 반환 **뺀 요소** / **맨 앞** 추가 → 반환 **새 길이** | ⑤ |
| 📄 slice · concat | `slice(시작, 끝)` 끝 **직전**까지 · 음수 = 뒤에서 (`slice(-3)` → [3, 4, 5]) · `concat` 이어 붙임 → 둘 다 **원본 그대로 · 새 배열** | ⑤ |
| 📄 forEach · includes | `forEach((item, idx, arr) => …)` 요소마다 · 반환 없음 / `includes(값)` → true · false | ⑥ |
| 📄 indexOf · findIndex | `indexOf(값)` → 인덱스 · 없으면 **-1** / `findIndex(콜백)` → 참인 첫 요소의 인덱스 · 없으면 -1 · 객체는 `indexOf({…})` → -1 (주소 비교) → `findIndex(i => i.name === …)` | ⑥ |
| ⚠️ 수업 파일 오타 | `arr.forEach` · `inIncludes` · `const` 같은 이름 두 번(SyntaxError → 한 줄도 실행 안 됨) · `findexIndex` | ⑥ |
| ✍️ 프론트 · 백엔드 · CRUD | 프런트엔드 = 브라우저 · 백엔드 = 서버 · 🤖 CRUD = Create · Read · Update · Delete · ✍️ 다음 주: 백엔드에 요청해서 투두리스트 | ⑦ |

> 자세한 코드 · 실행 결과는 [10주차](웹프로그래밍-10주차.html) · 문제는 🔒 실제시험.
