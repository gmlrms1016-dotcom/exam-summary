## 1. 🔥 [Quiz 1-1] R · S 조인 — 결과 릴레이션의 카디널리티 (1교시 · 엑셀 · ✍️ 시험출제)
> 강의자료 8쪽 [Quiz 13-01] · 실습 엑셀 Quiz1-1-join-stu “카디날리티는 무엇인가?” — 다음 두 릴레이션 R 과 S 에 대해 **R 을 왼쪽, S 를 오른쪽** 릴레이션으로 하고 **속성 B 를 조인 속성**으로 하여 자연조인, 왼쪽외부조인, 완전외부조인으로 수행하였을 때 결과 릴레이션의 카디널리티는 각각 얼마인가? · ✍️ 내 엑셀 답 **3 · 4 · 5** ✅

| R.A | R.B | | S.B | S.C |
|---|---|---|---|---|
| a | 2 | | 1 | x |
| b | 3 | | 2 | y |
| c | 3 | | 3 | z |
| d | 5 | | | |

```sql
-- 1) 자연조인 — 같은 이름의 열 B 가 같은 짝만 · B 는 한 번만
SELECT *
FROM R NATURAL JOIN S;                                       -- R.B 2 · 3 · 3 이 S 와 짝 (a · b · c) → 3행 (MySQL 은 B 를 맨 앞에: B · A · C)
-- (같은 짝을 ON 으로 쓰면 동등조인 — B 열이 2개)
SELECT *
FROM R INNER JOIN S
ON R.B = S.B;                                                -- 3행 · A · B · B · C
-- 2) 왼쪽 외부조인 — 왼쪽(R) 행은 짝이 없어도 모두
SELECT *
FROM R LEFT OUTER JOIN S
ON R.B = S.B;                                                -- 짝 3행 + d · 5 (S 에 B=5 없음) → NULL · NULL → 4행
-- (오른쪽 외부조인 — 오른쪽(S) 행은 모두)
SELECT *
FROM R RIGHT OUTER JOIN S
ON R.B = S.B;                                                -- 짝 3행 + 1 · x (R 에 B=1 없음) → NULL · NULL → 4행
-- 3) 완전 외부조인 — 양쪽 모두 (MySQL 은 FULL OUTER JOIN 이 없음 → 왼쪽 UNION 오른쪽)
SELECT * FROM R LEFT OUTER JOIN S ON R.B = S.B
UNION                                                        -- 겹친 짝 3행은 한 번만
SELECT * FROM R RIGHT OUTER JOIN S ON R.B = S.B;             -- 4 + 4 − 3 = 5행
```

| 1) 자연조인 A | B | C |
|---|---|---|
| a | 2 | y |
| b | 3 | z |
| c | 3 | z |

| 2) 왼쪽 외부 A | R.B | S.B | C |
|---|---|---|---|
| a | 2 | 2 | y |
| b | 3 | 3 | z |
| c | 3 | 3 | z |
| d | 5 | NULL | NULL |

| (오른쪽 외부) A | R.B | S.B | C |
|---|---|---|---|
| NULL | NULL | 1 | x |
| a | 2 | 2 | y |
| b | 3 | 3 | z |
| c | 3 | 3 | z |

| 3) 완전 외부 A | R.B | S.B | C |
|---|---|---|---|
| a | 2 | 2 | y |
| b | 3 | 3 | z |
| c | 3 | 3 | z |
| d | 5 | NULL | NULL |
| NULL | NULL | 1 | x |

| 조인 | 카디널리티 (행 수) | 왜 |
|---|---|---|
| 1) 자연조인 | **3** | B = 2 · 3 · 3 인 a · b · c 만 S 와 짝 — d(5) 와 S 의 1(x) 은 짝 없음 |
| 2) 왼쪽 외부조인 | **4** | 짝 3 + 짝 없는 **왼쪽** d → `d · 5 · NULL · NULL` |
| (오른쪽 외부조인) | 4 | 짝 3 + 짝 없는 **오른쪽** 1(x) → `NULL · NULL · 1 · x` |
| 3) 완전 외부조인 | **5** | 짝 3 + 왼쪽 d + 오른쪽 1(x) |

> ✍️ 내 엑셀 답 3 · 4 · 5 ✅ · 왼쪽 · 오른쪽 결과 표 ✅ · ⚠️ 1) 자연조인 표는 `a 2 2 y` 한 행에서 멈췄어요 → b · c 까지 **3행** · 자연조인은 B 를 **한 번만** (A · B · C 3열 — 교수님 엑셀 틀은 B 칸이 2개지만 묻는 건 행 수라 답은 같음) · 🤖 카디널리티 = **짝 수** (+ 외부조인이면 짝 없는 쪽 행 수) — b 와 c 가 둘 다 B=3 이라 S 의 3(z) 은 **두 번** 짝이 돼요.

## 2. [Quiz 1-2] 카디널리티 · 차수 · [Quiz 1-3] 관계대수(집합) — ✍️ 시험 미출제

|---|---|---|---|
| 1-2 R × S 카디널리티 | 행은 **곱하기** 4 × 6 | **24** | 24 ✅ |

| 1-3 ① R1 ∩ R2 교집합 | 공통 투플만 | **5** ⭕ | ⚠️ 20 (`=(10+15)-5`) ✕ — 합집합 값 |
| 1-3 ② R1 × R2 | 10 × 15 | **150** ⭕ | 150 ✅ |
| 1-3 ③ R1 − R2 차집합 | R1 에만 있는 것 10 − 5 | **5** ⭕ | ⚠️ −5 (`=10-15`) ✕ — 투플 수는 음수가 안 됨 |
| 1-3 ④ R1 ∪ R2 합집합 | 10 + 15 − 공통 5 | **20** → 15개는 **틀림** | ⚠️ 25 (`=10+15`) ✕ — 공통 5개를 두 번 셈 |

## 5. 🔥 [실습 3-1] 중첩질의 — IN · ALL · SOME · ANY · MAX (stu · pro)
✍️ **필기 (📷 사진 · 캡처)** — “하위질의: 서브 쿼리 (sub query, 하위질의, 부질의, 중첩질의, 상관중첩질의)” · 강의자료 33 · 35쪽 [요약]

| ✍️ 키워드 | 뜻 | 🤖 같은 것 · 예 |
|---|---|---|
| **ANY** | 서브쿼리의 여러 개의 결과 중 **한 가지만** 만족해도 되며 | `> ANY` = 가장 **작은** 값보다 크면 참 (3-4) |
| **ALL** | 서브쿼리의 여러 개의 결과를 **모두** 만족시켜야 된다 | `> ALL` = 가장 **큰** 값보다 커야 참 (3-3) |
| **SOME** | ANY 와 동일한 의미 | `> SOME` = `> ANY` (✍️ “위랑 아래랑 같음”) |
| **IN** | `= ANY` 와 동일 | 목록 중 하나와 같으면 참 (3-1 · 3-2) |
| **NOT IN** | `<> ALL` 과 동일 | 목록 어느 것과도 다르면 참 |
| **EXISTS** | 존재하면 참, 아니면 거짓 | 22번 |
| **NOT EXISTS** | 존재하지 않으면 참 | 24번 (6번) |

> 🤖 `> ALL` ↔ `> MAX` · `> ANY` ↔ `> MIN` 은 하위질의 결과가 비어 있지 않고 NULL 이 없을 때 같은 결과예요 (3-3 · 3-4 를 MAX · MIN 으로 바꿔 실행해 봄).

| stu.sno | sname | dept | sage | | pro.pno | pname | dept | page |
|---|---|---|---|---|---|---|---|---|
| s1 | 유준호 | 컴퓨터 | 23 | | p1 | 이정무 | 컴퓨터 | 36 |
| s2 | 오정민 | 컴퓨터 | 34 | | p2 | 우태하 | 컴퓨터 | 32 |
| s3 | 이태현 | 건축 | 22 | | p3 | 이성민 | 건축 | 45 |

```sql
-- 3-1) 교수 테이블에서 이정무 의 학과와 같은 학생 이름, 학과, 나이를 검색하라      ✍️ 내 SQL
SELECT sname, dept, sage                                     -- ③ 이름 · 학과 · 나이
FROM stu
WHERE dept IN (SELECT dept                                   -- ① 괄호 안 — 이정무의 dept → '컴퓨터' (1행)
               FROM pro
               WHERE pname = '이정무');                       -- ② dept IN ('컴퓨터') → 유준호 · 오정민
-- 3-2) 교수 테이블에서 pno 가 p1 이거나 p2 인 학과와 같은 학생 이름, 학과, 나이를 검색하라
SELECT sname, dept, sage
FROM stu
WHERE dept IN (SELECT dept                                   -- ① p1 · p2 의 dept → '컴퓨터' · '컴퓨터' (2행)
               FROM pro
               WHERE pno IN('p1','p2'));                     -- ② dept IN ('컴퓨터', '컴퓨터') → 유준호 · 오정민
```
| sname | dept | sage |
|---|---|---|
| 유준호 | 컴퓨터 | 23 |
| 오정민 | 컴퓨터 | 34 |

