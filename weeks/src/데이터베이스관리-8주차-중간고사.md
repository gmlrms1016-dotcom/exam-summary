## 7주차 — 🔥 ALTER · Quiz 7-3 dept · dmember ([7주차 자세히](데이터베이스관리-7주차.html))
- 🔥 ✍️ **필기** — **ALTER ADD 가 시험에 나옴** (“추가하는 게 시험문제임”) · 7주차 내용은 시험의 **10%**
- **ALTER** (DDL) = 테이블 **구조** 변경 — 추가 `ALTER TABLE project ADD budget int;` (기존 행의 budget 은 **NULL**) · 수정 `ALTER TABLE project MODIFY projname varchar(20);` (✍️ MySQL · Oracle 문법, MS-SQL 은 다름) · 삭제 `ALTER TABLE project DROP COLUMN budget;`
- 🔥 **Quiz 7-3 (8 · 9쪽 시험 페이지)** — 생성 순서 **dept → dmember** (부모 → 자식) · 삭제 순서 **dmember → dept** (자식 → 부모) · 입력 순서 **dept → dmember** · dmember.dept_id 자료형 = **char(3)** (참조하는 열과 같게) · FK 테이블명 **dept** · FK 열 **dept_id**
- 9쪽 빈칸: 1) **dmember** 2) **dept** 3) **CREATE** 4) **PRIMARY** · (빈칸) **CREATE** · 5) **char(3)** · (빈칸) **PRIMARY** · 6) **FOREIGN KEY(dept_id) REFERENCES dept(dept_id)**
- 순서를 어기면 — 자식 먼저 CREATE **1824** · 자료형 다름 **3780** · 부모 먼저 DROP **3730** · 없는 학과 입력 **1452**
- DCL = **GRANT**(권한부여 · TO) · **REVOKE**(권한취소 · FROM) — 중간고사엔 안 나옴 · 데이터베이스 사용자 = **DBA(root)** · 응용 프로그래머 · 일반(최종) 사용자

## 6주차 — 무결성 제약조건 · SELECT · UPDATE · DELETE ([6주차 자세히](데이터베이스관리-6주차.html))
> ✍️ **필기** — **오늘 하는 실습이 다 중간고사 시험 예상문제** (실습 6-1 customer SELECT · Quiz 6-1 직원 SELECT · 실습 6-2 주소록 UPDATE/DELETE · 실습 6-03 부서/사원 참조 무결성) · 교재(생능) 1 · 2 · 3장 / 5장 p132~147 · p170~174 · p176 / 6장 p188~199 · p207~210

| 무결성 제약조건 | 내용 | SQL | 범위 |
|---|---|---|---|
| **개체 무결성** (엔티티) | **기본키는 널 값을 가질 수 없다** — ✍️ “객체”라고 쓰면 오답 | PRIMARY KEY | **중간** |
| **참조 무결성** ★ | 참조**하는** 테이블의 **외래키** 값은 참조**되는** 테이블의 **기본키** 값에 반드시 존재 — ✍️ **하는 / 되는 빈칸** | FOREIGN KEY | **중간** |
| 키 제약조건 | 키는 중복된 값을 갖지 않는다 | UNIQUE | 기말 |
| 도메인 제약조건 | 값의 범위 · 기본값 | CHECK · DEFAULT | 기말 |

- ⭐ **강조** — 참조 무결성 검사가 **필요한** 곳 = **부모 UPDATE · DELETE, 자식 INSERT · UPDATE** (부모 입력 · 자식 삭제는 제약 없음) · 1-2 부모 수정 **Error 1451** · 1-6 자식을 없는 값으로 수정 **Error 1452**
- ⭐ **강조** — SELECT 실행 순서 **FROM → WHERE → SELECT** · 관계 연산자 `>` `>=` `=` `<>`/`!=` `<=` `<` · **이하 `<=` 는 그 값도 포함**
- ⭐ **강조** — `UPDATE 테이블 SET 필드=값, 필드=값 WHERE …;` · `DELETE FROM 테이블 WHERE …;` — ✍️ DELETE 는 **레코드 단위**라 필드명 · `*` 안 씀 · (MySQL) `SET SQL_SAFE_UPDATES = 0;`
- ⭐ **강조** — 수강(학번, 과목번호, 성적): 후보키 = 기본키 **(학번, 과목번호)** · 대체키 **없음** · (학번, 과목번호, 성적) 은 **최소성 위배 → 수퍼키**
- ✍️ **필기** — 용어 같은 말: **투레행**(투플 = 레코드 = 행) · **필속열**(필드 = 속성 = 열 = 컬럼) · 테이블 = 릴레이션 · 차수 = 필드 개수 · 카디날리티 = 레코드 개수 · 스키마 = 내포(정적) · 인스턴스 = 외연(동적)

## 5주차 — 키 5종 · 뷰 · 널 값 · INSERT ([5주차 자세히](데이터베이스관리-5주차.html))
| 키 | 성질 ★ |
|---|---|
| 수퍼키 | **유일성** |
| 후보키 | **유일성 + 최소성** |
| 기본키 | **중복불가 · 필수입력** (후보키 중 선택한 하나) |
| 대체키 | 후보키 중 **기본키로 뽑히지 않은** 키 |
| 외래키 | **다른 릴레이션의 기본키를 참조** |

- ⭐ **강조** — 신입생: 후보키 {학번}·{주민등록번호} / 기본키 {학번} / 대체키 {주민등록번호} · `(학번,주민등록번호)`·`(주민등록번호,이름)` 은 **최소성 위배 → 후보키 아님(수퍼키)**
- ⭐ **강조** — **뷰(view) = 가상의 테이블** · 장점 **보안 · 사용의 편의성** · `CREATE VIEW 뷰이름 as SELECT … FROM …;` / `DROP VIEW 뷰이름;`
- ⭐ **강조** — 뷰에 INSERT 하면 **기반 테이블에 저장**되고, 뷰에 없는 열은 NULL·기본값 · 뷰 이름 뒤 괄호로 **뷰의 열 이름 바꾸기** 가능
- ⭐ **강조** — **널 값(NULL)** = 알려지지 않은 값, **0도 공백도 아님** · 따옴표 붙인 `'NULL'` 은 글자
- ⭐ **강조** — INSERT 5가지: 열이름 생략 · NULL · **열 순서 변경** · 열 일부만 · **DEFAULT** (`TIMESTAMP DEFAULT NOW()` = 현재 시각 자동)
- ⭐ **강조** — 릴레이션 특성 4가지: 투플 **유일성 · 무순서성** / 속성 **무순서성 · 원자성**
- ⭐ **강조** — 데이터 모델 3요소 **SOC**(구조 · 연산 · 제약조건) · 스키마 = **구조 + 제약조건** 명세
- ✍️ **필기** — 논리적 독립성(개념↔외부) · 물리적 독립성(내부↔개념·외부) · 파일시스템 단점 **중복성·종속성** ↔ DBMS 장점 **독립성**

### 📏 MySQL 자료형 범위 — 몇부터 몇까지 (MySQL 8.4 에 직접 넣어 확인)
| 정수 자료형 | 크기 | 기본 (SIGNED · 음수 있음) | UNSIGNED (음수 없음) |
|---|---|---|---|
| `TINYINT` | 1byte | **-128 ~ 127** | **0 ~ 255** |
| `SMALLINT` | 2byte | **-32,768 ~ 32,767** | **0 ~ 65,535** |
| `MEDIUMINT` | 3byte | **-8,388,608 ~ 8,388,607** | **0 ~ 16,777,215** |
| **`INT`** | 4byte | **-2,147,483,648 ~ 2,147,483,647** (약 ±21억) | **0 ~ 4,294,967,295** (약 42억) |
| `BIGINT` | 8byte | **-9,223,372,036,854,775,808 ~ 9,223,372,036,854,775,807** | **0 ~ 18,446,744,073,709,551,615** |

| 자료형 | 크기 | 범위 | 예 · 비고 |
|---|---|---|---|
| `FLOAT` | 4byte | **±1.175494351E-38 ~ ±3.402823466E+38** (그리고 0) | 정확한 자리 약 7자리 |
| `DOUBLE` | 8byte | **±2.2250738585072014E-308 ~ ±1.7976931348623157E+308** (그리고 0) | 정확한 자리 약 15자리 |
| `DECIMAL(M, D)` | M 에 따라 | 전체 **M 자리** 중 소수 **D 자리** · M 최대 **65** · D 최대 **30** | `mgpa decimal(3, 1)` → **-99.9 ~ 99.9** |
| `CHAR(n)` | 고정 | n = **0 ~ 255** 글자 | 주민번호 · 남는 칸은 공백으로 채워 저장 |
| `VARCHAR(n)` | 가변 | n = 글자 수 · utf8mb4 에서 최대 **16,383** 글자 | 주소 · `varchar(30)` → 한글도 **30 글자**까지 |
| `DATE` | 3byte | **1000-01-01 ~ 9999-12-31** | `mbirth date` |
| `DATETIME` | 5byte | **1000-01-01 00:00:00 ~ 9999-12-31 23:59:59** | |
| `TIMESTAMP` | 4byte | **1970-01-01 00:00:01 ~ 2038-01-19 03:14:07** (UTC) | 4byte 에 초를 세서 저장 → 2038년까지 · `DEFAULT NOW()` |
| `YEAR` | 1byte | **1901 ~ 2155** | |

- 🧮 정수 범위는 C · 자바와 같은 공식 — TINYINT 8비트 → 2⁸ = 256 가지 → SIGNED -128 ~ 127 / UNSIGNED 0 ~ 255 (`INT UNSIGNED` = 음수 자리를 양수로 돌려서 0 ~ 약 42억)
- ⚠️ **범위 밖 값을 넣으면** — 기본(STRICT) 모드에서 **ERROR 1264 Out of range value** (TINYINT 에 128 · UNSIGNED 에 -1 · INT 에 2147483648 · `decimal(3,1)` 에 100) · 글자가 길면 **ERROR 1406 Data too long** (`varchar(30)` 에 31 글자) · 소수 자리만 넘으면 오류 없이 **반올림** (`decimal(3,1)` 에 12.36 → **12.4**)
- `CHAR(n)` · `VARCHAR(n)` 의 n 은 **바이트가 아니라 글자 수** → 한글 '가' 도 1 글자 · `INT(11)` 의 괄호 숫자는 화면 표시 폭일 뿐 범위와 상관없음

```sql
-- 📏 범위 확인 — 끝값은 들어가고, 1 만 넘어도 오류
CREATE DATABASE rangedb;                          -- 연습용 데이터베이스 만들기
USE rangedb;                                      -- 이제부터 rangedb 사용
CREATE TABLE t (                                  -- 범위 확인용 테이블
    a TINYINT,                                    -- 1byte · SIGNED → -128 ~ 127
    b TINYINT UNSIGNED,                           -- 1byte · 음수 없음 → 0 ~ 255
    c INT,                                        -- 4byte → -2147483648 ~ 2147483647
    d DECIMAL(3, 1)                               -- 전체 3자리 중 소수 1자리 → -99.9 ~ 99.9
);                                                -- 테이블 정의 끝
INSERT INTO t VALUES (127, 255, 2147483647, 99.9);   -- 전부 최댓값 → 들어감
INSERT INTO t VALUES (128, 0, 0, 0);              -- a 에 128 → 127 을 넘음 → ERROR 1264 Out of range value for column 'a'
INSERT INTO t VALUES (0, -1, 0, 0);               -- b 는 UNSIGNED → -1 불가 → ERROR 1264 (column 'b')
INSERT INTO t VALUES (0, 0, 0, 12.36);            -- 소수 2자리 → 1자리로 반올림 → 12.4 로 저장 (오류 아님)
SELECT * FROM t;                                  -- 들어간 2줄만 나옴 → 127 255 2147483647 99.9 / 0 0 0 12.4
```
```output
a   | b   | c          | d
127 | 255 | 2147483647 | 99.9
0   | 0   | 0          | 12.4
```
