## 4주차 — 사용자·그룹 관리 · rpm·dnf ([4주차 자세히](운영체제실습-4주차.html))
### ★ 시험문제 — DNF 작동 흐름도 (그림 4-111)
| 순서 | 하는 일 |
|---|---|
| ① | **dnf install** 입력 |
| ② | `/etc/yum.repos.d/` 디렉터리의 **repo 파일**을 열어서 **URL 주소** 확인 |
| ③ | **전체 패키지 목록 파일** 요청 (내 컴퓨터 → 저장소) |
| ④ | **전체 패키지 목록 파일만** 다운로드 (저장소 → 내 컴퓨터) |
| ⑤ | 설치할 패키지와 **관련된 패키지의 이름**을 화면에 출력 |
| ⑥ | **'y'** 를 입력하면 설치에 필요한 **패키지 파일** 요청 (내 컴퓨터 → 저장소) |
| ⑦ | 설치할 **패키지 파일을 다운로드**해서 **자동 설치** (저장소 → 내 컴퓨터) |

- ⭐ **시험** — 요청(③⑥)은 내 컴퓨터 → 저장소, 다운로드(④⑦)는 저장소 → 내 컴퓨터 · **목록**(③④)을 먼저, **파일**(⑥⑦)은 y 를 누른 뒤
- 저장소 = **baseos · appstream · 기타 패키지 · 패키지 목록** · 교재 예시는 실습 11 의 **mysql8.4-errmsg** · 핵심 repo 파일 **rocky.repo**
- ⑥ 의 끝 단어는 사진에서 가려져 '요청' 으로 추정

### 사용자 만들기 · 수정 · 삭제
| 명령 | 설명 |
|---|---|
| `useradd -d /work_06 use_002` | 홈 디렉터리 **직접 지정** |
| `usermod -u 2001 user_002` | **UID** 변경 |
| `usermod -d 디렉터리 -l 새이름 기존이름` | 홈 · **로그인 이름** 변경 (새 이름이 **앞**) |
| `chage -l` / `-m` / `-M` / `-E` | 기간 보기 / 최소 날 수 / **최대 날 수** / **계정 만료일** |
| `userdel -r user_001` | 홈 디렉터리까지 삭제 |
| `find -user 1001 -exec rm -r {} \;` | 그 UID 소유 파일 찾아 삭제 |

- `chage -M 30 manager` → `암호 만료 : 안함` 이 **마지막 변경일 + 30일** 로 바뀜 · `chage -E 2030/05/05 manager` → 계정 만료일
- 새 계정 UID 는 만든 순서대로 1씩 증가 · useradd 는 **같은 이름의 개인 그룹**도 자동 생성

### 그룹 관리 ★
| 명령 | 설명 |
|---|---|
| `groupadd -g 2018 student` | GID 지정 |
| `groupadd -g 2018 -o db_space` | **이미 쓰는 GID 중복 허용** (`-o`) |
| `gpasswd -a 사용자 그룹` / `-d` | 그룹에 **추가** / **제거** |
| `gpasswd 그룹` / `gpasswd -r 그룹` | 그룹 **암호 설정** / **제거** |

- `/etc/group` = 그룹명 : x : GID : **소속 사용자**(여러 명이면 쉼표) · `/etc/gshadow` = 그룹명 : **암호** : 관리자 : 소속 사용자
- 암호를 지우면 `gp_zone:::` 처럼 **빈칸**

### 전환 · 소유권
- `su - 사용자` 전환(프롬프트 `#` → `$`) · `exit` 돌아가기 · `id` = UID · GID · 소속 그룹 · `newgrp 그룹` = 주 그룹 바꾸기
- `chown rocky 파일` = **소유자만** · `chown rocky:rocky 파일` = 소유자 + **그룹까지**

### 패키지 rpm · dnf ★
| 명령 | 설명 |
|---|---|
| `rpm -Uvh 파일.rpm` | 설치 (U 업그레이드 · v 자세히 · h 진행 막대) |
| `rpm -qi 패키지` | 설치된 패키지 **정보** |
| `rpm -e 패키지` | **삭제** |
| `dnf -y install 패키지` | 저장소에서 **의존성까지 자동** 설치 |

- ⭐ **강조** — `rpm -Uvh mysql8.4-*` 는 **실패한 의존성**으로 설치 안 됨 → `dnf -y install mysql8.4-*` 는 mariadb-connector-c-config · mecab · mysql-selinux · protobuf-lite 를 **알아서 받아** 9개 설치
- DVD 패키지 위치: **BaseOS** · **AppStream** 의 `Packages/첫글자/` · 저장소 설정은 `/etc/yum.repos.d/*.repo`

## 3주차 — 마운트 · 링크 · 권한 · 사용자관리 ([3주차 자세히](운영체제실습-3주차.html))
### 마운트
- ⭐ **강조** — `mount` = 저장장치를 디렉터리 트리에 연결 / 해제는 **`umount /dev/cdrom`**
- DVD 를 넣으면 `/dev/sr0 on /run/media/root/... type iso9660 (ro, ...)` 한 줄 추가 · `ro` = 읽기 전용
- USB 포맷: **FAT O** / **NTFS X**

### inode와 링크 ★
| 구분 | 명령 | inode | 원본 삭제 시 |
|---|---|---|---|
| 하드 링크 | `ln 원본 링크` | 원본과 **같음** | 내용 **유지** |
| 심볼릭 링크 | `ln -s 원본 링크` | **새 번호** | **깨짐** (다시 만들면 복구) |

- ⭐ **강조** — inode = 파일 정보(크기·소유자·권한·데이터 위치) 번호표, 파일 1개당 1개 · **이름이 달라도 inode 가 같으면 같은 파일** · `ls -i` 로 확인

### 접근 권한 chmod ★
- ⭐ **강조** — 기호 모드: 대상 `u` 소유자 · `g` 그룹 · `o` 기타 · `a` 전체 / 연산 `+` `-` `=` / 권한 `r` `w` `x` → `chmod u+x,go+w story.txt`
- ⭐ **강조** — 8진수 모드: r=4 · w=2 · x=1 → `755` = rwxr-xr-x · `644` = rw-r--r-- · `775` = rwxrwxr-x
- `rm -i 파일` = 삭제 전 확인 · 기본 권한 `rw-r--r--`(644) 에서 실습 시작

### 사용자와 그룹 관리 ★
| 명령 | 설명 |
|---|---|
| `useradd user100` | 사용자 생성 |
| `useradd -g YHG user100` | 그룹을 지정해서 생성 |
| `userdel -r user100` | 사용자 삭제(`-r` 홈 디렉터리까지) |
| `groupadd YHG` | 그룹 생성 |
| `passwd user100` | 비밀번호 설정 (8자 미만 경고) |
| `head` / `tail -5` | 파일 앞 · 뒤 확인 |

| 파일 | 필드 구조 |
|---|---|
| `/etc/passwd` | 이름 : x : **UID** : **GID** : 설명 : 홈 : 셸 |
| `/etc/group` | 그룹명 : x : **GID** : 소속 사용자 |
| `/etc/shadow` | 이름 : **암호화 해시** : 최종변경일 : … (`!` `*` 로 시작 = **로그인 불가**) |

- 실습 결과 `user100:x:1001:1001` / `user200:x:1002:1001` → **UID 는 다르고 GID 는 같다** = 같은 그룹

## 2주차 — 리눅스 명령어 실습 ([2주차 자세히](운영체제실습-2주차.html))
