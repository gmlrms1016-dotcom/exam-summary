## 📑 교수님이 찍어 준 PPT — 4장 · 5장 · 7장
> 📌 **Rocky10 강의자료 PPT 3개** (`8주차_중간고사/OS/`) — 4장 필수 개념과 명령어 (72쪽) · 5장 그래픽 환경 사용법 (26쪽) · 7장 셸 스크립트 프로그래밍 (30쪽) · 칸 안의 ✅ = 아래 ①~⑧ 에 이미 자세히 · 나머지는 여기서 처음 정리 · 🖍 = PPT 에 **형광펜**이 칠해진 곳 (2곳)

### 4장 필수 개념과 명령어
| 주제 | 꼭 외울 것 |
|---|---|
| 종료 | `shutdown -P now` · `halt -p` · `init 0` (수업의 `poweroff` 도 종료) |
| 재부팅 | `shutdown -r now` · `reboot` · `init 6` |
| 로그아웃 | `logout` · `exit` · 리눅스 명령은 **대 · 소문자 구분** · 프롬프트 `#` root / `$` 일반 |
| 가상 콘솔 | ‘가상의 모니터’ **6개** · **Ctrl+Alt+F1 ~ F6** (F2 = X 윈도 모드) · 키가 안 되면 `chvt 번호` |
| 경로 | `/` = **루트 디렉터리**(최상위) · 윈도우는 백슬래시 `\` (`C:\Windows\Boot`) · 숨김 파일 = 이름 맨 앞이 **`.`** |
| 기본 명령 | `touch` 크기 **0** 인 새 파일 (있으면 수정 시간만 바뀜) · `cp` 복사 · `mv` 이름 바꾸기 · 이동 · `cat` 내용 · `head` / `tail` **앞 / 끝 10행** · `more` / `less` 페이지 단위 · `file` 파일 종류 · `clear` 화면 지우기 · `top` 실시간 CPU · 메모리 |
| 런레벨 | ✅ 🔥 2번 · `init` 뒤의 숫자 · 확인 **`/lib/systemd/system/`** 의 `runlevel?.target` |
| 자동 완성 | **Tab** (`cd /et[Tab]cry[Tab]st[Tab]`) · 히스토리 = **↑ ↓** 또는 `history` (도스 키) |
| vi | 명령 모드 ↔ 입력 모드 · 바꾸기 **`:%s/기존/새`** · 행 번호 **`:set number`** |
| 도움말 | **`man 명령어`** · man 페이지는 섹션 **1 ~ 9** |
| 사용자 | ✅ ④ · `/etc/passwd` = 이름 : 암호 : UID : GID : 전체 이름 : 홈 : 셸 · 만들 때 **-u** ID · **-g** 그룹 · **-d** 홈 · **-s** 셸 · `chage -m 2` · `groups` · `groupmod -n 새 기존` |
| 소유권 | ✅ ③ · `chown rocky:rocky 파일` = `chown rocky 파일` + `chgrp rocky 파일` |
| 링크 | ✅ 🔥 3번 · 하드 = **같은 inode1** · 심볼릭 = **새 inode2** = 윈도우 **바로 가기** |
| RPM 이름 | `gzip-1.13-3.el10.x86_64.rpm` = **패키지이름 - 버전 - 릴리즈번호 . Rocky 버전 . 아키텍처** · `x86_64` 64비트 (Intel · AMD) · `aarch64` ARM64 (맥 M1) · `noarch` 모든 CPU · `src` 소스 |
| RPM 옵션 | ✅ ⑤ · `-Uvh` 설치 · `-e` 삭제 · `-qa 이름` 설치됐나 · **`-qf 절대경로`** 어느 패키지 · `-qlp 파일.rpm` 든 파일 · `-qip 파일.rpm` 상세 · 단점 = **의존성** → DNF 등장 |
| DNF | ✅ 🔥 9번 · RHEL 7 = YUM → 8 부터 **DNF** · `-y` 모두 yes · `check-update` 업데이트 목록 · `update` · `remove` · `info` · `groupinstall "그룹"` · `list` · `provides 파일` · `--nogpgcheck` · `clean all` 저장소 목록 지우기 · 설정 `/etc/yum.conf` · 저장소 **`/etc/yum.repos.d/*.repo`** |
| 🖍 퀴즈 4-1 | **형광펜** — Server(B) 메모리 2GB 이상 → **`dnf -x rpm -y groupinstall Workstation`** (`-x rpm` = 충돌하는 rpm 패키지 제외) → 재부팅 → **`systemctl enable --now gdm`** = 그래픽 모드 켜기 |
| 압축 | `xz 파일` · `bzip2 파일` · `gzip 파일` → 압축 / **`-d`** 풀기 (`bunzip2` · `gunzip` 도 풀기) · 압축률 **xz · bz2** 가 더 좋음 · 윈도우와 호환은 `zip` / `unzip` |
| tar | 동작 **c 묶기 · x 풀기 · t 확인** / 옵션 **f 파일 · v 과정 · J xz · z gzip · j bzip2** → `tar cvfJ my.tar.xz /etc/sysconfig/` 묶기 + xz · `tar xvfJ my.tar.xz` 풀기 (⑥ 백업 `tar cfJ`) |
| find | `find 경로 옵션 조건 action` · `-name` · `-user` · `-newer` · `-perm` · `-size` · `-exec 명령 {} \;` → `find /etc -name "*.conf"` · `find /usr/bin -size +10k -size -100k` |
| 찾기 3종 | `which` = **PATH** 안만 · `whereis` = 실행 파일 + **소스 · man** · `locate` = 파일 목록 **DB** 에서 |
| 시스템 설정 | 네트워크 `nmtui` · 방화벽 `firewall-config` · 서비스 `ntsysv` · 시간대 = 설정 → 날짜 및 시각 |
| cron · at | ✅ 🔥 1번 · ⑥ · 서비스 `crond` · `01 * * * *` = **매시 1분** · `at 3:00am tomorrow` · `at now + 1 hours` · 끝내기 **Ctrl+D** · 확인 `at -l` · 취소 `atrm 번호` |
| 네트워크 | IP = **4바이트** (자리마다 0 ~ 255) · 네트워크 주소 `192.168.111.0` · 브로드캐스트 = 끝자리 **255** · 게이트웨이 = 라우터 (VMware `192.168.111.2`) · 넷마스크 `255.255.255.0` = **C 클래스** · DNS = URL → IP · 랜카드 이름 **ens160** |
| IP 설정 | `nmtui` → 적용 `systemctl restart NetworkManager` · `ifup` / `ifdown 장치` 켜기 / 끄기 · `ifconfig 장치` 정보 · `nslookup` DNS 테스트 · `ping` 응답 확인 |
| 설정 파일 | **`/etc/resolv.conf`** = DNS 서버 · `/etc/hosts` = 호스트 이름 · FQDN · 장치(ens160) 설정 = `/etc/NetworkManager/` 의 `장치이름.nmconnection` |
| SELinux | 확인 `sestatus` · `getenforce` · **강제(Enforcing)** = 아예 막음 · **허용(Permissive)** = 허용 + 로그 · **비활성화(Disabled)** |
| 파이프 | ✅ ⑦ · `\|` 두 프로그램 연결 (`ls -l /etc \| more`) · **필터** = grep · tail · wc · sort · awk · sed (`ps -ef \| grep bash`) · **리디렉션** `ls -l > list.txt` · `sort < list.txt > out.txt` |
| 프로세스 | ✅ 🔥 8번 · ⑦ · 포그라운드 = 화면에서 상호작용 · 백그라운드 = 화면에 안 보임 (백신 · 서버 데몬) · 부모를 kill → **자식도 kill** · 트리 **`pstree`** |
| 서비스 | ✅ ⑦ · **항상 가동** (httpd · mysqld · vsftpd) · `systemctl start/stop/restart 이름` · 파일 `/usr/lib/systemd/system/이름.service` (cron = **crond.service**) |
| 소켓 | **요청할 때만** systemd 가 구동 · 끝나면 종료 → 처음 연결이 조금 느림 · 예 **텔넷** · `이름.socket` |
| GRUB | 응급 복구(root 비밀번호 분실) = 부팅 때 GRUB 편집 · **`/boot/grub2/grub.cfg` 직접 수정 X** → `/etc/default/grub` · `/etc/grub.d/` 고치고 **`grub2-mkconfig`** · GRUB2 = 셸 스크립트 · 동적 모듈 · 그래픽 메뉴 · ISO 부팅 |
| 모듈 | 필요할 때마다 호출되는 코드 · 커널 컴파일 → 최신 커널로 업그레이드 (비타민 퀴즈 4-3 = `make menuconfig`) |

### 🔗 하드 링크 vs 심볼릭 링크 — 차이 한눈에 (🔥 3번)
> 🪟 **GUI 세대용** — 터미널은 마우스 대신 **글자로 탐색기를 조작하는 창**이에요. 아래 표 오른쪽 칸에 윈도우로 치면 무엇인지 같이 적었고, 🖥️ 터미널에서 명령을 누르면 출력 아래에 💡 설명과 🪟 윈도우 예시가 나와요.

| 구분 | 하드 링크 | 심볼릭 링크 (소프트 링크) |
|---|---|---|
| 명령 | `ln 원본 링크` | `ln -s 원본 링크` |
| 정체 | 같은 파일(같은 데이터)에 **이름을 하나 더** 붙인 것 | 원본의 **경로(이름)만 적어 둔 작은 파일** |
| inode | `ls -i` → 원본과 **같음** (1106188 = 1106188) | **새 번호** (1106189) |
| 종류 표시 | `ls -l` 맨 앞 `-` — 일반 파일과 똑같이 보임 | 맨 앞 `l` (`lrwxrwxrwx`) |
| 이름 옆 | 표시 없음 | `softlink -> basefile` (가리키는 원본) |
| 링크 수 | `ls -l` 둘째 칸 — 원본 · 링크 **둘 다 2** (1 → 2) | **1** · 원본의 링크 수도 그대로 |
| 크기 | 원본과 같음 — **61바이트** (같은 데이터) | **8바이트** = 경로 `basefile` 의 글자 수 |
| 원본 수정 | 링크에도 바로 보임 (같은 파일) | 링크로 열어도 고친 내용 (원본을 따라감) |
| 원본 삭제 | 원본을 지우거나 옮겨도 **내용 그대로** 읽힘 | **깨짐** → `그런 파일이나 디렉터리가 없습니다` |
| 원본 복귀 | — | 제자리에 되돌리면 다시 **복구** |
| 링크 삭제 | 원본은 그대로 (링크 수만 2 → 1) | 원본은 그대로 (강의자료) |
| 디렉터리 | 거의 안 됨 (`-d` 옵션도 root 라도 실패 가능성 높음 — 강의자료) | 됨 |
| 다른 디스크 | 🤖 안 됨 (파티션 · USB 처럼 다른 파일 시스템 — inode 번호는 그 안에서만 통함) | 됨 |

| 리눅스에서 | 🪟 윈도우로 치면 |
|---|---|
| 터미널 | 마우스 대신 **글자로 탐색기를 조작하는 창** · 명령 한 줄 = 탐색기에서 한 번 클릭 · 메뉴 선택 |
| `. .. ~` | 지금 폴더 · 위 폴더 · 내 폴더 (디렉터리 = 폴더 · root 의 `/root` ↔ 윈도우 `C:\Users\이름`) |
| `cat` | 메모장으로 열어 내용 보기 |
| `ls -l` | 탐색기 **‘자세히’ 보기** (이름 · 크기 · 수정한 날짜) · `-i` 를 붙이면 inode 번호까지 — inode · 링크 수 칸은 탐색기에 없음 |
| `mv` | **잘라내기**(Ctrl+X) → 다른 폴더에 **붙여넣기**(Ctrl+V) |
| `ln -s` | 심볼릭 링크 = 오른쪽 클릭 → **바로 가기 만들기** · 아이콘에 작은 화살표 · [속성] 의 **대상** 칸 = `-> basefile` |
| 깨진 링크 | 원본을 옮긴 뒤 바로 가기를 더블클릭 → **‘바로 가기 문제’** 창 |
| `ln` | 하드 링크 — 탐색기 메뉴엔 없음 (명령 프롬프트 `mklink /H 링크 원본`) · 같은 파일이 두 이름으로 보이고 **한쪽을 고치면 다른 쪽도** 바뀜 · 복사(Ctrl+C → Ctrl+V)는 따로 노는 두 파일이라 다름 |
| ⚠️ 순서 | 리눅스 `ln 원본 링크` (**원본이 앞**) ↔ 윈도우 `mklink 링크 원본` (**링크가 앞** · 심볼릭은 관리자 권한) |

> ⚠️ **강의자료 헷갈림 주의** — 강의자료 ‘링크 파일’ 쪽의 “하드 링크 = 원본 파일을 **복사**하여 … 다른 **사본** 파일” → 🤖 실제로는 **복사가 아니에요**: 같은 I-node(같은 데이터)에 이름만 하나 더 붙는 것이라 크기가 같고, 원본을 고치면 링크도 자동으로 바뀌어요 (같은 쪽의 “원본 파일의 내용이 변경되면 링크 파일은 자동으로 변경됨” 이 이 뜻) · `cp` 로 만든 사본은 고쳐도 따로 놀아요.

> ⚠️ **정정** — 강의자료 예제 3-54 ‘여기서 잠깐’ 의 “같은 **I-node 번호 2**를 부여받은 것” → `ls -l` 둘째 칸 **2 는 링크 수**(같은 파일에 붙은 이름 개수)예요. I-node 번호는 `ls -i` 로 보는 **52075475** (예제 3-55).

### 그 밖의 3주차

- **inode** = 파일 정보(크기 · 소유자 · 권한 · 데이터 위치)의 번호표 · 파일 1개당 1개 → **이름이 달라도 inode 가 같으면 같은 파일** (`ls -i` 로 확인)
- **마운트** `mount` = 저장장치를 디렉터리 트리에 연결 · 해제 **`umount /dev/cdrom`** · DVD 를 넣으면 `/dev/sr0 … type iso9660 (ro, …)` → `ro` = 읽기 전용 · USB 포맷 **FAT O / NTFS X**

## ③ 접근 권한 chmod (3주차)
> 📌 **시험 포인트** — r = 4 · w = 2 · x = 1 · 한 자리 = 3비트 · 기호 모드 u g o a

| 8진수 | 비트로 펼치기 | 권한 |
|---|---|---|
| `755` | 7 = 111 = 1+2+4 · 5 = 101 = 1+4 | `rwxr-xr-x` |
| `644` | 6 = 110 = 2+4 · 4 = 100 | `rw-r--r--` (기본 권한) |
| `775` | 7 · 7 · 5 | `rwxrwxr-x` |
| `744` | 7 · 4 · 4 | `rwxr--r--` (실행은 소유자만) |

- **기호 모드** — 대상 `u` 소유자 · `g` 그룹 · `o` 기타 · `a` 전체 / 연산 `+` `-` `=` / 권한 `r` `w` `x` → `chmod u+x,go+w story.txt` (쉼표 뒤 띄어쓰기 X)
- 권한은 **chmod** · 소유자는 **chown** → `chown rocky 파일` = 소유자만 · `chown rocky:rocky 파일` = 소유자 + **그룹까지**

## ④ 사용자 · 그룹 관리 (3 · 4주차)
> 📌 **시험 포인트** — 관리 파일 3종의 칸 · `usermod -l 새이름 기존이름` (새 이름이 **앞**) · 마스터 유저 디렉터리 (🔥 7번)

| 명령 | 뜻 |
|---|---|
| `useradd user100` · `useradd -g YHG user100` | 만들기 · **그룹을 지정**해서 만들기 (같은 이름의 개인 그룹도 자동 생성) |
| `useradd -d /work_06 master` | 홈 디렉터리를 **직접 지정**해서 만들기 (🔥 도전 6-1) |
| `usermod -u 2003 master` · `usermod -d /home/workspace_06 master` | **UID** 바꾸기 · **홈** 바꾸기 (🔥 도전 6-2) |
| `usermod -l manager master` | **로그인 이름** 바꾸기 → master 가 manager 로 (새 이름이 앞) |
| `passwd master` | 암호 설정 (8자 미만이면 경고) |
| `userdel -r user100` | 삭제 + **홈 디렉터리까지** |
| `chage -l` · `-M 30` · `-E 2030/05/05` | 암호 정보 보기 · 암호 **최대 사용 날 수** · **계정 만료일** |
| `groupadd -g 2018 student` · `-o` | GID 지정 · **이미 쓰는 GID 중복 허용** |
| `gpasswd -a 사용자 그룹` · `-d` · `gpasswd 그룹` · `-r` | 그룹에 추가 · 제거 · 그룹 **암호 설정** · 암호 제거 |
| `su - 사용자` · `exit` · `id` · `newgrp 그룹` | 전환(`#` → `$`) · 돌아가기 · UID · GID · 소속 그룹 · **주 그룹** 바꾸기 |
| `find -user 1001 -exec rm -r {} \;` | 그 UID 소유 파일을 찾아 삭제 |

| 파일 | 칸 (`:` 로 나눔) |
|---|---|
| `/etc/passwd` | 이름 : x : **UID** : **GID** : 설명 : **홈** : 셸 |
| `/etc/shadow` | 이름 : **암호 해시** : 최종 변경일 : … → `!` · `*` 로 시작하면 **로그인 불가** |
| `/etc/group` | 그룹명 : x : **GID** : **소속 사용자**(쉼표) |
| `/etc/gshadow` | 그룹명 : **암호** : 관리자 : 소속 사용자 → 암호를 지우면 `gp_zone:::` 처럼 빈칸 |

- `user100:x:1001:1001` / `user200:x:1002:1001` → **UID 는 다르고 GID 는 같다** = 같은 그룹 · 새 계정 UID 는 만든 순서대로 1씩 증가
- `chage -M 30 manager` → `암호 만료 : 안함` 이 **마지막 변경일 + 30일** 로 바뀜

> 📌 **시험 포인트** — DNF 흐름도 ①~⑦ 순서 (🔥 9번) · rpm 은 의존성 X / dnf 는 의존성 자동

| 순서 | DNF 작동 흐름도 (그림 4-111) | 방향 |

## ⑥ 작업 예약 cron · at · 백업 (5주차)
> 📌 **시험 포인트** — crontab 칸 순서 (🔥 1번) · cron = **반복** / at = **한 번만**

| 칸 | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
|---|---|---|---|---|---|---|---|
| 뜻 | **분** | **시** | **일** | **월** | **요일** | 사용자 | 명령 |
| 예 | 01 | 3 | 15 | * | * | root | run-parts /etc/cron.monthly |

- `01 3 15 * *` = **매월 15일 03:01** (순서를 바꿔 `01 15 3` 이면 매월 3일 15:01) · `run-parts 폴더` = 그 폴더의 **실행 권한 있는** 파일을 모두 실행 → 스크립트에 `chmod 755`
- `systemctl restart crond` 는 서비스 재시작일 뿐 → 백업은 **정해진 시각**에 실행 (시계를 03:00 으로 맞추면 1분 뒤 03:01 에 실행)

| 백업 스크립트 줄 | 뜻 |
|---|---|
| `set $(date)` | date 결과를 띄어쓰기로 나눠 $1 $2 $3 … 에 |
| `fname="backup-$2$3tar.xz"` | $2 · $3 = 월 · 일 → 한국어 화면 `backup-01.15.tar.xz` · 영어 화면 `backup-Jan15tar.xz` |
| `tar cfJ /backup/$fname /home` | c 묶기 · f 파일 이름 · **J = xz 압축** → /home 을 /backup 에 (폴더가 없으면 `mkdir /backup`) |

| 시계 · at | 뜻 |
|---|---|
| `date 011503002035` | **MMDDhhmmYYYY** 12자리 → 2035년 1월 15일 03:00 (11자리면 `부적절한 날짜`) |
| `rdate -s time.bora.net` | 시간 서버의 시각으로 맞추기 |
| `at 4:00 am tomorrow` → `at>` 명령 → Ctrl+D | **한 번만** 예약 |
| `at -l` (`atq`) · `atrm 1` | 예약 목록 · 1번 예약 취소 |

## ⑦ 프로세스 · 서비스 · 작업 제어 (6 · 7주차)
> 📌 **시험 포인트** — 프로세스 정의 (🔥 8번) · Ctrl+Z → bg (🔥 4번) · 프로세스 상태 5개 · 서비스 = 데몬

- **프로세스** = 하드디스크에 저장된 실행코드가 메모리에 로딩되어 활성화된 것 · 상태 = **생성 → 실행 → 준비 → 대기 → 종료**
- **서비스(service)** = 서버 프로세스 = **데몬** (거의 백그라운드) · `systemctl start · stop · restart · enable`(부팅 때 자동 시작)

| 명령 · 키 | 뜻 |
|---|---|
| `ps -ef` · `ps -ef \| grep yes` | 모든(-e) 프로세스를 자세히(-f) · yes 줄의 두 번째 칸 = **PID** |
| `kill -9 PID` | **강제 종료** → 터미널에 `죽었음` |
| `명령 &` | 처음부터 **백그라운드**로 실행 |
| **Ctrl+Z** → `bg` | 포그라운드 작업을 **멈춤** → **백그라운드에서 계속** |
| `jobs` · `fg 1` · **Ctrl+C** | 작업 목록(`[1]` = **작업 번호**) · 1번을 **앞으로** · 포그라운드 작업 **종료** |
| `ls -l > list.txt` · `ls -l /etc \| more` | 출력을 파일로 (**리디렉션**) · 한 화면씩 (**파이프**) |
| `yes > /dev/null` | y 를 끝없이 출력 (실습용 · 화면엔 안 보임) |

- **PID**(프로세스 번호 · `kill` 에 씀) ≠ **작업 번호**(한 터미널 안 · `jobs` · `fg 1` 에 씀)
- GNOME 프로그램 이름 — **노틸러스** = 파일탐색기 · **에볼루션** = 메일

## ⑧ 셸 스크립트 (6주차 · 7장)
> 📌 **시험 포인트** — 비중은 낮지만 **sh 문제** (출력결과 · 파일 존재 · 사이즈 체크 if문 · 🔥 6번) · 코드를 읽고 출력결과를 알면 됨

| 문법 | 뜻 · 예 |
|---|---|
| `sh 파일` / `chmod +x 파일` → `./파일` | 실행 (sh 로 실행하면 실행 권한 없어도 됨) |
| `변수=값` · `$변수` | `=` 좌우 띄어쓰기 X · 모든 변수는 **문자열** |
| `"$v"` / `'$v'` · `\$v` | 큰따옴표 = **값** / 작은따옴표 · `\` = 글자 그대로 `$v` |
| `num2=$num1+200` | 계산 안 함 → **`100+200`** (글자) |
| `` `expr $num1 + 200` `` | **300** · 띄어쓰기 필수 · `\(` `\)` `\*` → `expr \( 100 + 200 \) / 10 \* 2` = **60** |
| 📏 숫자 | 자료형이 없음 · `expr` 는 **정수만** → `expr 10 / 3` = **3** |
| `$0` · `$1` · `$*` | 파일 이름 · 첫 번째 값 · 전체 |
| `if [ 조건 ]` → `then` → `elif` → `else` → `fi` | `[` 뒤 · `]` 앞 **띄어쓰기** 필수 |
| `=` `!=` / `-eq` `-ne` `-gt` `-ge` `-lt` `-le` | **문자열** 비교 / **숫자** 비교 |
| `-e` · `-f` · `-d` · `-s` · `-r` | **있으면** · 일반 파일 · 디렉터리 · **크기 > 0** · 읽기 가능 |
| `&&` (`-a`) · `\|\|` (`-o`) | AND (둘 다) · OR (하나라도) |
| `case 값 in` `패턴)` … `;;` `*)` `esac` | `yes \| y)` = 또는 · `[nN]*` = n · N 으로 시작 · `*)` = 나머지 |
| `for i in 1 2 3` · `while [ ]` · `until [ ]` → `do` `done` | until = 조건이 **참이 될 때까지** |
| `break` · `continue` · `exit 1` | 반복 빠져나감 · 다음 반복으로 · 프로그램 끝 |
| `함수 () { … }` → `함수 10 20` | 함수 안의 `$1 $2` = 넘긴 값 |
| `eval` · `export` · `set $(date)` · `shift` | 문자열을 명령으로 · 외부 변수 · $1… 에 나눠 넣기 · 한 칸씩 당김 |

- **andor.sh** (파일 존재 + 사이즈) — `if [ -f $fname ] && [ -s $fname ]` → 일반 파일이고 **크기가 0 이 아니면** `head -5` · 아니면 `파일이 없거나, 크기가 0입니다.` → **빈 파일**은 -s 가 거짓이라 else
- **if4.sh** — 원본 `cron.service` 는 Rocky 에서 **crond.service** 라 else · 수업에서 **sshd.service** 로 바꿔 앞 5줄 출력

| 7 | `cp` | 2. 파일을 **복사**한다 | 3주차 |
| 8 | `mkdir` | 2. 새로운 **디렉터리**를 만든다 | 2주차 |
| 9 | `rm` | 2. 파일을 **삭제**한다 | 2주차 |
| 10 | `mv` | 3. 파일의 **이름을 변경하거나 이동**한다 | 수업에 안 나옴 |
| 11 | `cat` | 2. 파일 **내용을 출력**한다 | 6주차 |
| 12 | `top` | 2. 시스템의 현재 **CPU 사용률**을 보여준다 | 수업에 안 나옴 |
| 13 | `df` | 2. 파일 시스템의 사용 가능한 **디스크 공간** | 수업에 안 나옴 |
| 14 | `man` | 1. **매뉴얼 페이지**를 보여준다 | 수업에 안 나옴 |
| 15 | `echo` | 2. **텍스트**를 출력한다 | 6주차 (셸 스크립트) |
| 16 | `find` | 2. 파일을 **검색**한다 | 4주차 |

- 헷갈리는 짝 — `cp` 복사 ↔ `mv` 이동 · 이름 변경 / `cat` 파일 내용 ↔ `echo` 내가 쓴 글자 / `ps` 목록 ↔ `kill` 종료 ↔ `top` 실시간 / `find` **파일** ↔ `grep` 파일 **안의 글자**
- 2번 오답 보기 “파일의 소유자를 변경” = `chown` (4주차) → 권한은 chmod, 소유자는 chown
- 1~7주차 수업에 **안 나온 명령**: `top` · `df` · `mv` · `man` — 시험 범위는 교수님 진도 기준
