## 2. 생성자 호출 순서 — 슈퍼 생성자가 먼저 실행 (ConstructorEx2 · 3 · 4 · 5장 13 ~ 20쪽)
| 질문 (13쪽) | 답 |
|---|---|
| 서브 클래스 객체를 만들면 서브 · 슈퍼 생성자 중 누가 실행? | **둘 다** 실행 — 객체 안에 서브 · 슈퍼 멤버가 다 들어 있어서 각자 초기화 |
| 누가 먼저? | **호출**: 서브 생성자가 먼저 호출 → 서브 생성자는 실행 **전에** 슈퍼 생성자를 호출 / **실행**: **슈퍼 생성자가 먼저** 실행된 뒤 서브 생성자 |

### ① 서브 생성자가 슈퍼 생성자를 고르지 않으면 → 기본 생성자 자동 (ConstructorEx2 · 16쪽)
```java
// ConstructorEx2.java — 서브 생성자가 슈퍼 생성자를 고르지 않으면 → 슈퍼의 기본 생성자가 자동 (5장 16쪽)
public class 연습 {                              // 원래 이름 ConstructorEx2
    public static void main(String[] args) {    // 프로그램 시작
        BB BB;                                  // 수업 파일 그대로 — 변수 이름도 BB (문법은 되지만 헷갈려서 보통 BB b;)
        BB = new BB();                          // BB() 호출 → 실행 전에 첫 줄 super() → AA() 가 먼저 실행
    }                                           // main 끝
}                                               // 연습 끝
class AA {                                      // 슈퍼 클래스
    public AA() {                               // 기본 생성자 ← 자동 super() 가 고르는 생성자
        System.out.println("생성자A");           // ① 먼저 출력
    }                                           // AA() 끝
    public AA(int x) {                          // 매개변수 생성자 — 비어 있고 오늘은 불리지 않음
    }                                           // AA(int) 끝
}                                               // AA 끝
class BB extends AA {                           // 서브 클래스 — AA 를 상속
    public BB() {                               // super(…) 를 안 씀 → 컴파일러가 첫 줄에 super(); 를 넣음 → AA()
        System.out.println("생성자B");           // ② AA() 가 끝난 뒤 출력
    }                                           // BB() 끝
}                                               // BB 끝
```
```output
생성자A
생성자B
```
### ② 서브가 매개변수 생성자여도 super 가 없으면 → 슈퍼는 기본 생성자 (ConstructorEx3 · 18쪽)
```java
// ConstructorEx3.java — 서브가 매개변수 생성자여도 super 를 안 쓰면 → 슈퍼는 기본 생성자 (5장 18쪽)
public class 연습 {                              // 원래 이름 ConstructorEx3
    public static void main(String[] args) {    // 프로그램 시작
        BBB b;                                  // 레퍼런스 변수만 선언
        b = new BBB(5);                         // BBB(int x) 호출 (x = 5) → 첫 줄 자동 super() → AAA() 먼저
    }                                           // main 끝
}                                               // 연습 끝
class AAA {                                     // 슈퍼 클래스
    public AAA() {                              // 기본 생성자 ← 자동 super() 는 매개변수 없는 이것을 고름
        System.out.println("생성자A");           // ① 출력
    }                                           // AAA() 끝
    public AAA(int x) {                         // 매개변수 생성자 — 5 를 받았어도 자동으로는 안 불림
        System.out.println("매개변수생성자A");    // (출력 안 됨)
    }                                           // AAA(int) 끝
}                                               // AAA 끝
class BBB extends AAA {                         // 서브 클래스
    public BBB() {                              // 기본 생성자 — 오늘은 안 불림
        System.out.println("생성자B");           // (출력 안 됨)
    }                                           // BBB() 끝
    public BBB(int x) {                         // x = 5 · super(…) 를 안 씀 → 컴파일러가 super(); (매개변수 없음) 를 넣음
        System.out.println("매개변수생성자B");    // ② AAA() 다음에 출력
    }                                           // BBB(int) 끝
}                                               // BBB 끝
```
```output
생성자A
매개변수생성자B
```
> `new BBB(5)` 로 5 를 넘겨도 슈퍼 쪽은 `AAA(int x)` 가 아니라 **AAA()** 가 불려요 — 컴파일러가 넣는 건 매개변수 없는 `super();` 뿐이에요.

### ③ super(x) 로 슈퍼 생성자를 직접 고르기 (ConstructorEx4 · 19 · 20쪽)
```java
// ConstructorEx4.java — super(x) 로 슈퍼의 매개변수 생성자를 직접 고름 (5장 19 · 20쪽)
public class 연습 {                              // 원래 이름 ConstructorEx4
    public static void main(String[] args) {    // 프로그램 시작
        BBBB b;                                 // 레퍼런스 변수만 선언
        b = new BBBB(5);                        // BBBB(int x) 호출 (x = 5) → 첫 줄 super(x) → AAAA(5) 먼저
    }                                           // main 끝
}                                               // 연습 끝
class AAAA {                                    // 슈퍼 클래스
    public AAAA() {                             // 기본 생성자 — 오늘은 안 불림 (super(x) 로 다른 걸 골랐으니까)
        System.out.println("생성자A");           // (출력 안 됨)
    }                                           // AAAA() 끝
    public AAAA(int x) {                        // super(x) 가 고른 생성자 → x = 5
        System.out.println("매개변수생성자A" + x);   // 문자열 + 5 → ① 매개변수생성자A5
    }                                           // AAAA(int) 끝
}                                               // AAAA 끝
class BBBB extends AAAA {                       // 서브 클래스
    public BBBB() {                             // 기본 생성자 — 오늘은 안 불림
        System.out.println("생성자B");           // (출력 안 됨)
    }                                           // BBBB() 끝
    public BBBB(int x) {                        // x = 5
        super(x);                               // 반드시 첫 줄 — 5 를 넘겨 AAAA(int x) 를 고름
        System.out.println("매개변수생성자B" + x);   // ② AAAA(5) 가 끝난 뒤 → 매개변수생성자B5
    }                                           // BBBB(int) 끝
}                                               // BBBB 끝
```
```output
매개변수생성자A5
매개변수생성자B5
```
| 경우 (쪽) | 서브 생성자 첫 줄 | 불리는 슈퍼 생성자 | 출력 |
|---|---|---|---|
| ① ConstructorEx2 (16쪽) | `super` 없음 → 컴파일러가 `super();` | **AA()** (기본 생성자) | 생성자A / 생성자B |
| ② ConstructorEx3 (18쪽) | `super` 없음 → `super();` | **AAA()** — 매개변수 생성자 BBB(int) 여도 | 생성자A / 매개변수생성자B |
| ③ ConstructorEx4 (20쪽) | **`super(x);`** | **AAAA(int x)** — x = 5 전달 | 매개변수생성자A5 / 매개변수생성자B5 |
| ④ 17쪽 — 오류 | `super` 없음 → `super();` | 슈퍼에 **기본 생성자가 없음** | 컴파일 오류 |

### ④ 슈퍼에 기본 생성자가 없으면 — 컴파일 오류 (17쪽)
```java
// 17쪽 — 슈퍼 클래스에 기본 생성자가 없어서 오류 (일부러 틀린 코드)
public class 연습 {                              // 원래 이름 ConstructorEx2
    public static void main(String[] args) {    // 프로그램 시작
        B b;                                    // 레퍼런스 변수
        b = new B();                            // B() 호출 → 첫 줄 자동 super() → A() 를 찾음
    }                                           // main 끝
}                                               // 연습 끝
class A {                                       // 슈퍼 클래스 — 매개변수 생성자만 있음
    public A(int x) {                           // 생성자를 하나라도 쓰면 기본 생성자 A() 는 자동으로 안 생김
        System.out.println("생성자A");           // (실행 안 됨)
    }                                           // A(int) 끝
}                                               // A 끝
class B extends A {                             // 서브 클래스
    public B() {                                // ❌ super(…) 가 없어서 컴파일러가 super(); → A() 가 없음 → 오류
        System.out.println("생성자B");           // (실행 안 됨)
    }                                           // B() 끝
}                                               // B 끝
```
```output
연습.java:14: error: constructor A in class A cannot be applied to given types;
    public B() {                                // ❌ super(…) 가 없어서 컴파일러가 super(); → A() 가 없음 → 오류
               ^
  required: int
  found: no arguments
  reason: actual and formal argument lists differ in length
1 error
```
> 강의자료(17쪽)는 이클립스 메시지 “**Implicit super constructor A() is undefined. Must explicitly invoke another constructor**” · 위는 javac(JDK 8) 메시지예요 — 뜻은 같아요: **A() 가 없으니 super(정수) 로 다른 생성자를 직접 고르라**는 것 (예: B() 첫 줄에 `super(0);` → `생성자A` / `생성자B` — 실행해서 확인).

### ⑤ super(…) 는 반드시 첫 줄 (19쪽)
```java
// super(x) 가 첫 줄이 아니면 오류 (일부러 틀린 코드 · ConstructorEx4 를 바꿈)
public class 연습 {                              // 원래 이름 ConstructorEx4
    public static void main(String[] args) {    // 프로그램 시작
        BBBB b;                                 // 레퍼런스 변수
        b = new BBBB(5);                        // BBBB(int x) 호출
    }                                           // main 끝
}                                               // 연습 끝
class AAAA {                                    // 슈퍼 클래스
    public AAAA() {                             // 기본 생성자
        System.out.println("생성자A");           // (실행 안 됨 — 컴파일부터 실패)
    }                                           // AAAA() 끝
    public AAAA(int x) {                        // 매개변수 생성자
        System.out.println("매개변수생성자A" + x);   // (실행 안 됨)
    }                                           // AAAA(int) 끝
}                                               // AAAA 끝
class BBBB extends AAAA {                       // 서브 클래스
    public BBBB(int x) {                        // x = 5
        System.out.println("매개변수생성자B" + x);   // 첫 줄이 super 가 아님
        super(x);                               // ❌ 둘째 줄 → 오류
    }                                           // BBBB(int) 끝
}                                               // BBBB 끝
```
```output
연습.java:19: error: call to super must be first statement in constructor
        super(x);                               // ❌ 둘째 줄 → 오류
             ^
1 error
```
> 🤖 `this(…)` 도 첫 줄이어야 해서 한 생성자에 `this(…)` 와 `super(…)` 를 **같이 쓸 수 없어요** (javac 같은 오류로 확인 · [9주차 this()](자바프로그래밍-9주차.html)) · 🤖 **Java 25** 부터는 super(…) 앞에 `this` 를 쓰지 않는 문장(인자 검사 등)을 둘 수 있게 바뀌었어요 (JEP 513 Flexible Constructor Bodies · 이 맥 JDK 8 에서는 위처럼 오류) → 수업 · 시험은 강의자료대로 **“제일 첫 라인”** 으로 답해요.

## 3. Point · ColorPoint — super(x, y) (Point.java · ColorPointEx.java · 예제 5-1 → 5-3)
```java
// Point.java + ColorPointEx.java 를 한 파일로 — extends · super(x, y) (5장 예제 5-1 → 5-3)
class Point {                                   // 슈퍼 클래스(부모) — 한 점 (x, y)
    private int x, y;                           // private → Point 안에서만 씀 (자식 ColorPoint 도 x · y 를 직접 못 씀)
    public Point() {                            // 기본 생성자 — 매개변수 0개
        this.x = this.y = 0;                    // 오른쪽부터: this.y = 0 → 그 값 0 을 this.x 에 → 둘 다 0
    }                                           // Point() 끝
    public Point(int x, int y) {                // 매개변수 2개 생성자
        this.x = x;                             // 필드 x ← 매개변수 x
        this.y = y;                             // 필드 y ← 매개변수 y
    }                                           // Point(int, int) 끝
    public void set(int x, int y) {             // 예제 5-1 에서 좌표를 넣던 메소드 (오늘은 생성자로 대신)
        this.x = x;                             // 필드 x ← x
        this.y = y;                             // 필드 y ← y
    }                                           // set 끝
    public void showPoint() {                   // 좌표 출력
        System.out.println("(" + x + "," + y + ")");   // "(" + 1 + "," + 2 + ")" → (1,2) 찍고 줄바꿈
    }                                           // showPoint 끝
}                                               // Point 끝
class ColorPoint extends Point {                // 서브 클래스(자식) — Point 를 상속(확장) + 색
    private String color;                       // 추가 필드: 색
    public ColorPoint() {                       // 기본 생성자 — 비어 있어도 첫 줄에 super(); 가 자동으로 들어감
    }                                           // ColorPoint() 끝
    public ColorPoint(int x, int y, String color) {   // 매개변수 3개 생성자
        super(x, y);                            // 첫 줄 — 부모의 Point(int x, int y) 호출 → 부모의 private x · y 는 부모 생성자가 채움
        this.color = color;                     // 내 필드 color ← "빨강"
    }                                           // ColorPoint(…) 끝
    public void setColor(String color) {        // 색만 바꾸는 메소드 (예제 5-1)
        this.color = color;                     // 필드 color ← 매개변수 color
    }                                           // setColor 끝
    public void showColorPoint() {              // 색 + 좌표 출력
        System.out.print(color);                // 색을 줄바꿈 없이 → 빨강
        showPoint();                            // 부모에게 물려받은 메소드 → (3,4) + 줄바꿈 → 합쳐서 빨강(3,4)
    }                                           // showColorPoint 끝
}                                               // ColorPoint 끝

public class 연습 {                              // 원래 이름 ColorPointEx → 파일 이름 연습.java
    public static void main(String[] args) {    // 프로그램 시작
        Point p1 = new Point(1, 2);             // Point(int, int) → x = 1 · y = 2
//      p1.set(1, 2);                           // 예제 5-1 방식(set 으로 좌표 넣기) — 생성자로 바꾸면서 주석 처리
        p1.showPoint();                         // (1,2)

        ColorPoint cp1 = new ColorPoint(3, 4, "빨강");   // super(3, 4) 로 부모 부분 먼저 → 그다음 color = "빨강"
//      cp1.set(3, 4);                          // 예제 5-1 방식 — 물려받은 set 으로 좌표
//      cp1.setColor("빨강");                    // 예제 5-1 방식 — 색
        cp1.showColorPoint();                   // 빨강 + (3,4) → 빨강(3,4)
        ColorPoint cp2 = new ColorPoint(10, 20, "코발트");   // x = 10 · y = 20 · color = "코발트"
        cp2.showColorPoint();                   // 코발트(10,20)
    }                                           // main 끝
}                                               // 연습 끝
```

- 수업 파일은 예제 5-1 (6쪽)의 `p1.set(1, 2)` · `cp1.set(3, 4)` · `cp1.setColor("빨강")` 을 **주석으로 막고**, 예제 5-3 (21쪽)처럼 **생성자 + super(x, y)** 로 값을 넣었어요 → 출력 모양은 예제 5-1 의 `(1,2)` / `red(3,4)` 와 같고 색 이름만 빨강 · 코발트 줄이 하나 더 있어요.
- 7 · 8쪽 — `new ColorPoint(…)` 로 만든 **객체 하나 안에** Point 부분(x · y · set · showPoint)과 ColorPoint 부분(color · setColor · showColorPoint)이 **함께** 들어 있어요 · x · y 는 **private** 이라 ColorPoint 메소드에서 직접 못 쓰고, 물려받은 public `showPoint()` 를 불러서 출력해요 (ColorPoint 안에 `System.out.println(x);` 를 쓰면 `x has private access in Point` — javac 로 확인).
- `this.x = this.y = 0;` — 대입은 **오른쪽부터** → `this.y = 0` → 그 값 0 을 `this.x` 에 → 둘 다 0.

```java
        this.inch=inch;                         // 내 필드 inch ← 75
    }                                           // TV(…) 끝

    }                                           // printTV 끝

public class 연습 {                              // 원래 이름 InheEx1 (수업 파일에서는 public 이 아님) → 연습.java

        TV gsTv = new TV("LGTV",2000000,75);    // TV 생성자 → super("LGTV", 2000000) → inch = 75

}                                               // 연습 끝
```

## 6. 과제 3 · 4 — Book → Magazine · TextBook · toString()
📄 **과제 3** — Book(제목 title · 페이지수 pages · 저자 author) 을 상속한 **Magazine**(발매일 date) · 생성자 포함 · 객체 2개 출력 (MagaEx)

```java
// 과제 3 · 4 — Book.java + MagaEx.java + TextBookEx.java 를 한 파일로 (Book → Magazine · TextBook · toString)
class Book {                                    // 슈퍼 클래스 — 책 (제목 · 페이지수 · 저자)
    private String title;                       // 제목
    private int pages;                          // 페이지수
    private String author;                      // 저자
    Book(){}                                    // 기본 생성자
    Book(String title,int pages,String author){ // 매개변수 3개 생성자
        this.title=title;                       // 필드 title ← 매개변수
        this.pages=pages;                       // 필드 pages ← 매개변수
        this.author=author;                     // 필드 author ← 매개변수
    }                                           // Book(…) 끝
    void printInfo() {                          // 과제 3 용 — 바로 출력 (줄바꿈 없이)
        System.out.print(" 제목 : "+title+" 페이지수 : "+pages+" 저자 : "+author);
    }                                           // printInfo 끝
    public String toString() {                  // 과제 4 용 — 출력하지 않고 같은 글자를 문자열로 돌려줌 (Object 의 toString 을 다시 씀)
        return " 제목 : "+title+" 페이지수 : "+pages+" 저자 : "+author;   // " 제목 : 웹프로그래밍 페이지수 : 100 저자 : 장용미"
    }                                           // toString 끝
}                                               // Book 끝
class Magazine extends Book{                    // 과제 3 — Book 을 상속 + 발매일
    private String date;                        // 발매일
    Magazine(){}                                // 기본 생성자
    Magazine(String title,int pages,String author,String date){   // 부모 것 3개 + 발매일
        super(title,pages,author);              // 첫 줄 — 부모 Book(…) 이 제목 · 페이지수 · 저자를 채움

        super.printInfo();                      // 부모 메소드 → " 제목 : … 페이지수 : … 저자 : …" (줄바꿈 X)
        System.out.println(" 발매일 : "+date);   // 이어서 " 발매일 : 2026-11-02" + 줄바꿈
    }                                           // printMagazine 끝
}                                               // Magazine 끝
class TextBook extends Book{                    // 과제 4 — Book 을 상속 + 학년학기 · 학교
    private String hakgi;                       // 학년학기
    private String school;                      // 학교 (초중고대)
    TextBook(){}                                // 기본 생성자
    TextBook(String title,int pages,String author,String hakgi,String school){   // 부모 것 3개 + 내 것 2개
        super(title,pages,author);              // 첫 줄 — 부모 생성자
        this.hakgi=hakgi;                       // 내 필드 학년학기

    }                                           // TextBook(…) 끝
    public String toString() {                  // 부모의 toString 을 다시 씀 — 부모 글자 + 내 필드
        return super.toString()+" 학년학기 : "+hakgi+" 학교 : "+school;   // super.toString() = 부모 Book 의 toString → " 제목 : … 저자 : …" + " 학년학기 : … 학교 : …"
    }                                           // toString 끝
}                                               // TextBook 끝
public class 연습 {                              // 원래 MagaEx · TextBookEx 두 main 을 하나로 → 연습.java
    public static void main(String[]args) {     // 프로그램 시작
        Magazine m1 = new Magazine("컴퓨터공학1",120,"컴소과","2026-11-02");   // 잡지 1
        Magazine m2 = new Magazine("컴퓨터공학2",90,"웹소과","2026-11-03");    // 잡지 2
        m1.printMagazine();                     // 제목 · 페이지수 · 저자 → 발매일 (한 줄)

        TextBook t1 = new TextBook("웹프로그래밍",100,"장용미","1학년2학기","동양미래대학교");     // 교과서 1
        TextBook t2 = new TextBook("자바프로그래밍",200,"강은영","1학년2학기","동양미래대학교");   // 교과서 2
        System.out.println(t1.toString());      // toString() 이 돌려준 문자열을 println 이 출력

    }                                           // main 끝
}                                               // 연습 끝
```

| 🤖 toString() 더 알기 | 확인 (javac · java) |
|---|---|
| toString() 은 모든 클래스의 조상 **Object** 에 이미 있는 메소드 → Book 이 같은 모양 `public String toString()` 으로 **다시 씀** | 다시 쓰지 않은 클래스를 출력하면 `Book@15db9742` 처럼 **클래스이름@해시값** (값은 실행마다 다를 수 있음) |
| `System.out.println(t1);` 만 써도 toString() 이 **자동으로** 불림 | `t1.toString()` 과 같은 줄이 찍힘 |
| **public** 을 빼고 `String toString()` 으로 쓰면 | `attempting to assign weaker access privileges; was public` 컴파일 오류 |
| TextBook 의 toString 안에서 `super.` 없이 `toString()` 을 부르면 | **자기 자신**을 끝없이 불러 `StackOverflowError` → 부모 것은 꼭 `super.toString()` |

> 부모의 메소드를 자식이 **같은 이름 · 매개변수 · 리턴 타입**으로 다시 쓰는 것 = **메소드 오버라이딩** (5장 32쪽 — 오늘 수업 범위 21쪽 뒤에 나오는 내용이라 이름만 미리 알아 두기).

## 7. 🤖 정리 — super vs this
| 코드 | 뜻 | 오늘 코드 |
|---|---|---|
| `super(…)` | 슈퍼 클래스의 **생성자** 호출 · 서브 생성자의 **첫 줄** | `super(x, y)` · `super(brand,price)` · `super(name,addr,phone)` |
| `super.메소드()` | 슈퍼 클래스의 **메소드** 호출 | `super.printInfo()` · `super.toString()` |
| `this(…)` | 같은 클래스의 **다른 생성자** 호출 · 첫 줄 ([9주차](자바프로그래밍-9주차.html)) | (오늘 없음) |
| `this.필드` | 이 객체의 **필드** (매개변수와 이름이 같을 때 구분) | `this.color = color` · `this.inch=inch` |
| (아무것도 안 씀) | 컴파일러가 서브 생성자 첫 줄에 **`super();`** 를 넣음 | ConstructorEx2 · 3 · `ColorPoint(){}` |
