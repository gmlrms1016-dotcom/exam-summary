## 1. 조건문 if · if ~ else · else if
> 📂 **5주차 자료** — 수업 코드(WorkC **w05**) · 수업 화면 사진(**Quiz 6 · 7 · 8**) · 메모장 필기를 중심으로 정리했고, 수업 중에 보지 않은 **요약 PDF**(교재 6 · 7장 실습 = **HW01 과제**, 6 · 7장은 시험범위)는 각 절 끝 **📘 접기**에 넣었습니다. 아래 코드의 주석과 **▶ 출력 결과**는 전부 직접 컴파일·실행한 값이고, 입력이 있는 예제는 **입력한 값까지** 화면 그대로입니다.

> 🔥 **9/29 — HW01 과제 32개(교재 6 · 7장 실습)가 전부 중간고사 예상문제** · 각 절 끝 **📘 접기**에 코드와 실행 결과가 있고, 과목 페이지의 🖥️ 출력 결과 맞히기 · 💻 코딩테스트 **🔥 중간고사 예상문제** 묶음(각 32개)에서 직접 풀 수 있어요.
> ✍️ **필기** — 조건: `if` · `if ~ else` · `if ~ else if` · `switch` / 반복: `for` · `while` · `do ~ while` (+ 흐름을 바꾸는 `break` · `continue` · `goto`) · **조건식은 0 이 아닌 값 = 참, 0 = 거짓** · 입력을 받으려면 `#define _CRT_SECURE_NO_WARNINGS` 를 쓰거나 `scanf_s()` 를 써도 된다
| 형태 | 모양 | 실행되는 것 |
|---|---|---|
| `if` | `if (조건) 문장;` | 참일 때만 실행 (거짓이면 건너뜀) |
| `if ~ else` | `if (조건) A; else B;` | 참 → A, 거짓 → B (둘 중 **하나는 반드시**) |
| `if ~ else if ~ else` | `if (조건1) A; else if (조건2) B; else C;` | 위에서부터 검사해 **처음 참인 것 하나만** |
| `switch` | `switch (식) { case 값: … break; }` | 식의 값과 같은 case 로 이동 → 3번 |
### 예제 ① E00-condition/ex01_00-01if1.c (수업 코드) — if ~ else if
```c
// E00-condition/ex01_00-01if1.c (수업 코드) — if ~ else if
#define _CRT_SECURE_NO_WARNINGS
#include <stdio.h>
int main() {
    int a = 10;
    int b = 20;
    if (a > b) {                       // 10 > 20 → 거짓(0) → 건너뜀
        printf("a는 b보다 크다");
    }
    else if (a < b) {                  // 10 < 20 → 참(1) → 실행
        printf("a는 b보다 작다");        // \n 이 없다 → 출력 뒤 줄이 안 바뀜
    }
    return 0;
}
```
```output
a는 b보다 작다
```
> ⚠️ printf 에 `\n` 이 없어서 출력 뒤에 줄이 바뀌지 않아요 → 실행결과를 쓸 때 **`\n` 있나 없나** 먼저 확인 (필기) · 노션에 붙여넣은 첫 버전은 `else` 였고 WorkC 파일은 `else if (a < b)` 라서, **a == b 이면 아무것도 출력되지 않습니다** (두 조건이 모두 거짓)

### 02evenifelse.c — 짝수와 홀수 판정 (if else · 조건 연산자) — 입력: 7 / 10
> ⚠️ **정정** — 요약 PDF 코드는 아래처럼 **여는 중괄호 `{` 가 주석 안**에 들어가 있어서, `};` 의 `}` 가 main 을 닫아 버리고 뒤의 `else` 는 짝이 되는 if 가 없어 **컴파일 오류**가 납니다 (직접 컴파일해서 확인). `{` 를 주석 밖으로 빼고 `};` → `}` 로 고쳐야 실행돼요.
```c
    if (n % 2) // if (n % 2 != 0) {    ← { 가 주석 안에 들어감
        printf("홀수\n");
    };                                 ← } 가 main 을 닫고, 뒤의 else 는 짝이 없음 → 오류
    else {
        printf("짝수\n");
    }
```
```c
// 02evenifelse.c — 짝수와 홀수 판정 (if else · 조건 연산자)  ※ 중괄호 정정
#define _CRT_SECURE_NO_WARNINGS
#include <stdio.h>

int main(void) {
    int n;
    printf("정수 입력: ");
    scanf("%d", &n);

    if (n % 2) {                       // if (n % 2 != 0) 과 같다 — 나머지 1(0 이 아님) → 참
        printf("홀수\n");
    }
    else {                             // 나머지 0 → 거짓
        printf("짝수\n");
    }

    //조건연산자 이용
    (n % 2) ? printf("홀수\n") : printf("짝수\n");   // 같은 판정을 한 줄로

    return 0;
}
```

    printf("두 정수 입력 >> ");

## 2. 중첩 if — 세 수 중 가장 큰 값
> 📌 if 안에 또 if — **바깥 조건이 참일 때만** 안쪽 if 를 검사 · 안쪽 if 도 한 문장이면 `{ }` 생략 가능 (Quiz 8 의 `else printf(...)`)
### 예제 ① Quiz 8 (수업 코드) — 세 수 중 최대값 — 입력: 3 9 5
```c
// Quiz 8 (수업 코드) — 키보드로 세 수를 입력받아 가장 큰 값 출력 (중첩 if)
#define _CRT_SECURE_NO_WARNINGS
#include <stdio.h>
int main() {
    int x, y, z;
    printf("세 수를 입력하세요? ");
    scanf("%d%d%d", &x, &y, &z);       // 스페이스 · 엔터로 구분해서 3개
    if (x > y) {                       // x 가 더 크면 → 이제 x 와 z 만 비교
        if (x > z) {
            printf("max : %d", x);
        }
        else
            printf("max : %d", z);
    }
    else {                             // y 가 x 이상이면 → y 와 z 만 비교
        if (y > z) {
            printf("max : %d", y);
        }
        else {
            printf("max : %d", z);
        }
    }
    return 0;
}
```
```output
세 수를 입력하세요? 3 9 5
max : 9
```
| 바깥 조건 | 안쪽 비교 | 출력되는 max |
|---|---|---|
| `x > y` 참 | `x > z` ? | 참 → x · 거짓 → z |
| `x > y` 거짓 (y ≥ x) | `y > z` ? | 참 → y · 거짓 → z |
### 예제 ② Quiz 8 수업 화면(사진) 버전 — 입력: 3 9 5
> ✍️ **필기** — 수업 화면 코드는 입력 뒤에 세 수를 **한 번 더 출력**하고, max 줄 끝에 ` \n` 이 있어요. 또 x 가 최대일 때만 `max : ` (콜론 앞에 공백), 나머지는 `max: ` → 실행결과를 쓸 때는 **코드에 적힌 printf 를 글자 그대로** 따라가기
```c
// Quiz 8 (수업 화면 사진) — 세 수를 한 번 더 찍고, max 뒤에 \n
#define _CRT_SECURE_NO_WARNINGS
#include <stdio.h>
int main() {
    int x, y, z;

    printf("세 수를 입력하세요? ");
    scanf("%d%d%d", &x, &y, &z);

    printf("x : %d, y : %d, z : %d\n", x, y, z);

    if (x > y) {
        if (x > z)
            printf("max : %d \n", x);
        else
            printf("max: %d \n", z);
    } else {
        if (y > z)
            printf("max: %d \n", y);
        else
            printf("max: %d \n", z);
    }
    return 0;
}
```
```output
세 수를 입력하세요? 3 9 5
x : 3, y : 9, z : 5
max: 9 
```

## 3. switch ~ case · break ★시험
> 🔥 **필기 [시험]** — **switch case 에 break 를 빼면?** → 그 case 에서 **안 멈추고 밑의 case 까지 계속 실행**돼서 아래 printf 들도 출력된다 · `break` = switch 블록을 빠져나오는 문장 · 어느 case 에도 맞지 않으면 `default`
| 부분 | 뜻 |
|---|---|
| `switch (식)` | 식의 값(정수 · 문자)을 보고 |
| `case 값:` | 그 값과 같은 case 로 **이동해서 거기부터** 실행 |
| `break;` | switch 블록을 빠져나감 — **없으면 아래 case 로 계속** |
| `default:` | 맞는 case 가 없을 때 (생략 가능 · 위치 자유) |
### 예제 ① ★ break 가 있을 때 vs 없을 때 (필기 시험 내용 확인)
```c
// ★시험 — switch 에서 break 를 빼면? (필기: 안 멈추고 밑의 case 까지 실행)
#include <stdio.h>
int main() {
    int n = 2;

    printf("① break 있음\n");
    switch (n) {
    case 1:
        printf("one\n");
        break;
    case 2:                            // n == 2 → 여기로 이동
        printf("two\n");
        break;                         // switch 블록을 빠져나감
    case 3:
        printf("three\n");
        break;
    default:
        printf("default\n");
    }

    printf("② break 없음\n");
    switch (n) {
    case 1:
        printf("one\n");
    case 2:                            // n == 2 → 여기서 시작해서
        printf("two\n");
    case 3:                            // break 가 없으니 멈추지 않고 아래로 계속
        printf("three\n");
    default:                           // default 까지 전부 실행
        printf("default\n");
    }
    return 0;
}
```
```output
① break 있음
two
② break 없음
two
three
default
```
| n = 2 | 실행되는 case | 출력 |
|---|---|---|
| break 있음 | case 2 → break | `two` |
| break 없음 | case 2 → case 3 → default | `two` `three` `default` |

## 4. 반복문 for · while · do ~ while
> ✍️ **필기** — **for 는 반복 횟수가 정해져 있다** · **while 은 조건이 참일 때까지만 실행되고 거짓이면 빠져나온다** · do ~ while 은 **먼저 한 번 실행하고** 조건을 검사 (끝에 `;`)
| 반복문 | 모양 | 조건 검사 | 특징 |
|---|---|---|---|
| `for` | `for (초기식; 조건식; 증감식) { }` | 반복 **전** | 횟수가 정해진 반복 · 세 식을 한 줄에 |
| `while` | `while (조건식) { }` | 반복 **전** | 처음부터 거짓이면 **0번** 실행 |
| `do ~ while` | `do { } while (조건식);` | 반복 **후** | **최소 1번** 실행 · 끝에 `;` 필수 |
```text
for (i = 0; i < 10; i++) { 몸체 }

① 초기식 i = 0  (처음 한 번만)
② 조건식 i < 10 → 참이면 ③, 거짓이면 반복 끝
③ 몸체 실행
④ 증감식 i++ → 다시 ②
```

## 5. break · continue · goto ★시험
> 🔥 **필기 [시험]** — **continue, break 시험에 나옴** · `break` = **반복문을 빠져나온다** + **switch 블록을 빠져나온다** (필기) · `continue` = 반복 몸체의 **나머지를 건너뛰고 다음 반복**으로 (for 는 증감식 → 조건식, while 은 조건식으로) · `goto 레이블;` = 레이블 위치로 이동
> ✍️ **필기 정정** — 필기의 `continue:` 설명이 비어 있어서 수업 Quiz 7 과 교재 12continue.c 로 채웠어요.
| 문장 | 하는 일 | 쓰는 곳 |
|---|---|---|
| `break;` | 가장 가까운 반복문 · switch 를 **즉시 빠져나감** | for · while · do ~ while · switch |
| `continue;` | 이번 반복의 **남은 문장을 건너뛰고** 다음 반복으로 | for · while · do ~ while |
| `goto 레이블;` | `레이블:` 위치로 이동 | 함수 안 어디서나 |
### 예제 ① ★ Quiz 6 (수업 코드 · break.c) — 1 ~ 100 반복하다 10 에서 탈출

#define _CRT_SECURE_NO_WARNINGS
#include <stdio.h>
int main() {
    int i, j;                          // j 는 선언만 하고 쓰지 않음
    for (i = 1; i <= 100; i++) {

        if (i % 10 == 0)               // i == 10 → 10 % 10 == 0 → 참
            break;                     // for 를 즉시 빠져나감 (11 ~ 100 은 실행 안 함)

    return 0;
}

```c
// 17loopsum.c — 1에서 입력된 정수까지의 합 구하기 (do ~ while 안에 중첩 for)
#define _CRT_SECURE_NO_WARNINGS
#include <stdio.h>

int main(void) {
    int input, sum, i, j;
    do {
        printf("양의 정수 또는 0(종료)을 입력: ");
        scanf("%d", &input);

        for (i = 1; i <= input; i++) {             // 1 줄 ~ input 줄
            for (j = 1, sum = 0; j <= i; j++) {    // 1 + 2 + … + i
                printf("%d", j);
                j == i ? printf(" = ") : printf(" + ");   // 마지막 수 뒤에는 =
                sum += j;
            }
            printf("%d\n", sum);
        }
    } while (input > 0);               // 0 이하면 종료

    puts("종료합니다.");

    return 0;
}
```
