## 1. C 프로그램 빌드 과정 ★핵심
- ⭐ **강조** — 소스 작성 → 전처리(preprocessor) → 빌드(컴파일+링크) → 실행
- ⭐ **강조** — 소스파일(.c) → [컴파일] → 목적파일(.obj) → [링크] → 실행파일(.exe)
- ✍️ **필기** — 1.소스작성 2.컴파일 3.링크 4.실행결과 확인

## 2. 출력 함수
- ⭐ **강조** — `printf("...")` : 서식 출력 (자동 줄바꿈 없음, `\n` 필요)
- ⭐ **강조** — `puts("...")` : 문자열을 출력하고 자동으로 줄바꿈
- `putc()` : 문자 하나 출력
```c
// P02-PutString/02put.c
#include <stdio.h>
int main() {
    printf("hello world!\n");
    puts("C 언어, 재미있다!");
    return 0;
}
```

## 3. 함수와 프로그램 구조 ★핵심
- ✍️ **필기** — C언어는 함수들로 구성된다
- ✍️ **필기** — C언어는 main() 함수로 시작된다 (자동 실행), 다른 함수는 호출해야 실행됨
- 표준 라이브러리 함수 vs 사용자 정의 함수
```c
#include <stdio.h>
void func1(void);
int main(void) {
    printf("main() start!!!\n");
    func1();            // 호출해야 실행
    printf("main() end!!!\n");
    return 0;
}
void func1(void) {
    printf("func1() start!!!\n");
    printf("func1() end!!!\n");
}
```

## 4. 디버깅 & 퀴즈
- ✍️ **필기** — 오류 예: `printf("...")` 뒤 세미콜론(;) 누락, 닫는 따옴표 누락 → 컴파일 오류
- Quiz: printf 한 번으로 여러 줄 출력 / 함수(func1,func2)를 사용해 출력 순서 맞추기
```c
// 마지막 퀴즈 정답
int main(void){
    printf("안녕하세요\n");
    func2();   // "제 이름은"
    func1();   // "gdhong 입니다."
    return 0;
}
```
- 여러 프로젝트 중 실행할 것은 [시작 프로젝트로 설정] (굵은 글씨로 표시)
