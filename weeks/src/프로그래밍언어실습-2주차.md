## 1. C 프로그램 빌드 과정 ★핵심
- ⭐ **강조** — 소스 작성 → 전처리(preprocessor) → 빌드(컴파일+링크) → 실행
- ⭐ **강조** — 소스파일(.c) → [컴파일] → 목적파일(.obj) → [링크] → 실행파일(.exe)
- ✍️ **필기** — 1.소스작성 2.컴파일 3.링크 4.실행결과 확인

## 2. 출력 함수
- ⭐ **강조** — `printf("...")` : 서식 출력 (자동 줄바꿈 없음, `\n` 필요)
- ⭐ **강조** — `puts("...")` : 문자열을 출력하고 자동으로 줄바꿈
- `putc()` : 문자 하나 출력
```c
// P02-PutString/02put.c
#include <stdio.h>   // printf · scanf 를 쓰기 위한 표준 입출력 헤더
int main() {   // () = 괄호를 비워 둔 옛 방식 · int main(void) 는 '매개변수 없음'을 확실히 적음 — 실행 결과는 같음
    printf("hello world!\n");   // \n 을 직접 넣어야 줄바꿈
    puts("C 언어, 재미있다!");   // puts 는 자동 줄바꿈
    return 0;                   // 0(정상 종료)을 운영체제에 돌려주고 끝냄
}                               // main 함수 끝
```

### 예제 — printf 와 puts 의 줄바꿈 (모든 경우)
```c
// printf 는 자동 줄바꿈이 없다 → \n 을 직접 넣어야 한다
#include <stdio.h>   // printf · scanf 를 쓰기 위한 표준 입출력 헤더
int main() {   // () = 괄호를 비워 둔 옛 방식 · int main(void) 는 '매개변수 없음'을 확실히 적음 — 실행 결과는 같음
    printf("hello");             // 줄바꿈 없음 → 다음 출력이 바로 뒤에 붙는다
    printf("world\n");           // 여기서 \n → 줄이 바뀜   => helloworld
    printf("C 언어\n");           // 한 줄 출력
    printf("첫째 줄\n둘째 줄\n");   // printf 한 번으로 두 줄 (\n 이 두 번)
    puts("puts 는");              // puts 는 출력한 뒤 자동으로 줄을 바꾼다
    puts("자동 줄바꿈");            // \n 을 안 넣어도 다음 출력은 새 줄에서 시작
    printf("끝\n");   // 끝 출력 후 줄바꿈
    return 0;        // 0(정상 종료)을 운영체제에 돌려주고 끝냄
}                    // main 함수 끝
```
```output
helloworld
C 언어
첫째 줄
둘째 줄
puts 는
자동 줄바꿈
끝
```
> printf 는 **\n 을 만날 때만** 줄이 바뀌고, puts 는 **출력할 때마다** 줄이 바뀝니다. 첫 두 줄이 **helloworld** 로 붙은 이유가 이것이에요.
### 예제 — 2주차 연습문제 Quiz-01 · 02 · 05 (printf 한 번으로)
```c

    // Quiz-01 : 한 줄에 공백 두 칸씩
    printf("C  Pascal  Java  Python  kotlin\n");   // 한 줄에 공백 두 칸씩 → C  Pascal  Java  Python  kotlin

    // Quiz-05 : 여러 줄 문장도 \n 으로 이어서 한 번에

    return 0;                                   // 0(정상 종료)을 운영체제에 돌려주고 끝냄
}                                               // main 함수 끝
```

## 3. 함수와 프로그램 구조 ★핵심
- ✍️ **필기** — C언어는 함수들로 구성된다
- ✍️ **필기** — C언어는 main() 함수로 시작된다 (자동 실행), 다른 함수는 호출해야 실행됨
- 표준 라이브러리 함수 vs 사용자 정의 함수
```c
#include <stdio.h>                  // printf · scanf 를 쓰기 위한 표준 입출력 헤더
void func1(void);                   // 함수 원형 — main 아래에 정의할 func1 을 미리 알림
int main(void) {   // (void) = '매개변수 없음'을 확실히 적음 · int main() 은 괄호를 비워 둔 옛 방식 — 실행 결과는 같음
    printf("main() start!!!\n");    // ① main() start!!!
    func1();            // 호출해야 실행
    printf("main() end!!!\n");      // ③ func1 에서 돌아와서 → main() end!!!
    return 0;                       // 0(정상 종료)을 운영체제에 돌려주고 끝냄
}                                   // main 함수 끝
void func1(void) {                  // func1 정의 시작
    printf("func1() start!!!\n");   // ② func1() start!!!
    printf("func1() end!!!\n");     // ② func1() end!!! → main 으로 돌아감
}                                   // func1 함수 끝 → 호출한 곳으로 돌아감
```

### 예제 ① 함수를 만들기만 하고 호출하지 않으면
```c
// ex-function-01.c — func1() 을 만들기만 하고 호출하지 않은 경우
#include <stdio.h>                   // printf · scanf 를 쓰기 위한 표준 입출력 헤더
void func1();                       // 함수 원형(선언): main 보다 아래에 정의할 거라 미리 알려 줌
int main(void) {                    // C 프로그램은 main() 부터 자동 실행 · (void) = '매개변수 없음'을 확실히 적음 · int main() 은 괄호를 비워 둔 옛 방식 — 실행 결과는 같음
    printf("main() start!!! \n");    // main() start!!!
    printf("main() end!!! \n");     // func1() 을 부르지 않았다
    return 0;                        // 0(정상 종료)을 운영체제에 돌려주고 끝냄
}                                    // main 함수 끝
void func1(void) {                  // 정의는 있지만 호출이 없으니 실행되지 않는다
    printf("func1() start!!! \n");   // 호출이 없어서 실행 안 됨
    printf("func1() end!!! \n");     // 호출이 없어서 실행 안 됨
}                                    // func1 함수 끝 → 호출한 곳으로 돌아감
```
```output
main() start!!! 
main() end!!! 
```
> func1() 안의 printf 는 **한 줄도 출력되지 않습니다** — 호출하지 않았기 때문.
### 예제 ② main() 안에서 호출하면
```c
// ex-function-02.c — main() 안에서 func1() 을 호출한 경우
#include <stdio.h>                   // printf · scanf 를 쓰기 위한 표준 입출력 헤더
void func1();                        // 함수 원형(선언) — main 아래에 정의할 func1 을 미리 알림
int main(void) {   // (void) = '매개변수 없음'을 확실히 적음 · int main() 은 괄호를 비워 둔 옛 방식 — 실행 결과는 같음
    printf("main() start!!! \n");   // ① 먼저 실행
    func1();                        // ② func1 로 이동 → 안의 두 줄을 실행하고 돌아온다
    printf("main() end!!! \n");     // ③ 돌아와서 나머지 실행
    return 0;                        // 0(정상 종료)을 운영체제에 돌려주고 끝냄
}                                    // main 함수 끝
void func1(void) {                   // func1 함수 정의 시작 (매개변수 · 반환값 없음)
    printf("func1() start!!! \n");   // ②-1 func1() start!!!
    printf("func1() end!!! \n");     // ②-2 func1() end!!! → main 으로 돌아감
}                                    // func1 함수 끝 → 호출한 곳으로 돌아감
```
```output
main() start!!! 
func1() start!!! 
func1() end!!! 
main() end!!! 
```
### 예제 ③ 실행 순서는 "정의한 순서"가 아니라 "부른 순서"
```c
// 함수 호출 순서 = 출력 순서 (정의한 순서가 아니라 "부른 순서")
#include <stdio.h>       // printf · scanf 를 쓰기 위한 표준 입출력 헤더
void func1(void);        // 함수 원형 — main 아래에 정의할 func1 을 미리 알림
void func2(void);        // 함수 원형 — func2 도 미리 알림
int main(void) {   // (void) = '매개변수 없음'을 확실히 적음 · int main() 은 괄호를 비워 둔 옛 방식 — 실행 결과는 같음
    printf("안녕하세요\n");   // 안녕하세요 출력 후 줄바꿈
    func2();          // func2 를 먼저 부른다 → "제 이름은" (\n 없음 → 다음 글자가 붙는다)
    func1();          // 그다음 func1         → "gdhong 입니다."
    func1();          // 같은 함수를 여러 번 부르면 여러 번 실행된다
    return 0;            // 0(정상 종료)을 운영체제에 돌려주고 끝냄
}                        // main 함수 끝
void func1(void) { printf("gdhong 입니다. \n"); }   // 정의는 func1 이 먼저여도
void func2(void) { printf("제 이름은 "); }         // 실행 순서는 main 이 정한다
```
```output
안녕하세요
제 이름은 gdhong 입니다. 
gdhong 입니다. 
```

## 4. 디버깅 & 퀴즈
- ✍️ **필기** — 오류 예: `printf("...")` 뒤 세미콜론(;) 누락, 닫는 따옴표 누락 → 컴파일 오류
- Quiz: printf 한 번으로 여러 줄 출력 / 함수(func1,func2)를 사용해 출력 순서 맞추기
```c
// 마지막 퀴즈 정답
#include <stdio.h>              // printf · scanf 를 쓰기 위한 표준 입출력 헤더

void func1(void);   // 함수 원형(선언) — main 보다 아래에 정의할 거라 미리 알려 줌
void func2(void);               // func2 도 미리 알림

int main(void) {   // (void) = '매개변수 없음'을 확실히 적음 · int main() 은 괄호를 비워 둔 옛 방식 — 실행 결과는 같음
    printf("안녕하세요\n");          // 안녕하세요 출력 후 줄바꿈
    func2();   // func2() 실행 → printf("제 이름은") → 제 이름은 (\n 없음 → 다음 출력이 바로 뒤에 붙음)
    func1();   // func1() 실행 → "gdhong 입니다. \n" 이 앞 줄에 이어 붙음 → 제 이름은gdhong 입니다.
    return 0;                   // 0(정상 종료)을 운영체제에 돌려주고 끝냄
}                               // main 함수 끝

void func1(void) {              // func1 정의 시작
    printf("gdhong 입니다. \n");   // gdhong 입니다.  출력 후 줄바꿈
}                               // func1 함수 끝 → 호출한 곳으로 돌아감

void func2(void) {              // func2 정의 시작
    printf("제 이름은");            // 제 이름은 (\n 없음 → 다음 출력이 바로 뒤에 붙음)
}                               // func2 함수 끝 → 호출한 곳으로 돌아감
```
```output
안녕하세요
제 이름은gdhong 입니다. 
```
> func2() 의 "제 이름은" 에는 **\n 이 없어서** 다음에 부른 func1() 의 글자가 **같은 줄에 바로 붙습니다**.

- 여러 프로젝트 중 실행할 것은 [시작 프로젝트로 설정] (굵은 글씨로 표시)

### 예제 — 03debug.c 의 오류 2개 고치기
```c
// P03-Debugging/03debug.c — 강의자료 원본에는 오류가 2군데 숨어 있다
#include <stdio.h>   // printf · scanf 를 쓰기 위한 표준 입출력 헤더
int main() {   // () = 괄호를 비워 둔 옛 방식 · int main(void) 는 '매개변수 없음'을 확실히 적음 — 실행 결과는 같음
    // ❌ printf("컴퓨터공학과학생이며\n")    ← 세미콜론(;) 누락 → 컴파일 오류
    // ❌ printf("C 언어를수강합니다\n);     ← 닫는 따옴표(") 누락 → 컴파일 오류
    printf("컴퓨터공학과학생이며\n");      // ✅ 문장 끝에는 항상 ;
    printf("C 언어를수강합니다\n");        // ✅ 문자열은 " 로 열고 " 로 닫는다
    return 0;   // 0(정상 종료)을 운영체제에 돌려주고 끝냄
}               // main 함수 끝
```
```output
컴퓨터공학과학생이며
C 언어를수강합니다
```
