## 9주차 · 빌드 · 메모리 공간 · 변수의 유효범위
| 포인트 | 핵심 · 답 | 그림 |
|---|---|---|
| ✍️ 빌드 = 컴파일 + 링크 | 컴파일 → 목적파일 (`.obj` · `.o`) · 링크(+ 라이브러리) → 실행파일 (`.exe`) · ⚠️ `.o` 는 실행파일이 아니라 링크 전 목적파일 | ① |
| ✍️ 메모리 4영역 | A. 정적(컴파일 시간) = **코드 · 데이터 · 스택**(아주 중요!) / B. 동적(런타임) = **힙** · 전역 → 데이터 · 지역 · 매개변수 → 스택 | ② |
| ✍️ 유효범위 (scope) | 선언된 변수가 사용될 수 있는 범위 · 지역 = 블록(중괄호) · 함수 **안** · 전역 = 함수 **밖** | ③ |
| 📄 scope1_5.c | while 블록 안 `int b = 20;` → while 밖 `printf("b: %d\n", b);` = **컴파일 오류** (선언되지 않은 b) | ③ |
| 📄 01localvar.c | `for (int m = 0, sum = 0; …)` 의 m · sum 은 for 밖에서 못 씀 · main 의 n 은 sub 에서 못 씀 · 출력 `10` / 탭 `0 0` `1 1` `2 3` / `10` / 탭 `20 100` | ③ |
| 🔥 ✍️ 지역이 전역보다 우선 | 02-1global.c — 둘레1 **36.88**(지역 PI 3.141592) ≠ 둘레2 **36.86**(전역 PI 3.14) · 면적 108.19 · 전역 gi 기본값 **0** · `extern double PI;` = 다른 파일의 전역변수 | ④ |
