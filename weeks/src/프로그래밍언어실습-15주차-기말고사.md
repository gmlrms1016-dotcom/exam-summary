## 🎓 튜터링 3회차 (10/29) — 배열 합 · 0~9 중 가장 많이 나온 수
> 자료: `8주차_중간고사/튜터링/3회차/c.c` (CP949 저장) — 프로그램 2개가 한 파일에 있어요(앞의 1개는 주석 처리). 아래 결과는 전부 **직접 컴파일 · 실행**한 값이에요.
> 기말 범위 **8장 배열**과 이어지는 문제 (중간고사 때 ✍️ “배열을 기말고사에”). `#define _CRT_SECURE_NO_WARNINGS` 는 이번엔 밑줄까지 맞게 썼어요 (1회차 정정 참고).

### ① 정수 4개 입력 → 그대로 출력 · 합
```c
#define _CRT_SECURE_NO_WARNINGS        // Visual Studio 에서 scanf 보안 경고(C4996) 끄기 — 맨 위에 써야 함
#include <stdio.h>                     // printf · scanf 를 쓰기 위한 표준 입출력 헤더
int main(void) {   // (void) = '매개변수 없음'을 확실히 적음 · int main() 은 괄호를 비워 둔 옛 방식 — 실행 결과는 같음
	int a[5];                          // 정수 5칸 배열 a[0] ~ a[4] — 4칸만 쓰니 a[4] 로도 충분 (a[4] 칸은 안 씀)
	int sum = 0;                       // 합을 모을 변수 — 0 에서 시작해야 함
	printf("4개의 정수 입력 >> ");      // 질문 출력 (줄바꿈 없음)
	for (int i = 0; i <= 3; i++) {     // i = 0 → 1 → 2 → 3 (4번 · i < 4 와 같음)
		scanf("%d", &a[i]);            // 10 20 30 40 입력 → a[0]=10 · a[1]=20 · a[2]=30 · a[3]=40
	}                                  // for 끝
	for (int j = 0; j <= 3; j++) {     // j = 0 → 3 (4번)
		printf("%d ", a[j]);           // 10 → "10 " · 20 → "20 " … (숫자 뒤에 칸 하나)
		sum += a[j];                   // 0 → 10 → 30 → 60 → 100
	}                                  // for 끝
	printf("%d", sum);                 // 100 → "100" — 앞의 "40 " 바로 뒤에 붙어서 나옴
}                                      // main 끝 (return 0 이 없어도 main 은 0 을 돌려준 것으로 침)
```
```output
4개의 정수 입력 >> 10 20 30 40
10 20 30 40 100
```
- 🤖 합 `100` 이 숫자들 바로 뒤에 붙어서 **다섯 번째 수처럼** 보여요 → `printf("\n합: %d\n", sum);` 처럼 줄을 나누면 `합: 100` 으로 따로 나와요 (실행 확인)
- `i <= 3` = 0 · 1 · 2 · 3 → **4번** — 배열 칸 번호는 **0부터**라서 4칸이면 마지막이 3
- 🤖 `main` 끝에 `return 0;` 이 없어도 괜찮아요 — C99 부터 main 은 끝까지 가면 0 을 돌려준 것으로 쳐요 (다른 함수는 아님)

### ② 0~9 정수를 -1 이 나올 때까지 입력 → 가장 많이 나온 수 (빈도수 배열)
```c
#define _CRT_SECURE_NO_WARNINGS        // Visual Studio 에서 scanf 보안 경고(C4996) 끄기 — 맨 위에 써야 함
#include <stdio.h>                     // printf · scanf 를 쓰기 위한 표준 입출력 헤더

int main(void) {   // (void) = '매개변수 없음'을 확실히 적음 · int main() 은 괄호를 비워 둔 옛 방식 — 실행 결과는 같음
    int count[10] = { 0 };             // 0~9 가 몇 번 나왔는지 세는 칸 10개 — { 0 } = 10칸 모두 0 으로 시작
    int n;                             // 입력한 수를 잠깐 담을 변수

    printf("0에서 9까지의 정수를 입력하세요.\n");   // 안내 출력 후 줄바꿈

    while (1) {                        // 1 = 항상 참 → break 를 만날 때까지 계속 반복
        scanf("%d", &n);               // 3 5 3 7 5 3 -1 을 하나씩 → n

        if (n == -1)                   // -1 = 끝 신호
            break;                     // while 을 빠져나감 (-1 은 세지 않음)

        if (n >= 0 && n <= 9)          // 0~9 범위일 때만 (12 · -5 같은 수는 무시)
            count[n]++;                // 입력한 수 자체를 칸 번호로 → 3 → count[3] 이 1 증가
    }                                  // while 끝 → count[3]=3 · count[5]=2 · count[7]=1 · 나머지 0

    int max = 0;                       // 지금까지 가장 많이 나온 수 = 일단 0 이라고 가정

    for (int i = 1; i < 10; i++) {     // 1 ~ 9 를 하나씩 max 와 비교 (0 은 이미 max)
        if (count[i] > count[max])     // 더 많이 나왔으면 → 3: 3 > 0 → max=3 · 5: 2 > 3 거짓 · 7: 1 > 3 거짓
            max = i;                   // max 를 그 수로 바꿈 → 마지막에 max = 3
    }                                  // for 끝

    printf("0~9중 가장 많이 나온 수는 %d이고, %d번 나왔습니다.\n",   // 3 · count[3]=3 → "…3이고, 3번 나왔습니다."
        max, count[max]);              // %d 두 개 → max · count[max] 순서

    return 0;                          // 0(정상 종료)을 운영체제에 돌려주고 끝냄
}                                      // main 끝
```
```output
0에서 9까지의 정수를 입력하세요.
3 5 3 7 5 3 -1
0~9중 가장 많이 나온 수는 3이고, 3번 나왔습니다.
```
| 입력 (끝은 -1) | count 배열 | 결과 | 이유 |
|---|---|---|---|
| `3 5 3 7 5 3 -1` | [3]=3 · [5]=2 · [7]=1 | **3이고, 3번** | 3 이 3번으로 가장 많음 |
| `2 4 2 4 -1` | [2]=2 · [4]=2 | **2이고, 2번** | 같으면 `>` 가 거짓이라 **먼저(작은 수)** 가 남음 |
| `12 -5 7 -1` | [7]=1 | **7이고, 1번** | 12 · -5 는 범위 밖이라 안 셈 |
| `0 0 9 -1` | [0]=2 · [9]=1 | **0이고, 2번** | max 시작값 0 이 그대로 답 |
| `-1` (바로 끝) | 모두 0 | **0이고, 0번** | 🤖 하나도 안 넣어도 0 이 답처럼 나옴 → `count[max] == 0` 이면 “입력 없음” 을 찍게 하면 더 정확 |

- **빈도수 배열** — 입력한 수(0~9)를 **칸 번호**로 써서 `count[n]++` → 숫자마다 if 를 10개 쓸 필요가 없음
- **최댓값 찾기 패턴** — `max` 를 첫 칸(0)으로 두고 `i = 1` 부터 비교해 더 크면 바꿈 (배열 최댓값 · 최솟값 문제에 그대로 씀)
- `while (1)` + `break` — 몇 번 입력할지 모를 때 **끝 신호(-1)** 로 멈추는 방법
