## 2. 🔥 Car + CarMain — 생성자 2개 · this
```java
// Car.java + CarMain.java 를 한 파일로 — 🔥 시험범위 (생성자 2개 · this · showInfo)
class Car {                                     // 자동차 설계도(클래스) · public 은 파일 이름과 같은 클래스(연습)에만
    String juin;                                // 필드: 소유주
    String model;                               // 필드: 모델
    int year;                                   // 필드: 연식

    Car() {}                                    // 2-1. 기본 생성자 — 매개변수 없음 · 하는 일 없음
    Car(String juin, String model, int year) {  // 2-2. 매개변수 생성자 — 객체를 만들면서 값까지 넣음
        this.juin = juin;                       // this.juin = 이 객체의 필드 ← 오른쪽 juin = 매개변수 "내차"
        this.model = model;                     // 필드 model ← 매개변수 "BMW M5"
        this.year = year;                       // 필드 year ← 매개변수 2026
    }                                           // 생성자 끝

    void showInfo() {                           // 3. 메소드 — 자기 필드 값을 한 줄로 출력
        System.out.println("소유주 : " + juin + "     모델 : " + model + "     연식 : " + year);   // 칸 사이 공백 5칸
    }                                           // showInfo 끝
}                                               // Car 클래스 끝

public class 연습 {                              // 원래 이름 CarMain → 파일 이름 연습.java
    public static void main(String[] args) {    // 프로그램이 시작되는 main
        Car myCar = new Car("내차", "BMW M5", 2026);   // new → 메모리에 객체 생성 → 매개변수 생성자 호출
        myCar.showInfo();                       // 소유주 : 내차     모델 : BMW M5     연식 : 2026

        Car dadCar = new Car("아빠차", "롤스로이스 팬텀", 2025);   // 두 번째 객체 (myCar 와 따로)
        dadCar.showInfo();                      // 소유주 : 아빠차     모델 : 롤스로이스 팬텀     연식 : 2025

        Car momCar = new Car("엄마차", "페라리 SF90", 2024);   // 세 번째 객체
        momCar.showInfo();                      // 소유주 : 엄마차     모델 : 페라리 SF90     연식 : 2024

        Car empty = new Car();                  // 기본 생성자로 만들면 필드는 기본값 (String → null · int → 0)
        empty.showInfo();                       // 소유주 : null     모델 : null     연식 : 0
    }                                           // main 끝
}                                               // 연습 클래스 끝
```
```output
소유주 : 내차     모델 : BMW M5     연식 : 2026
소유주 : 아빠차     모델 : 롤스로이스 팬텀     연식 : 2025
소유주 : 엄마차     모델 : 페라리 SF90     연식 : 2024
소유주 : null     모델 : null     연식 : 0
```
| 코드 | 뜻 |
|---|---|
| `Car() {}` | **기본 생성자** — 매개변수 없음 · `new Car()` 로 부르면 필드는 기본값(`String` → `null` · `int` → `0`) |
| `Car(String juin, String model, int year)` | **매개변수 생성자** — `new Car("내차", "BMW M5", 2026)` 처럼 만들면서 값까지 넣음 |
| `this.juin = juin;` | **this** = 지금 만들어지는 **이 객체 자신** → 왼쪽 `this.juin` 은 필드, 오른쪽 `juin` 은 매개변수 (이름이 같아서 this 로 구분) |
| 생성자 이름 | **클래스 이름과 같고** 반환형(void · int …)을 쓰지 않음 · 이름은 같고 매개변수가 다른 생성자를 여러 개 = **생성자 오버로딩** |

> ✍️ 수업 코드는 처음에 `myCar.juin="내차";` 처럼 **점(.)으로 필드에 하나씩** 넣다가(주석으로 남김) → **생성자로 한 줄에** 넣는 방식으로 바꿨어요. 두 방법의 결과는 같아요. 마지막 `new Car()` 줄은 🤖 기본 생성자를 보여 주려고 더한 줄이에요.

## 4. 🔥 자바 데이터타입 8가지 · 조건식 true / false
| 분류 | 타입 | 크기 | 범위 (몇부터 몇까지) | 예 |
|---|---|---|---|---|
| 정수 | `byte` | 1바이트 | -128 ~ 127 | `127` |
| 정수 | `short` | 2바이트 | -32,768 ~ 32,767 | `32767` |
| 정수 | **`int`** (정수 기본) | 4바이트 | -2,147,483,648 ~ 2,147,483,647 (약 ±21억) | `2147483647` |
| 정수 | `long` | 8바이트 | -9,223,372,036,854,775,808 ~ 9,223,372,036,854,775,807 (약 ±922경) | `10000000000L` (끝에 **L**) |
| 실수 | `float` | 4바이트 | ±1.4E-45 ~ ±3.4028235E38 · 정확한 자리 약 7자리 | `3.14F` (끝에 **F**) |
| 실수 | **`double`** (실수 기본) | 8바이트 | ±4.9E-324 ~ ±1.7976931348623157E308 · 약 15자리 | `3.14` |
| 문자 | `char` | 2바이트 | 0 ~ 65,535 (음수 없음) | `'A'` (작은따옴표 · 문자 하나) |
| 논리 | `boolean` | 1바이트 | true · false 두 값만 | `true` · `false` |

> 📌 외우는 법 — 정수 4개(byte · short · int · long) + 실수 2개(float · double) + 문자 1개(char) + 논리 1개(boolean) = **8개** · **String 은 기본 타입이 아니라 클래스(레퍼런스 타입)** 라서 8가지에 안 들어가요.

```java
// 🔥 자바 데이터 타입 8가지(기본형) · 조건식 출력 true / false
public class 연습 {                              // 파일 이름 연습.java
    public static void main(String[] args) {    // 시작점
        byte b = 127;                           // 1바이트 정수 (-128 ~ 127)
        short s = 32767;                        // 2바이트 정수
        int i = 2147483647;                     // 4바이트 정수 (정수 기본형)
        long l = 10000000000L;                  // 8바이트 정수 — int 범위를 넘는 수는 끝에 L
        float f = 3.14F;                        // 4바이트 실수 — 끝에 F (없으면 double 이라 오류)
        double d = 3.14;                        // 8바이트 실수 (실수 기본형)
        char c = 'A';                           // 2바이트 문자 하나 — 작은따옴표
        boolean ok = true;                      // 1바이트 논리 — true / false 만
        System.out.println(b + " " + s + " " + i + " " + l);   // 127 32767 2147483647 10000000000
        System.out.println(f + " " + d + " " + c + " " + ok);  // 3.14 3.14 A true
        int score = 85;                         // 점수 85
        System.out.println(score >= 80);        // 조건식 85 >= 80 → true (숫자 1 이 아니라 true 로 출력)
        System.out.println(score == 100);       // 85 == 100 → false
        System.out.println(score > 80 && score < 90);   // true && true → true
    }                                           // main 끝
}                                               // 연습 끝
```
```output
127 32767 2147483647 10000000000
3.14 3.14 A true
true
false
true
```
> 자바의 조건식(관계 · 논리 연산)은 **true / false** 로 출력돼요 — C 언어처럼 1 · 0 이 아니에요.

## 5. class 와 object · 객체지향의 특성 (6주차 복습)
| 구분 | 뜻 |
|---|---|
| **클래스** (class) | 객체를 만들어내기 위한 **설계도 혹은 틀** — 필드(속성) + 메소드(행동) + 생성자 |
| **객체** (object · 인스턴스) | 클래스 모양 그대로 **new 로 찍어낸 실체** · 객체마다 필드 값이 다름 |
| **캡슐화** | 필드와 메소드를 클래스 안에 묶고, 내부를 감춰 보호 |
| **상속** | 부모 클래스의 필드 · 메소드를 자식 클래스가 물려받음 (`extends`) |
| **다형성** | 같은 이름의 메소드가 객체에 따라 다르게 동작 (오버로딩 · 오버라이딩) |

> 자세한 설명 · 붕어빵 비유는 [6주차 5 · 6번](자바프로그래밍-6주차.html)

```java
// 4장-1 예제 1번 — Student.java + StudentMain.java (개인정보는 예시 값으로 바꿈)
class Student {                                 // 학생 설계도
    String name;                                // 이름
    String stuid;                               // 학번 (문자열 — 0 으로 시작해도 안 잘림)
    int age;                                    // 나이
    String phone;                               // 연락처 (- 가 있어서 문자열)

    Student() {                                 // 기본 생성자
    }                                           // 생성자 끝
    Student(String name, String stuid, int age, String phone) {   // 4개를 받는 생성자
        this.name = name;                       // 필드 name ← 매개변수 name
        this.stuid = stuid;                     // 필드 stuid ← 매개변수 stuid
        this.age = age;                         // 필드 age ← 매개변수 age
        this.phone = phone;                     // 필드 phone ← 매개변수 phone
    }                                           // 생성자 끝

    void showInfo() {                           // 정보 출력
        System.out.println("이름 : " + name + "     학번 : " + stuid + "     나이 : " + age + "     전화번호 : " + phone);   // 한 줄
    }                                           // showInfo 끝
}                                               // Student 끝

public class 연습 {                              // 원래 이름 StudentMain
    public static void main(String[] args) {    // 시작점
        Student s1 = new Student("홍길동", "20260001", 20, "010-0000-0001");   // 객체 1
        s1.showInfo();                          // 이름 : 홍길동     학번 : 20260001     나이 : 20     전화번호 : 010-0000-0001
        Student s2 = new Student("성춘향", "20260002", 21, "010-0000-0002");   // 객체 2
        s2.showInfo();                          // 이름 : 성춘향     학번 : 20260002     나이 : 21     전화번호 : 010-0000-0002
    }                                           // main 끝
}                                               // 연습 끝
```

```java
        d1.hungry();                            // 배고파요

        d2.showInfo();                          // 이름 : 둥이     종 : 말티즈     나이 : 20     색깔 : 흰색
        d2.barking();                           // 멍멍 짖는다
    }                                           // main 끝
}                                               // 연습 끝
```

```java
// 4장-1 예제 3번 — Movie.java + MovieMain.java (문제의 필드 이름 · print() 메소드로)
class Movie {                                   // 영화 설계도
    String title;                               // 영화 제목
    double jumsu;                               // 평점 (7.5 처럼 소수 → double)
    String gamdok;                              // 감독
    int year;                                   // 발표된 연도

    Movie() {                                   // 기본 생성자
    }                                           // 생성자 끝
    Movie(String title, double jumsu, String gamdok, int year) {   // 4개를 받는 생성자
        this.title = title;                     // 필드 ← 매개변수
        this.jumsu = jumsu;                     // 10 을 넘기면 double 로 자동 변환 → 10.0
        this.gamdok = gamdok;                   // 필드 ← 매개변수
        this.year = year;                       // 필드 ← 매개변수
    }                                           // 생성자 끝

    void print() {                              // 문제: 모든 정보를 출력하는 print() 메소드
        System.out.println("제목 : " + title + "     평점 : " + jumsu + "     감독 : " + gamdok + "     연도 : " + year);   // 한 줄
    }                                           // print 끝
}                                               // Movie 끝

public class 연습 {                              // 원래 이름 MovieMain
    public static void main(String[] args) {    // 시작점
        Movie m1 = new Movie("영화1", 10, "홍길동", 2004);   // int 10 → double 매개변수 → 10.0
        m1.print();                             // 제목 : 영화1     평점 : 10.0     감독 : 홍길동     연도 : 2004
        Movie m2 = new Movie("영화2", 7.5, "성춘향", 2007);  // 객체 2
        m2.print();                             // 제목 : 영화2     평점 : 7.5     감독 : 성춘향     연도 : 2007
    }                                           // main 끝
}                                               // 연습 끝
```

> ⚠️ **정정 · 보충 (내 수업 파일 ↔ 문제)** — Dog 의 출력이 문제와 달라요: `멍멍!` → **멍멍 짖는다** · `배고프다` → **배고파요** · `Zzz...` → **ZZzz....** / Movie 는 문제가 필드 이름 **title · jumsu · gamdok · year** 와 메소드 **print()** 를 정했는데 수업 파일은 `Mname · score · Pname` · `showInfo()` 예요 → 위 코드는 문제대로 고쳤어요 (실행 결과 모양은 같음) · `double` 필드에 `10` 을 넣으면 **10.0** 으로 출력돼요.
