## 1. ✍️ String 길이 · Math.max · min (Ex1 · 6장 49 · 50 · 60쪽)
```java
public class 연습 {                                             // 원래 이름 Ex1 → 파일 이름도 연습.java
    public static void main(String[] args) {                     // 프로그램 시작
        String school = "동양미래대학교";                          // 리터럴로 만든 문자열
        String dept = new String("컴퓨터소프트웨어공학과");          // new 로 만든 문자열 (6장 43쪽 — 리터럴 · new 두 방법)
        int school_len = school.length();                        // length() = 글자 수 → 한글도 한 글자 = 1 → 7
        System.out.println(school + " 글자수는 " + school_len + "자 입니다.");  // 동양미래대학교 글자수는 7자 입니다.
        int dept_len = dept.length();                            // 컴퓨터소프트웨어공학과 → 11
        System.out.println(dept + " 글자수는 " + dept_len + "자 입니다.");      // … 11자 입니다.
        int i = 5, j = 2;                                        // 비교할 두 수
        System.out.println("큰 값 : " + Math.max(i, j));          // Math.max(5, 2) → 5
        System.out.println("작은 값 : " + Math.min(i, j));        // Math.min(5, 2) → 2
    }                                                            // main 끝
}                                                                // 클래스 끝
```
```output
동양미래대학교 글자수는 7자 입니다.
컴퓨터소프트웨어공학과 글자수는 11자 입니다.
큰 값 : 5
작은 값 : 2
```
- 🤖 자바 `length()` 는 **글자(char) 수** — 한글도 한 글자에 1 (C 의 strlen 처럼 바이트를 세지 않음)
- Math 는 객체를 만들지 않고 `Math.max(…)` 처럼 **클래스 이름으로 바로** 부름 (📄 60쪽 — 모든 메소드가 static)

## 2. ✍️ Math 클래스 (MathEx · 6장 60 ~ 62쪽)
```java
public class 연습 {                                             // 원래 이름 MathEx → 파일 이름도 연습.java
    public static void main(String[] args) {                     // 프로그램 시작
        double a = Math.PI;                                      // 원주율 상수 3.141592653589793
        System.out.println(a);                                   // 3.141592653589793
        System.out.println(Math.ceil(a));                        // 올림 → 4.0 (double)
        System.out.println(Math.floor(a));                       // 내림 → 3.0
        System.out.println(Math.sqrt(9));                        // 제곱근 √9 → 3.0
        System.out.println(Math.exp(2));                         // e² → 7.38905609893065
        System.out.println(Math.round(a));                       // 반올림 → 3 (long · 소수점 없음)
        System.out.print("이번주 행운의 번호는 ");                  // 줄바꿈 없이
        for (int i = 0; i < 5; i++)                              // 5번
            System.out.print((int) (Math.random() * 45 + 1) + " ");  // random() = 0.0 이상 1.0 미만 → ×45 → 0 ~ 44.xx → +1 → (int) 로 버림 → 1 ~ 45
    }                                                            // main 끝
}                                                                // 클래스 끝
```
```output
3.141592653589793
4.0
3.0
3.0
7.38905609893065
3
이번주 행운의 번호는 41 12 24 2 37 
```
- 마지막 줄 숫자 5개는 **실행마다 달라요** (`Math.random()`) · ceil · floor · sqrt 는 double 이라 `.0` 이 붙고 round 는 정수(long)

## 3. ✍️ Calendar — 오늘 날짜 · 시각 (CalendarEx · 6장 63 ~ 68쪽)
```java
import java.util.Calendar;                                       // Calendar 는 java.util 패키지

public class 연습 {                                             // 원래 이름 CalendarEx → 파일 이름도 연습.java
    public static void main(String[] args) {                     // 프로그램 시작
        Calendar now = Calendar.getInstance();                   // new 가 아니라 getInstance() 로 지금 날짜 · 시각을 가진 객체
        int year = now.get(Calendar.YEAR);                       // 연도
        int month = now.get(Calendar.MONTH) + 1;                 // ✍️ “0부터 시작해서 1을 더해줘야함” → 11월은 10 + 1
        int day = now.get(Calendar.DAY_OF_MONTH);                // 일
        int hour = now.get(Calendar.HOUR);                       // 시 — HOUR 는 12시간제 (오후 4시 → 4)
        int minute = now.get(Calendar.MINUTE);                   // 분
        int second = now.get(Calendar.SECOND);                   // 초
        System.out.println(year + "년 " + month + "월 " + day + "일 " + hour + "시 " + minute + "분 " + second + "초");  // 이어 붙여 출력
    }                                                            // main 끝
}                                                                // 클래스 끝
```
```output
2026년 11월 24일 4시 51분 51초
```
- ✍️ 수업 코드는 맨 앞에 `System.out.println(now);` 도 있어요 → `java.util.GregorianCalendar[time=…` 처럼 객체 속 값이 길게 다 찍힘
- 🤖 `Calendar.HOUR` = **12시간제** (오후 4시 → 4) · 24시간제는 `Calendar.HOUR_OF_DAY` (→ 16) · 결과는 실행한 시각마다 달라요

## 4. ✍️ ArrayList — add · get · size · for 와 for-each (ArrayListEx1 · 7장 18 ~ 24쪽)
```java
import java.util.ArrayList;                                      // ArrayList 는 java.util 패키지

public class 연습 {                                             // 원래 이름 ArrayListEx1 → 파일 이름도 연습.java
    public static void main(String[] args) {                     // 프로그램 시작
        ArrayList<Integer> suList = new ArrayList<Integer>();    // 정수를 담는 리스트 (기본 타입 int 대신 Integer)
        suList.add(5);                                           // [5]
        suList.add(4);                                           // [5, 4]
        suList.add(-1);                                          // [5, 4, -1]
        suList.add(2, 100);                                      // 2번 자리에 끼워 넣기 → [5, 4, 100, -1] (뒤는 한 칸씩 밀림)
        System.out.println("리스트 객체 수 : " + suList.size());   // size() = 요소 개수 → 4
        for (int index = 0; index < suList.size(); index++) {    // 인덱스 0 ~ 3
            int result = suList.get(index);                      // get(인덱스) → 그 자리 값 (Integer → int 자동 언박싱)
            System.out.println(result);                          // 5 / 4 / 100 / -1
        }                                                        // for 끝
        System.out.println("위 for문과 아래 for문은 같음");          // ✍️ 수업 코드의 안내 문장
        for (int hangae : suList) {                              // for-each — 앞에서부터 하나씩 꺼냄
            System.out.println(hangae);                          // 5 / 4 / 100 / -1
        }                                                        // for-each 끝
    }                                                            // main 끝
}                                                                // 클래스 끝
```
```output
리스트 객체 수 : 4
5
4
100
-1
위 for문과 아래 for문은 같음
5
4
100
-1
```
- ✍️ 수업 코드는 같은 방법으로 `ArrayList<String> nameList` 에 RM · 진 · 슈가 · 제이홉 · 지민 · 뷔 · 정국 7명도 넣어 출력 (`리스트 객체 수 : 7`)
- ✍️ `nameList.add(1);` — **String 리스트에 정수를 넣으면 컴파일 오류** (제네릭 `<String>` 이 타입을 정해 둠)
- ✍️ 노션 “ArrayList for문 실수 예” — `for (int index = 1; …)` 로 시작하면 **첫 칸(0번)을 건너뜀** → ArrayList 번호도 배열처럼 **0부터**

| 메소드 (📄 7장 20쪽) | 하는 일 |
|---|---|
| `add(값)` · `add(인덱스, 값)` | 맨 뒤에 추가 · 그 자리에 **끼워 넣기** (뒤는 한 칸씩 밀림 · 덮어쓰지 않음) |
| `get(인덱스)` · `size()` | 그 자리 요소 · 요소 **개수** (배열은 `a.length` · String 은 `s.length()`) |
| `remove(인덱스)` · `remove(객체)` | 그 자리 삭제 · 같은 첫 요소 삭제 → 뒤 요소가 앞으로 당겨짐 |
| `indexOf(객체)` · `contains(객체)` | 같은 첫 요소의 인덱스(없으면 **-1**) · 있으면 true |
| `isEmpty()` · `clear()` | 비어 있으면 true · 모든 요소 삭제 |

- 📄 18쪽 — ArrayList = **가변 크기 배열** (java.util) · 기본 타입은 박싱/언박싱으로 **Wrapper 객체**로 저장 · 23쪽 `new ArrayList<>()` (타입 생략) 도 됨
- 📄 21 · 22쪽 오류 — `a.capacity()` 는 없는 메소드 (컴파일 오류) · 요소 4개일 때 `a.add(5, …)` · 3개일 때 `a.remove(4)` → 실행 중 `IndexOutOfBoundsException` (javac · java 확인)
- ⚠️ 20쪽 표의 `elementAt(int index)` 는 **Vector 의 메소드** — ArrayList 에 쓰면 컴파일 오류 (`cannot find symbol` · javac 확인) → `get(인덱스)` 를 씀

## 5. ✍️ ArrayList 에 객체 넣기 · remove · toString (ArrayListEx2 · 6장 31쪽 · 7장)
```java
import java.util.ArrayList;                                      // ArrayList 사용

class Point {                                                    // 점 클래스 (public 없이 같은 파일에)
    private int x, y;                                            // 좌표 (private → 메소드로만 접근)
    Point(int x, int y) {                                        // 생성자
        this.x = x;                                              // this.x = 필드 · x = 매개변수
        this.y = y;                                              // y 도 같게
    }                                                            // 생성자 끝
    @Override                                                    // Object 의 toString 을 다시 정의 (6장 31쪽 예제 6-2)
    public String toString() {                                   // 객체를 출력하면 자동으로 불림
        return "Point [x=" + x + ", y=" + y + "]";               // 예: Point [x=2, y=3]
    }                                                            // toString 끝
}                                                                // Point 끝

public class 연습 {                                             // 원래 이름 ArrayListEx2 → 파일 이름도 연습.java
    public static void main(String[] args) {                     // 프로그램 시작
        ArrayList<Point> ptList = new ArrayList<Point>();        // Point 객체를 담는 리스트
        ptList.add(new Point(2, 3));                             // 0번
        ptList.add(new Point(-5, 20));                           // 1번 (곧 지움)
        ptList.add(new Point(30, -8));                           // 2번
        ptList.add(new Point(1, 2));                             // 3번
        ptList.remove(1);                                        // 1번 (-5, 20) 삭제 → 뒤가 한 칸씩 당겨짐 → 3개
        for (Point p : ptList) {                                 // for-each 로 하나씩
            System.out.println(p);                               // println(객체) → toString() 결과
        }                                                        // for-each 끝
    }                                                            // main 끝
}                                                                // 클래스 끝
```
```output
Point [x=2, y=3]
Point [x=30, y=-8]
Point [x=1, y=2]
```
- ✍️ 수업 코드는 Eclipse 의 Source → Generate 로 getX · setX · getY · setY · toString 을 만들었어요 · 인덱스 for 와 for-each 로 두 번 출력 (사이에 `-` 100개)
- `remove(인덱스)` 는 그 자리를 지우고 **뒤 요소가 앞으로 당겨짐** → 크기 4 → 3
