## 1. 표준 입출력 함수 · 포맷 문자열
✍️ **필기** — 한 개 문자 입력 `getchar()` · 한 개 문자 출력 `putchar()` · 문자열 입력 `gets()` · 문자열 출력 `puts()` · 다양한 타입 입력 `scanf()` · 출력 `printf()`
> ⚠️ **필기 정정** — 노션 필기의 `prinf()` → **`printf()`** (t 가 빠짐)

| 함수 | 하는 일 | 짝 |
|---|---|---|
| `getchar()` | 문자 **1개** 입력 | ↔ `putchar()` 문자 1개 출력 (줄바꿈 없음) |
| `gets()` | **문자열** 입력 (한 줄) | ↔ `puts()` 문자열 출력 + **자동 줄바꿈** |
| `scanf()` | 다양한 타입의 값 입력 (포맷 문자 사용) | ↔ `printf()` 다양한 타입의 값 출력 |

> 🤖 **참고** — `gets()` 는 입력 길이를 검사하지 않아 C11 에서 빠졌어요. Visual Studio 2022 에서는 `gets()` 가 없어서 **`gets_s(문자열, 크기)`** 로 써야 컴파일돼요 (`scanf` 대신 `scanf_s` 와 같은 관계).

### 🤖 포맷 문자열 표 (필기: “claude야 이거 표로 정리해”)
포맷 문자 = `scanf()` 와 `printf()` 에서 `%` 로 값을 넣고 뺄 때 쓰는 문자 (강의자료 4p)

| 포맷 | 뜻 | 자료형 예 | `printf` 결과 예 |
|---|---|---|---|
| `%d` | 부호 **있는** 정수 (10진수) | `int i = -7;` | `-7` |
| `%u` | 부호 **없는** 정수 (0 이상) | `unsigned int j = 7;` | `7` |
| `%f` | 실수 — 소수점 아래 **6자리** | `double d = 3.14159;` | `3.141590` |
| `%0.3f` | 실수 — 소수점 아래 **3자리**까지 (반올림) | `double d = 3.14159;` | `3.142` |
| `%c` | 문자 **1개** | `char c = 'K';` | `K` |
| `%s` | **문자열** | `char s[] = "Hello";` | `Hello` |

### 예제 ① 포맷 문자 한 번에 써 보기
```c
// 포맷 문자 한 번에 써 보기 — %d %u %f %0.3f %c %s
#include <stdio.h>                       // printf 를 쓰기 위한 표준 입출력 헤더
int main(void) {   // (void) = '매개변수 없음'을 확실히 적음 · int main() 은 괄호를 비워 둔 옛 방식 — 실행 결과는 같음
    int i = -7;                          // 부호 있는 정수 -7
    unsigned int j = 7;                  // 부호 없는 정수 7 (0 이상만)
    double d = 3.14159;                  // 실수 3.14159
    char c = 'K';                        // 문자 1개 → 작은따옴표
    char s[] = "Hello";                  // 문자열 → 큰따옴표 (char 배열)
    printf("%%d : %d\n", i);             // %% = % 글자 그대로 · %d → -7
    printf("%%u : %u\n", j);             // %u → 7
    printf("%%f : %f\n", d);             // %f → 소수점 6자리 → 3.141590
    printf("%%0.3f : %0.3f\n", d);       // %0.3f → 소수점 3자리 (넷째 자리 5 에서 반올림) → 3.142
    printf("%%c : %c\n", c);             // %c → K
    printf("%%s : %s\n", s);             // %s → Hello
    return 0;                            // 0(정상 종료)을 운영체제에 돌려주고 끝냄
}                                        // main 함수 끝
```
```output
%d : -7
%u : 7
%f : 3.141590
%0.3f : 3.142
%c : K
%s : Hello
```
### 예제 ② input1.c (수업 코드 · 강의자료 4p) — getchar · putchar — 입력: A
```c
// input1.c (수업 코드 · 강의자료 4p) — getchar() 로 문자 1개 입력 → putchar() 로 출력
#include <stdio.h>                 // printf · getchar · putchar 를 쓰기 위한 표준 입출력 헤더
int main(void) {   // (void) = '매개변수 없음'을 확실히 적음 · int main() 은 괄호를 비워 둔 옛 방식 — 실행 결과는 같음
    printf("문자 입력: ");          // 안내 문구 (\n 없음 → 커서가 같은 줄에 남음)
    char a1 = getchar();           // 키보드에서 문자 1개 → a1 (A 입력 → a1 = 'A')
    printf("a1: %c\n", a1);        // %c = 문자 1개 → a1: A 다음 줄바꿈
    putchar(a1);                   // 문자 1개 출력 → A (putchar 는 줄을 안 바꿈)
    return 0;                      // 0(정상 종료)을 운영체제에 돌려주고 끝냄
}                                  // main 함수 끝
```
```output
문자 입력: A
a1: A
A
```
> 마지막 `putchar(a1);` 은 줄을 바꾸지 않아서 `A` 뒤에 줄바꿈이 없어요 · 입력한 `A` ⏎ 는 화면에 보이는 그대로 적었어요.

### 예제 ③ input2.c (수업 코드 · 강의자료 4p) — %f 와 %0.3f
```c
// input2.c (수업 코드 · 강의자료 4p) — %f 와 %0.3f 의 차이
#include <stdio.h>                 // printf 를 쓰기 위한 표준 입출력 헤더
int main(void) {   // (void) = '매개변수 없음'을 확실히 적음 · int main() 은 괄호를 비워 둔 옛 방식 — 실행 결과는 같음
    float a1 = 11.1111111;         // float 는 유효숫자 약 7자리 → 11.111111 정도로 저장
    printf("a1: %f\n", a1);        // %f = 소수점 아래 6자리까지 → 11.111111
    printf("a1: %0.3f\n", a1);     // %0.3f = 소수점 아래 3자리까지 → 11.111
    return 0;                      // 0(정상 종료)을 운영체제에 돌려주고 끝냄
}                                  // main 함수 끝
```
```output
a1: 11.111111
a1: 11.111
```
> ⚠️ **정정** — 수업 코드 주석은 `/*11.1111111 (%f는 소수점을 모두 출력)*/` 인데, 실제로는 **`%f` = 소수점 아래 6자리까지** → `11.111111` (1 이 6개) · `%0.3f` → `11.111` 은 주석과 같아요.

## 2. 함수 — 정의 · 호출 · return · void
✍️ **필기** — **return 문** = ① **반환값(리턴값)** 을 돌려줌 ② **함수의 종료** · **void 형 = 값이 없음** · **실인수** / **가인수(형식 인수)** · `메서드()` ↔ `속성;` / `함수()` ↔ `변수;` (괄호가 붙으면 실행하는 것, 안 붙으면 값을 담는 것)

| 용어 | 뜻 | `sum(a, b)` · `int sum(int i, int j)` 에서 |
|---|---|---|
| 함수 | 특정한 작업을 처리하도록 작성한 독립된 프로그램 단위 · C 프로그램 = 최소한 `main()` + 필요한 다른 함수 | `sum` |
| 반환형 | 함수 이름 앞 — 돌려줄 값의 자료형 · 없으면 `void` | `int` |
| 실인수 | 호출할 때 넘기는 **실제 값** | `a`(2) · `b`(3) |
| 가인수 (형식 인수 · 매개변수) | 함수 정의의 괄호 안 변수 — 실인수 값이 **복사**됨 | `i` · `j` |
| return | 값을 돌려주고 **그 자리에서 함수 종료** | `return result;` |
| 함수 원형 선언 (prototype) | 함수가 `main()` **뒤에** 있으면 `main()` 앞에 머리만 적어 둠 | `int sum(int i, int j);` |

- 매개변수 없는 함수는 `sum()` 또는 `sum(void)` (강의자료 11p)
- 호출 흐름 (8p) — `s = sum(2, 3);` → sum 으로 이동 → `return` 을 만나면 함수 종료하고 값 반환 → 돌아와서 받은 값을 `s` 에 저장
- main() 4가지 모양 (6p) — `void main(void)` 반환값 없음 · `int main(void)` 인수 없음 · `int main(int argc)` 인수 있음 · main 은 운영체제에 정수를 반환하고 **정상 종료 시 0**

### 예제 ① func1.c (필기 · 강의자료 7p) — ⚠️ 필기 오타를 고친 코드
```c
// func1.c (필기 · 강의자료 7p) — ⚠️ 필기의 오타 3곳을 고친 코드
#include <stdio.h>                       // printf 를 쓰기 위한 표준 입출력 헤더
int sum(int i, int j) {                  // 가인수(형식 인수) i, j ← 실인수 2, 3 이 복사됨 (⚠️ 필기는 i.int j → 쉼표)
    int result = i + j;                  // 2 + 3 → result = 5
    return result;                       // return → 5 를 돌려주고 sum 함수 종료
}                                        // sum 함수 끝
int main(void) {   // (void) = '매개변수 없음'을 확실히 적음 · int main() 은 괄호를 비워 둔 옛 방식 — 실행 결과는 같음
    int a = 2, b = 3;                    // ⚠️ 필기는 a = 2.b = 3 → 쉼표로 구분
    int value;                           // ⚠️ 필기 · 강의자료 모두 선언이 빠짐 → 없으면 컴파일 오류
    value = sum(a, b);                   // 실인수 a(2), b(3) 전달 → 돌려받은 5 를 value 에 저장
    printf("value: %d\n", value);        // value: 5
    return 0;                            // 0(정상 종료)을 운영체제에 돌려주고 끝냄
}                                        // main 함수 끝
```
```output
value: 5
```
> ⚠️ **필기 정정 3곳** — ① `int sum(int i.int j)` → **`int i, int j`** (마침표 → 쉼표) ② `int a = 2.b = 3;` → **`int a = 2, b = 3;`** ③ `value` 를 선언하지 않음 → **`int value;`** 필요 (강의자료 7p 도 선언이 빠져 있어요 — 그대로 치면 컴파일 오류) · `void main()` 은 VS 에서 되지만 시험 답안은 `int main(void)` + `return 0;` 이 안전해요.

### 예제 ② input3.c (수업 코드) — 함수 위치 · 원형 선언 · 반환값
```c
// input3.c (수업 코드) — 함수 정의 위치 · 원형 선언 · 반환값
#include <stdio.h>                       // printf 를 쓰기 위한 표준 입출력 헤더
void test1() {                           // main 보다 위에 정의 → 원형 선언 없이 호출 가능
    printf("test1 함수 호출\n");         // test1 이 하는 일
}                                        // test1 끝 (void → return 값 없음)
void test2();                            // 함수 원형 선언 — 정의가 main 뒤에 있어서 필요
int test3() {                            // 반환형 int → 정수를 돌려줌
    return 100;                          // 100 을 돌려주고 종료
}                                        // test3 끝
int test4(int i, int j) {                // 가인수 i, j
    int result = i + j;                  // 2 + 3 → 5
    return result;                       // 5 를 돌려줌
}                                        // test4 끝
int main(void) {   // (void) = '매개변수 없음'을 확실히 적음 · int main() 은 괄호를 비워 둔 옛 방식 — 실행 결과는 같음
    test1();                             // ① 위로 올라가 test1 실행 → test1 함수 호출
    test2();                             // ② 아래로 내려가 test2 실행 → test2 함수 호출
    int a1 = test3();                    // ③ test3 이 돌려준 100 → a1
    int a2 = test4(2, 3);                // ④ 실인수 2, 3 → 돌려받은 5 → a2
    printf("a1: %d\n", a1);              // a1: 100
    printf("a2: %d\n", a2);              // a2: 5
    return 0;                            // 0(정상 종료)을 운영체제에 돌려주고 끝냄
}                                        // main 함수 끝
void test2() {                           // main 뒤에 정의 → 위에 원형 선언이 있어야 함
    printf("test2 함수 호출\n");         // test2 가 하는 일
}                                        // test2 끝
```
```output
test1 함수 호출
test2 함수 호출
a1: 100
a2: 5
```
> 수업 코드 주석 그대로 — `int main` 이 **먼저 시작**되고, `test1` 을 호출하니 **위로 올라가서** 호출받고, `test2` 를 호출하니 **밑으로 내려가서** 호출받는다 · 정의가 main 뒤에 있는 `test2` 만 위에 **원형 `void test2();`** 가 필요해요.

### 예제 ③ Project1 · E04-func (강의자료 18p) — 원형 선언 + 사칙연산 함수
```c
// Project1 · E04-func (강의자료 18p) — 함수 4개를 main 뒤에 정의 → 원형 선언 4줄
#include <stdio.h>                                // printf 를 쓰기 위한 표준 입출력 헤더
int add(int value1, int value2);                  // 원형 선언 — 덧셈
int sub(int value1, int value2);                  // 원형 선언 — 뺄셈
int mul(int value1, int value2);                  // 원형 선언 — 곱셈
int div(int value1, int value2);                  // 원형 선언 — 나눗셈
int main(void) {   // (void) = '매개변수 없음'을 확실히 적음 · int main() 은 괄호를 비워 둔 옛 방식 — 실행 결과는 같음
    int result1, result2, result3, result4;       // 결과 4개를 담을 변수
    result1 = add(2, 3);                          // 2 + 3 → 5
    result2 = sub(2, 3);                          // 2 - 3 → -1
    result3 = mul(2, 3);                          // 2 * 3 → 6
    result4 = div(2, 3);                          // 2 / 3 → 정수끼리 나누면 몫만 → 0
    printf("result1: %d\n", result1);             // result1: 5
    printf("result2: %d\n", result2);             // result2: -1
    printf("result3: %d\n", result3);             // result3: 6
    printf("result4: %d\n", result4);             // result4: 0
    return 0;                                     // 0(정상 종료)을 운영체제에 돌려주고 끝냄
}                                                 // main 함수 끝
int add(int value1, int value2) {                 // 덧셈 함수 정의
    return value1 + value2;                       // 두 값의 합을 돌려줌
}                                                 // add 끝
int sub(int value1, int value2) {                 // 뺄셈 함수 정의
    return value1 - value2;                       // 두 값의 차를 돌려줌
}                                                 // sub 끝
int mul(int value1, int value2) {                 // 곱셈 함수 정의
    return value1 * value2;                       // 두 값의 곱을 돌려줌
}                                                 // mul 끝
int div(int value1, int value2) {                 // 나눗셈 함수 정의
    return value1 / value2;                       // 정수 나눗셈 → 몫만 돌려줌
}                                                 // div 끝
```
```output
result1: 5
result2: -1
result3: 6
result4: 0
```
> `div(2, 3)` → 정수끼리 나누면 **몫만** → `0` (소수점 버림)

### 예제 ④ Project1 마지막 코드 (수업 코드) — sqrt() 제곱근 — 입력: 16

## 4. 🔥 헤더파일 — Project3 시험문제 (파일 3개)
✍️ **필기** — **“솔루션 밑에 project3 시험문제(파일3개)”** · **“오늘 한 거 다 시험에 나온다 함”** · 3교시 = 헤더파일

| 파일 | 들어 있는 것 | include |
|---|---|---|
| `func.h` | 함수 **원형(선언)** 만 — `int myAbs(int value);` | — |
| `func.c` | 함수 **정의(몸체)** — 절대값 계산 | — |
| `main.c` | `main()` — 입력 · 호출 · 출력 | `#include <stdio.h>` + **`#include "func.h"`** |

- `< >` = 표준 헤더 (컴파일러 폴더에서 찾음) · `" "` = **내가 만든 헤더** (프로젝트 폴더에서 먼저 찾음)
- `#pragma once` = 같은 헤더를 여러 번 include 해도 **한 번만** 읽게 함 (VS 가 헤더 파일을 추가하면 자동으로 넣어 줌)
- VS 실습 방법 (강의자료 17 · 18p) — 솔루션 탐색기 → **소스 파일** 에 `main.c` · `func.c` 추가 / **헤더 파일** 에 `func.h` 추가 · 솔루션명 `w06`

### func.h
```c
// func.h — 함수 원형(선언)만 두는 헤더파일
#pragma once                                      // 헤더 중복 포함 막기
int myAbs(int value);                             // 절대값 함수 원형 — 몸체는 func.c 에
```
### func.c
```c
// func.c — 함수 정의(몸체)만 두는 소스파일 · 절대값 계산 (기억하고 있기)
int myAbs(int value) {                            // 정수 1개를 받아 절대값을 돌려줌
    int iAbs;                                     // 결과를 담을 변수
    if (value > 0) {                              // 양수면 (예: 5 > 0 → 참)
        iAbs = value;                             // 그대로 → 5
    }                                             // if 끝
    else {                                        // 0 이나 음수면 (예: -7)
        iAbs = -value;                            // 부호를 뒤집음 → -(-7) → 7
    }                                             // else 끝
    return iAbs;                                  // 절대값을 돌려주고 종료
}                                                 // myAbs 끝
```
### main.c — 입력: -7 / 5
```c

#include "func.h"                                 // 내가 만든 헤더 → int myAbs(int value); 가 여기 들어옴

    printf("정수를 입력하세요: ");                // 안내 문구 (\n 없음)
    scanf("%d", &iValue);                         // 정수 입력 → iValue (예: -7)
    iResult = myAbs(iValue);                      // func.c 의 myAbs 실행 → 7 을 돌려받음
    printf("%d의 절대값은 %d입니다.\n", iValue, iResult);   // -7의 절대값은 7입니다.
    return 0;                                     // 0(정상 종료)을 운영체제에 돌려주고 끝냄
}                                                 // main 함수 끝
```
