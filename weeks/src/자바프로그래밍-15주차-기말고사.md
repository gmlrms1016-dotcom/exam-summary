## 9주차 · 4장 클래스 — this() · 오버로딩 · 접근 지정자 · static · 객체 배열
| 포인트 | 핵심 · 답 | 그림 |
|---|---|---|
| this() | 같은 클래스의 다른 생성자 호출 · 생성자 안에서만 · **반드시 첫 문장** · `new Book()` → `this("", "")` → 돌아와서 “기본 생성자 호출됨” (출력 첫 줄) | ① |
| 메소드 오버로딩 | 이름 같고 **매개변수 개수 · 타입이 다름** · 리턴 타입은 상관없음 (리턴 타입만 다르면 already defined 오류) · `getSum(1.1, 2.2)` → 3.3000000000000003 | ② |
| ✍️ 접근 지정자 | private(클래스 안) < 디폴트(✍️ 아무것도 안 씀 · 같은 패키지) < protected(같은 패키지 + 자식 클래스) < public(모든 클래스) · 예제 4-10 `aClass.b = 10;` → **b has private access** | ③ |
| ✍️ static | **클래스당 하나** · 클래스 로딩 때 생김 · 모든 객체가 공유 · Counter → gongyuCount **2** · instanceCount 1 · 1 · static 메소드는 non-static 멤버 · this 를 못 씀 · `Calc.abs(-5)` → 5 | ④ |
| 객체 배열 | `Book[] book = new Book[2];` → 칸은 null → `book[i] = new Book(…)` 로 객체 생성 · 빼먹으면 NullPointerException | ⑤ |
| for-each (복습) | `for (int point : pointsArr)` → 80 이상만 82점 · 95점 · 88점 | |

> 자세한 코드 · 실행 결과는 [9주차](자바프로그래밍-9주차.html).
