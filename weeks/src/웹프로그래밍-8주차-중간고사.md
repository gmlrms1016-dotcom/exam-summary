## 5주차 — 함수 · 콜백 · 객체 · 배열 ([5주차 자세히](웹프로그래밍-5주차.html))
- 🔥 **시험문제** — "문제가 생기는 코드 라인을 찍어주시오" (0922_01.js)
```javascript
console.log(imsi);            // ← 문제가 생기는 줄 (ReferenceError: let 선언 전에 사용)
let imsi;
console.log(getArea(5, 5));   // 문제없음 — 선언적 함수는 호이스팅
function getArea(width, height) {
    let area = width * height;
    return area;
}
```
- ⭐ **강조** — **호이스팅**: 선언적 함수는 선언이 맨 위로 끌어올려진 것처럼 동작 → 선언보다 먼저 호출 가능 · `let` 변수와 `let` 에 담은 익명 함수는 선언 전에 쓰면 ReferenceError
- ⭐ **강조** — **콜백 함수** = 다른 함수에 인자로 전달되어서, 나중에 실행되는 함수 · 넘길 때는 괄호 없이 `call2(call1)` (`call1()` 은 실행 결과)
- 객체: 리터럴 `{}` · 점 표기법 `person.name` / 대괄호 `person["age"]` · 속성 추가 `person.job = …` · 삭제 `delete` · `const` 객체는 통째로 재대입 X, 속성 추가·수정 O
- 배열: 리터럴 `[]` · 번지는 0 부터 · `arr.length` = 요소 개수

## 4주차 — 연산자 · truthy/falsy · 단락 평가 ([4주차 자세히](웹프로그래밍-4주차.html))
- ⭐ **강조** — Node.js = 자바스크립트를 **브라우저 밖에서도 단독으로 실행**할 수 있게 해 주는 런타임 실행 플랫폼 **(주관식)**

| 언어 | 주석 문법 |
|---|---|
| HTML | `<!-- 주석 -->` |
| CSS | `/* 주석 */` (한 줄 `//` 없음) |
| JavaScript | `// 한 줄` · `/* 여러 줄 */` |

- 📝 **교수님 메모** — 연산자 9가지: 대입 / 산술 / 복합 대입 / 증감 / 논리 / 비교 / null 병합 / typeof / 삼항
- ⭐ **강조** — 전위 `++num8` 먼저 증가 후 사용 / 후위 `num8++` 먼저 사용 후 증가 → `let num8 = 10; console.log(num8++);` 은 **10**, 이어서 `console.log(++num8);` 은 **12**
- ⭐ **강조** — `==` 형변환 후 값만 비교(`"10" == 10` → true) / `===` 값과 타입 모두 비교(`"10" === 10` → false)
- 📝 **교수님 메모** — **Truthy와 Falsy**: 참·거짓이 아닌 값도 조건문 안에서는 참 또는 거짓으로 판단되는 값 · **단락평가**: `&&` `||`
- ⭐ **강조** — falsy 8가지: `false` `0` `-0` `0n` `""` `null` `undefined` `NaN` (나머지는 모두 truthy, `"0"` `[]` `{}` 도 truthy)
- ⭐ **강조** — `A || B`: A 가 falsy 면 B / `A && B`: A 가 truthy 면 B · `&` 는 비트 연산자라 양쪽을 **모두** 계산
- `??` 는 왼쪽이 null·undefined 일 때만 오른쪽 (`0 ?? 5` → 0) · `typeof true` → "boolean" · 삼항 `조건 ? 참 : 거짓`
- 형변환: `10 + "20"` → `"1020"` · `Number("10") + 20` → 30 · `prompt()` 값은 항상 **문자열**
- `querySelector("#id")` 는 CSS 선택자로 첫 요소 선택 · id = JS / class = CSS / name = 백엔드
- 매개변수 = 함수 **정의** 때 괄호 안 변수 / 인수 = **호출** 때 넘기는 값

## 3주차 — 변수 · 자료형 · 형변환 ([3주차 자세히](웹프로그래밍-3주차.html))
- ⭐ **강조** — 변수 선언 키워드: `var`(재선언 가능) / `let`(재선언 불가) / `const`(상수, 값 변경 불가)
- ⭐ **강조** — 원시형: String · Number · Boolean (+ null, undefined) / 참조형: 객체
- ✍️ **필기** — 기본 데이터타입 5종: 문자열 · 숫자 · 부울린 · undefined · null / null = 의도적으로 비운 값, undefined = 값을 넣지 않은 상태
- ⭐ **강조** — 객체 = 사용자정의 객체 + 내장 객체
- ⭐ **강조** — 명시적 형변환 `String()` `Number()` `Boolean()` / 묵시적 형변환 `"10" + 5` → `"105"`
- ⭐ **강조** — 템플릿 문자열: 백틱 안에 `${ }` → `` `273 + 52의 값은 ${273 + 52}입니다` ``
- ✍️ **필기** — 스택 = 원시형 값 / 힙 = 참조형(객체)
