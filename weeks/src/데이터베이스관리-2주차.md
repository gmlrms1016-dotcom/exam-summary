## 1. 데이터베이스 정의 4대 특징 ★핵심암기
- ⭐ **강조** — 공유(shared data): 여러 응용시스템이 함께 사용
- ⭐ **강조** — 통합(integrated data): 중복의 최소화
- ⭐ **강조** — 저장(stored data): 저장장치에 저장
- ⭐ **강조** — 운영(operational data): 조직 운영에 필요한 데이터
- DBMS: 데이터베이스를 관리하는 시스템 소프트웨어 (MySQL, Oracle, MS SQL, MariaDB, PostgreSQL 등)

## 2. 자료형 (필기 정리)
- ✍️ **필기** — 1 byte = 8 bit / 문자형 = 1 byte / 정수형 = 4 byte = 32bit
- ✍️ **필기** — 문자형: 고정문자열 char(n) (예 주민번호) · 가변문자열 varchar(n) (예 주소·영화제목)
- 숫자형: 정수 / 실수

## 3. MySQL 실습 4단계 ★핵심
- ⭐ **강조** — 1단계 데이터베이스(스키마) 생성 → 2단계 테이블 생성 → 3단계 데이터 입력 → 4단계 데이터 조회
- ✍️ **필기** — 주의: 들여쓰기는 Tab 말고 Spacebar 4번
```sql
CREATE DATABASE testdb DEFAULT CHARACTER SET utf8mb4;
USE testdb;
CREATE TABLE 학생(
  학번 int NOT NULL,
  이름 varchar(30) NOT NULL,
  성적 int,
  지도교수 char(2),
  PRIMARY KEY(학번)
);
insert into 학생 values('100','Kim',92,'P1');
select * from 학생;
```
- PRIMARY KEY(기본키): 각 행을 유일하게 구분하는 열 (예: 학번, 고객번호)
- GUI 입력 시: 데이터 입력 후 오른쪽 하단 `Apply` 를 눌러야 저장됨
