## ① 🔥 기말고사 — 오류 수정: 배열 크기는 컴파일 시간에 (4쪽)
✍️ 노션 “다음 코드를 보고 오류가 나는 곳을 수정하시오 — 1. 컴파일 시간 2. 런타임”

📄 4쪽 주의 — 오류 나는 코드
```c
int count = 10;          // count 는 '변수' → 값이 실행할 때(런타임) 정해짐
short student[count];    // ❌ error — 배열 칸 수는 컴파일할 때 알아야 하는데 변수로 줌
```
✅ 고친 코드 ① — 칸 수를 **숫자(상수)** 로
```c
short student[10];       // ✅ ok — 10 은 컴파일 시간에 정해진 값
```
✅ 고친 코드 ② — ✍️ **`#define`** 으로 이름 붙인 상수
```c
#define MAX 10           // 전처리기가 컴파일 전에 MAX 를 10 으로 바꿈
short student[MAX];      // ✅ ok — 컴파일러가 보는 코드는 short student[10];
```
- 📄 4쪽 — **일반 변수**는 컴파일 시간에 자료형으로 크기가 정해지지만, **배열 변수**는 크기를 알아야 하므로 **원소 개수를 컴파일 시간 전에 알 수 있어야** 한다 → `자료형 배열명[원소개수];`
- 🤖 “1. 컴파일 시간 2. 런타임” = 배열 칸 수는 **컴파일 시간**에 정해져야 하는데 `count` 는 **실행(런타임)** 때 값이 정해지는 변수라서 오류
- ⚠️ 팩트체크 — **Visual Studio(수업 환경)는 컴파일 오류** (C2057 상수 식이 필요합니다). 🤖 gcc · clang 은 C99 의 **가변 길이 배열(VLA)** 로 지역 배열이면 통과해요 (직접 확인: `clang -std=c11` 통과 · `-std=c89 -pedantic-errors` 는 “variable length arrays are a C99 feature” 오류) → 시험 답은 수업대로 **상수로 고치기**

## ② 🔥 기말고사 — 9쪽 [실습 1-01] 매개변수가 배열 타입 (외우기)
📄 9쪽 · ✍️ “매개변수에 배열을 보냄 · `printf("%d", );` · `printf("%p", );`”
```c
// w11-ex01_01-array.c
#include <stdio.h>                                  // printf 를 쓰기 위한 표준 입출력 헤더

void test(int v1[]) {                               // 매개변수가 배열 타입 — 받는 것은 배열의 '시작 주소'
    int i;                                          // 반복에 쓸 첨자
    for (i = 0; i < 5; i++) {                       // i = 0 → 4 (5번)
        printf("v1[%d]: %d\n", i, v1[i]);           // v1[0] = 보낸 배열의 0번 칸 → 10 (array2 면 100) …
    }                                               // for 끝
}                                                   // test 끝 (반환값 없음 → void)

int main() {   // 원본 그대로 int main() — 괄호를 비워 둔 옛 방식 · int main(void) = '매개변수 없음'을 확실히 적음 — 실행 결과는 같음
    int array1[] = {10, 20, 30, 40, 50};            // 크기 생략 → 값 5개라 5칸
    int array2[] = {100, 200, 300, 400, 500};       // 5칸
    test(array1);                                   // 배열 이름 = 시작 주소 → test 의 v1 이 array1 을 가리킴
    printf("--------------------\n");               // 구분선
    test(array2);                                   // 이번엔 array2 의 시작 주소 → 100 ~ 500 출력
    return 0;                                       // 0(정상 종료)을 운영체제에 돌려주고 끝냄
}                                                   // main 끝
```
```output
v1[0]: 10
v1[1]: 20
v1[2]: 30
v1[3]: 40
v1[4]: 50
--------------------
v1[0]: 100
v1[1]: 200
v1[2]: 300
v1[3]: 400
v1[4]: 500
```
- 함수에 배열을 보낼 때는 **배열 이름만** (`test(array1)` · 대괄호 X) → 📄 8쪽 “함수 호출할 때 배열의 주소값을 전달하면 함수 안에서 배열을 사용할 수 있다”
- ✍️ `printf("%d", )` = **값**(정수) · `printf("%p", )` = **주소**(포인터) — 🤖 함수 안에서 `printf("%p\n", v1);` 을 찍으면 main 의 `printf("%p\n", array1);` 과 **같은 주소** (주소 자체는 실행마다 다름)

## ③ 🔥 기말고사 — 12쪽 [실습 1-03] 매개변수가 포인터 (외우기)
```c
// w11-ex01_03-pointer.c
#include <stdio.h>                                  // printf 를 쓰기 위한 표준 입출력 헤더

void test(int* v1) {                                // 매개변수가 포인터 — int 칸의 주소를 받음 (9쪽 int v1[] 와 같은 뜻)
    int i;                                          // 반복에 쓸 첨자
    for (i = 0; i < 5; i++) {                       // i = 0 → 4 (5번)
        printf("*(v1 + %d): %d\n", i, *(v1 + i));   // v1 + i = i칸 뒤 주소 → * 로 그 칸의 값 → 10, 20 … (array2 면 100 …)
    }                                               // for 끝
}                                                   // test 끝

int main() {   // 원본 그대로 int main() — 괄호를 비워 둔 옛 방식 · int main(void) = '매개변수 없음'을 확실히 적음 — 실행 결과는 같음
    int array1[] = {10, 20, 30, 40, 50};            // 5칸
    int array2[] = {100, 200, 300, 400, 500};       // 5칸
    test(array1);                                   // array1 의 시작 주소를 v1 에
    printf("--------------------\n");               // 구분선
    test(array2);                                   // array2 의 시작 주소를 v1 에
    return 0;                                       // 0(정상 종료)을 운영체제에 돌려주고 끝냄
}                                                   // main 끝
```
```output
*(v1 + 0): 10
*(v1 + 1): 20
*(v1 + 2): 30
*(v1 + 3): 40
*(v1 + 4): 50
--------------------
*(v1 + 0): 100
*(v1 + 1): 200
*(v1 + 2): 300
*(v1 + 3): 400
*(v1 + 4): 500
```
| | 9쪽 (배열 타입) | 12쪽 (포인터) |
|---|---|---|
| 매개변수 | **`int v1[]`** | **`int* v1`** |
| 칸 읽기 | **`v1[i]`** | **`*(v1 + i)`** |
| 출력 서식 | `"v1[%d]: %d\n"` | `"*(v1 + %d): %d\n"` |
| 받는 것 | 둘 다 **배열의 시작 주소** → 결과 값은 같음 (10 ~ 50 / 100 ~ 500) | |

## ④ 🔥 기말고사 — 강의자료에 없음 · 숫자만 바꿔서 (✍️ w11-ex01_05-pointer-03.c)
✍️ 수업 파일 맨 위 주석 “(강의자료에 없음)(숫자만 바꿔서 기말고사 시험문제)”
```c
// w11-ex01_05-pointer-03.c
#include<stdio.h>                                   // printf (< 앞 공백은 없어도 됨)

int main() {   // 원본 그대로 int main() — 괄호를 비워 둔 옛 방식 · int main(void) = '매개변수 없음'을 확실히 적음 — 실행 결과는 같음
    int a1 = 100;                                   // 일반 변수 a1 = 100
    int* a2 = &a1;                                  // 포인터 변수 a2 = a1 의 '주소' → a2 가 a1 을 가리킴
    int a3 = a1;                                    // 일반 변수 a3 = a1 의 '값' 100 을 복사 (주소 X)

    a3 = 1000;                                      // a3 만 1000 으로 → 복사본이라 a1 은 그대로 100
    printf("a1: %d\n", a1);                         // a1 = 100 → "a1: 100"
    printf("a3: %d\n", a3);                         // a3 = 1000 → "a3: 1000"

    *a2 = 2000;                                     // a2 가 가리키는 곳(= a1)에 2000 → a1 이 2000 으로 바뀜
    printf("a1: %d\n", a1);                         // a1 = 2000 → "a1: 2000"
    printf("*a2: %d\n", *a2);                       // *a2 = a2 가 가리키는 a1 의 값 = 2000 → "*a2: 2000"

    return 0;                                       // 0(정상 종료)을 운영체제에 돌려주고 끝냄
}                                                   // main 끝
```
```output
a1: 100
a3: 1000
a1: 2000
*a2: 2000
```
| 줄 | a1 | a3 | a2 (가리키는 곳) | 핵심 |
|---|---|---|---|---|
| `int a1 = 100;` | 100 | | | |
| `int* a2 = &a1;` | 100 | | **a1** | `&` = 주소 |
| `int a3 = a1;` | 100 | 100 | a1 | **값만 복사** |
| `a3 = 1000;` | **100** | 1000 | a1 | 복사본을 바꿔도 a1 은 그대로 |
| `*a2 = 2000;` | **2000** | 1000 | a1 | `*a2` 에 쓰면 = **a1 에 쓰는 것** |

- 🔥 숫자만 바꿔 연습 — `a1 = 7` · `a3 = 70` · `*a2 = 700` 이면 → `a1: 7` · `a3: 70` · `a1: 700` · `*a2: 700`
- 🤖 일반 변수 복사(`a3 = a1`)는 **따로 노는 사본** · 포인터(`a2 = &a1`)는 **같은 칸을 가리키는 열쇠** → ✍️ “일반 변수 = 값(value) · 참조 변수 = 방의 주소(key)”

## 1. ✍️ [이론] 배열 · 포인터 (노션 + 4 · 8 · 10 · 14쪽 · 교수님 엑셀)
- ✍️ **배열 변수 = 주소 값을 가지고 있다** · **배열명 == 배열의 시작 주소** · `[]` 를 사용
- ✍️ `int count[5];` → `count == &count[0]` · ⚠️ 필기 “`count ==&count[0],&count[1],&count[2],&count[3],&count[4]`” 는 칸마다 주소가 있다는 뜻 — 정확히는 `count == &count[0]` 이고 **`count + i == &count[i]`**
- 📄 4쪽 — 배열 = 같은 자료형의 기억장소가 **연속적**으로 나열 · 1차원 `int student1[5];` (한 학생 국 · 영 · 수 · 총점 · 평균) · 2차원 `int student2[50][5];` (한 반 50명) · 3차원 `int student2[3][50][5];` (3개 반)
- 📄 10쪽 — 배열의 주소값 = 포인터 변수 · 배열은 `[ ]` 로도, **포인터 변수로도** 관리 가능 · 배열 주소를 가진 포인터는 **첫 번째 칸**을 가리킴 (+0 · +1 · +2 …)

🖥️ 교수님 엑셀 (사진) — `int array1[5] = {10,20,30,40,50};`

| 첨자 | [0] | [1] | [2] | [3] | [4] |
|---|---|---|---|---|---|
| 값 | 10 | 20 | 30 | 40 | 50 |
| 주소 (예) | 100 | 104 | 108 | 112 | 116 |
| 포인터 | +0 | +1 | +2 | +3 | +4 |

- 배열 변수 **`array1 == &array1[0]`** · 포인터 변수 **`*(array1 + 0) == array1[0]`** … **`*(array1 + 4) == array1[4]`**
- 🤖 주소가 4씩 늘어나는 이유 = `int` 1칸 = **4바이트** · `array1 + 1` 은 주소 +1 이 아니라 **한 칸(4바이트) 뒤**

✍️ 포인터
- ✍️ **포인터 변수 = 주소 값을 가지고 있는 변수**
- ✍️ 자료형 ① **일반 변수** = 값을 저장 (value) — short · int · float · char ② **참조 변수** = 방의 주소를 저장 (key) — **주소 지정 연산자 `&`** · **포인터 연산자 `*`**
- 📄 14쪽 — 포인터 변수 선언은 **`*` 를 붙여서** · 담을 주소는 **`&` 연산자**로 · 사용할 때 `*` 를 붙이면 그 주소의 기억장소에 접근 · **기본자료형 변수 = 일반 변수** · **참조자료형 변수 = 포인터 변수**
- ✍️ 진도 — **11주차** 배열 + 함수(1교시) · 배열 · 포인터 / **12주차** 함수 포인터 · 함수에서 포인터 사용

## 2. [실습 1-02] 포인터로 배열 읽기 (11쪽)
```c
// w11-ex01_02-pointer.c
#include <stdio.h>                                  // printf 를 쓰기 위한 표준 입출력 헤더

int main() {   // 원본 그대로 int main() — 괄호를 비워 둔 옛 방식 · int main(void) = '매개변수 없음'을 확실히 적음 — 실행 결과는 같음
    int array1[] = { 10, 20, 30, 40, 50 };          // 5칸
    printf("array1[0]: %d\n", array1[0]);           // 첨자로 0번 칸 → 10
    printf("array1[1]: %d\n", array1[1]);           // 1번 칸 → 20
    printf("array1[2]: %d\n", array1[2]);           // 2번 칸 → 30
    printf("--------------------\n");               // 구분선
    printf("*(array1 + 0): %d\n", *(array1));       // array1 = 시작 주소 → * 로 그 칸 = 10 (글자는 + 0 이지만 코드는 *(array1))
    printf("*(array1 + 1): %d\n", *(array1 + 1));   // 시작 주소 + 1칸 → 20
    printf("*(array1 + 2): %d\n", *(array1 + 2));   // 시작 주소 + 2칸 → 30
    printf("--------------------\n");               // 구분선
    for (int i = 0; i < 5; i++)                     // i = 0 → 4 (for 안에서 i 선언 — C99 부터)
        printf("array1[%d]: %d\n", i, array1[i]);   // 첨자로 → 10 ~ 50
    printf("--------------------\n");               // 구분선
    for (int i = 0; i < 5; i++) {                   // 같은 일을 포인터로
        printf("*(array1 + %d): %d\n", i, *(array1 + i));   // *(array1 + i) == array1[i] → 10 ~ 50
    }                                               // for 끝
    return 0;                                       // 0(정상 종료)을 운영체제에 돌려주고 끝냄
}                                                   // main 끝
```

## 3. 🔥 [실습 1-04] 함수가 배열을 돌려줄 때 — `static` (13쪽)
📄 8쪽 “함수 안에서 배열의 주소값을 반환하면, 함수를 호출한 쪽에서 배열 사용할 수 있다” — 단, **지역 배열**이면 함수가 끝날 때 사라져요.

✅ `static` 을 붙인 코드 (✍️ 수업 파일 `w11-ex01_04-pointer-static.c`)
```c
// w11-ex01_04-pointer-static.c
#include <stdio.h>                                  // printf 를 쓰기 위한 표준 입출력 헤더

int* test2() {                                      // 반환형 int* = int 칸의 주소를 돌려줌 (함수 반환타입으로 배열을 넘긴 경우)
    static int array2[3] = {1,2,3};                 // static → 함수가 끝나도 사라지지 않는 배열 (프로그램 끝까지 유지)
    return array2;                                  // 배열 이름 = 시작 주소를 돌려줌
}                                                   // test2 끝 — array2 는 그대로 남아 있음

int main() {   // 원본 그대로 int main() — 괄호를 비워 둔 옛 방식 · int main(void) = '매개변수 없음'을 확실히 적음 — 실행 결과는 같음
    int *array3 = test2();                          // 돌려받은 주소를 포인터 array3 에
    for(int i = 0; i < 3; i++)                      // i = 0 → 2
        printf("*(array3 + %d): %d\n",              // 서식 — 칸 번호와 값
                      i, *(array3 + i));            // array2 의 i번 칸 → 1, 2, 3
    return 0;                                       // 0(정상 종료)을 운영체제에 돌려주고 끝냄
}                                                   // main 끝
```

## 4. [실습 2-01] 포인터 변수 `&` · `*` (16쪽)

// w11-ex01_05-pointer-01.c

## 5. [실습 2-02] 함수에서 포인터로 값 돌려받기 (17쪽)
```c
// w11-ex01_07-pointer-2.c
#include <stdio.h>                                  // printf 를 쓰기 위한 표준 입출력 헤더

int test1() {                                       // 값 하나는 return 으로 돌려줄 수 있음
    return 100;                                     // 100 을 돌려줌
}                                                   // test1 끝

void test2(int* v1) {                               // 주소를 받아서 그 칸에 직접 씀
    *v1 = 100;                                      // v1 이 가리키는 곳(= main 의 a2)에 100
}                                                   // test2 끝

void test3(int* v1, int* v2) {                      // 주소 2개 → 값 2개를 한 번에 돌려받는 효과
    *v1 = 1000;                                     // 첫 번째 주소(= a3)에 1000
    *v2 = 2000;                                     // 두 번째 주소(= a4)에 2000
}                                                   // test3 끝

int main() {   // 원본 그대로 int main() — 괄호를 비워 둔 옛 방식 · int main(void) = '매개변수 없음'을 확실히 적음 — 실행 결과는 같음
    int a1 = test1();                               // return 값 100 → a1 = 100
    printf("a1: %d\n", a1);                         // "a1: 100"

    int a2;                                         // 아직 값 없음
    test2(&a2);                                     // a2 의 주소를 보냄 → 함수가 a2 에 100 을 씀
    printf("a2: %d\n", a2);                         // "a2: 100"

    int a3;                                         // 아직 값 없음
    int a4;                                         // 아직 값 없음
    test3(&a3, &a4);                                // 주소 2개 → a3 = 1000 · a4 = 2000
    printf("a3: %d\n", a3);                         // "a3: 1000"
    printf("a4: %d\n", a4);                         // "a4: 2000"

    return 0;                                       // 0(정상 종료)을 운영체제에 돌려주고 끝냄
}                                                   // main 끝
```
```output
a1: 100
a2: 100
a3: 1000
a4: 2000
```
- ⚠️ 슬라이드(17쪽)는 `int test2(int* v1)` · `int test3(…)` 인데 **return 이 없어요** → 돌려줄 값이 없는 함수는 **`void`** 가 맞음 (✍️ 수업 파일처럼) · 🤖 VS 는 C4716(값을 반환해야 합니다) 경고
- 🤖 `return` 은 값을 **하나만** 돌려줄 수 있음 → 여러 값을 돌려받고 싶으면 **주소를 보내서** 함수가 직접 쓰게 (test3)

## 6. [실습 3-01] 포인터 변수 `NULL` (18쪽)
📄 18쪽 왼쪽 — 주소를 넣지 않은 포인터
```c
int *pt;                 // ❌ 주소를 안 넣음 → 예상하지 못한 값(쓰레기 주소)
printf("pt: %p\n", pt);  // 수업 PC: pt: CCCCCCCCCCCCCCCC
```
📄 18쪽 오른쪽 — **`NULL`** 을 넣은 포인터
```c
// w11-ex01_06-pointer-null.c
#include <stdio.h>                                  // printf · NULL 을 쓰기 위한 표준 입출력 헤더

int main() {   // 원본 그대로 int main() — 괄호를 비워 둔 옛 방식 · int main(void) = '매개변수 없음'을 확실히 적음 — 실행 결과는 같음
    int *pt = NULL;                                 // 아직 가리킬 곳이 없으면 NULL(의미가 없는 값 = 주소 0)
    printf("pt: %p\n", pt);                         // NULL 주소 → Windows 0000000000000000 · 맥 0x0
    return 0;                                       // 0(정상 종료)을 운영체제에 돌려주고 끝냄
}                                                   // main 끝
```
▶ 수업 PC 실행 결과
```output
pt: 0000000000000000
```
- 📄 포인터 변수를 선언하고 주소값을 넣지 않을 때는 **NULL** 을 넣어 준다 — 안 넣으면 **예상하지 못한 값**이 들어 있을 수 있음
- 📄 **NULL = 의미가 없는 값** · 기본자료형은 **void** · 참조자료형은 **NULL** 사용
- ✍️ 수업 PC — 왼쪽 코드는 Visual Studio 가 **SDL 검사(C4700 초기화되지 않은 지역 변수)** 로 빌드를 막고, 풀어도 **런타임 검사(Run-Time Check Failure #3)** 창이 떠요 → 그 프로젝트만 둘 다 끄고 실행하니 `CCCCCCCCCCCCCCCC` (🤖 디버그 모드가 빈 공간에 채우는 값)
- 🤖 맥(clang)은 `0x0` 으로 찍혀요 — `%p` 모양은 컴퓨터마다 다름

### Quiz 3번 (포인터) — q-pointer02.c · 실행 결과와 실행 순서
```c
// q-pointer02.c
#include <stdio.h>                                  // printf 를 쓰기 위한 표준 입출력 헤더

void func(int* a) {                                 // 배열의 시작 주소를 받음 → a 로 바꾸면 main 의 arr1 이 바뀜
    int x = 1;                                      // 한 번에 움직일 칸 (처음엔 +1)
    for (int i = 0; i >= 0; i += x) {               // i 가 0 이상인 동안 x 만큼 이동

        if (i >= 4)                                 // 끝 칸(4)에 닿으면
            x = -1;                                 // 방향을 거꾸로 (-1)
    }                                               // for 끝 — i = -1 이 되면 멈춤
}                                                   // func 끝

int main(void) {   // 원본은 main() — 반환형을 안 쓴 옛 C → int main(void) 로
    int arr1[] = {1,2,3,2,1};                       // arr1[0] ~ arr1[4]
    func(arr1);                                     // 시작 주소를 보냄 → 함수가 arr1 을 직접 바꿈
    for (int i = 4; i >= 0; i--) {                  // 4번 칸부터 거꾸로
        printf("%d ", arr1[i]);                     // 값 + 공백
    }                                               // for 끝
    return 0;                                       // 0(정상 종료)을 운영체제에 돌려주고 끝냄
}                                                   // main 끝
```

## 9. 한 줄 정리
- 🔥 **배열 칸 수 = 컴파일 시간에 정해져야** → `short student[count];` ❌ → `short student[10];` · `#define MAX 10` → `short student[MAX];` ✅ (Visual Studio)

- 🔥 함수에 배열 = **이름(주소)만** 보냄 — 9쪽 `void test(int v1[])` + `v1[i]` / 12쪽 `void test(int* v1)` + `*(v1 + i)` → 결과 같음
- 포인터 변수 = 주소를 가진 변수 · **`&` 주소 지정 연산자** · **`*` 포인터 연산자**(선언할 때 · 값을 읽고 쓸 때) · `%p` = 주소 출력
- 🔥 `int* a2 = &a1;` → **`*a2 = 2000;` 은 a1 을 바꿈** · `int a3 = a1;` 은 값만 복사 (pointer-03 · 숫자만 바뀜)
