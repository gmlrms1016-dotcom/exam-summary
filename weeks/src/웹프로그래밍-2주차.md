# <9월 1일> 실행단계·이벤트·함수·객체

> 자료: 필기.png · first.html · eClass 강의노트(9/1)

## 1. 웹문서를 웹브라우저로 실행하는 단계 ★필수암기
- ⭐ **강조** — DOM 트리 → 렌더 트리 → 페인팅(Painting) → 결과 화면
  - 브라우저는 HTML을 파싱해 DOM 트리를 만들고, CSS와 결합해 렌더 트리를 구성한 뒤 페인팅하여 화면에 출력
- ✍️ **필기** — 리플로우(Reflow): 요소의 넓이·크기·배치를 다시 계산·조정하는 과정
- ✍️ **필기** — 리페인트(Repaint): 요소의 색상·모양을 다시 그리는 과정

## 2. 이벤트(Event) 4요소 ★필수암기
- ⭐ **강조** — 이벤트 · 이벤트 소스 · 이벤트 핸들러(=이벤트 리스너) · 이벤트 객체
  - 이벤트: 웹에서 발생하는 사건(클릭 등)
  - 이벤트 소스: 이벤트가 발생한 근원지 (예: button)
  - 이벤트 핸들러(리스너): 이벤트 처리 방법을 담은 코드를 등록
  - 이벤트 객체: 발생한 이벤트의 정보를 담은 객체

## 3. 함수 선언 방법 3가지 ★필수암기
- ⭐ **강조** — ① 선언적 함수 — `function btnClick(){ ... }` 로 선언, `btnClick();` 로 호출
```javascript
function btnClick(){
    ...
}
btnClick();  // 호출
```
- ⭐ **강조** — ② 표현적 함수(익명 함수) — 변수에 함수를 대입
```javascript
let btnClick = function(){
    ...
};
btnClick();  // 호출
```
- ⭐ **강조** — ③ 화살표 함수 — function 키워드를 화살표 `=>` 로 축약
```javascript
let btnClick = () => {
    ...
};
btnClick();  // 호출
```
- ✍️ **필기** — 함수도 데이터(값)처럼 변수에 담아 넘겨줄 수 있다 (일급 객체)

## 4. 객체(Object)의 구성요소 ★필수암기
- ⭐ **강조** — 객체의 구성요소 = 속성(변수) + 메서드(함수)
- ✍️ **필기** — 속성(Property) = 객체가 가진 값(변수), 메서드(Method) = 객체가 하는 동작(함수)
- ⭐ **강조** — 비유: 붕어빵틀 = 클래스(Class) / 붕어빵 = 객체(Object)
  - 즉 클래스는 설계도(틀), 객체는 그 틀로 찍어낸 실체(인스턴스)

## 5. HTML 태그 중첩
- ✍️ **필기** — 태그 안에 태그를 설정하는 것을 '중첩'이라고 한다 (예: `<div><h1></h1></div>`)
- 파싱(Parsing) = 분석 / 크롤링(Crawling) = 콘텐츠를 긁어오는 것
