## 1. 웹프로그래밍이란 / 프런트엔드 vs 백엔드
- ✍️ **필기** — 프런트엔드(Front-end): 클라이언트(웹브라우저)에서 실행되는 기술
- ✍️ **필기** — 백엔드(Back-end): 서버에서 실행되는 기술
- 웹서비스 프로세스: 클라이언트(브라우저)가 URL로 요청(Request) → 서버가 처리 → 결과를 응답(Response)
  - 요청 예: http://naver.com/news.html → 해당 서버 IP로 접속하여 문서를 받아옴
- 웹서버는 웹 애플리케이션을 실행하여 브라우저가 요청한 기능을 수행한 뒤 결과를 브라우저에 응답한다

## 2. 정적 페이지 vs 동적 페이지
- 정적(Static) 콘텐츠: 변하지 않는 콘텐츠 (예: news.html 파일을 그대로 전달)
- 동적(Dynamic) 콘텐츠: 서버에서 동적으로 만들어진 변화 있는 콘텐츠 (예: login.jsp → '홍길동, 안녕!')
  - 동적 처리 흐름: 요청 → 컨테이너(Container)에서 실행코드 실행 → DB 연동 → 결과(html 또는 data 형식) 응답 → 브라우저가 렌더링
- ⭐ **강조** — MPA vs SPA: Multi Page Application(여러 페이지) vs Single Page Application(단일 페이지)
  - 결과 형식: html 형식(jsp) 또는 data 형식(JSON, 예 {"name":"Kelly",...})

## 3. 웹페이지 구성 3요소
- ⭐ **강조** — HTML = 웹페이지의 구조와 내용 (Hyper Text Markup Language)
- ⭐ **강조** — CSS = 웹페이지의 모양 (Cascading Style Sheet)
- ⭐ **강조** — JS = 웹페이지의 행동/동작 (JavaScript)

## 4. 웹브라우저의 기본 구조
- 사용자 인터페이스: 주소표시줄·이전/다음·북마크 등 (페이지 표시 창 제외 부분)
- 브라우저 엔진: UI와 렌더링 엔진 사이의 동작을 제어
- ⭐ **강조** — 렌더링 엔진: 요청한 콘텐츠 표시 — HTML·CSS를 파싱하여 화면에 표시
- 통신: HTTP 요청 등 네트워크 호출에 사용 (플랫폼 독립적 인터페이스)
- UI 백엔드: 콤보박스·창 등 기본 장치를 그림 (OS UI 체계 사용)
- ⭐ **강조** — 자바스크립트 해석기: 자바스크립트 코드를 해석하고 실행
- 자료 저장소: 쿠키 등 자원을 저장 (HTML5의 웹 데이터베이스 포함)

## 5. 자바스크립트로 할 수 있는 일
- 웹 클라이언트 애플리케이션 개발 — 브라우저에서 실행할 수 있는 유일한 프로그래밍 언어
- ⭐ **강조** — 웹 서버 개발 — Node.js 등장으로 서버도 JS로 개발 가능 (페이팔 결제시스템에도 활용, 빠름)
- 모바일 앱 개발 — React Native(페이스북): JS로 네이티브 앱 개발
- 데스크톱 앱 개발 — Electron 모듈 (VS Code 등)
- 게임 개발 — Unity 게임엔진(JS 기반)
- 데이터베이스 관리 — MongoDB(JS 활용하는 NoSQL)

## 6. 실습 환경 설정
- ⭐ **강조** — 설치 3종: Chrome(브라우저) / Visual Studio Code(에디터) / Node.js(런타임)
- 실습 폴더(예: ch3) 생성 → VS Code에서 〔File〕→〔Open Folder〕로 열기 → 이후 파일은 폴더 내부에 생성
- JS 파일 실행: 〔Terminal〕→〔New Terminal〕 → 프롬프트에 `node 파일명.js` 입력
