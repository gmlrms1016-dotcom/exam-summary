## 5주차 — 반복문 · 배열 실습 ([5주차 자세히](자바프로그래밍-5주차.html))
- ⭐ **수업 중 중요 표시** — 3장 p21 **배열의 필요성**: 변수 10개(`i0 ~ i9`) 대신 `int i[] = new int[10];` → for 문에서 `sum += i[n];` 으로 한 번에 처리 · 인덱스 0 ~ 크기-1
- 예제 3-2 while: 첫 수는 while 전에 받고, `-1` 이면 종료 · 평균은 `(double) sum / count` (타입 변환 ★시험단골) · 처음부터 -1 이면 "입력된 수가 없습니다."
- 예제 3-4 구구단: 2중 중첩 for, 바깥 i(단) · 안쪽 j(곱하는 수), 한 단 끝나면 `println()`
- `continue` = 다음 반복으로 (예제 3-5: 5 -2 6 10 -4 → 양수의 합 21) · `break` = 반복문 하나만 탈출, 중첩이면 안쪽만 (예제 3-6: exit 입력 시 종료, 문자열 비교는 `equals()`)
- 실습: 5! = 120 · 1~10 짝수 `i % 2 == 0` · while 로 0~9 (초기화는 while 앞, 증감은 while 안)

## 4주차 — 연산자·조건문 실습 + 반복문 · 배열 · 예외처리 ([4주차 자세히](자바프로그래밍-4주차.html))
- ⭐ **강조** — `/` 몫 · `%` 나머지 → 5000초: `time % 60` = 20초 · `(time / 60) % 60` = 23분 · `(time / 60) / 60` = 1시간
- ⭐ **강조** — `a = d++` 대입 먼저·증가 나중(d=3 → a=3, d=4) / `a = ++d` 증가 먼저·대입 나중
- 삼항 `(a > b) ? (a - b) : (b - a)` → 3, 8 이면 5
- switch: `case 10: case 9:` 처럼 이어 쓰면 같은 코드(fall-through) · 문자열 case 가능(`"카페라떼"`) · 없는 값은 default

| 구분 | while | do-while |
|---|---|---|
| 조건 검사 | 먼저 검사 후 실행 | 실행 후 검사 |
| 최소 실행 | 0번일 수 있음 | **무조건 1번** |

- ⭐ **강조** — `for(초기작업; 반복조건; 반복후작업)` · for 안에서 선언한 변수는 밖에서 못 씀 · 조건이 비면 무한 반복 · 1~10 합 = **55**
- ⭐ **강조** — `continue` 다음 반복으로 / `break` 반복문 하나 탈출(중첩이면 안쪽만) · 문자열 비교는 `equals()`
- 배열: 인덱스 0부터 · `int intArray[] = new int[10];` · `int a[10];` 은 **컴파일 오류** · `배열.length` = 크기 · for-each `for (int k : num)`
- ⭐ **강조** — `public static void main(String[] args)` : public · static · void · 문자열 배열
- 컴파일 오류 = 문법 오류 / **예외** = 실행 중 오류 → 처리 안 하면 강제 종료 · `finally` 는 예외 여부와 상관없이 실행

| 예외 클래스 | 발생 상황 |
|---|---|
| `ArithmeticException` | 정수를 0으로 나눌 때 |
| `ArrayIndexOutOfBoundsException` | 배열 인덱스 범위를 벗어날 때 |
| `InputMismatchException` | Scanner 가 정수를 기다리는데 문자 입력 |
| `NumberFormatException` | 정수가 아닌 문자열을 `Integer.parseInt()` |
| `NullPointerException` | null 레퍼런스로 객체 사용 |

## 3주차 — 2장 자료형 · 연산자 · 조건문 ([3주차 자세히](자바프로그래밍-3주차.html))
- ⭐ **강조** — 식별자: 특수문자·공백 불가(`_` `$` 가능) · 숫자로 시작 불가 · 키워드 불가 · 대소문자 구별
- ⭐ **강조** — 카멜 표기: 클래스 첫 글자 대문자 · 변수·메서드 첫 글자 소문자 · 상수 모두 대문자
- ⭐ **강조** — 기본타입 8개: boolean char byte short int long float double / **String 은 클래스**(기본타입 아님)
- ⭐ **강조** — 자동 형변환: 작은 → 큰 / 강제 형변환: 큰 → 작은, `(int)2.9` → 2
  - `(int)2.9 + 1.8` → 3.8 · `(int)(2.9 + 1.8)` → 4 · `(int)2.9 + (int)1.8` → 3
- ⭐ **강조** — Scanner: `import java.util.Scanner;` → `new Scanner(System.in)` · `next()` `nextInt()` `nextDouble()` `nextBoolean()`
- `69 / 10` = 6 · `69 % 10` = 9
- ✍️ **필기** — switch 의 case 값은 **문자 · 정수 · 문자열 리터럴**만 (실수·변수·수식 불가)

## 1~2주차 — 자바 개요 ([2주차 자세히](자바프로그래밍-2주차.html))
- ⭐ **강조** — 자바 개발 목적 = **플랫폼 독립성** · WORA(Write Once Run Anywhere)
- ⭐ **강조** — 바이트코드 = CPU 중립적 목적코드(.class) / JVM = 바이트코드를 인터프리터 방식으로 실행
- ✍️ **필기** — **JVM 자체는 플랫폼 종속**(OS마다 별도), 바이트코드는 플랫폼 독립
- ⭐ **강조** — 자바는 **링크 과정이 없다**(실행 중 동적 로딩) · 느린 실행은 JIT 컴파일러로 개선
- ⭐ **강조** — JDK = 개발도구 + JRE / JRE = JVM + 표준 라이브러리
- ⭐ **강조** — 특성: 플랫폼 독립 · 객체지향 · 멀티스레드 · **가비지 컬렉션** · 포인터 없음
- ✍️ **필기** — public 클래스는 소스당 1개, 파일명 = public 클래스명 · 실행은 `main()` 에서 시작
