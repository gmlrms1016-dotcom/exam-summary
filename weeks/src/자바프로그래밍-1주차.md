## 2. 첫 자바 프로그램 (heegeun.java)
- package 선언 + `import java.util.Scanner` + public class(파일명과 동일)
- ⭐ **강조** — 자바 프로그램은 `public static void main(String[] args)` 에서 실행을 시작한다
- Scanner로 키 입력, if-else 조건문, for/while 반복문 사용 실습
```java
import java.util.Scanner;                      // Scanner(키보드 입력)를 쓰려고 불러옴
public class 연습 {   // 원래 이름 heegeun → 파일 이름도 연습.java
    public static void main(String[] args) {   // 프로그램이 시작되는 main 메소드
        Scanner sc = new Scanner(System.in);   // 키보드(System.in)로 입력받는 Scanner 객체 sc 만들기
        System.out.println("반갑습니다. 여러분~~");    // 인사말 출력 후 줄바꿈 → 반갑습니다. 여러분~~
        int age = sc.nextInt();                // 정수 하나 입력 → age (예: 20)
        if (age >= 19) {                       // age 가 19 이상이면 → 아래 for 실행 / 아니면 else
            for (int i=1; i<=10; i++) {        // i = 1 → 10 까지 1씩 증가 → 10번 반복
                System.out.println(1+100*30/23);   // 100*30 → 3000 → 3000/23 → 130 (정수 나눗셈) → 1+130 → 131
                int j=1;                       // 안쪽 반복용 j 를 1 로 시작
                while (j<=10) {                // j 가 10 이하인 동안 반복 → 1 ~ 10
                    System.out.println(j);     // j 출력 후 줄바꿈 → 1, 2, … 10 (한 줄에 하나)
                    j++;                       // j = j + 1 → 다음 숫자
                }                              // while 끝 → 조건 다시 검사 (거짓이면 빠져나옴)
            }                                  // for 끝 → 증감식 실행 후 조건 다시 검사 (거짓이면 빠져나옴)
        } else {                               // if 끝 · 조건이 거짓이면 아래 else 실행
            System.out.printf("10대 입니다.");     // printf 는 줄바꿈 없이 출력 → 10대 입니다.
        }                                      // else 끝
    }                                          // main 끝 → 프로그램 종료
}                                              // 클래스 끝
```
- ✍️ **필기** — 클래스 이름과 파일 이름은 반드시 같아야 하며, main() 메서드가 있어야 실행된다
