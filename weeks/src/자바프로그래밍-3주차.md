## 1. 프로그램 기본 구조 & 식별자
- 클래스 선언(public class) 안에 main() 메서드에서 실행 시작, 문장 끝은 `;`
- 주석: `//` 한 줄, `/* 여러 줄 */`
- ⭐ **강조** — 식별자 규칙: 특수문자(@,#,!)·공백 불가(단 `_`, `$` 가능), 첫 글자 숫자 불가, 키워드 불가, 대소문자 구별
- ⭐ **강조** — 카멜 표기법: 클래스=첫 글자 대문자, 변수·메서드=첫 글자 소문자, 상수=모두 대문자

## 2. 데이터 타입 & 변수 ★암기
- ⭐ **강조** — 기본타입 8개: boolean, char, byte, short, int, long, float, double
- ⭐ **강조** — 레퍼런스타입 1개(배열·클래스·인터페이스). 문자열 String은 기본타입이 아니라 클래스
- 변수 선언: 타입 다음에 이름 (예: `int radius = 10;`), 지역변수는 메서드 종료 시 소멸
  - 리터럴: 10진/8진(0)/16진(0x)/2진(0b), 실수는 double 기본, 문자 'A'

## 3. 타입 변환 ★시험단골
- ⭐ **강조** — 자동 형변환: 작은 타입 → 큰 타입 (컴파일러가 자동)
- ⭐ **강조** — 강제 형변환(캐스팅): 큰 타입 → 작은 타입, ()로 지정, 값 손실 우려 — 예 `(int)2.9` → 2
```java
public class 연습 {                              // 클래스 시작 — 파일 이름은 연습.java (public 클래스 이름과 같아야 함)
    public static void main(String[] args) {   // 프로그램이 시작되는 main 메소드
        System.out.println((int)2.9 + 1.8);      // (int)2.9 → 2 (소수점 버림) → 2 + 1.8 → 3.8
        System.out.println((int)(2.9 + 1.8));    // 괄호 먼저 2.9 + 1.8 → 4.7 → (int)4.7 → 4
        System.out.println((int)2.9 + (int)1.8); // (int)2.9 → 2 · (int)1.8 → 1 → 2 + 1 → 3
    }                                          // main 끝 → 프로그램 종료
}                                              // 클래스 끝
```

## 4. 키 입력 (Scanner)
- ⭐ **강조** — `import java.util.Scanner;` → `Scanner sc = new Scanner(System.in);`
- 메서드: `next()` · `nextInt()` · `nextDouble()` · `nextBoolean()` (공백 단위로 읽음), 끝에 `close()`

## 5. 연산자
- 산술(`+ - * / %`): 69/10=6, 69%10=9 / n%2로 홀짝 판단
- 대입(`=`, `+=`…), 증감(`++`, `--`) 전위·후위 차이, 비교(`==`, `!=`, `<`, `>`), 논리(`&&`, `||`, `!`, `^`)
- 조건(삼항) 연산자: `condition ? A : B` (예: `(x>y)?1:-1`)
- 비트 연산: `& | ^ ~` 와 시프트 `<<`, `>>`, `>>>`

## 6. 조건문 ★핵심
- 단순 if / if-else / 다중 if-else(else if) / 중첩 if
- ⭐ **강조** — switch 문: case 값과 비교, break로 탈출, 없으면 다음 case로 계속(fall-through), default 생략가능
- ✍️ **필기** — case 값은 문자·정수·문자열 리터럴만 가능(실수·변수·수식 불가)
```java
public class 연습 {                              // 클래스 시작 — 파일 이름은 연습.java (public 클래스 이름과 같아야 함)
    public static void main(String[] args) {   // 프로그램이 시작되는 main 메소드
        int score = 85;                        // 점수 85
        char grade;                            // 학점을 담을 문자 변수 (아래 switch 에서 정해짐)
        switch (score/10) {             // 85 / 10 → 8 (정수 나눗셈)
          case 10: case 9: grade='A'; break;   // 10 · 9 → A 를 넣고 break 로 switch 탈출
          case 8: grade='B'; break;            // 8 → B
          case 7: grade='C'; break;            // 7 → C
          case 6: grade='D'; break;            // 6 → D
          default: grade='F';                  // 그 밖(0~5) → F
        }                                      // switch 끝
        System.out.println("학점은 " + grade);   // 8 → case 8 → B → 학점은 B
    }                                          // main 끝 → 프로그램 종료
}                                              // 클래스 끝
```
