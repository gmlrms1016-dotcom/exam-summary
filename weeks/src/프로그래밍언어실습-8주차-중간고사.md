### ① 🔥 Project3 시험문제 — 헤더파일 3개로 나눈 절대값 myAbs
| 파일 | 들어 있는 것 |
|---|---|
| `func.h` | 원형만 — `int myAbs(int value);` (+ `#pragma once`) |
| `func.c` | 몸체 — 양수면 그대로, 아니면 `-value` |
| `main.c` | `#include "func.h"` (따옴표 = 내가 만든 헤더) · 입력 → `myAbs(iValue)` → 출력 |
```c
// func.h — 함수 원형(선언)만 두는 헤더파일
#pragma once                                      // 헤더 중복 포함 막기
int myAbs(int value);                             // 절대값 함수 원형 — 몸체는 func.c 에
```
```c
// func.c — 함수 정의(몸체)만 두는 소스파일 · 절대값 계산 (기억하고 있기)
int myAbs(int value) {                            // 정수 1개를 받아 절대값을 돌려줌
    int iAbs;                                     // 결과를 담을 변수
    if (value > 0) {                              // 양수면 (예: 5 > 0 → 참)
        iAbs = value;                             // 그대로 → 5
    }                                             // if 끝
    else {                                        // 0 이나 음수면 (예: -7)
        iAbs = -value;                            // 부호를 뒤집음 → -(-7) → 7
    }                                             // else 끝
    return iAbs;                                  // 절대값을 돌려주고 종료
}                                                 // myAbs 끝
```
```c
// main.c — 입력 → myAbs 호출 → 출력
#define _CRT_SECURE_NO_WARNINGS                   // Visual Studio 에서 scanf 보안 경고(C4996) 끄기 — 맨 위에 써야 함
#include <stdio.h>                                // printf · scanf 를 쓰기 위한 표준 입출력 헤더
#include "func.h"                                 // 내가 만든 헤더 → int myAbs(int value); 가 여기 들어옴
int main(void) {   // (void) = '매개변수 없음'을 확실히 적음 · int main() 은 괄호를 비워 둔 옛 방식 — 실행 결과는 같음
    int iValue, iResult;                          // 입력값 · 결과값
    printf("정수를 입력하세요: ");                // 안내 문구 (\n 없음)
    scanf("%d", &iValue);                         // 정수 입력 → iValue (예: -7)
    iResult = myAbs(iValue);                      // func.c 의 myAbs 실행 → 7 을 돌려받음
    printf("%d의 절대값은 %d입니다.\n", iValue, iResult);   // -7의 절대값은 7입니다.
    return 0;                                     // 0(정상 종료)을 운영체제에 돌려주고 끝냄
}                                                 // main 함수 끝
```
```output
정수를 입력하세요: -7
-7의 절대값은 7입니다.
```
### ② 함수 용어 — return · void · 실인수 · 가인수 · 원형
- **return** = 반환값을 돌려주고 **그 자리에서 함수 종료** · **void** = 값이 없음
- **실인수** = 호출할 때 넘기는 실제 값 `sum(a, b)` · **가인수(형식 인수)** = 정의의 괄호 안 변수 `int sum(int i, int j)` → 실인수 값이 **복사**됨
- 함수가 `main()` **뒤**에 있으면 앞에 **원형 선언** `int sum(int i, int j);` · 원형만 모아 두면 **헤더파일** (`MyMath.h`)
### ③ 포맷 문자 · 문자 입출력 함수
| 포맷 | 뜻 | | 함수 | 뜻 |
|---|---|---|---|---|
| `%d` | 부호 있는 정수 | | `getchar()` | 문자 1개 입력 |
| `%u` | 부호 없는 정수 | | `putchar()` | 문자 1개 출력 |
| `%f` | 실수 (소수 6자리) | | `gets()` | 문자열 입력 |
| `%0.3f` | 실수 소수 3자리 | | `puts()` | 문자열 출력 + 줄바꿈 |
| `%c` · `%s` | 문자 1개 · 문자열 | | `scanf()` · `printf()` | 다양한 타입 입력 · 출력 |

```c
// input3.c (수업 코드) — 함수 정의 위치 · 원형 선언 · 반환값
#include <stdio.h>                       // printf 를 쓰기 위한 표준 입출력 헤더
void test1() {                           // main 보다 위에 정의 → 원형 선언 없이 호출 가능

void test2();                            // 함수 원형 선언 — 정의가 main 뒤에 있어서 필요
int test3() {                            // 반환형 int → 정수를 돌려줌
    return 100;                          // 100 을 돌려주고 종료
}                                        // test3 끝
int test4(int i, int j) {                // 가인수 i, j
    int result = i + j;                  // 2 + 3 → 5
    return result;                       // 5 를 돌려줌
}                                        // test4 끝
int main(void) {   // (void) = '매개변수 없음'을 확실히 적음 · int main() 은 괄호를 비워 둔 옛 방식 — 실행 결과는 같음
    test1();                             // ① 위로 올라가 test1 실행 → test1 함수 호출
    test2();                             // ② 아래로 내려가 test2 실행 → test2 함수 호출
    int a1 = test3();                    // ③ test3 이 돌려준 100 → a1
    int a2 = test4(2, 3);                // ④ 실인수 2, 3 → 돌려받은 5 → a2
    printf("a1: %d\n", a1);              // a1: 100
    printf("a2: %d\n", a2);              // a2: 5
    return 0;                            // 0(정상 종료)을 운영체제에 돌려주고 끝냄
}                                        // main 함수 끝
void test2() {                           // main 뒤에 정의 → 위에 원형 선언이 있어야 함
    printf("test2 함수 호출\n");         // test2 가 하는 일
}                                        // test2 끝
```

### ① 온도 변환 (F → 섭씨 · C → 화씨)
```c
#include <stdio.h>   // printf · scanf 를 쓰기 위한 표준 입출력 헤더

int main(void) {   // (void) = '매개변수 없음'을 확실히 적음 · int main() 은 괄호를 비워 둔 옛 방식 — 실행 결과는 같음
    float i = 100;   // 섭씨 100도
    // 튜터링 코드에서 틀린 줄
    printf("섭씨온도 %.2f는 화씨 온도로 %.2f입니다.\n", i, (9.0 / 5.0) * (i + 32));   // ⚠️ 100 → (100 + 32) × 9/5 → 132 × 1.8 → 237.6 (틀림)
    // 고친 줄
    printf("섭씨온도 %.2f는 화씨 온도로 %.2f입니다.\n", i, (9.0 / 5.0) * i + 32);     // 100 → 100 × 9/5 → 180 → 180 + 32 → 212 (맞음)
    return 0;   // 0(정상 종료)을 운영체제에 돌려주고 끝냄
}               // main 함수 끝
```
```c
#define _CRT_SECURE_NO_WARNINGS                 // Visual Studio 에서 scanf 보안 경고(C4996) 끄기 — 맨 위에 써야 함
#include <stdio.h>                              // printf · scanf 를 쓰기 위한 표준 입출력 헤더
int main() {   // () = 괄호를 비워 둔 옛 방식 · int main(void) 는 '매개변수 없음'을 확실히 적음 — 실행 결과는 같음
	printf("입력한 온도를 변환합니다.\n문자를 F나 f를 입력하면 섭씨로,\n문자를 C나 c를 입력하면 화씨로 변환합니다.\n");   // 안내문 3줄 출력 (\n 마다 줄바꿈)
	char a;                                        // 변환 종류 문자를 담을 변수
	printf("문자 입력 >> : ");                         // 질문 출력 (줄바꿈 없음)
	scanf("%c", &a);                       // 문자 하나 → a
	float i;                                       // 온도를 담을 실수 변수
	printf("온도 입력 >> : ");                         // 질문 출력 (줄바꿈 없음)
	scanf("%f", &i);                       // 실수 → i

	if (a == 'F' || a == 'f') {            // 대문자 · 소문자 둘 다 → || (또는)
		printf("화씨온도 %.2f는 섭씨 온도로 %.2f입니다.", i, (5.0 / 9.0) * (i - 32));   // 212 → 212 - 32 = 180 → 180 × 5/9 → 100.00
	}                                              // if 끝
	else if (a == 'C' || a == 'c') {               // C 또는 c 이면 → 섭씨 → 화씨
		printf("섭씨온도 %.2f는 화씨 온도로 %.2f입니다.", i, (9.0 / 5.0) * i + 32);     // 100 → 100 × 9/5 = 180 → 180 + 32 → 212.00
	}                                              // if 끝
	else {                                         // 그 밖의 문자
		printf("입력 오류!");               // F · f · C · c 말고 다른 문자
	}                                              // else 끝
	return 0;                                      // 0(정상 종료)을 운영체제에 돌려주고 끝냄
}                                               // main 함수 끝
```

```output
문자를 F나 f를 입력하면 섭씨로,
문자를 C나 c를 입력하면 화씨로 변환합니다.
문자 입력 >> : C
```

- `5.0 / 9.0` 처럼 **실수**로 나눠야 해요 → `5 / 9` 는 정수 나눗셈이라 0 → 결과가 항상 0
- `%.2f` → 소수점 아래 **2자리**까지 (100 → 100.00)
- ⚠️ **정정** 튜터링 파일 맨 위 `#define CRT_SECURE_NO_WARNINGS` → 앞에 밑줄이 빠졌어요. 맞는 이름은 **`_CRT_SECURE_NO_WARNINGS`** (빠지면 VS 에서 scanf 가 C4996 오류)
- ⚠️ **정정** 튜터링 코드는 `scanf_s("%c", &a)` — scanf_s 로 **%c** 를 받을 때는 크기를 하나 더 줘야 해요 → `scanf_s("%c", &a, 1)`. 위처럼 `_CRT_SECURE_NO_WARNINGS` + `scanf` 를 쓰면 신경 쓸 필요 없음

### ② 윤년 판별
```c
// 튜터링 코드에서 틀린 조건
if (i % 4 == 0 && i % 100 != 0 || i % 400 != 0)   // ⚠️ 마지막이 != 0 → 400 으로 안 나눠지는 해(2023 · 1900 …)가 전부 윤년이 됨
// 고친 조건
if (i % 4 == 0 && i % 100 != 0 || i % 400 == 0)   // (4의 배수이면서 100의 배수가 아님) 또는 (400의 배수)
```
```c
#define _CRT_SECURE_NO_WARNINGS   // Visual Studio 에서 scanf 보안 경고(C4996) 끄기 — 맨 위에 써야 함
#include <stdio.h>                // printf · scanf 를 쓰기 위한 표준 입출력 헤더
int main() {   // () = 괄호를 비워 둔 옛 방식 · int main(void) 는 '매개변수 없음'을 확실히 적음 — 실행 결과는 같음
	printf("년도입력: ");                // 질문 출력 (줄바꿈 없음)
	int i;                           // 연도를 담을 변수
	scanf("%d", &i);                 // 연도 입력 → i (예: 2024)
	if (i % 4 == 0 && i % 100 != 0 || i % 400 == 0) {   // && 가 || 보다 먼저 계산 → (A && B) || C
		printf("%d 년은 윤년입니다.", i);      // 예: 2024 → 2024 년은 윤년입니다.
	}                                // if 끝
	else {                           // 윤년 조건이 거짓이면
		printf("%d 년은 평년입니다.", i);      // 예: 2023 · 1900 → 2023 년은 평년입니다.
	}                                // else 끝
	return 0;                        // 0(정상 종료)을 운영체제에 돌려주고 끝냄
}                                 // main 함수 끝
```

| 1900 | 100의 배수 → 앞부분 거짓 → 1900 % 400 = 300 | 윤년 (틀림) | **평년** |
| 2000 | 100의 배수 → 앞부분 거짓 → 2000 % 400 = 0 | 평년 (틀림) | **윤년** |

### ③ for 문 실행결과 — 시험 유형 “실행결과 쓰기”
```c
#define _CRT_SECURE_NO_WARNINGS   // Visual Studio 에서 scanf 보안 경고(C4996) 끄기 — 맨 위에 써야 함
#include<stdio.h>                 // printf 를 쓰기 위한 표준 입출력 헤더 (< 앞 공백은 없어도 됨)
int main() {   // () = 괄호를 비워 둔 옛 방식 · int main(void) 는 '매개변수 없음'을 확실히 적음 — 실행 결과는 같음
	for (int i = 3; i <= 18; i += 3) {   // i = 3 → 6 → 9 → 12 → 15 → 18 (3씩 증가 · 18 까지)
		if (i == 15) {                  // 15 를 찍을 차례가 되면
			printf("\n");                 // 15 를 찍기 직전에 줄바꿈 한 번
		}                               // if 끝
		printf("%5d", i);                  // 5칸을 잡고 오른쪽 정렬 → 3 은 공백 4개 + 3
	}                                // for 끝 → 증감식 실행 후 조건 다시 검사 (거짓이면 빠져나옴)
	return 0;                        // 0(정상 종료)을 운영체제에 돌려주고 끝냄
}                                 // main 함수 끝
```
```output

```
- `%5d` → 숫자를 **5칸 오른쪽 정렬** → 한 자리 수 앞에 공백 **4개**, 두 자리 수 앞에 공백 **3개**

- 마지막에 `\n` 이 **없음** → `18` 뒤에서 줄바꿈 없이 끝 (5주차 필기 “`\n` 있나 없나 주의”)

### ① switch 에서 break 를 빼면? (n = 2)
```c
#include <stdio.h>             // printf · scanf 를 쓰기 위한 표준 입출력 헤더

int main(void) {   // (void) = '매개변수 없음'을 확실히 적음 · int main() 은 괄호를 비워 둔 옛 방식 — 실행 결과는 같음
    int n = 2;                 // n = 2 → case 2 로 이동
    switch (n) {               // n 과 같은 case 로 이동
    case 1:                    // n == 1 일 때 (지금은 아님)
        printf("one\n");       // one
    case 2:                  // n == 2 → 여기서 시작해서
        printf("two\n");       // two
    case 3:                  // break 가 없으니 아래로 계속
        printf("three\n");     // three (break 가 없어서 이어서 실행)
    default:                   // default 까지 계속
        printf("default\n");   // default → 출력: two / three / default
    }                          // switch 끝
    return 0;                  // 0(정상 종료)을 운영체제에 돌려주고 끝냄
}                              // main 함수 끝
```
```output
two
three
default
```
- ⭐ **강조** — break 가 있으면 `two` 만 · 없으면 맞는 case 부터 **아래 case · default 까지 전부** 실행 (필기 “안 멈추고 밑에 case 까지 실행되서 printf 가 실행”)

### ② break — Quiz 6
```c
#include <stdio.h>                 // printf · scanf 를 쓰기 위한 표준 입출력 헤더
```

### ③ continue + break — Quiz 7 (입력 5, -2, 3, 7)
```c
#define _CRT_SECURE_NO_WARNINGS   // Visual Studio 에서 scanf 경고 끄기
#include <stdio.h>                   // printf · scanf 를 쓰기 위한 표준 입출력 헤더

int main(void) {   // (void) = '매개변수 없음'을 확실히 적음 · int main() 은 괄호를 비워 둔 옛 방식 — 실행 결과는 같음
    int num, sum = 0, count = 0;     // 입력값 · 합 · 개수
    while (1) {                      // 조건이 항상 참 → break 를 만나야 끝남
        printf("input number ? ");   // 입력 안내 (줄바꿈 없음)
        scanf("%d", &num);           // 정수 입력 → num
        if (num < 0)                 // 음수면
            continue;        // 음수 → 아래를 건너뛰고 다시 입력
        sum += num;                  // 양수만 합에 더함
        count++;                     // 더한 개수 1 증가
        if (count == 3)              // 3개가 모이면
            break;           // 3개가 모이면 빠져나감
    }                                // while 끝 → 조건 다시 검사 (거짓이면 빠져나옴)
    printf("합 : %d \n", sum);        // 예: 5 -1 3 4 → 합 : 12
    return 0;                        // 0(정상 종료)을 운영체제에 돌려주고 끝냄
}                                    // main 함수 끝
```
```output
input number ? 5
input number ? -2
input number ? 3
input number ? 7
합 : 15 
```
- ⭐ **강조** — `continue` = 남은 문장을 건너뛰고 **다음 반복** · `break` = 반복문 · switch 를 **빠져나옴** · 0 은 음수가 아니라 더해짐

### ④ `\n` 있나 없나
- `printf("a는 b보다 작다");` · `printf("quit..");` · `printf("for문 종료...");` 처럼 **`\n` 이 없으면 다음 출력이 같은 줄에** 붙는다

## ★ 4주차 시험문제 ([4주차 자세히](프로그래밍언어실습-4주차.html))
### ① 1)시험문제! — 증감 + 우선순위
```c
#include <stdio.h>                           // printf · scanf 를 쓰기 위한 표준 입출력 헤더

int main(void) {   // (void) = '매개변수 없음'을 확실히 적음 · int main() 은 괄호를 비워 둔 옛 방식 — 실행 결과는 같음
    int x = 10;                              // x = 10
    int y = 10;                              // y = 10
    int z;                                   // 결과를 담을 z
    z = -x++ + ++y;                          // -x++ → 지금 x(10) 를 써서 -10 → 그다음 x = 11 · ++y → 먼저 y = 11 → -10 + 11 → z = 1
    printf("x=%d\ty=%d\tz=%d\n", x, y, z);   // x=11\ty=11\tz=1 (\t = 탭 간격)
    return 0;                                // 0(정상 종료)을 운영체제에 돌려주고 끝냄
}                                            // main 함수 끝
```
```output
x=11	y=11	z=1
```
- ⭐ **강조** — `x++` 후위: **지금 값 10** 을 쓰고 나중에 11 · `++y` 전위: **먼저 11** → z = -10 + 11 = **1**

### ② 2)시험문제! — 콤마 + printf 안의 증감
```c
#include <stdio.h>                              // printf · scanf 를 쓰기 위한 표준 입출력 헤더

int main(void) {   // (void) = '매개변수 없음'을 확실히 적음 · int main() 은 괄호를 비워 둔 옛 방식 — 실행 결과는 같음
    int x = 1, y = 1, z = 1;                    // x · y · z 모두 1
    ++x, y++;                                   // ++x → x = 2 · y++ → y = 2 (콤마로 둘 다 실행)
    printf("x:%d\t\ty:%d\t\tz:%d \n", x, y, z); // x:2\t\ty:2\t\tz:1
    printf("x:%d\t\ty:%d\t\tz:%d \n", x++, --y, z--);   // x++ → 2 를 찍고 x = 3 · --y → y = 1 을 찍음 · z-- → 1 을 찍고 z = 0 → x:2\t\ty:1\t\tz:1
    return 0;                                   // 0(정상 종료)을 운영체제에 돌려주고 끝냄
}                                               // main 함수 끝
```
```output
x:2		y:2		z:1 
x:2		y:1		z:1 
```
- ⭐ **강조** — 두 번째 줄은 **찍히는 값**: `x++` → 2 (그 뒤 3) · `--y` → 1 · `z--` → 1 (그 뒤 0)

### ③ 3)시험문제! — 비트 연산자 (a=60 `0011 1100`, b=13 `0000 1101`)
> 💡 **비트 연산** = 숫자를 **2진수로 바꿔서 같은 자리끼리** 계산하는 것. 순서: ① 2진수로 바꾸기 → ② 자리마다 규칙 적용 → ③ 다시 10진수로

#### 0단계 — 2진수로 바꾸기 (8비트 자리값 128 · 64 · 32 · 16 · 8 · 4 · 2 · 1)
| 자리값 | 128 | 64 | 32 | 16 | 8 | 4 | 2 | 1 | 더하기 |
|---|---|---|---|---|---|---|---|---|---|
| a = 60 | 0 | 0 | **1** | **1** | **1** | **1** | 0 | 0 | 32 + 16 + 8 + 4 = **60** |
| b = 13 | 0 | 0 | 0 | 0 | **1** | **1** | 0 | **1** | 8 + 4 + 1 = **13** |

#### 연산자 한눈에
| 기호 | 읽는 법 | 규칙 | 피연산자 |
|---|---|---|---|
| `&` | AND (앰퍼샌드) | 둘 다 1 이면 1 | 2개 |
| `\|` | OR (세로 막대) | 하나라도 1 이면 1 | 2개 |
| `^` | XOR (캐럿) | 서로 다르면 1 | 2개 |
| `~` | **NOT (물결표 · 틸드)** | **모든 비트를 0 ↔ 1 뒤집기** | **1개** (`~a`) |
| `<<` | 왼쪽 시프트 | 왼쪽으로 n칸 · 빈자리 0 · 1칸마다 ×2 | 2개 |
| `>>` | 오른쪽 시프트 | 오른쪽으로 n칸 · 끝 비트는 버림 · 1칸마다 ÷2 | 2개 |

#### ① `a & b` = 12 — 둘 다 1 인 자리만 1
```bits
  0011 1100   (a = 60)
& 0000 1101   (b = 13)
-----------
  0000 1100   → 8 + 4 = 12
```

#### ② `a | b` = 61 — 하나라도 1 이면 1
```bits
  0011 1100   (60)
| 0000 1101   (13)
-----------
  0011 1101   → 32 + 16 + 8 + 4 + 1 = 61
```

#### ③ `a ^ b` = 49 — 서로 다르면 1 (같으면 0)
```bits
  0011 1100   (60)
^ 0000 1101   (13)
-----------
  0011 0001   → 32 + 16 + 1 = 49
```

#### ④ `~a` = −61 — 물결표 `~` = 모든 비트 뒤집기 ★
```bits
~ 0011 1100   (60)
-----------
  1100 0011   → 0 은 1 로, 1 은 0 으로 → 맨 앞(부호 비트)이 1 → 음수
```
- **물결표 `~`** 는 숫자 **하나**에만 붙는 연산자예요 (`~a`). 모든 자리의 0 과 1 을 **서로 바꿔요** (= **1의 보수**).
- 왜 **−61** 일까?
  1. int 는 맨 앞 비트가 **부호**예요 → 0 이면 양수, **1 이면 음수**. `1100 0011` 은 맨 앞이 1 → **음수**
  2. 컴퓨터는 음수를 **2의 보수**(뒤집고 + 1)로 저장해요 → 그래서 몇인지 읽을 때는 **거꾸로**: 다시 뒤집기 → `0011 1100` = 60 → **+ 1** → 61 → 앞에 − → **−61**
  3. 그래서 외우는 공식: **`~x = -(x + 1)`** → `~60` = −(60 + 1) = **−61** · `~13` = **−14** · `~0` = **−1** (직접 실행해서 확인)
- 실제 int 는 **32비트**라 앞의 24비트(전부 0)도 같이 뒤집혀 1 이 돼요 → `1111 1111 1111 1111 1111 1111 1100 0011` (16진수 `FFFFFFC3`) · 위의 8비트는 보기 쉽게 줄인 것
- ⚠️ 헷갈리지 말기 — `~` 는 **비트 NOT**(모든 비트 뒤집기) → `~60` = **−61** / `!` 는 **논리 NOT**(참 ↔ 거짓) → `!60` = **0** (0 이 아니면 참 → 뒤집어서 거짓 0)

#### ⑤ `a << 2` = 240 — 왼쪽으로 2칸 (×4)
```bits
  0011 1100   (60)
<< 2          → 모두 왼쪽으로 2칸, 오른쪽 빈자리에 0 두 개
-----------
  1111 0000   → 128 + 64 + 32 + 16 = 240 = 60 × 2 × 2
```

#### ⑥ `a >> 2` = 15 — 오른쪽으로 2칸 (÷4)
```bits
  0011 1100   (60)
>> 2          → 모두 오른쪽으로 2칸, 오른쪽 끝 두 칸(00)은 버림
-----------
  0000 1111   → 8 + 4 + 2 + 1 = 15 = 60 ÷ 2 ÷ 2
```

#### 시험 코드 (수업 화면 ex01_00-op2.c) · 실행 결과
```c
#include <stdio.h>                // printf · scanf 를 쓰기 위한 표준 입출력 헤더
int main() {   // () = 괄호를 비워 둔 옛 방식 · int main(void) 는 '매개변수 없음'을 확실히 적음 — 실행 결과는 같음
    int a = 60;          // 60 = 32 + 16 + 8 + 4 → 0011 1100
    int b = 13;          // 13 = 8 + 4 + 1 → 0000 1101
    int c;                        // 결과를 담을 c

    c = a & b;           // 0011 1100 & 0000 1101 → 둘 다 1 인 자리만 1 → 0000 1100 → 12
    printf("a & b: %d \n", c);    // a & b: 12
    c = a | b;           // 하나라도 1 이면 1 → 0011 1101 → 61
    printf("a | b: %d \n", c);    // a | b: 61
    c = a ^ b;           // 서로 다르면 1 → 0011 0001 → 49
    printf("a ^ b: %d \n", c);    // a ^ b: 49
    c = ~a;              // 물결표: 0011 1100 → 전부 뒤집기 → 1100 0011 → 맨 앞 1 = 음수 → 뒤집기 60 + 1 = 61 → -61
    printf("~a: %d \n", c);       // ~a: -61
    c = a << 2;          // 왼쪽 2칸 → 1111 0000 → 60 × 4 → 240
    printf("a << 2: %d \n", c);   // a << 2: 240
    c = a >> 2;          // 오른쪽 2칸 → 0000 1111 → 60 ÷ 4 → 15
    printf("a >> 2: %d \n", c);   // a >> 2: 15
    return 0;                     // 0(정상 종료)을 운영체제에 돌려주고 끝냄
}                                 // main 함수 끝
```
```output
a & b: 12 
a | b: 61 
a ^ b: 49 
~a: -61 
a << 2: 240 
a >> 2: 15 
```
- `%d` 뒤에 **공백 한 칸**이 있어서 숫자 뒤에 공백이 찍혀요 (`"~a: %d \n"`)
- 혼자 연습: `~13` → −(13 + 1) = **−14** · `13 << 1` → 0001 1010 = **26** · `13 >> 1` → 0000 0110 = **6** (끝의 1 은 버림)

### ④ 우선순위 · 필기 정정
- ⭐ **강조** — 괄호 → 단항 → 산술 → 관계 → 논리 → 조건(삼항) → 대입 → 콤마 · `3<<2+5<<3` = `3<<7<<3` = **3072** (+ 가 먼저) · 52 를 원하면 `(3<<2)+(5<<3)`
- `x = 3+4, 5-10;` → x = **7** (대입이 콤마보다 먼저) · `y = (3+4, 5-10, 2*3);` → **6** (괄호 안 콤마는 맨 뒤 값)
- 관계 연산 결과는 **참 1 / 거짓 0** (강의자료 11p 의 “참이면 0” 은 오타) · `^` 는 논리가 아니라 **비트 XOR**
- `<<` 왼쪽 · `>>` 오른쪽 · `(double)3.45` → 3.450000 (반올림 X) · `0xDF` = 1101 1111 = 223
