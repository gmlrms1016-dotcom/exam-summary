## 2. 🔥 APM 설치 (VITAMIN QUIZ 12-1)

### 2-1. 처음 — 기본 저장소로 설치 (수업 로그)
```term root@localhost:~#
$ rpm -qa httpd php mariadb-server  ## 아무것도 안 나옴 = 아직 설치 안 됨
$ dnf -y install httpd php php-mysqlnd mariadb-server  ## 처음엔 `Curl error (28): Timeout` · `404` → ^C 뒤 다시 치니 설치됨
종속성이 해결되었습니다.
 httpd                x86_64 2.4.63-1.el10_0.2  appstream  52 k
 mariadb-server       x86_64 3:10.11.11-1.el10  appstream 9.9 M
 php                  x86_64 8.3.19-1.el10_0    appstream  11 k
 php-mysqlnd          x86_64 8.3.19-1.el10_0    appstream 141 k
설치  39 꾸러미
```
- `rpm -qa 이름` = 설치돼 있는지 확인 (아무것도 안 나오면 없음) → 기본 저장소 PHP = **8.3.19** · httpd 2.4.63 · mariadb-server 10.11.11 → 39 꾸러미
- 🤖 ownCloud 10 은 **PHP 7.4** 가 필요 → 아래처럼 **Remi 저장소**의 PHP 7.4 로 다시 설치

### 2-2. 🔥 Remi 저장소 + PHP 7.4 (과제 = 이 순서)
```bash
dnf -y install dnf-utils https://rpms.remirepo.net/enterprise/10/remi/x86_64/remi-release-10.0-3.el10.remi.noarch.rpm   # Remi 저장소 등록 (EPEL 도 같이)
dnf -y module reset php                     # PHP 모듈 선택을 처음으로
dnf -y module enable php:remi-7.4           # PHP 7.4 (Remi) 를 쓰겠다고 정함
dnf -y install httpd mariadb-server php php-mysqlnd php-gd php-mbstring php-pecl-zip php-xml php-json php-intl
```
- `php-mysqlnd` = PHP 가 MariaDB 에 연결하는 부품 · gd(그림) · mbstring(한글 같은 여러 바이트 글자) · zip · xml · json · intl = ownCloud 가 쓰는 PHP 확장
- 학교 PC 기록: 한 줄(`&&`)로 이어 치면 PHP **7.4.33** + httpd + mariadb-server **56 꾸러미** 설치 · 미러 연결 실패는 다른 미러로 넘어가서 괜찮음 · “PHP 7.4 End of Life” 경고는 정상

### 2-3. 서비스 켜기 · 확인
```bash
systemctl restart mariadb && systemctl enable mariadb    # DB 서버 시작 + 부팅 때 자동 시작
systemctl restart httpd && systemctl enable httpd        # 웹 서버 시작 + 자동 시작
systemctl status mariadb --no-pager                      # active (running) 이면 정상
systemctl status httpd --no-pager
```
- `restart` = 껐다 켜기(꺼져 있으면 켬) · `enable` = 부팅할 때 자동으로 · `status` = 지금 상태 · `--no-pager` = 한 화면에 다 출력하고 바로 프롬프트로

### 2-4. 방화벽 · 웹 페이지 확인
```bash
firewall-cmd --permanent --add-service=http     # 80번 (웹)
firewall-cmd --permanent --add-service=https    # 443번 (보안 웹)
firewall-cmd --reload                           # 바꾼 설정 적용
firewall-cmd --list-services                    # 열린 서비스 목록에 http https 가 보이면 됨
echo '<?php phpinfo(); ?>' > /var/www/html/phpinfo.php    # PHP 정보 페이지
ip addr                                         # ens160 의 inet = 서버 주소 (Server 192.168.111.100 · Server(B) .200)
```
- 수업(Server · GNOME) = 그래픽 **`firewall-config`** 창 → 설정 **런타임 → 영구적** · 영역 public · 서비스 탭에서 **http · https 체크** → 옵션 → Firewalld 다시 불러오기 · 창은 **파일 → 끝내기**로 닫기 (학교 PC 기록)
- 수업은 `gedit index.html` 로 첫 화면을 만들고(Rocky 10 은 `alias gedit="gnome-text-editor"`) Windows 크롬 **`http://192.168.111.100`** · **`/phpinfo.php`** 로 확인 · 📖 phpinfo.php = 교재 714쪽
- 🤖 웹 문서 폴더 = **/var/www/html** — 주소창 `http://IP/파일이름` 이 이 폴더의 파일

`cd /var/www/html` 로 웹 문서 폴더에 들어간 뒤:

```term root@localhost:/var/www/html#
$ wget https://download.owncloud.com/server/stable/owncloud-10.15.3.zip  ## 인터넷에서 내려받기
```

| 순서 | 명령 | 하는 일 |
|---|---|---|
| 1 | `wget 주소` | 인터넷에서 파일 내려받기 (69M zip) |
| 2 | `unzip -q` | 조용히(-q) 압축 풀기 → owncloud 폴더 |
| 3 | `mkdir owncloud/data` | 올린 파일이 저장될 폴더 |
| 4 | 🔥 `chown -R apache:apache owncloud` | 주인 · 그룹을 **apache** 로 (-R = 안쪽까지 모두) — 🤖 웹 서버(httpd)가 apache 사용자로 돌아서 이래야 data 에 쓸 수 있음 |
| 5 | `chmod -R 755 owncloud` | 주인 rwx · 나머지 r-x (7 = 4+2+1 · 5 = 4+1) |
| 6 | `systemctl restart httpd` | 웹 서버 다시 시작 |

## 6. 📖 웹 서버 설정 파일 httpd.conf (12.3 · 747 ~ 748쪽)
- 아파치 설정 파일 = **`/etc/httpd/conf/httpd.conf`** — 고급 웹 서비스를 만들려면 의미를 알아 두면 좋음 (수업 · 과제에선 고치지 않음)

| 📖 설정 | 뜻 |
|---|---|
| `ServerRoot "/etc/httpd"` | 웹 서버의 설정 파일 · 로그 파일 등이 저장되는 **최상위 디렉터리** |
| `Listen 80` | 웹 서버의 **포트 번호** (대부분 80번) |
| `Include conf.modules.d/*.conf` | 설정 파일에 포함될 파일의 경로와 이름 |
| `User apache` / `Group apache` | 웹 서비스를 작동하는 **사용자와 그룹** (→ ownCloud 를 `chown apache:apache` 한 이유) |
| `ServerAdmin root@localhost` | 관리자의 메일 주소 |
| `DocumentRoot "/var/www/html"` | 웹 서버의 **홈 디렉터리** — `http://서버IP` 로 접속되는 디렉터리 |
| `<Directory "/var/www/html">` … `</Directory>` | **디렉터리 단위**로 허가 · 거부 등 접근 권한 설정 · `Options Indexes FollowSymLinks` = DirectoryIndex 에 지정된 파일(index.html 등)이 없으면 **파일 목록을 대신 출력** · `AllowOverride None` · `Require all granted` |

- 고친 뒤 문법 검사 = **`service httpd configtest`** → 이상이 없으면 **`Syntax OK`**

## 7. 명령어 한 줄 사전

| 명령 | 뜻 |
|---|---|
| `rpm -qa 이름` | 설치된 꾸러미 찾기 |
| `dnf -y install 꾸러미…` | 꾸러미 설치 (-y = 묻지 않고 예) |
| `dnf -y module reset php` · `module enable php:remi-7.4` | PHP 버전 고르기 (Remi 7.4) |
| `systemctl restart · enable · status 서비스` | 다시 시작 · 부팅 때 자동 · 상태 |
| `firewall-cmd --permanent --add-service=http` · `--reload` · `--list-services` | 방화벽 열기 · 적용 · 목록 |
| `ip addr` | IP 주소 보기 |
| `echo '<?php phpinfo(); ?>' > 파일` | 한 줄 파일 만들기 (`>` = 덮어쓰기) |
| `wget 주소` · `unzip -q 파일` | 내려받기 · 압축 풀기 |
| `chown -R 사용자:그룹 폴더` · `chmod -R 755 폴더` | 주인 바꾸기 · 권한 바꾸기 (안쪽까지) |
| `mysql` → `create database` · `create user` · `grant all on DB.* to` | DB · 사용자 · 권한 |
