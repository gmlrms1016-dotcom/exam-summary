## 1. ✍️ 널 값과 집계함수 — Quiz 10-3 · 10-4 (강의자료 6 · 7쪽)
✍️ **필기**
- 널 값(NULL) 과 **산술연산**(+ − × ÷)의 결과는 **NULL** 이다
- `AVG(필드)` : NULL 값 **제외** · `COUNT(필드)` : NULL 값 **제외** · `COUNT(*)` : NULL 값 **포함**

```sql
SELECT 10 + NULL, 10 * NULL, NULL / 2;               -- 숫자와 NULL 을 계산하면 → 모두 NULL
```
| 10 + NULL | 10 * NULL | NULL / 2 |
|---|---|---|
| NULL | NULL | NULL |

### [Quiz 10-3] SAMPLE 1 (6쪽)
| col1 | col2 | col3 |
|---|---|---|
| NULL | 30 | 15 |
| 25 | NULL | 0 |
| 65 | 20 | NULL |

```sql
CREATE TABLE sample (col1 int, col2 int, col3 int);  -- 슬라이드의 SAMPLE 표
INSERT INTO sample VALUES (NULL, 30, 15);             -- 1행
INSERT INTO sample VALUES (25, NULL, 0);              -- 2행 — col3 의 0 은 NULL 이 아니라 '값 0'
INSERT INTO sample VALUES (65, 20, NULL);             -- 3행
SELECT AVG(col1) result1,                             -- col1 의 NULL 은 빼고 → (25 + 65) ÷ 2
       SUM(col2) result2,                             -- col2 의 NULL 은 빼고 → 30 + 20
       COUNT(col3) result3                            -- col3 에서 NULL 이 아닌 값의 개수 → 15 · 0 → 2
FROM sample;                                          -- SAMPLE 에서
```
| result1 | result2 | result3 |
|---|---|---|
| 45.0000 | 50 | 2 |

> ✍️ 내 풀이 `(25+65)/2 · 30+20 · 2` → **45 · 50 · 2** ✅ (MySQL 은 AVG 를 45.0000 처럼 소수 4자리로 보여 줘요) · 🤖 col3 의 **0 은 값**이라 COUNT 에 들어가요 (NULL 만 빠짐).

### [Quiz 10-4] SAMPLE 2 (7쪽)
| col1 | col2 |
|---|---|
| 10 | 5 |
| 20 | NULL |
| NULL | 15 |

```sql
CREATE TABLE sample2 (col1 int, col2 int);            -- 슬라이드의 SAMPLE 표 (Quiz 10-4)
INSERT INTO sample2 VALUES (10, 5);                   -- 1행
INSERT INTO sample2 VALUES (20, NULL);                -- 2행 — col2 가 NULL
INSERT INTO sample2 VALUES (NULL, 15);                -- 3행 — col1 이 NULL
SELECT SUM(col1), SUM(col2)                           -- ③ 남은 행으로 합계
FROM sample2                                          -- ① SAMPLE 에서
WHERE col2 IS NOT NULL;                               -- ② col2 가 NULL 인 2행(20, NULL)을 먼저 뺌 → 1행 · 3행만 남음
```
| SUM(col1) | SUM(col2) |
|---|---|
| 10 | 20 |

> ⚠️ **정정** — 내 풀이는 `SUM(col1) = 10 + 20 = 30` 이었는데, WHERE 가 **먼저** (20, NULL) 행을 빼서 col1 에는 **10 과 NULL** 만 남아요 → SUM(col1) = **10** · SUM(col2) = 5 + 15 = **20** (MySQL 로 확인). WHERE 가 없으면 30 · 20 이 나와요 — 실행 순서 FROM → **WHERE** → SELECT ([9주차](데이터베이스관리-9주차.html)).

## 2. 🔥 관계대수 — 일반 집합 연산 (강의자료 18 ~ 24쪽) · 기말 = 합집합
✍️ **필기** — 관계대수: **집합** · (MySQL) 1. **합집합 UNION** · (문법 지원하지 않음) 2. 교집합 INTERSECT · 3. 차집합 MINUS (Oracle) · EXCEPT (MS SQL)

| 연산자 (18쪽) | 기호 | 표현 | 뜻 |
|---|---|---|---|
| 🔥 **합집합** | ∪ | R ∪ S | R 과 S 의 합집합 → SQL **`UNION`** |
| 교집합 | ∩ | R ∩ S | R 과 S 의 교집합 → `INTERSECT` |
| 차집합 | − | R − S | R 과 S 의 차집합 → `MINUS`(Oracle) · `EXCEPT`(MS SQL) |
| 카티션 프로덕트 | × | R × S | R 의 각 투플과 S 의 각 투플을 모두 연결 (4번 조인) |

> 19쪽 예제 — A = {1, 3, 6} · B = {2, 3, 7} → **A ∪ B = {1, 2, 3, 6, 7}** · A ∩ B = {3} · A − B = {1, 6}

```sql
CREATE TABLE 사원 (사번 int, 이름 varchar(20), PRIMARY KEY(사번));   -- 24쪽 실습 — 사원 테이블
CREATE TABLE 직원 (사번 int, 이름 varchar(20), PRIMARY KEY(사번));   -- 직원 테이블 (열 구성이 사원과 같음)
insert into 사원 values(1, '고길동');                                -- 사원: 고길동
insert into 사원 values(2, '이순신');                                -- 사원: 이순신
insert into 직원 values(2, '이순신');                                -- 직원: 이순신 (사원과 겹침)
insert into 직원 values(3, '둘리');                                  -- 직원: 둘리
select * from 사원                                                    -- 🔥 합집합 — 사원 행
UNION                                                                 -- UNION = 두 결과를 합치고 중복은 한 번만
select * from 직원;                                                   -- + 직원 행 → 이순신은 한 번만
select * from 사원                                                    -- 20쪽 [Quiz] UNION ALL
UNION ALL                                                             -- UNION ALL = 중복도 그대로 (합치기만)
select * from 직원;                                                   -- → 이순신이 두 번
```
🔥 `UNION` (중복 제거) · `UNION ALL` (중복 포함)

| 사번 | 이름 |
|---|---|
| 1 | 고길동 |
| 2 | 이순신 |
| 3 | 둘리 |

| 사번 | 이름 |
|---|---|
| 1 | 고길동 |
| 2 | 이순신 |
| 2 | 이순신 |
| 3 | 둘리 |

| 20쪽 [Quiz] UNION vs UNION ALL | 결과 |
|---|---|
| `UNION` | 두 SELECT 결과를 합치고 **중복 행은 한 번만** → 3행 |
| `UNION ALL` | **중복까지 모두** → 4행 (이순신 2번) |

> 🔥 **합병 가능 (union-compatible)** — 합집합 · 교집합 · 차집합은 두 릴레이션의 **속성 개수가 같고 대응하는 속성의 도메인(자료형)이 같아야** 해요 (21쪽 — 고객(…, 나이 INT) 와 직원(…, 직위 CHAR) 은 불가능 ✕ · 나이 INT 끼리는 가능 ○). 🤖 열 개수가 다르면 MySQL 은 **ERROR 1222 The used SELECT statements have a different number of columns** (`select 사번, 이름 from 사원 UNION select 사번 from 직원;` — MySQL 로 확인).

> ⚠️ **팩트체크** — 필기 “교집합 · 차집합은 (MySQL) 문법 지원하지 않음” → **MySQL 8.0.31 부터는 `INTERSECT` · `EXCEPT` 를 지원**해요 (이 맥 MySQL 8.4 에서 `INTERSECT` → 2 이순신 · `EXCEPT` → 1 고길동 확인 · 학교 MySQL 이 그보다 낮은 버전이면 오류). `MINUS` 는 MySQL 에 없어서 **ERROR 1064** (문법 오류). 시험은 필기대로 **합집합만**.

## 3. 🔥 순수 관계 연산 — 실렉션 σ · 프로젝션 π (강의자료 26 ~ 28쪽 · 28쪽 = 기말)
| 연산 (26쪽) | 기호 | 뜻 | SQL |
|---|---|---|---|
| ✍️ **실렉션** (selection) = 시그마 | **σ** | 원하는 **행**(투플)을 검색 — 조건을 만족하는 투플 | `SELECT * FROM 테이블 WHERE 조건;` |
| ✍️ 🔥 **프로젝션** (projection) = 파이 | **π** | 원하는 **열**(속성)을 검색 | `SELECT 원하는 필드 FROM 테이블;` |
| 조인 | ⋈ | 공통 속성으로 두 릴레이션의 투플을 연결 | 4번 |
| 디비전 | ÷ | S 의 모든 투플과 관련 있는 R 의 투플 | (수업에서 다루지 않음) |

> ⚠️ 필기의 `프로젝션(PRODUCTION)` → **PROJECTION** 이에요 (production = 생산). 필기의 `S · F · W` 는 SELECT · FROM · WHERE 를 줄여 쓴 것.

```sql
-- 고객(고객아이디, 고객이름, 나이, 등급, 직업, 적립금) — 아래 6번 Quiz 10-2 의 고객 테이블로 실행
SELECT 고객이름, 등급, 적립금                          -- 🔥 28쪽 프로젝션 π 고객이름,등급,적립금 (고객) — 열 3개만
FROM 고객;                                             -- 고객의 모든 행 (조건 없음)
SELECT *                                               -- 27쪽 실렉션 σ 등급='gold' (고객) — 모든 열
FROM 고객                                              -- 고객에서
WHERE 등급='gold';                                     -- 등급이 gold 인 행만
```

## 4. 조인 — [Quiz 10-5] R1 · S1 (강의자료 9 · 36 ~ 39쪽)
✍️ **필기** — **조인(join)**: 2개 이상의 테이블에서 일치하는 행을 검색
- **카티션 프로덕트** (cartesian product) : **×**
- **동등조인** (equi join) : **=**
- **자연조인** (natural join) : 동등조인에서 **공통 필드 한 개를 제거**한 것
- **세타조인** (theta join) : `>` `>=` `=` `<>` `<=` `<`

| R1 | | | S1 | | |
|---|---|---|---|---|---|
| **A** | **B** | | **A** | **C** | **D** |
| 1 | 4 | | 1 | 3 | 4 |
| 2 | 5 | | 2 | 2 | 6 |
| | | | 3 | 1 | 9 |

```sql
create table R1 (A int, B int);                       -- R1(A, B)
insert into R1 values(1,4);                           -- R1 1행
insert into R1 values(2,5);                           -- R1 2행
create table S1 (A int, C int, D int);                -- S1(A, C, D)
insert into S1 values(1,3,4);                         -- S1 1행
insert into S1 values(2,2,6);                         -- S1 2행
insert into S1 values(3,1,9);                         -- S1 3행
select * from R1, S1;                                 -- 1. 카티션 프로덕트 R1 × S1 — 조건 없이 모든 짝 → 2 × 3 = 6행
select * from R1, S1 where R1.A = S1.A;               -- 2. 동등조인 R1 ⋈ S1 — A 가 같은 짝만 → 2행 (A 열이 2개)
select R1.A, B, C, D from R1, S1 where R1.A = S1.A;   -- 3. 자연조인 R1 ⋈N S1 — 동등조인에서 같은 A 열 하나를 뺌 (38쪽)
select * from R1, S1 where R1.A >= C;                 -- 4. 세타조인 R1 ⋈(R1.A>=C) S1 — 비교 연산자로 짝 짓기 (39쪽)
```
1. 카티션 프로덕트 — 2 × 3 = **6행** · 열은 2 + 3 = **5개**

| A | B | A | C | D |
|---|---|---|---|---|
| 2 | 5 | 1 | 3 | 4 |
| 1 | 4 | 1 | 3 | 4 |
| 2 | 5 | 2 | 2 | 6 |
| 1 | 4 | 2 | 2 | 6 |
| 2 | 5 | 3 | 1 | 9 |
| 1 | 4 | 3 | 1 | 9 |

2. 동등조인 (`R1.A = S1.A`) — A 열이 **두 번** 나와요

| A | B | A | C | D |
|---|---|---|---|---|
| 1 | 4 | 1 | 3 | 4 |
| 2 | 5 | 2 | 2 | 6 |

3. 자연조인 — 공통 열 A 를 **하나만**

| A | B | C | D |
|---|---|---|---|
| 1 | 4 | 3 | 4 |
| 2 | 5 | 2 | 6 |

4. 세타조인 (`R1.A >= C`) — R1.A = 1 → C 가 1 인 (3, 1, 9) 만 · R1.A = 2 → C 가 2 · 1 인 두 짝 → **3행**

| A | B | A | C | D |
|---|---|---|---|---|
| 2 | 5 | 2 | 2 | 6 |
| 2 | 5 | 3 | 1 | 9 |
| 1 | 4 | 3 | 1 | 9 |

> 🤖 MySQL 은 자연조인을 `select * from R1 NATURAL JOIN S1;` 로도 쓸 수 있어요 — 결과는 3번과 같음 (A · B · C · D · MySQL 로 확인). 카티션 프로덕트의 행 순서는 MySQL 이 정한 것 (집합이라 순서는 상관없음).

## 5. [Quiz 10-1] fruit (강의자료 3쪽)
```sql
create table fruit (                                  -- fruit 테이블 만들기 (기본키: 과일번호)
    과일번호     int      NOT NULL  ,                  -- 과일번호 — 정수 · 필수
    과일이름     varchar(30)           ,               -- 과일이름
    가격           int                      ,          -- 가격
    색상           char(12)              ,             -- 색상
    원산지        varchar(30)          ,               -- 원산지
    PRIMARY KEY(과일번호)                              -- 과일번호를 기본키로
);                                                    -- CREATE TABLE 끝
insert into fruit values('1','사과',2000,'빨간색','한국');         -- '1' 처럼 따옴표를 써도 int 열이라 숫자 1 로 들어감

insert into fruit values('3','바나나',1500,'노란색','인도네시아');  -- 3 바나나
insert into fruit values('4','키위',4000,'초록색','호주');         -- 4 키위
insert into fruit values('5','수박',8000,'초록색','한국');         -- 5 수박

-- ✍️ 내 답
SELECT 과일이름,색상 FROM fruit WHERE 색상='노란색';              -- 2-1) 노란색 → 배 · 바나나
SELECT * FROM fruit ORDER BY 과일이름;                           -- 2-2) 과일이름 오름차순 (ASC 생략 = 오름차순)
SELECT 과일이름 FROM fruit WHERE 가격<=5000 AND 색상='빨간색';     -- 2-3) 5000 이하 이면서 빨간색 → 사과
SELECT 과일이름,가격,원산지 FROM fruit WHERE 가격 BETWEEN 2000 AND 5000;   -- 2-4) 2000 ~ 5000 (양 끝 포함)
SELECT 과일이름,색상 FROM fruit WHERE 색상 IN('노란색','초록색');   -- 2-5) IN
SELECT 과일이름,색상 FROM fruit WHERE 색상='노란색' OR 색상='초록색';   -- 2-6) OR — 2-5 와 같은 결과

```

## 6. [Quiz 10-2] 고객 — NOT NULL · DEFAULT (강의자료 4쪽)
조건: 고객아이디 = **기본키** · 고객이름 = **반드시 입력**(NOT NULL) · 적립금 = 입력하지 않으면 **0 이 기본**(DEFAULT 0)

```sql
create table 고객 (                                   -- 고객 테이블 만들기
    고객아이디  varchar(8)      NOT NULL  ,            -- 고객아이디 — 필수
    고객이름     varchar(20)    NOT NULL  ,            -- 고객이름 — 반드시 입력 (NOT NULL)
    나이           int ,                               -- 나이 — 비워도 됨
    등급           varchar(10) ,                       -- 등급
    직업           varchar(20) ,                       -- 직업
    적립금        int                DEFAULT 0 ,       -- 적립금 — 값을 안 주면 0 (DEFAULT)
    PRIMARY KEY(고객아이디)                            -- 고객아이디를 기본키로
);                                                    -- CREATE TABLE 끝

-- ✍️ 내 답
SELECT 고객이름,직업,등급 FROM 고객 WHERE 직업 IN('학생','간호사','교사');   -- 2-1) 직업이 셋 중 하나
SELECT 고객아이디,나이,적립금 FROM 고객 WHERE 적립금>=300 AND 나이 IS NULL;  -- 2-2) 300 이상 이면서 나이를 모름(IS NULL)
SELECT 고객아이디,나이,등급,적립금 FROM 고객 WHERE 나이>=25 ORDER BY 등급,적립금 DESC;   -- 2-3) 등급 ↑ → 같으면 적립금 ↓
SELECT 등급,AVG(적립금) FROM 고객 GROUP BY 등급 HAVING AVG (적립금)>=1000;   -- 2-4) 등급별 평균 → 1000 이상인 등급만
```

> 🤖 2-4 — silver 는 적립금이 NULL · 300 · 500 → AVG 는 NULL 을 빼고 (300 + 500) ÷ **2** = 400 이라 빠져요 (COUNT(*) = 3 · COUNT(적립금) = 2). 2-3 의 등급은 글자라 **가나다(알파벳) 순** gold → silver → vip.
