### Tools.java — import · java.lang.String (수업 소스 + 확인용 줄)
```java
// Tools.java — 패키지 · import · 경로명 (수업 소스 + 확인용 줄 · package test; 는 뺌)
import java.util.Scanner;                       // java.util 패키지의 Scanner 를 이 파일에서 이름만으로 쓰겠다고 알림
public class 연습 {                              // 원래 이름 Tools → 파일 이름도 연습.java
    public static void main(String[] args) {    // 프로그램 시작
        Scanner sc = new Scanner(System.in);    // import 했으니 Scanner 만 써도 됨 (import 를 빼면 cannot find symbol)
        java.lang.String school = "동양미래대학교";   // 수업 소스 — String 의 전체 경로명 java.lang.String 으로 써도 됨
        String school2 = "동양미래대학교";            // java.lang 은 자동 import → 보통은 String 만 씀 (26쪽)
        java.util.Scanner sc2 = new java.util.Scanner(System.in);   // import 없이 쓰려면 전체 경로명 (7쪽)
        System.out.println(school + " " + school2);  // 같은 String → "동양미래대학교 동양미래대학교"
    }                                           // main 끝
}                                               // 연습 끝
```
```output

```

### ① Point + Main — toString() 오버라이딩 · getter/setter · == (수업 소스)
```java
// Point.java + Main.java — toString() 오버라이딩 · getter/setter · == 비교 (수업 소스를 한 파일로)
class Point {                                   // 점 클래스 (수업은 public class Point — 한 파일로 합쳐서 public 뺌)
    private int x, y;                           // 속성 — private 라 밖에서 p1.x 로 못 씀
    Point() {}                                  // 기본 생성자 (수업 주석 “생성자”)
    Point(int x, int y) {                       // 매개변수 생성자 — new Point(2, 3)
        this.x = x;                             // this.x(필드) = x(매개변수) → 2
        this.y = y;                             // this.y = y → 3
    }                                           // 생성자 끝
    @Override                                   // Object 의 toString() 을 다시 씀 (오버라이딩 · 11주차)
    public String toString() {                  // public 꼭 (빼면 weaker access privileges 오류)
        return ("x : " + x + "\t" + "y : " + y);   // "x : 2" + 탭 + "y : 3" 을 이어 붙인 문자열을 돌려줌
    }                                           // toString 끝
    public int getX() {                         // getter — x 값 꺼내기
        return x;                               // x 돌려줌
    }                                           // getX 끝
    public void setX(int x) {                   // setter — x 값 바꾸기
        this.x = x;                             // 필드 x = 매개변수 x
    }                                           // setX 끝
    public int getY() {                         // getter — y
        return y;                               // y 돌려줌
    }                                           // getY 끝
    public void setY(int y) {                   // setter — y
        this.y = y;                             // 필드 y = 매개변수 y
    }                                           // setY 끝
}                                               // Point 끝
public class 연습 {                              // 원래 이름 Main → 파일 이름도 연습.java
    public static void main(String[] args) {    // 프로그램 시작
        Point p1 = new Point(2, 3);             // p1 → (2, 3) 객체
        System.out.println(p1);                 // 객체만 넣어도 p1.toString() 자동 호출 → x : 2 (탭) y : 3
        System.out.println(p1.toString());      // 직접 불러도 같음 → x : 2 (탭) y : 3
        Point p2 = new Point(2, 3);             // 값은 같지만 new 로 만든 다른 객체
        if (p1 == p2) {                         // == 는 레퍼런스(주소) 비교 → 서로 다른 객체 → false
            System.out.println("p1과 p2는 같습니다.");     // 실행 안 됨
        }                                       // if 끝
        else if (p1 != p2) {                    // != → true
            System.out.println("p1과 p2는 같지않습니다.");  // 이 줄 실행
        }                                       // else if 끝
        else {                                  // == 도 != 도 아닌 경우는 없음
            System.out.println("error");        // 실행될 일 없음
        }                                       // else 끝
        p1.setX(4);                             // setter 로 x = 4
        p1.setY(5);                             // y = 5
        System.out.println("\np1.setX(4) and p1.setY(5) after\n" + p1.toString());   // \n 빈 줄 → 안내 줄 → x : 4 (탭) y : 5
    }                                           // main 끝
}                                               // 연습 끝
```
```output
x : 2	y : 3
x : 2	y : 3
p1과 p2는 같지않습니다.

p1.setX(4) and p1.setY(5) after
x : 4	y : 5
```

| 이렇게 쓰면 (🤖 javac 로 확인) | 결과 |
|---|---|
| toString() 을 **안 쓰면** | Object 의 것 → `Point@` + 16진수 해시코드 (30쪽) · 패키지 안의 클래스면 `test.Point@…` 처럼 **패키지 이름까지** |
| `public` 을 빼고 `String toString()` | 컴파일 오류 `attempting to assign weaker access privileges; was public` (Object 의 toString 이 public) |
| `p1 == p2` | **false** — 값이 같아도 `new` 로 만든 **다른 객체** (3번) |
| `p1.equals(p2)` (equals 를 안 쓴 Point) | **false** — Object 의 equals 는 `==` 처럼 레퍼런스 비교 (3번) |

### ② Car + CarMain — "car1" + car1 (수업 소스)
```java
// Car.java + CarMain.java — "car1" + car1 → car1.toString() 자동 호출 (수업 소스를 한 파일로)
class Car {                                     // 자동차 클래스
    private String juin;                        // 소유주 (수업 변수 이름 그대로 · juin = 주인)
    private String model;                       // 모델
    private int year;                           // 연식
    Car() {}                                    // 기본 생성자
    Car(String juin, String model, int year) {  // 매개변수 생성자
        this.juin = juin;                       // 필드 = 매개변수 → "아빠차"
        this.model = model;                     // → "BMW"
        this.year = year;                       // → 2023
    }                                           // 생성자 끝
    @Override                                   // Object 의 toString() 오버라이딩
    public String toString() {                  // 객체를 문자열로
        return ("\t소유주 : " + juin + "\t모델 : " + model + "\t연식 : " + year);   // 탭 + 소유주 : 아빠차 + 탭 + 모델 : BMW + 탭 + 연식 : 2023
    }                                           // toString 끝
    public String getJuin() {                   // getter (수업 소스의 model · year getter/setter 는 안 써서 뺌)
        return juin;                            // 소유주 돌려줌
    }                                           // getJuin 끝
    public void setJuin(String juin) {          // setter
        this.juin = juin;                       // 소유주 바꿈
    }                                           // setJuin 끝
}                                               // Car 끝
public class 연습 {                              // 원래 이름 CarMain → 파일 이름도 연습.java
    public static void main(String[] args) {    // 프로그램 시작
        Car car1 = new Car("아빠차", "BMW", 2023);     // car1 객체
        Car car2 = new Car("엄마차", "벤츠", 2020);    // car2 객체
        System.out.println("car1" + car1);      // 문자열 + 객체 → "car1" + car1.toString() 으로 자동 변환 (30쪽)
        System.out.println("car2" + car2.toString());   // 직접 불러도 같은 모양
        car1.setJuin("내차");                     // 주인 수정 (setter)
        System.out.println("\ncar1.setJuin(\"내차\") after\ncar1" + car1);   // \" = 큰따옴표 글자 · 빈 줄 → 안내 → 바뀐 car1
    }                                           // main 끝
}                                               // 연습 끝
```

### ③ FishBread + MainFish — 붕어빵 가격 인상 (수업 소스)
```java
// FishBread.java + MainFish.java — 붕어빵 맛 · 가격 · toString() · setter 로 가격 인상 (수업 소스를 한 파일로)
class FishBread {                               // 붕어빵 클래스 (수업은 public class — 합쳐서 public 뺌)
    private String flavor;                      // 맛
    private int price;                          // 가격
    FishBread() {}                              // 기본 생성자
    FishBread(String flavor, int price) {       // 매개변수 생성자
        this.flavor = flavor;                   // 맛 = "팥" …
        this.price = price;                     // 가격 = 1000 …
    }                                           // 생성자 끝
    @Override                                   // Object 의 toString() 오버라이딩
    public String toString() {                  // 객체를 문자열로
        return ("맛 : " + flavor + "\n가격 : " + price + "원\n");   // "맛 : 팥" → 줄바꿈 → "가격 : 1000원" → 줄바꿈 (끝의 \n 때문에 println 하면 빈 줄이 하나 더)
    }                                           // toString 끝
    public void setPrice(int price) {           // setter — 가격 바꾸기 (수업 소스의 다른 getter/setter 는 안 써서 뺌)
        this.price = price;                     // 2000 → 2500 …
    }                                           // setPrice 끝
}                                               // FishBread 끝
public class 연습 {                              // 원래 이름 MainFish → 파일 이름도 연습.java

        FishBread f2 = new FishBread("슈크림", 2000);    // 슈크림 2000원

        f2.setPrice(2500);                      // 슈크림 2000 → 2500
        f3.setPrice(3500);                      // 치즈 3000 → 3500
        System.out.println(f1);                 // 팥은 그대로 1000원
        System.out.println(f2);                 // 슈크림 2500원
        System.out.println(f3);                 // 치즈 3500원
    }                                           // main 끝
}                                               // 연습 끝
```

## 3. == vs equals() — ✍️ 43쪽 질문 (6장 32 · 33 · 42 ~ 44쪽)
✍️ **필기** — “강의자료 43페이지에서 if(e==f) 의 결과가 false 가 나오는 이유는? equals() 로 비교하면 true 가 나온다?”

🤖 **답 — 네, `e.equals(f)` 는 true 예요** (java 로 확인)
- `==` 연산자 = **두 개의 레퍼런스 비교** (32쪽) → **같은 객체**를 가리켜야 true
- `boolean equals(Object obj)` = **객체 내용이 같은지 비교** (32쪽) → String 의 equals 는 글자가 같으면 true
- 43쪽 그림 — **리터럴**(`String a = "Hello";`)은 **JVM 이 리터럴 테이블에서 관리 · 응용프로그램 안에서 공유** → a 와 c 는 **같은 객체** / **`new String("Hello")`** 는 **힙 메모리에 String 객체를 새로** 만듦 → e 와 f 는 내용("Java")은 같지만 **서로 다른 객체** → `e == f` **false** · `e.equals(f)` **true**

```java
// 43쪽 — 스트링 리터럴과 new String() · == 와 equals() 비교 (✍️ 필기 질문 확인)
public class 연습 {                              // 43쪽 코드에 비교하는 줄을 더함
    public static void main(String[] args) {    // 프로그램 시작
        String a = "Hello";                     // 리터럴 → JVM 의 스트링 리터럴 테이블에 "Hello"
        String b = "Java";                      // 리터럴 → 테이블에 "Java"
        String c = "Hello";                     // 같은 리터럴 → a 와 같은 "Hello" 를 공유 (같은 객체)
        String d = new String("Hello");         // new → 힙 메모리에 새 "Hello" 객체
        String e = new String("Java");          // new → 힙에 새 "Java" 객체
        String f = new String("Java");          // new → 또 다른 새 "Java" 객체 (e 와 다른 객체)
        System.out.println(a == c);             // a · c 는 같은 객체 → 주소가 같음 → true
        System.out.println(e == f);             // ✍️ 질문 — 내용은 같아도 서로 다른 객체(주소가 다름) → false
        System.out.println(e.equals(f));        // ✍️ 질문 — equals 는 내용 비교 → "Java" 와 "Java" → true
        System.out.println(a == d);             // 테이블의 "Hello" vs 힙의 "Hello" → 다른 객체 → false
        System.out.println(a.equals(d));        // 내용 "Hello" 같음 → true
        System.out.println(b.equals(e));        // 내용 "Java" 같음 → true
    }                                           // main 끝
}                                               // 연습 끝
```

- ⚠️ **팩트체크** (44 · 46쪽 “스트링 비교 시 **반드시** equals() 사용 · == 사용하면 안 됨”) — `==` 를 써도 **컴파일 오류는 안 나요** (javac 확인). 주소를 비교해서 **내용이 같아도 false 가 될 수 있으니**(`e == f`) 내용을 비교할 때는 equals() 를 쓰라는 뜻이에요 · 리터럴끼리는 `a == c` 가 true 라서 더 헷갈려요

### 예제 6-3 — Point 에 equals() 작성 (33쪽)
```java
// 예제 6-3 (33쪽) — Point 에 equals() 작성 · 두 점의 좌표가 같으면 true
class Point {                                   // 점 클래스
    private int x, y;                           // 좌표
    public Point(int x, int y) {                // 생성자
        this.x = x;                             // 필드 x = 매개변수 x
        this.y = y;                             // 필드 y = 매개변수 y
    }                                           // 생성자 끝
    public boolean equals(Object obj) {         // Object 의 equals(Object) 를 오버라이딩 — 매개변수 타입이 Object 라야 함
        Point p = (Point) obj;                  // Object 로 받은 것을 Point 로 바꿈 (다운캐스팅) → p.x · p.y 를 쓰려고
        if (x == p.x && y == p.y)               // 내 좌표와 p 의 좌표가 둘 다 같으면 (같은 클래스라 p.x 처럼 private 도 됨)
            return true;                        // → true
        else                                    // 하나라도 다르면
            return false;                       // → false
    }                                           // equals 끝
}                                               // Point 끝
public class 연습 {                              // 원래 이름 EqualsEx → 파일 이름도 연습.java
    public static void main(String[] args) {    // 프로그램 시작
        Point a = new Point(2, 3);              // (2, 3)
        Point b = new Point(2, 3);              // 같은 좌표 · 다른 객체
        Point c = new Point(3, 4);              // 다른 좌표
        if (a == b)                             // 레퍼런스 비교 → 다른 객체 → false
            System.out.println("a==b");         // 실행 안 됨
        if (a.equals(b))                        // 내용 비교 → 2==2 && 3==3 → true
            System.out.println("a is equal to b");   // 이 줄만 실행
        if (a.equals(c))                        // 2==3 → false
            System.out.println("a is equal to c");   // 실행 안 됨
    }                                           // main 끝
}                                               // 연습 끝
```
```output
a is equal to b
```

|---|---|---|
| `a == b` (같은 좌표 · 다른 객체) | false | false |
| `a.equals(b)` | **false** (Object 의 equals = 레퍼런스 비교) | **true** (좌표 비교) |

### 박싱 · 언박싱 (40 · 41쪽)

| **언박싱** (unboxing) | Wrapper 객체에 들어 있는 **기본 타입의 값을 빼내는 것** | `int n = ten.intValue();` |

### 예제 6-7 · StringEx — a 가 바뀌는 과정 (수업 소스 = 교재 예제)
```java
// 예제 6-7 (50쪽) · StringEx.java — String 메소드 활용 · a 가 바뀌는 과정 (수업 소스 = 교재 예제 그대로)
public class 연습 {                              // 원래 이름 StringEx → 파일 이름도 연습.java
    public static void main(String[] args) {    // 프로그램 시작
        String a = new String(" C#");           // a = " C#" (맨 앞 공백 포함 3글자)
        String b = new String(",C++ ");         // b = ",C++ " (맨 뒤 공백 포함 5글자)
        System.out.println(a + "의 길이는 " + a.length());   // 공백 + C + # = 3 → " C#의 길이는 3" (앞 공백 그대로 출력)
        System.out.println(a.contains("#"));    // " C#" 에 "#" 이 있음 → true
        a = a.concat(b);                        // " C#" + ",C++ " → 새 문자열 " C#,C++ " 을 a 에 다시 대입 (원래 문자열은 안 바뀜)
        System.out.println(a);                  // " C#,C++ " (앞뒤 공백 그대로)
        a = a.trim();                           // 앞뒤 공백 제거 → "C#,C++"
        System.out.println(a);                  // "C#,C++"
        a = a.replace("C#", "Java");            // "C#" 을 "Java" 로 → "Java,C++"
        System.out.println(a);                  // "Java,C++"
        String s[] = a.split(",");              // "," 기준으로 나눔 → s[0] = "Java" · s[1] = "C++"
        for (int i = 0; i < s.length; i++)      // i = 0, 1 (s.length = 2)
            System.out.println("분리된 문자열" + i + ": " + s[i]);   // "분리된 문자열0: Java" → "분리된 문자열1: C++"
        a = a.substring(5);                     // "Java,C++" 의 인덱스 5 부터 끝까지 → J0 a1 v2 a3 ,4 C5 → "C++"
        System.out.println(a);                  // "C++"
        char c = a.charAt(2);                   // "C++" 의 인덱스 2 → C0 +1 +2 → '+'
        System.out.println(c);                  // +
    }                                           // main 끝
}                                               // 연습 끝
```
