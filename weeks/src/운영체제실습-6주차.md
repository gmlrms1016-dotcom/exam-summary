## 5. 프로세스 — ps · kill ★

> 🔥 **프로세스** = 하드디스크에 저장된 실행코드가 메모리에 로딩되어 활성화된 것 (1번 시험 용어)

```bash
yes > /dev/null          # (터미널 1) yes = y 를 끝없이 출력 → /dev/null(버리는 곳)으로 보냄 → 화면엔 안 나오고 계속 실행
ps -ef | grep yes        # (터미널 2) ps -ef = 모든 프로세스를 자세히 → grep yes = yes 가 들어간 줄만
```
```output
root        2324    2145 99 14:29 pts/0    00:01:09 yes
root        2352    2328  0 14:30 pts/1    00:00:00 grep --color=auto yes
```

| 칸 | 값 | 뜻 |
|---|---|---|
| UID | root | 실행한 사용자 |
| PID | **2324** | 프로세스 번호 → kill 할 때 씀 |
| PPID | 2145 | 부모 프로세스 번호 (yes 를 실행한 터미널 1 의 bash) |
| C | 99 | CPU 사용률 — yes 가 CPU 를 거의 다 씀 |
| STIME | 14:29 | 시작한 시각 |
| TTY | pts/0 | 실행 중인 터미널 (터미널 1 = pts/0 · 터미널 2 = pts/1) |
| TIME | 00:01:09 | CPU 를 쓴 시간 |
| CMD | yes | 명령 |

- 두 번째 줄은 방금 친 **grep 자기 자신** (pts/1) → 찾는 프로세스는 첫 줄

```bash
kill -9 2324     # -9 = 강제 종료 신호 → PID 2324 (yes) 를 끝냄
```
```output
죽었음
```
- 터미널 1 에 `죽었음` → 영어 화면의 `Killed` (bash 가 강제 종료된 작업을 알려 주는 말)

## 6. 작업 제어 — Ctrl+Z · bg · jobs · fg ★

```bash
yes > /dev/null      # 앞에서(포그라운드) 실행 → 터미널을 붙잡고 있음
```
```output
^Z
[1]+  멈춤                  yes > /dev/null
```
```bash
bg       # 멈춘 작업을 백그라운드(뒤)에서 계속 실행
jobs     # 이 터미널의 작업 목록 → [번호] 상태 명령
fg 1     # 1번 작업을 포그라운드(앞)로 → Ctrl+C 로 종료
```
```output
[1]+ yes > /dev/null &
[1]+  실행중               yes > /dev/null &
yes > /dev/null
^C
```

| 키 · 명령 | 하는 일 |
|---|---|
| `명령 &` | 처음부터 **백그라운드**로 실행 → `[1] 2680` = 작업 번호 · PID |
| **Ctrl + Z** | 포그라운드 작업을 **멈춤**(일시 정지) |
| `bg` | 멈춘 작업을 **백그라운드**에서 계속 |
| `jobs` | 작업 목록 (실행중 · 멈춤 · 완료) |
| `fg 번호` | 그 작업을 **포그라운드**로 |
| **Ctrl + C** | 포그라운드 작업 **종료** |
| `kill -9 PID` | PID 로 **강제 종료** (다른 터미널에서도) |

## 7. gedit — alias 로 편집기 이름 붙이기

```bash
gedit aaa.txt                      # Rocky Linux 10 에는 gedit 가 없음
```
```output
bash: gedit: 명령을 찾을 수 없습니다...
```
```bash
alias gedit="gnome-text-editor"    # alias 새이름="명령" → gedit 라고 치면 gnome-text-editor 가 실행됨
gedit name.sh &                    # & → 편집기를 백그라운드로 띄우고 터미널은 계속 사용
```
```output
[1] 2680
```
- ✍️ 수업 중 실수 — `gditor forin2.sh` → `bash: gditor: 명령을 찾을 수 없습니다...` (gedit 오타)
- 🤖 alias 는 **지금 터미널에서만** 유지돼요 → 새 터미널을 열면 다시 입력 (계속 쓰려면 `~/.bashrc` 에 같은 줄을 넣음)
- 수업에서는 `gedit var1.sh & sh var1.sh` 처럼 한 줄에 → `A & B` = A 는 백그라운드로 띄우고 바로 B 실행 → **소스를 편집기로 보면서** 실행 결과를 확인

## 8. 첫 셸 스크립트 — name.sh 작성 · 실행 ✍️

```bash
echo "사용자 이름:" $USER        # 환경변수 USER = 지금 사용자 → 인자 두 개를 띄어쓰기 하나로 이어서 출력
echo "홈디렉토리:"$HOME          # 따옴표 바로 뒤에 $HOME 을 붙임 → 띄어쓰기 없이 출력
exit 0                           # 스크립트 끝 · 0 = 정상 종료
```
```bash
ls -l na*.sh        # na 로 시작하고 .sh 로 끝나는 파일 → 실행 권한 없음 (rw-r--r--)
chmod +x name.sh    # +x → 실행 권한 추가
ls -l na*.sh        # rwxr-xr-x 로 바뀜
sh name.sh          # sh 로 실행
```
```output
-rw-r--r-- 1 root root 67 10월  8일  14:46 name.sh
-rwxr-xr-x 1 root root 67 10월  8일  14:46 name.sh
사용자 이름: root
홈디렉토리:/root
```
- ✍️ **필기** 내가 쓴 name.sh (67바이트 = 위 세 줄) — 교수님 원본은 첫 줄에 `#!/bin/sh` 가 있고 `echo  "사용자 이름: "  $USER` / `echo  "홈 디렉터리: "  $HOME`
- `#!/bin/sh` = 이 파일을 /bin/sh 로 실행하라는 표시 → `sh name.sh` 처럼 sh 로 실행하면 없어도 됩니다

| 실행 방법 (PPT 5쪽) | 실행 권한 |
|---|---|
| `sh 스크립트파일` | 없어도 됨 |
| `chmod +x 스크립트파일` → `./스크립트파일` | **있어야** 함 |

- 셸 스크립트 파일의 확장명은 되도록 `*.sh` · `/usr/local/bin/` 에 복사하고 `755` 로 바꾸면 모든 사용자가 사용 (보안상 root 만)
- 그다음 교수님 예제 25개(`chapter7_sources`)를 홈 디렉터리에 받아서 실습 → ✍️ **필기** 실습한 파일 = var1 · numcalc · paravar · if1 · if4 · case1 · case2 · andor · forin2

## 9. 변수 — var1.sh ✍️ 수업

```bash
#!/bin/sh                 # /bin/sh 로 실행
myvar="Hi Woo"            # 변수에 값 넣기 → = 좌우에 띄어쓰기가 없어야 함 · 모든 변수는 문자열
echo $myvar               # $변수 → 값으로 바뀜 → Hi Woo
echo "$myvar"             # 큰따옴표 안의 $변수도 값으로 바뀜 → Hi Woo
echo '$myvar'             # 작은따옴표 안은 글자 그대로 → $myvar
echo \$myvar              # \ → 바로 뒤 $ 를 글자로 → $myvar
echo 값 입력 :            # 따옴표 없이 써도 글자 출력 → 값 입력 :
read myvar                # 키보드로 입력한 한 줄을 myvar 에 저장 (예: 3)
echo '$myvar' = $myvar    # 앞은 글자 $myvar · 뒤는 값 3 → $myvar = 3
exit 0                    # 정상 종료
```
```output
Hi Woo
Hi Woo
$myvar
$myvar
값 입력 :
3
$myvar = 3
```

| 쓰는 법 | 결과 | 이유 |
|---|---|---|
| `$myvar` · `"$myvar"` | Hi Woo | 변수 → 값 |
| `'$myvar'` · `\$myvar` | $myvar | 작은따옴표 · `\` → 글자 그대로 |

## 10. 숫자 계산 — numcalc.sh ✍️ 수업

```bash
#!/bin/sh                                     # /bin/sh 로 실행
num1=100                                      # num1 = "100" (문자열)
num2=$num1+200                                # 계산하지 않고 글자를 이어 붙임 → "100+200"
echo $num2                                    # 100+200
num3=`expr  $num1   +  200`                   # `명령` → 명령의 결과로 바뀜 → expr 100 + 200 → 300
echo $num3                                    # 300
num4=`expr  \(  $num1  +  200  \)  /  10  \*  2`   # ( 100 + 200 ) = 300 → 300 / 10 = 30 → 30 * 2 = 60
echo $num4                                    # 60
exit 0                                        # 정상 종료
```
```output
100+200
300
60
```
- ⭐ **강조** 계산은 **expr** · 숫자와 연산자 사이에 **띄어쓰기 필수** · `(` `)` `*` 는 셸의 특수문자라 앞에 **`\`** (`\(` `\)` `\*`)
- `` `명령` `` 과 `$(명령)` 은 같은 뜻 — 명령의 실행 결과로 바뀜

## 12. if 문 — 문자열 · 숫자 비교 (if1 ✍️ · if2 · if3 📝)

```bash
#!/bin/sh                        # if1.sh
if [  "woo"  =  "woo"  ]         # [ 조건 ] → "woo" 와 "woo" 가 같음 → 참 · [ 뒤와 ] 앞에 띄어쓰기 필수
then                             # 참이면 아래 실행
  echo "참입니다"                # 출력
fi                               # if 끝 (if 를 거꾸로)
exit 0                           # 정상 종료
```
```output
참입니다
```
```bash
#!/bin/sh                        # if2.sh
if  [  "woo"  !=  "woo"  ]       # != → 다르면 참 → 같으니까 거짓
then                             # 참이면 (여기는 실행 안 됨)
  echo "참입니다"                # 건너뜀
else                             # 거짓이면 아래 실행
  echo "거짓입니다"              # 출력
fi                               # if 끝
exit 0                           # 정상 종료
```
```output
거짓입니다
```
```bash
#!/bin/sh                        # if3.sh
if [ 100 -eq 200 ]               # -eq → 숫자가 같으면 참 → 100 ≠ 200 → 거짓
then                             # 참이면 (실행 안 됨)
  echo "100과 200은 같다."       # 건너뜀
```

## 18. break · continue · exit — bce.sh 📝

```bash
#!/bin/sh                                                             # bce.sh
echo "무한반복 입력을 시작합니다. (b: break, c: continue, e: exit)"   # 안내
while [ 1 ] ; do                                                      # 무한 반복
  read input                                                          # 한 줄 입력
  case $input in                                                      # 입력에 따라
    b | B)                                                            # b 면
      break;;                                                         # break → while 을 빠져나가 done 다음 줄로
    c | C)                                                            # c 면
      echo "continue를 누르면 while의 조건으로 돌아감"                # 출력
      continue ;;                                                     # continue → 아래를 건너뛰고 while 조건으로
    e | E)                                                            # e 면
      echo  "exit를 누르면 프로그램(함수)를 완전히 종료함"            # 출력
      exit 1;;                                                        # exit → 프로그램 끝 (마지막 echo 도 안 나옴)
  esac;                                                               # case 끝 (그 밖의 입력은 아무 일 없이 다시 read)
done                                                                  # while 끝
echo "break를 누르면 while을 빠져나와 지금 이 문장이 출력됨."         # break 했을 때만 여기까지 옴
exit 0                                                                # 정상 종료
```
```output
무한반복 입력을 시작합니다. (b: break, c: continue, e: exit)
c
continue를 누르면 while의 조건으로 돌아감
b
break를 누르면 while을 빠져나와 지금 이 문장이 출력됨.
```
- `e` 를 넣으면 `exit를 누르면 프로그램(함수)를 완전히 종료함` 만 나오고 끝 (마지막 echo 안 나옴)

| | 하는 일 |
|---|---|
| `break` | 반복문을 **빠져나감** → done 다음 줄 |
| `continue` | 아래를 건너뛰고 반복문의 **조건으로** 돌아감 |
| `exit 번호` | 프로그램을 **완전히 끝냄** (0 = 정상) |

```bash
exit 0                                          # 정상 종료
```
```output
AAA BBB CCC DDD EEE FFF GGG HHH III JJJ KKK
```
- 🤖 shift 를 쓰는 이유 — 파라미터가 몇 개든 `$1` 하나로 차례차례 꺼낼 수 있음 (파라미터 변수는 `$9` 다음부터 `${10}` 처럼 써야 해서 불편)

### Lab4 · 짝수 · 홀수 ($(( )))
```bash
#!/bin/sh                                    # Lab4.sh
read num                                     # 정수 입력 (예: 2)
if [ $(($num % 2)) -eq 0 ]                   # $(( )) = 산술 계산 → 2 % 2 = 0 (나머지) → 0 이면 짝수
then                                         # 나머지 0
    echo "짝수입니다."                       # 출력
else                                         # 나머지 1
    echo "홀수입니다."                       # 출력
fi                                           # if 끝
exit 0                                       # 정상 종료
```
```output
2
짝수입니다.
```

### Lab5 · 파일 백업 (-f · cp)
```bash
#!/bin/sh                                    # Lab5.sh
read filename                                # 파일 이름 입력 (예: Lab4.sh)
if [ -f "$filename" ]                        # 따옴표 → 이름에 띄어쓰기가 있어도 한 덩어리
then                                         # 있으면
    cp -f "$filename" "$filename.bak"        # Lab4.sh → Lab4.sh.bak 으로 복사 · -f 이미 있으면 덮어씀
else                                         # 없으면
    echo "백업할 파일이 없습니다."           # 출력
fi                                           # if 끝
exit 0                                       # 정상 종료
```
```bash
sh Lab5.sh       # Lab4.sh 입력 → 성공하면 아무것도 출력 안 함
ls -l *.bak      # 백업 파일이 생겼는지 확인
```
