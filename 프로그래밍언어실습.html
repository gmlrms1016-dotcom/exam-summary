2. C 프로그램 실행 과정1주차

C 프로그램은 4단계를 거쳐 실행됩니다. 시험에 자주 나오는 핵심 흐름입니다.

단계내용
① 소스코드 작성C 문법으로 코드 작성 → .c 파일
② 컴파일(Compile)컴파일러가 기계어로 변환 → .obj (또는 .o) 오브젝트 파일
③ 링킹(Linking)여러 오브젝트 파일 + 라이브러리를 연결 → .exe (또는 a.out)
④ 실행(Execution)컴파일된 프로그램을 실행해 결과 확인

첫 프로그램 (hello.c)

// hello.c
#include <stdio.h>          // 표준 입출력 헤더 포함
int main(void) {            // main(): 프로그램 시작 지점
    printf("hello world!"); // 화면 출력
    return 0;               // 프로그램 정상 종료
}
Visual Studio 단축키 — 모두 저장 Ctrl+Shift+S · 빌드 Ctrl+Shift+B · 실행 Ctrl+F5
⚠️ 새 항목 추가 시 파일명에 확장자 .c 를 생략하면 .cpp 로 저장됩니다.

3. 빌드 과정과 생성되는 파일2주차

소스 작성 → 전처리(preprocessor) → 빌드(컴파일+링크) → 실행 순서로 진행됩니다.

파일설명
소스 파일 (*.c)C 문법으로 작성한 원본 파일
목적 파일 (*.obj)컴파일러가 소스를 컴파일하면 생성
실행 파일 (*.exe)하나 이상의 목적 파일을 링커가 연결해 생성
소스 작성  →  전처리  →  빌드(컴파일 + 링크)  →  실행
(hello.c)              (.obj)          (.exe)

5. 함수와 프로그램 구조2주차

암기 — ① C언어는 함수들로 구성된다 ② C언어는 main() 함수로 시작된다(자동 실행) ③ 다른 함수는 호출해야 실행된다

함수는 표준 라이브러리 함수(printf 등)와 사용자 정의 함수로 나뉩니다.

#include <stdio.h>
void func1(void);            // 함수 원형(선언)

int main(void) {
    printf("main() start!!!\n");
    func1();                 // ← 호출해야 실행된다
    printf("main() end!!!\n");
    return 0;
}
void func1(void) {           // 함수 정의
    printf("func1() start!!!\n");
    printf("func1() end!!!\n");
}

7. ★ 시험문제 — sizeof · printf 서식3주차

🎯 시험 포인트 — 강의자료 23p [실습 1-05] sizeof 실행결과 쓰기 · 27p [quiz 1-01] 빈칸채우기(printf 서식) + 오류 수정. 먼저 직접 풀어 보고 💡 정답을 펼쳐 확인하세요.

먼저 암기 — 자료형 크기와 printf 서식

자료형크기 (sizeof)printf 서식비고
char1%c문자 1개 · 'w'
int4%d정수 상수(10)는 int
float4%f3.14f 처럼 f 를 붙인 실수
double8%lf (printf 는 %f 도 가능)실수 상수(3.14159)는 double

문제 ① 실행결과를 쓰시오 — [실습 1-05] ex01_05-sizeof.c강의자료 23p

// ex01_05-sizeof.c
#include <stdio.h>
int main() {
    char gender;
    int age;
    float weight;
    double height;

    printf("변수의 할당크기\n");
    printf("gender: %d, age: %d, weight: %d, height: %d\n\n",
        sizeof(gender), sizeof(age), sizeof(weight), sizeof(height));

    printf("자료형 크기\n");
    printf("char: %d, int: %d, float: %d, double: %d\n\n",
        sizeof(char), sizeof(int), sizeof(float), sizeof(double));

    printf("정수형상수: %d, 실수형상수: %d\n",
        sizeof(10), sizeof(3.14159));
    return 0;
}
💡 정답(실행결과) 보기 
변수의 할당크기
gender: 1, age: 4, weight: 4, height: 8

자료형 크기
char: 1, int: 4, float: 4, double: 8

정수형상수: 4, 실수형상수: 8
풀이 — sizeof 는 크기(바이트 수)를 정수로 돌려주므로 %d 로 출력합니다. 변수의 크기는 자료형 크기와 같고(char 1 · int 4 · float 4 · double 8), sizeof(10)은 정수 상수라 int → 4, sizeof(3.14159)는 실수 상수라 double → 8입니다.
수업 중 “시험문제!” — sizeof(float) 를 %f, sizeof(double) 을 %lf, sizeof(char) 를 %c 로 출력하는 코드가 나오면 틀린 것 → 전부 %d (결과: int 4 · float 4 · double 8 · char 1)

문제 ② 출력결과가 나오도록 프로그램을 작성하시오 — [quiz 1-01] quiz01-01_ex01.c강의자료 27p빈칸채우기

성별: w, 나이: 21, 신장: 165.700000
// quiz01-01_ex01.c
#include <stdio.h>
int main() {
    char gender;
    int age;
    double height;

    gender = 'w';
    age = 21;
    height = 165.7

    printf("  ①  %lf\n", gender, age, height);
    return 0;
}
✏️ 빈칸채우기 — 위 코드를 보고 답을 입력한 뒤 확인을 누르세요. (띄어쓰기·따옴표는 채점에서 무시합니다)

빈칸 ①printf 의 가려진 서식 문자열을 쓰시오.

서식double 변수 height 를 출력하는 서식 지정자는?

오류 수정코드에서 오류가 있는 줄을 찾아 바르게 고쳐 쓰시오.

💡 정답 코드 보기 
// quiz01-01_ex01.c (정답)
#include <stdio.h>
int main() {
    char gender;
    int age;
    double height;

    gender = 'w';
    age = 21;
    height = 165.7;     // 오류 수정: 세미콜론(;) 누락 → 컴파일 오류

    printf("성별: %c, 나이: %d, 신장: %lf\n", gender, age, height);   // 빈칸 ①
    return 0;
}
풀이 — char → %c · int → %d · double → %lf (printf 에서는 %f 도 OK). 실수는 소수점 아래 6자리까지 출력되므로 165.7 → 165.700000. 자료 속 height = 165.7 뒤에 세미콜론이 빠져 있어 그대로 두면 컴파일 오류가 납니다.

2소스 파일(.c)을 컴파일하면 만들어지는 파일은?

3문자열을 출력한 뒤 자동으로 줄바꿈까지 해 주는 함수는?

정답 A — printf() 는 자동 줄바꿈이 없어 \n 을 직접 넣어야 하고, putc() 는 문자 하나를 출력합니다.

4C 언어의 특징이 아닌 것은?

정답 D — C 언어의 3가지 특징은 절차지향 · 간결·효율 · 이식성입니다. 클래스 중심 객체지향은 자바 같은 언어의 특징입니다.

5sizeof(3.14159) 의 결과는? (강의자료 23p)

정답 D — 실수 상수는 기본이 double 이라 8바이트입니다. (sizeof(10) 은 int → 4)

정답 C — 변수 이름은 대·소문자를 구별합니다 — age 와 Age 는 서로 다른 변수 (3주차 강의자료)

7변수의 메모리 주소를 출력하는 printf 서식 지정자는?

정답 C — printf("%p, %d\n", &age, age); 처럼 %p 가 주소를 출력합니다. (3주차 강의자료 · scanf 의 & 와 함께 기억)

8const 상수에 대한 설명으로 옳은 것은?

정답 B — const 는 선언과 동시에 초기화, 재할당 불가. 전처리기가 치환하는 것은 #define 매크로 상수입니다.

9scanf("%d", &age); 에서 & 의 역할은?

정답 B — & 는 주소 연산자 — 변수의 시작 주소를 넘겨야 입력값이 저장됩니다.

10char a1; 에 문자 c 를 올바르게 대입한 것은?

정답 B — 작은따옴표 'c' 는 문자 1개(char), 큰따옴표 "c" 는 문자열이라 char 에 넣을 수 없습니다.
